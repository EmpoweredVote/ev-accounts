## Accomplishments
- `classifyRaceTier({active, stanced, motivated})` implements the D-01 min/ALL rule: a race's tier is capped by its weakest active candidate — T3 only if both stance and motivation reach every active candidate, T2 if exactly one signal reaches ALL, T1 if any candidates are active but neither signal reaches ALL, T0 if no active candidates.
- `weightedDepthScore(tiers: number[])` maps T0→0, T1→⅓, T2→⅔, T3→1, averages across races, scales to 0..100, and rounds to one decimal (matching `raceCoverage`'s existing rounding idiom); returns 0 for an empty array.
- `RaceRow` extended additively with `active_count`, `stanced_count`, `motivated_count`; existing `candidate_count` untouched for the county/breadth path.
- 14 new unit tests covering every tier boundary (T0, T1 name-only, T1 partial-both, T2 stance-only, T2 motivation-only, T3) and every weighted-score case (single-tier fractions, multi-race averaging, empty-array guard).
