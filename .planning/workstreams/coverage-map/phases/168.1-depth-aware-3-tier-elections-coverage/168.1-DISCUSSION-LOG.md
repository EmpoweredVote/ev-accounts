## Race-tier aggregation

| Option | Description | Selected |
|--------|-------------|----------|
| ALL candidates (min) | Race is Tier N only if every candidate reaches it; race tier = weakest candidate. Anti-inflation, consistent with Phase 168. | ✓ |
| ANY candidate | Race reaches Tier N if ≥1 candidate meets it. Overstates. | |
| Per-candidate, no race tier | Report counts of candidates at each tier, not races. Changes the unit. | |

**User's choice:** ALL candidates (min)

### Follow-up: withdrawn candidates

| Option | Description | Selected |
|--------|-------------|----------|
| Exclude withdrawn | Drop `candidate_status='withdrawn'` before aggregating (matches readrankService); active-only denominator, diverges from Phase 168's raw candidate_count. | ✓ |
| Include all candidates | Count every row regardless of status. | |

**User's choice:** Exclude withdrawn

### Follow-up: null-politician candidates

| Option | Description | Selected |
|--------|-------------|----------|
| Count them — cap at Tier 1 | Truthful: no politician record ⇒ no stance/motivation data ⇒ race honestly not fully covered. | ✓ |
| Exclude from stance/motivation check | Name-only challenger satisfies Tier 1 but is skipped for depth gates, so others can lift the race. | |

**User's choice:** Count them — cap at Tier 1

## What colors the map

| Option | Description | Selected |
|--------|-------------|----------|
| Weighted depth score | T0=0, T1=⅓, T2=⅔, T3=1, averaged → 0..100. Names-only = ~33%. Uses all three tiers in the color; slots into the existing single-hue ramp. | ✓ |
| % of races at Tier 3 | Fraction fully covered. Unambiguous but collapses T1 vs T2 on the map. | |
| % at Tier 2 or better | Names-only = 0%. Collapses T2 vs T3 on the map. | |

**User's choice:** Weighted depth score

## Signal thresholds + reuse

### Stance bar

| Option | Description | Selected |
|--------|-------------|----------|
| ≥1 answer, reuse completeness signal | `has stances` = ≥1 `inform.politician_answers` row (avoids `last_stances_researched_at` landmine); `has motivations` = ≥1 contribution. Same definition as the 7-axis map. | ✓ |
| Fuller stance bar (threshold) | Require a majority of topics. Diverges from completeness; needs a topic-count denominator. | |

**User's choice:** ≥1 answer, reuse completeness signal

### Empty race (Tier 0)

| Option | Description | Selected |
|--------|-------------|----------|
| Tier 0 / uncovered, contributes 0 | No active candidates ⇒ below Tier 1, contributes 0 to the weighted score. Scale T0=0, T1=⅓, T2=⅔, T3=1. | ✓ |
| Fold into Tier 1 | Treat 'no candidates' and 'names only' as the same bottom tier. | |

**User's choice:** Tier 0 / uncovered, contributes 0
