<objective>
Create the standalone shared FEC rate limiter module `fecRateLimiter.ts` exposing `acquireFecSlot()` — a per-minute fixed-window counter backed by Upstash Redis (`.incr`/`.expire`) with a graceful in-process `Map` fallback. This is the single gate every outbound FEC HTTP request will pass through (wired into the three call sites by Plans 02 and 03), guaranteeing the aggregate request rate stays under the ~1,000 req/hr api.data.gov key ceiling regardless of source count (FEC-03).

Purpose: The shipped per-request backoff (`d505c9ad`) recovers individual 429s but does not *pace the batch*; a ~1k-source 6-hourly run collectively overshoots the ceiling. A shared limiter caps aggregate throughput.
Output: One new module + its unit test. No changes to existing files (integration happens in later plans).
</objective>
