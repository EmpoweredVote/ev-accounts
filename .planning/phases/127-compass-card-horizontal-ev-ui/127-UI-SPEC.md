## Spacing Scale

Declared values sourced from `ev-ui/src/tokens.js` `spacing` export (4px base unit):

| Token | Value | Usage in this component |
|-------|-------|------------------------|
| xs | 4px | Icon-strip gap between affordance icons |
| sm | 8px | Vertical gap between name, title, subtitle within meta column |
| md | 16px | Card internal padding; horizontal gap between radar slot and meta column |
| lg | 24px | Card gap within page grid |
| xl | 32px | Page-level horizontal padding |
| 2xl | 48px | Empty and error state vertical padding |
| 3xl | 64px | Bottom page padding |

**Exceptions:**
- Radar wrapper: fixed at 260px wide (250px radar + 10px label bleed) — not a spacing token, a dimensional constraint inherited from variant C
- Touch target minimum: 44px height enforced on the card itself via `minHeight: '44px'` (matches existing `CompassFirstCard` convention)
- Affordance icon hit area: `padding: '4px'` (xs token) around each icon. The 44px card `minHeight` guarantees touch-target safety independently, so 4px padding is sufficient. Source `IconOverlay.jsx` uses 5px — ev-ui implementation uses 4px (xs token) to conform to the 4px scale.

**Source:** `ev-ui/src/tokens.js` spacing export; `essentials/src/components/CompassFirstCard.jsx` VARIANT_CONFIG.C

## Typography

All type is Manrope. Weights are sourced from `ev-ui/src/tokens.js` `fontWeights`.

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Name | 18px (`fontSizes.lg`) | 600 semibold | 1.4 | Politician full name — meta column heading |
| Label | 14px (`fontSizes.sm`) | 600 semibold | 1.4 | Office title (representatives surface) or "Position running for" (elections surface) |
| Caption | 14px (`fontSizes.sm`) | 400 regular | 1.5 | District/ward subtitle below title |
| Micro | 12px (`fontSizes.xs`) | 400 regular | 1.4 | "Running unopposed" banner text; tooltip copy |

**Declared weights: 400 (Caption + Micro) and 600 (Name + Label). Maximum 2 weights.**

"Running unopposed" banner text remains visually distinct from Caption via its 12px size, accent color `#00657C`, and banded background context — a third weight is not needed.

**Constraints:**
- Office title is clamped at 2 lines (`WebkitLineClamp: 2`) — overflow is truncated, not scrolled
- District subtitle is single-line with `textOverflow: 'ellipsis'` and `whiteSpace: 'nowrap'`
- Radar labels: 12px, weight 400, rendered by RadarChartCore internally — do not override

**Source:** `ev-ui/src/tokens.js` textStyles; `essentials/src/components/CompassFirstCard.jsx` VARIANT_CONFIG.C; `ev-ui/src/PoliticianCard.jsx`

## Layout & Dimensions

### Card Structure (Horizontal)
```
┌──────────────────────────────────────────────────────┐
│  [Radar 260px wide]  │  [Meta column — flex: 1]      │
│                      │  Name (18px/600)               │
│   RadarChartCore     │  Office title (14px/600, 2ln) │
│   size=250           │  District subtitle (14px/400) │
│   OR                 │  [Icon strip: ballot/branch]  │
│   Portrait photo     │                               │
│   (same 260px dims)  │  [Elections only]             │
│                      │  "Running unopposed" banner   │
└──────────────────────────────────────────────────────┘
```

**Primary visual anchor:** left radar/portrait slot (260px, dominant by width). Secondary anchor: politician name in accent color `#00657C`.

- **Direction:** `flexDirection: 'row'`, `alignItems: 'center'`
- **Radar slot width:** 260px fixed, `flexShrink: 0`, overflow hidden
- **Meta column:** `flex: 1`, `minWidth: 0`, `flexDirection: 'column'`, `gap: 4px`
- **Card padding:** 16px on all sides
- **Card gap (radar ↔ meta):** 16px
- **Card border-radius:** 12px (`borderRadius.xl`)
- **Card shadow (resting):** `shadows.md` = `0 4px 6px -1px rgba(0,0,0,0.1)`
- **Card shadow (hovered):** `shadows.cardHover` = `0 12px 32px -4px rgba(0,0,0,0.12), 0 4px 8px -2px rgba(0,0,0,0.04)`
- **Card shadow (focused):** `focus.ring` = `0 0 0 2px #FFFFFF, 0 0 0 4px #00657C`
- **Shadow transition:** `200ms ease` (matches `duration.normal`)
- **Card background:** `#FFFFFF` (`colors.bgWhite`)

### Portrait View (view='portrait')
The radar slot is replaced by a politician portrait image at **identical dimensions (260px wide)**. Grid uniformity is preserved — the card does not shrink or reflow.

- Photo: `objectFit: 'cover'`, `objectPosition: imageFocalPoint ?? 'center 20%'`
- Fallback when no photo or broken image: initials circle, background `colors.evMutedBlue` (`#00657C`), white text, `borderRadius.full`
- Initials extraction: first letter of first and last name, uppercase

### Grid Layout (page wrapper — reference for harness)
- `grid-cols-1 md:grid-cols-2` (matches VARIANT_CONFIG.C `gridCols`)
- Gap: 16px between cards

**Source:** `essentials/src/components/CompassFirstCard.jsx` VARIANT_CONFIG.C; D-10; `ev-ui/src/tokens.js` shadows, borderRadius, focus, duration

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#F0F8FA` (`colors.bgLight`) | Page background behind cards |
| Secondary (30%) | `#FFFFFF` (`colors.bgWhite`) | Card surface background |
| Accent (10%) | `#00657C` (`colors.evMutedBlue`) | Reserved for specific elements listed below |
| Error/destructive | `#EF4444` (`colors.error`) | Error state text only (no destructive actions on card) |

**Accent (`#00657C`) is reserved for:**
1. Politician name text color
2. Affordance icon color (BallotIcon, CompassIcon, BranchIcon)
3. Card focus ring (outer ring — `0 0 0 4px #00657C`)
4. Initials circle placeholder background
5. "Running unopposed" banner left border accent

**Color constraints:**
- No party colors. No partisan color associations. Antipartisan principle enforced. (Source: user memory `feedback_antipartisan.md`)
- `ev-coral` (`#FF5740`) is NOT used on this card — it is the Empower pillar color and does not map to a card affordance in this phase
- `ev-yellow` (`#FED12E`) is NOT used on this card
- Office title text: `#4a5568` (`colors.textSecondary`)
- District subtitle text: `#718096` (`colors.textMuted`)
- Card border: `1px solid #E2EBEF` (`colors.borderLight`) — always present at resting state, supplements shadow
- "Running unopposed" banner background: `colors.infoLight` (`#F5F9FA`), border-left `3px solid colors.evMutedBlue`

**Source:** CLAUDE.md §Design System; `ev-ui/src/tokens.js` colors; `ev-ui/src/PoliticianCard.jsx`; D-12; antipartisan principle

## Component API Contract

This section is load-bearing for the executor. It defines the exact prop surface.

### Props

```jsx
<CompassCardHorizontal
  politician={politicianObject}   // required
  userAnswers={answersArray}       // optional — null triggers PlaceholderRadar
  tierVisuals={tierVisualsObject}  // optional — defaults to no tier accent
  view="compass"                   // required: 'compass' | 'portrait'
  surface="representatives"        // required: 'representatives' | 'elections'
  onClick={fn}                     // optional — enables navigation on click
/>
```

**`politician` shape** (minimum fields; mirrors existing PoliticianCard + essentials data model):
```js
{
  id: string,
  full_name: string,
  office_title: string,           // label for meta column
  district_type: string,          // e.g. 'LOCAL', 'NATIONAL_UPPER'
  district_label: string | null,  // e.g. 'Ward 4', 'District 9'
  branch: string | null,          // 'Executive' | 'Legislative' | 'Judicial' | null
  ballot: {                       // null if not on user ballot
    onBallot: boolean,
    termEndDate: Date,
    electionDate: Date,
    electionLabel: string,
  } | null,
  hasStances: boolean,
  images: Array<{ url, type, focal_point }> | null,
  photo_origin_url: string | null,
  // Elections surface only:
  office_running_for: string | null,
  running_unopposed: boolean,
}
```

**`tierVisuals` shape** (from `ev-ui/src/tokens.js` `tierColors`):
```js
{
  bg: string,     // card background tint (federal=white, state=#F7FBFC, local=#EDF6F8)
  accent: string, // not used on card face — reserved for future tier band
  text: string,   // not used on card face in this phase
}
```

**`userAnswers`**: array of answer objects from CompassContext — passed raw to internal `buildAnswerMapByShortTitle` logic (same shape as existing `essentials` CompassContext `userAnswers`).

## Interaction Contract

### View prop (Controlled)
- Card is fully controlled via `view` prop. No internal toggle button.
- `view='compass'` → RadarChartCore renders in left slot (or PlaceholderRadar if `userAnswers` is null/empty)
- `view='portrait'` → Portrait photo renders in left slot at same 260px dimensions
- Transition: none (instant swap) — no animation on view change within card; the page-level SegmentedControl is the animated trigger

### Hover
- Box shadow upgrades from `shadows.md` to `shadows.cardHover`
- Transform: `translateY(-2px)` — 2px lift
- Transition: `200ms ease` (`duration.normal`)

### Focus
- Outline: none (suppressed default)
- Box shadow: `focus.ring` = `0 0 0 2px #FFFFFF, 0 0 0 4px #00657C`
- `tabIndex={0}` on card root div
- `role="article"`, `aria-label="{full_name}, {office_title}"`

### Keyboard
- `Enter` or `Space` on focused card triggers `onClick` (navigate to profile)

### Click
- Full card area is clickable
- Icon strip icons (BallotIcon, BranchIcon) do not block card navigation
- CompassIcon in icon strip, if present, calls `onCompassClick` and stops propagation

**Source:** `essentials/src/components/CompassFirstCard.jsx` event handlers; `ev-ui/src/tokens.js` focus, duration, shadows

## Surface Variants

### `surface='representatives'` — meta column content
1. **Name** — `politician.full_name`
2. **Office title** — `politician.office_title` (2-line clamp)
3. **District subtitle** — `politician.district_label` (single line, ellipsis)
4. **Icon strip** — BallotIcon (if `ballot`), CompassIcon (if `hasStances`), BranchIcon (if `branch`)

### `surface='elections'` — meta column content
1. **Name** — `politician.full_name`
2. **Position running for** — `politician.office_running_for` (2-line clamp)
3. **District subtitle** — `politician.district_label` (single line, ellipsis)
4. **Icon strip** — same as representatives
5. **"Running unopposed" banner** — shown only when `politician.running_unopposed === true`
   - Background: `colors.infoLight` (`#F5F9FA`)
   - Left border: `3px solid #00657C`
   - Border-radius: `borderRadius.md` (8px)
   - Padding: `4px 8px`
   - Text: "Running unopposed" — 12px, weight 400, color `#00657C`

## Accessibility Requirements

- Card root: `role="article"`, `tabIndex={0}`, `aria-label="{full_name}, {office_title}"`
- All affordance icons: accessible via `aria-label` on wrapper span (from `IconOverlay` pattern), `tabIndex={0}`
- Tooltips: `role="tooltip"` via `@floating-ui/react` `useRole` (existing pattern in `essentials/src/components/IconOverlay.jsx`)
- PlaceholderRadar: `role="img"`, `aria-label` set to name-aware string
- Focus ring: `0 0 0 2px #FFFFFF, 0 0 0 4px #00657C` — 6.66:1 contrast on white bg (WCAG AA)
- Name text `#00657C` on white: 6.66:1 — AA
- Office title `#4a5568` on white: ~6.0:1 — AA
- District subtitle `#718096` on white: ~4.6:1 — AA border (note: use sparingly; bump to `textSecondary` if AA fails in specific context)
- "Running unopposed" text `#00657C` on `#F5F9FA`: 6.66:1 — AA

**Source:** `ev-ui/src/tokens.js` WCAG notes; `essentials/src/components/IconOverlay.jsx`; WCAG 2.1 AA minimum 4.5:1 for normal text
