// Remove duplicate (geo_id, mtfcc) rows, keeping the most recently imported one.
// Required before CREATE UNIQUE INDEX if import scripts ran without the constraint.
if err := db.DB.Exec(`
    DELETE FROM essentials.geofence_boundaries
    WHERE id NOT IN (
        SELECT DISTINCT ON (geo_id, mtfcc) id
        FROM essentials.geofence_boundaries
        ORDER BY geo_id, mtfcc, id DESC

**Critical detail:** Use `id DESC` for ordering (not `imported_at DESC`) because `imported_at` may be NULL for some rows. The dedup uses `log.Printf` (warning, not fatal) because the table may not exist on a fresh database — the dedup is only meaningful when rows already exist.

**Change 1 — ST_Contains to ST_Covers (SCHEMA-02):**

On line 40, replace `ST_Contains` with `ST_Covers` in the `FindGeoIDsByPoint` query. Do NOT change the argument order — it stays as `ST_Covers(geometry, ST_SetSRID(ST_MakePoint($1, $2), 4326))`.

Before:
```go

```

**Why:** ST_Contains returns FALSE for points that lie exactly on the boundary of a polygon. ST_Covers returns TRUE. Both have identical argument order — `ST_Covers(A, B)` means "A covers B" just as `ST_Contains(A, B)` means "A contains B". Street addresses on district boundary lines are valid residents and must match.

**Change 2 — Expand mtfccToDistrictTypes map (SCHEMA-03):**
