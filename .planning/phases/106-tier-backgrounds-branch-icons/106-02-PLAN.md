**3. Results.jsx — Edge-to-edge tier background bands:**

Per D-04: tier backgrounds extend edge-to-edge (full viewport width) while cards stay within the content container. Per D-05: hard breaks between tier sections. Per D-06: minimal vertical padding.

The current structure has a results container `<div className="px-4 md:px-8 pt-6 pb-8">` with tier `<div data-tier="...">` children. To achieve edge-to-edge backgrounds, each tier div needs to:
1. Break out of the container padding using negative margins
2. Re-apply the padding internally to keep cards centered
3. Apply the tier background color

**Step 3a:** Add `import { tierColors } from '@chrisandrewsedu/ev-ui'` at the top of Results.jsx (alongside existing ev-ui imports).

**Step 3b:** Create a helper object for tier background styles near the top of the component (inside the component function, before the return):
```javascript
const tierBandStyle = (tier) => ({

  paddingTop: '1rem',

const tierBandStyleMd = (tier) => ({

```

However, since the container uses `px-4 md:px-8` (Tailwind), the negative margin values need to match: `-1rem` for mobile (`px-4` = 1rem) and `-2rem` for md+ (`px-8` = 2rem). Since inline styles can't do media queries, use a CSS class approach instead.

**Better approach — use Tailwind classes on tier wrappers:**

On each `<div data-tier="...">` wrapper, add classes for edge-to-edge:
```
className="-mx-4 md:-mx-8 px-4 md:px-8 py-3"
```
And add inline style for the background color:
```
style={{ backgroundColor: tierColors[tierKey].bg }}
```

Where `tierKey` is `'federal'`, `'state'`, or `'local'` (lowercase, matching the tierColors keys).

Apply to all three tier divs:

**Federal div** (currently `<div data-tier="Federal">`):
