Add the following exports to `backend/src/lib/roleService.ts`:

1. **`UserRoleGrant` type** — exported interface matching the return shape of `getUserRoles`:
   ```
   { role_id: string; slug: string; name: string; granted_at: string; feature_scope: string; jurisdiction_geoid: string | null; resource_id: string | null }
   ```

2. **`CheckRoleScope` type** — `{ geoid?: string; resourceId?: string }`

3. **`checkRole(grants: UserRoleGrant[], roleSlug: string | string[], scope?: CheckRoleScope): boolean`**
   - If `roleSlug` is an array, OR logic: return true if ANY slug matches
   - For each grant, match logic:
     - `grant.slug !== slug` → skip
     - If `scope?.geoid !== undefined`: `grant.jurisdiction_geoid !== null && grant.jurisdiction_geoid !== scope.geoid` → skip (NULL grant geoid = unrestricted, passes any check)
     - If `scope?.resourceId !== undefined`: `grant.resource_id !== null && grant.resource_id !== scope.resourceId` → skip (NULL grant resourceId = unrestricted, passes any check)
     - Otherwise → return true
   - No match found → return false
   - CRITICAL: The NULL-safe logic must check `grant.jurisdiction_geoid !== null` BEFORE comparing to `scope.geoid`. A NULL grant value means unrestricted — it passes any scope check.

4. **`getCachedUserRoles(userId: string): Promise<UserRoleGrant[]>`**
   - Import `cache` from `./cache.js`
   - Cache key: `roles:uid:${userId}`
   - Try cache.get first. On hit, return cached value.
   - On miss: call existing `getUserRoles(userId)`, then `cache.set(key, grants, 90)` (90s TTL), return grants.
   - Wrap ALL cache operations in try/catch — on Redis failure, log `[roleService] cache error:` and fall through to DB. Redis is optimization, not hard dependency.

5. **`invalidateRoleCache(userId: string): Promise<void>`**
   - `cache.del(`roles:uid:${userId}`)` wrapped in try/catch (log + swallow on failure)

Keep all existing exports (`grantRole`, `revokeRole`, `getUserRoles`, `getAllActiveRoles`) unchanged. The new functions are additive.

  <name>Task 2: Create requireRole middleware factory</name>

  <action>
Create `backend/src/middleware/requireRole.ts`:

```typescript
import type { Request, Response, NextFunction } from 'express';
import type { AuthenticatedRequest } from './auth.js';
import { getCachedUserRoles, checkRole } from '../lib/roleService.js';
```

**`requireRole` function signature:**
```
export function requireRole(
  roleSlug: string | string[],
  opts?: {
    geoid?: string | ((req: Request) => string | undefined);
    resourceId?: string | ((req: Request) => string | undefined);
  }
): (req: Request, res: Response, next: NextFunction) => Promise<void>
```

**Implementation:**
- Returns an async Express middleware function
- Check `(req as AuthenticatedRequest).userId` — if falsy, return `res.status(401).json({ error: 'unauthorized' })`. This makes requireRole safe to use without stacking requireAuth first.
- Resolve `geoid`: if `opts?.geoid` is a function, call it with `req`; if string, use directly; if undefined, leave undefined
- Resolve `resourceId`: same pattern as geoid
- Build scope object: `{ geoid: resolvedGeoid, resourceId: resolvedResourceId }` — only include defined values
- Call `getCachedUserRoles(userId)` to get grants
- Call `checkRole(grants, roleSlug, scope)` — if false, return `res.status(403).json({ error: 'forbidden' })`
- If true, call `next()`
- Wrap entire body in try/catch — on unexpected error, log `[requireRole] error:` and return 500

**Architecture constraint:** This file must NOT import `supabaseAdmin`. The architecture test scans `src/routes/` but this middleware file is safe — however, it's still correct practice to delegate to roleService rather than querying directly.

**Error bodies are intentionally opaque:** `{ error: 'unauthorized' }` and `{ error: 'forbidden' }` — no role name, no scope info leaked.
  </action>
