
Add route AFTER the existing `/me` route:

```
POST /check
```
- Middleware: `requireAuth`
- Body: `{ feature_scope: string, jurisdiction_geoid?: string, resource_id?: string }`
- Validate: `feature_scope` must be a non-empty string. If missing/empty, return `res.status(400).json({ error: 'feature_scope is required' })`
- Get `authReq.userId`, call `getCachedUserRoles(userId)`
- Build scope: `{ geoid: body.jurisdiction_geoid, resourceId: body.resource_id }` — only include defined values
- Call `checkRole(grants, body.feature_scope, scope)` — `feature_scope` in the body IS the role slug (per CONTEXT.md: "feature_scope in POST /api/roles/check body = role slug")
- Return `res.status(200).json({ permitted: result })`
- Error: `res.status(500).json({ error: 'Failed to check role' })`

Note: CORS is already handled globally in index.ts with `*.empowered.vote` origins. No per-route CORS config needed.
