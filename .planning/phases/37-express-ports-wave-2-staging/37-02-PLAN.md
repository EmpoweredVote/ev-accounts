**Shared helper — getDisplayName:**
```typescript
async function getDisplayName(userId: string): Promise<string> {
  const { rows } = await pool.query<{ display_name: string | null }>(
    `SELECT display_name FROM public.users WHERE id = $1`, [userId]
  );
  return rows[0]?.display_name ?? userId; // fallback to userId string
}
```

**Shared helper — assertPending:**
```typescript
function assertPending(status: string): void {
  if (status !== 'pending') {
    const err = new Error(`Cannot modify a record with status '${status}'`) as any;
    err.httpStatus = 422;
    throw err;
  }
}
```

**5. `reviewPolitician(id: string, action: 'approve' | 'reject', userId: string, comment?: string): Promise<StagingPolitician>`**
   - Fetch record. `assertPending(record.status)`.
   - Get `reviewerName = await getDisplayName(userId)`.
   - If action === 'approve':
     - Auto-promote to `essentials.politicians` (see promotion logic below)
     - UPDATE staging.politicians SET status = 'approved', reviewed_by = $reviewerName, review_count = review_count + 1, last_reviewed_at = NOW(), approved_at = NOW(), updated_at = NOW() WHERE id = $id RETURNING *
   - If action === 'reject':
     - UPDATE staging.politicians SET status = 'rejected', reviewed_by = $reviewerName, review_count = review_count + 1, last_reviewed_at = NOW(), updated_at = NOW() WHERE id = $id RETURNING *
   - INSERT into staging.politician_review_logs (politician_id, reviewer_name, action, comment)
   - Return mapped result.

   **Auto-promotion logic (politician -> essentials.politicians):**
   Column mapping from research:
   - full_name -> full_name
   - party -> party
   - bio_text -> bio_text
   - photo_url -> photo_origin_url
   - is_appointed -> is_appointed (default false)
   - is_vacant -> is_vacant (default false)
   - valid_from -> valid_from
   - valid_to -> valid_to
   - total_years_in_office -> total_years_in_office
   - Set: is_active = true, is_incumbent = true
   - external_id: try `Number(staging.external_id)` — if NaN or null, set to NULL in essentials (essentials.external_id is bigint)
   - Upsert strategy: If external_id is non-null and numeric, do `INSERT ... ON CONFLICT (external_id) DO UPDATE`. Otherwise plain INSERT (new politician).

**6. `lockPolitician(id: string, userId: string): Promise<{ locked: boolean; lockedBy?: string; lockedAt?: string }>`**
   - Atomic acquire: `UPDATE staging.politicians SET locked_by = $1, locked_at = NOW() WHERE id = $2 AND locked_by IS NULL RETURNING id`
   - If rows returned: return `{ locked: true }`
   - If no rows: fetch current record to get locked_by/locked_at. Return 409-shaped response: `{ locked: false, lockedBy, lockedAt }`

**7. `unlockPolitician(id: string): Promise<void>`**
   - `UPDATE staging.politicians SET locked_by = NULL, locked_at = NULL WHERE id = $1`
   - Any staging_reviewer or admin can unlock any lock (per CONTEXT.md decision).

**8. `mergePolitician(sourceId: string, targetId: string, userId: string): Promise<StagingPolitician>`**
   - Fetch source record. `assertPending(source.status)`.
   - Verify target exists (fetch target by targetId). Throw 404 if not found.
   - UPDATE staging.politicians SET merged_to_id = $targetId, status = 'rejected', reviewed_by = reviewerName, updated_at = NOW() WHERE id = $sourceId RETURNING *
   - INSERT review log with action = 'merged' and comment = `Merged into ${targetId}`
   - Return mapped source result.
