Create `backend/src/routes/staging.ts` following the pattern from treasury.ts and meetings.ts.

**Router-level middleware:**
```typescript
import { Router } from 'express';
import { requireAuth } from '../middleware/auth.js';
import { requireStagingReviewer } from '../middleware/requireStagingReviewer.js';
import type { AuthenticatedRequest } from '../middleware/auth.js';
import * as staging from '../lib/stagingService.js';

const router = Router();
const UUID_REGEX = /^[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}$/i;

// ALL staging routes require auth + staging_reviewer/admin role
router.use(requireAuth as any, requireStagingReviewer as any);
```

**Route ordering rule:** Subpath routes (/:id/review, /:id/lock, /:id/merge) BEFORE /:id to prevent Express treating "review" as a UUID param.

**Shared validation helpers:**
- `validateUuid(id: string, res: Response): boolean` — test UUID_REGEX, return 400 if invalid
- Use Zod for request body validation on POST/PATCH routes (import z from 'zod')

**Politician routes (8):**

1. `GET /politicians` — query param `?status=pending|approved|rejected`, call staging.getPoliticians({ status }), return array
2. `GET /politicians/:id` — validate UUID, call staging.getPoliticianById, return 404 if null
3. `POST /politicians` — Zod schema: fullName required string min 1. Optional: party, office, officeLevel, state, district, bioText, photoUrl, externalId, contacts, degrees, experiences, urls, images, addresses, validFrom, validTo, totalYearsInOffice, isAppointed, isVacant. Call staging.createPolitician(data, authReq.userId). Return 201.
4. `PATCH /politicians/:id` — validate UUID, Zod partial schema, call staging.updatePolitician. Catch httpStatus errors and return appropriate status.
5. `POST /politicians/:id/review` — validate UUID. Zod: action ('approve' | 'reject'), optional comment (string). Call staging.reviewPolitician(id, action, userId, comment). Catch httpStatus 422.
6. `POST /politicians/:id/lock` — validate UUID. Call staging.lockPolitician(id, userId). If locked: true, return 200. If locked: false, return 409 with lockedBy/lockedAt.
7. `DELETE /politicians/:id/lock` — validate UUID. Call staging.unlockPolitician(id). Return 204.
8. `POST /politicians/:id/merge` — validate UUID. Zod: targetId (required UUID string). Call staging.mergePolitician(id, targetId, userId). Catch httpStatus errors.

**Stance routes (7):**

9. `GET /stances` — query param ?status=, call staging.getStances
10. `GET /stances/:id` — validate UUID, call staging.getStanceById
11. `POST /stances` — Zod: contextKey required, politicianName required, topicKey required, value required (number). Optional: politicianExternalId, topicId, reasoning, sources (array of strings). Call staging.createStance(data, userId). Return 201.
12. `PATCH /stances/:id` — validate UUID, Zod partial, call staging.updateStance
13. `POST /stances/:id/review` — Zod: action ('approve' | 'reject'), optional comment, optional newValue (number — reviewer correction). Call staging.reviewStance(id, action, userId, comment, newValue). Catch 422.
14. `POST /stances/:id/lock` — same pattern as politician lock
15. `DELETE /stances/:id/lock` — same pattern as politician unlock, return 204

**Photo routes (4):**

16. `GET /photos` — query param ?status=, call staging.getPhotos
17. `GET /photos/:id` — validate UUID, call staging.getPhotoById
18. `POST /photos` — Zod: placeGeoid required, placeName required, url required, license required, attribution required. Optional: state, sourceUrl. Call staging.createPhoto(data, userId). Return 201.
19. `POST /photos/:id/review` — Zod: action ('approve' | 'reject'), optional comment. Call staging.reviewPhoto. Catch 422.

**NO lock/unlock routes for photos** (no locked_by/locked_at columns on staging.building_photos).

**Error handling pattern (same as treasury/meetings):**
```typescript
try {
  // ... service call
} catch (err: any) {
  if (err.httpStatus) {
    res.status(err.httpStatus).json({ error: err.message });
    return;
  }
  console.error('[staging] ...', err);
  res.status(500).json({ error: 'Internal server error' });
}
```
