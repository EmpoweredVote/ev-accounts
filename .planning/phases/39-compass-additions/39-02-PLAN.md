**1. compareWithPoliticians(userId: string, politicianIds: string[]): Promise<CompareResult[]>**

```typescript
interface CompareTopic {
  topic_id: string;
  user_value: number;
  politician_value: number;
}

interface CompareResult {
  id: string;
  name: string | null;
  alignment_score: number;
  topics: CompareTopic[];
}
```

Implementation:
- Fetch user's non-deleted compass_responses via pool.query: `SELECT topic_id, value FROM inform.compass_responses WHERE user_id = $1 AND deleted_at IS NULL`
- Build a Map<topic_id, number> from user answers
- Fetch all politician answers in parallel via Promise.all: for each politician_id, `SELECT pa.topic_id, pa.value::text, ep.full_name FROM inform.politician_answers pa JOIN essentials.politicians ep ON ep.id = pa.politician_id WHERE pa.politician_id = $1`
- For each politician, filter to only topics present in BOTH the user Map and the politician's answers (intersection)
- Score: `1 - (|user_value - politician_value| / 5)` per shared topic, averaged, * 100, Math.round
- If no shared topics, alignment_score = 0
- Return array of CompareResult

**2. getUserVerdicts(userId: string, politicianId?: string): Promise<Verdict[]>**

```typescript
interface Verdict {
  quote_id: string;
  supported: boolean;
  rank: number | null;
  session_size: number;
  created_at: string;
  updated_at: string;
}
```

Implementation:
- If no politicianId filter: `SELECT quote_id, supported, rank, session_size, created_at, updated_at FROM inform.compass_verdicts WHERE user_id = $1 ORDER BY updated_at DESC`
- If politicianId filter: JOIN to essentials.quotes to filter by politician. First, inspect the essentials.quotes table schema to find the politician FK column name. The query pattern: `SELECT cv.quote_id, cv.supported, cv.rank, cv.session_size, cv.created_at, cv.updated_at FROM inform.compass_verdicts cv JOIN essentials.quotes q ON q.id = cv.quote_id WHERE cv.user_id = $1 AND q.politician_id = $2 ORDER BY cv.updated_at DESC`
- IMPORTANT: Before implementing the politician_id filter JOIN, run a discovery query against the essentials.quotes table to confirm the column name. Use pool.query: `SELECT column_name FROM information_schema.columns WHERE table_schema='essentials' AND table_name='quotes'`. If the column is not `politician_id`, adjust the JOIN accordingly. If the quotes table has no politician FK column, skip the filter and document the gap.
- All via pool.query() — essentials schema is NOT in PostgREST exposed list.

Add four new route handlers to `backend/src/routes/compass.ts`. Place them BEFORE the existing `/politicians/:id/answers` route to prevent Express path capture issues.

**Route ordering is critical.** The new routes must be added in this specific position within compass.ts:
- `/politicians/:id/answers/batch` BEFORE `/politicians/:id/answers` (existing GET)
- `/compare` and `/verdicts` can go anywhere before the politician param routes

Add these Zod schemas near the existing validation schemas:

```typescript
const compareSchema = z.object({
  politician_ids: z.array(z.string().uuid()).min(1).max(50),
});

const batchPoliticianAnswersSchema = z.object({
  topic_ids: z.array(z.string().uuid()).min(1).max(100),
});

const postVerdictsSchema = z.object({
  verdicts: z.array(z.object({
    quote_id: z.string().uuid(),
    supported: z.boolean(),
    rank: z.number().int().min(1).nullable(),
    session_size: z.number().int().min(1),
  })).min(1).max(200),
});
```

**1. POST /api/compass/compare** (requireAuth):
- Parse body with compareSchema
- Call `compareWithPoliticians(authReq.userId, parsed.data.politician_ids)`
- Return `{ politicians: result }`
- 422 on validation error, 500 on unexpected error

**2. GET /api/compass/verdicts** (requireAuth):
- Optional query param `?politician_id=<uuid>` — validate UUID format if present
- Call `getUserVerdicts(authReq.userId, politicianId)`
- Return array of verdicts
- 422 if politician_id present but invalid UUID, 500 on error

**3. POST /api/compass/verdicts** (requireAuth):
- Parse body with postVerdictsSchema
- Call `adminRpc('upsert_compass_verdicts', { p_user_id: authReq.userId, p_verdicts: JSON.stringify(parsed.data.verdicts) })`
- Note: adminRpc serializes JSONB params — pass the verdicts array as JSON string
- Return `{ upserted: parsed.data.verdicts.length }`
- 422 on validation error, 500 on unexpected error

**4. POST /api/compass/politicians/:id/answers/batch** (optionalAuth):
- If !authReq.userId, return 200 []
- Validate :id as UUID
- Parse body with batchPoliticianAnswersSchema
- Call `getBatchPoliticianAnswers(politicianId, parsed.data.topic_ids)`
- Return array of answers
- 422 on validation error, 500 on unexpected error
