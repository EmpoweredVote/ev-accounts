func ImportGatewayBudgets(configFile string, dryRun bool) (ImportBudgetsResult, error)

**Function logic (in order):**

1. **Load config:** Read `configFile` with `os.ReadFile`, unmarshal into `GatewayConfig`. Default configFile to `"treasury-import-config.json"` if empty.

2. **Create HTTP client:** `&http.Client{Timeout: 60 * time.Second}` (government sites can be slow).

3. **Iterate entities:** For each `GatewayEntityConfig` in `config.GatewayEntities`:

4. **Iterate dataset types:** For each `datasetType` in entity's `DatasetTypes` (per D-09: includes both "operating" and "revenue"):

5. **Iterate fiscal years:** For each `year` in entity's `FiscalYears` (per D-10: 2021-2025):

6. **Fetch CSV from Gateway:** Construct the download URL/request for the Indiana Gateway.

   CRITICAL: The Gateway uses ASP.NET WebForms with POST-based downloads. The executor MUST investigate the actual download mechanism by:
   - Opening https://gateway.ifionline.org/public/download.aspx in a browser
   - Selecting a unit (e.g., Ellettsville), year, and dataset type
   - Capturing the POST request in DevTools Network tab
   - Noting the required form fields (ViewState, EventTarget, unit selection, year, dataset type)

   If the Gateway provides direct download URLs (unlikely but possible), use GET. Otherwise, construct the POST request with the captured form fields. The `unit_code` from config maps to the Gateway's unit selection parameter.

   Set `User-Agent: EmpoweredVote-Treasury-Importer/1.0` header.

   After receiving response, check:
   - `resp.StatusCode == 200`
   - Content-Type is NOT `text/html` (if it is, the download failed and returned the form page — log error and skip)

7. **Parse CSV:**
   - Create reader with `newGatewayCSVReader(resp.Body, rune(entity.Delimiter[0]))`
   - Read first row as headers
   - Call `validateHeaders(headers, append(entity.HierarchyColumns, entity.AmountColumn))` — fail fast per D-03 if columns missing
   - Build column index map from headers

8. **Build hierarchy tree from flat CSV rows (per D-05):**

   Create a map-based accumulator:
   ```go
   type fundAccum struct {
       name     string
       amount   float64
       depts    map[string]*deptAccum
   }
   type deptAccum struct {
       name   string
       amount float64
       items  []lineAccum
   }
   type lineAccum struct {
       description string
       amount      float64
   }
   ```

   For each CSV data row:
   - Extract fund name from `row[headerIdx[entity.HierarchyColumns[0]]]`
   - Extract dept name from `row[headerIdx[entity.HierarchyColumns[1]]]`
   - Extract line description from `row[headerIdx[entity.HierarchyColumns[2]]]`
   - Extract amount using `parseAmount(row[headerIdx[entity.AmountColumn]])`
   - Accumulate into the fund -> dept -> line item tree
   - Track total budget as sum of all row amounts
   - Count total rows and zero-amount rows; if zero-amount rows > 5% of total, log a warning (encoding misparse indicator)

9. **Convert accumulated tree to `[]CategoryImport`:**

   For each fund in the accumulator (sorted alphabetically):
   - Create a root `CategoryImport` with `Name = fundName`, `Amount = fund.amount`
   - For each dept under that fund (sorted alphabetically):
     - Create a child `CategoryImport` with `Name = deptName`, `Amount = dept.amount`
     - Dept's `Subcategories` is empty; line items go into the dept's CategoryImport (NOT as further subcategories)
   - Calculate `Percentage` for each category as `(category.Amount / totalBudget) * 100`

   **Also expose this tree-build logic as a testable function** (e.g., `buildCategoryTree(records [][]string, headerIdx map[string]int, entity GatewayEntityConfig) ([]CategoryImport, float64, error)`) so that TestImportEllettsville and TestImportMonroeCounty can exercise it without HTTP or DB dependencies.

10. **DB insertion (reuse existing pattern from ImportBudgets):**

    If `dryRun`, log what would be inserted and continue.

    Otherwise, in a GORM transaction:
    - Find or create Municipality: `tx.Where("name = ? AND state = ? AND entity_type = ?", entity.DisplayName, entity.State, entity.EntityType).First(&municipality)` — create if not found with `Name: entity.DisplayName`, `State: entity.State`, `EntityType: entity.EntityType`
    - Check idempotent: `tx.Where("municipality_id = ? AND fiscal_year = ? AND dataset_type = ?", municipality.ID, year, datasetType).First(&existing)` — skip if found
    - Create Budget: `MunicipalityID`, `FiscalYear: year`, `DatasetType: datasetType`, `TotalBudget: totalBudget`, `FiscalYearStartMonth: entity.FiscalYearStartMonth`, `DataSource: "Indiana Gateway"`, `Hierarchy: pq.StringArray(entity.HierarchyColumns)`
    - Call `importCategories(tx, budget.ID, nil, rootCategories, 0)`
    - Commit transaction
    - Increment `result.Inserted`

11. **Return `ImportBudgetsResult`** with totals.

**Error handling:** Each entity/year/dataset combination that fails should log the error, append to `result.Errors`, and continue to the next combination (matching the existing ImportBudgets pattern). Do NOT abort the entire import on a single file failure.
