**Step 4: Create generate_headshot_manifest.py**

Create a new script `EV-Backend/scripts/generate_headshot_manifest.py` that:

1. Connects to the database using the same `load_env()` + `get_connection()` pattern from scrape_city_headshots.py
2. Loads city_sources.json for city metadata (council URLs, roster member names)
3. Queries the database to find all LOCAL/LOCAL_EXEC CA politicians who do NOT have a 'default' type row in politician_images (or whose row does not contain 'supabase' in the URL)
4. Cross-references each missing politician against city_sources.json roster entries by name matching (case-insensitive) to determine which city they belong to
5. Groups results by city, sorted by roster size descending (biggest impact cities first)
6. Outputs a CSV file `headshot_research_manifest.csv` with columns:
   - `city_name` — from city_sources.json
   - `city_id` — from city_sources.json
   - `council_url` — the city's council page URL (for manual browser research)
   - `member_name` — the politician's full_name from the database
   - `role` — Mayor or Council Member
   - `has_existing_override` — whether city_sources.json already has a headshot_url for this member
   - `headshot_status` — the city's current headshot_status (scraped/blocked/failed)
7. Prints a summary to stdout:
   - Total politicians missing headshots
   - Breakdown by city headshot_status (how many are in scraped vs blocked vs failed cities)
   - Top 20 cities by gap size (most missing headshots)
   - Estimated effort: "X cities with Y members need manual research"

The script should use argparse with:
- `--output` flag (default: `headshot_research_manifest.csv`)
- `--include-blocked` flag (default: exclude blocked cities since they're harder to research)

Use the established patterns from scrape_city_headshots.py:
- `from utils import load_env` for environment
- `psycopg2` with `RealDictCursor` for DB queries
- `json.load()` for city_sources.json
- Same DB connection pattern (direct port 5432, not pooler)

The SQL query to find missing politicians:

```sql
SELECT p.id, p.full_name, d.district_type, o.title
FROM essentials.politicians p
JOIN essentials.offices o ON o.politician_id = p.id
JOIN essentials.districts d ON o.district_id = d.id
LEFT JOIN essentials.politician_images pi
  ON pi.politician_id = p.id AND pi.type = 'default' AND pi.url LIKE '%supabase%'
WHERE d.district_type IN ('LOCAL', 'LOCAL_EXEC')
  AND d.state = 'CA'
  AND p.is_active = true
  AND pi.id IS NULL
ORDER BY p.full_name
```
