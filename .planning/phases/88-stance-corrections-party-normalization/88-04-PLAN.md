<objective>
Verify and (if needed) correct the ukraine-support stance for the Republicans currently at value=2 ("continue current levels of military and economic aid"), per SACC-02. This is Wave 4 — investigative, not assumption-driven. The audit deferred this work because value=2 reflected a defensible pre-2025 Republican position; some politicians may have shifted (toward value=4 or value=5 = reduce/condition aid), others may still hold value=2 accurately. - 1 CSV with verification rows for all Republicans at ukraine-support=2 (politician_full_name, current_value=2, researched_value, reasoning, source_url_1...)
- 1 determinations markdown documenting per-politician disposition (`verified-correct` / `value-changed`) with cited source
- 1 migration (number 125) containing UPDATEs for politicians with `value-changed` disposition; if zero changes, file is a stub
</objective>
