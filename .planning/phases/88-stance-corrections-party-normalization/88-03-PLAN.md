<objective>
Work through the 21 Tier 2 borderline politicians from the Phase 87 audit individually (per SACC-02). Wave 2 differs from Wave 1: not every Tier 2 politician needs correction — some may be genuinely centrist (e.g., the MA value=3 cluster could reflect real moderate Democrats) or genuinely uniform (e.g., OR progressive Dems Hoyle and Salinas at value=1). Purpose: Close out Tier 2 without over-correcting — every change requires a real fetched source per SACC-02, and "do nothing" is a valid disposition when the original value is supported.

- 1 investigation CSV for the MA cluster
- 1 corrections CSV for the politicians needing re-research (may be empty if all 21 turn out to be confirmed correct, in which case the migration step is skipped)
- 1 determinations markdown file with per-politician disposition + rationale for all 21 Tier 2 cases
- Up to 1 combined migration file (number 124) applied to live DB via mcp__supabase-local__execute_sql
