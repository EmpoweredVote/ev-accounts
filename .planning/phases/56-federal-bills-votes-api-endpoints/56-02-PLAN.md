```go
type ImportFederalBillsConfig struct {
    DryRun          bool
    CongressNumbers []int  // default [119, 118]
    SkipSummaries   bool   // skip CRS summary fetch for faster runs
    CongressAPIKey  string
    MaxErrors       int    // abort after this many consecutive errors (default 50)
}

type ImportFederalBillsResult struct {
    BillsUpserted      int
    CosponsorsUpserted int
    SummariesFetched   int
    Skipped            int
    Errors             []string
}
```

**2. ImportFederalBills main function — flow:**

Step 1: Validate config — require CongressAPIKey non-empty. Default CongressNumbers to `[]int{119, 118}` if empty. Default MaxErrors to 50 if 0.

Step 2: Create CongressClient: `client := NewCongressClient(cfg.CongressAPIKey)`

Step 3: Load bioguide bridge table into `map[string]uuid.UUID` (same pattern as import_committees.go):
```go
var bridges []LegislativePoliticianIDMap
db.DB.Where("id_type = ?", "bioguide").Find(&bridges)
bioguideMap := make(map[string]uuid.UUID)
for _, b := range bridges {
    bioguideMap[b.IDValue] = b.PoliticianID
}
```
Log: `"Loaded %d bioguide bridge entries"`

Step 4: For each congress number in CongressNumbers:
  a. Call `getOrCreateSession(congressNum)` to get session UUID (reuse the existing helper from import_committees.go)
  b. For each `(bioguideID, politicianID)` in bioguideMap:
    - Use `context.Background()` as base context (CLI is not request-scoped)
    - **Fetch sponsored bills:**
      ```go
      sponsored, err := client.GetSponsoredLegislation(ctx, bioguideID, congressNum)
      ```
      If error: append to result.Errors, increment consecutive error counter, continue to next politician. If consecutive errors reach MaxErrors, return early with error "too many consecutive failures — Congress.gov may be unavailable".
      If success: reset consecutive error counter.
    - For each sponsored bill: upsert into legislative_bills with:
      - ExternalID: `fmt.Sprintf("%d-%s-%s", congressNum, bill.Type, bill.Number)`
      - Jurisdiction: "federal"
      - Number: `fmt.Sprintf("%s %s", bill.Type, bill.Number)`
      - Title: bill.LatestTitle
      - RawStatus: bill.LatestAction.Text
      - StatusLabel: `normalizeBillStatus(bill.LatestAction.Text)`
      - SponsorID: `&politicianID`
      - IntroducedAt: parse bill.IntroducedDate as time.Time (format "2006-01-02")
      - URL: bill.URL
      - Source: "congress"
      - SessionID: sessionID
      - Use `clause.OnConflict{Columns: [{external_id}, {jurisdiction}], DoUpdates: AssignmentColumns(["title", "raw_status", "status_label", "summary", "sponsor_id", "url"])}`
      - After upsert, query back the bill's DB ID for cosponsorship linking (the upsert may not return ID with OnConflict; do a SELECT on external_id + jurisdiction to get the ID)
    - **Fetch cosponsored bills:**
      ```go
      cosponsored, err := client.GetCosponsoredLegislation(ctx, bioguideID, congressNum)
      ```
      Error handling: same pattern as sponsored.
    - For each cosponsored bill:
      - Upsert bill into legislative_bills with SponsorID = nil (cosponsor is NOT the primary sponsor; the bill may already exist with a different sponsor)
      - **IMPORTANT:** For the bill upsert of cosponsored bills, do NOT overwrite sponsor_id if the bill already exists. Use DoUpdates that exclude sponsor_id:
        `clause.AssignmentColumns([]string{"title", "raw_status", "status_label", "url"})`
      - Then upsert the cosponsorship link:
        ```go
        cosponsor := LegislativeBillCosponsor{BillID: billDBID, PoliticianID: politicianID}
        db.DB.Clauses(clause.OnConflict{DoNothing: true}).Create(&cosponsor)
        ```
    - Log progress every 25 politicians: `"Processed %d/%d politicians for %dth Congress"`

Step 5: **CRS Summary Fetch** (unless SkipSummaries is true):
  - Query all bills that have empty summary: `SELECT id, external_id FROM essentials.legislative_bills WHERE jurisdiction = 'federal' AND summary = ''`
  - For each bill, parse congress/type/number from external_id (split on "-")
  - Call `client.GetBillSummary(ctx, congress, billType, billNumber)`
  - If non-empty summary returned, UPDATE the bill's summary column
  - If error, log and continue (non-fatal)
  - Log: `"Fetched %d CRS summaries"`

Step 6: Return result with counts.

**3. Helper: parseBillExternalID** — splits "119-HR-1044" into (congress int, billType string, billNumber string).

**CRITICAL anti-patterns to avoid:**
- Do NOT `log.Fatal` on individual politician failures — append to errors and continue
- Do NOT overwrite sponsor_id when upserting cosponsored bills
- ExternalID MUST include congress number: `"{congress}-{type}-{number}"`
- Bill type in summary URL must be lowercase: `strings.ToLower(billType)`
- Parse IntroducedDate carefully — some bills may have empty date; skip setting IntroducedAt if empty
- If DryRun: log what would be done but skip all DB writes

```go
case "import-federal-bills":
    dryRun := false
    skipSummaries := false
    congresses := []int{119, 118}
    maxErrors := 50
    for _, arg := range os.Args[2:] {
        switch {
        case arg == "--dry-run":
            dryRun = true
        case arg == "--skip-summaries":
            skipSummaries = true
        case strings.HasPrefix(arg, "--congress="):
            n, err := strconv.Atoi(strings.TrimPrefix(arg, "--congress="))
            if err != nil {
                log.Fatal("invalid --congress value: ", arg)
            }
            congresses = []int{n}
        case strings.HasPrefix(arg, "--max-errors="):
            n, err := strconv.Atoi(strings.TrimPrefix(arg, "--max-errors="))
            if err != nil {
                log.Fatal("invalid --max-errors value: ", arg)
            }
            maxErrors = n
        }
    }
    congressAPIKey := os.Getenv("CONGRESS_API_KEY")
    if congressAPIKey == "" {
        log.Fatal("CONGRESS_API_KEY environment variable is required")
    }
    result, err := essentials.ImportFederalBills(essentials.ImportFederalBillsConfig{
        DryRun:          dryRun,
        CongressNumbers: congresses,
        SkipSummaries:   skipSummaries,
        CongressAPIKey:  congressAPIKey,
        MaxErrors:       maxErrors,
    })
    if err != nil {
        log.Fatal("import-federal-bills failed: ", err)
    }
    fmt.Printf("Import complete: %d bills, %d cosponsors, %d summaries, %d skipped\n",
        result.BillsUpserted, result.CosponsorsUpserted, result.SummariesFetched, result.Skipped)
    if len(result.Errors) > 0 {
        fmt.Printf("Errors (%d):\n", len(result.Errors))
        for _, e := range result.Errors {
            fmt.Printf("  - %s\n", e)
        }
    }
    os.Exit(0)
```

Flags supported:
- `--dry-run` — log what would be done without writing to DB
- `--skip-summaries` — skip the CRS summary fetch phase (faster)
- `--congress=N` — import only a specific Congress number (default: 119 + 118)
- `--max-errors=N` — abort after N consecutive failures (default: 50)

Env var: `CONGRESS_API_KEY` (required, fatal if missing)

Note: `strings`, `strconv` are already imported in main.go from prior CLI cases.
