5. Main `run_upload(manifest_path, dry_run=False)` function:
   - Call `load_env()` and `load_supabase_env()`
   - Open CSV with `csv.DictReader`, filter rows where `research_status == 'found'` AND `found_url` is non-empty
   - Print total rows to process
   - Open DB connection via `get_connection()`, create `RealDictCursor`
   - For each row:
     a. Extract `politician_id`, `found_url`, `city_id`, `member_name`
     b. Try `download_image(found_url)` — on exception, log `FAIL download: {member_name} — {error}`, increment fail counter, continue
     c. Derive `ext = content_type_to_ext(content_type)` and `storage_path = make_storage_path(city_id, member_name, ext)`
     d. If `dry_run`: print `DRY-RUN: {member_name} -> {storage_path}`, increment ok counter, continue
     e. Upload: `cdn_url = upload_photo_to_storage(image_bytes, storage_path, content_type)`
     f. Upsert: `action = upsert_politician_image(cur, politician_id, cdn_url, get_photo_license(found_url))`
     g. `conn.commit()` after EACH successful upsert (isolate failures)
     h. Print `{action}: {member_name} -> {cdn_url}`
     i. Increment ok counter
     j. Sleep `DOWNLOAD_DELAY` between downloads (skip on last item)
   - Close cursor and connection
   - Print summary: `Done: {ok} ok, {skip} skipped, {fail} failed`
   - Return `(ok, skip, fail)` tuple
