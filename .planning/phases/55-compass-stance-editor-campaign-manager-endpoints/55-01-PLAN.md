**Step 1: Update UserRoleGrant in roleService.ts**

Add `id: string` to the `UserRoleGrant` interface (this is the user_roles row UUID now returned by get_user_roles). Place it as the first field for clarity. This is the grant row identifier that audit log entries reference via role_grant_id.

**Step 2: Create `backend/src/lib/stanceService.ts`** with these functions:

**1. `getPoliticianJurisdiction(politicianId: string): Promise<string | null>`**
- Queries `essentials.politicians` (NOT inform.politicians) via `pool.query` for `home_jurisdiction_geoid` WHERE `id = $1`
- Returns the geoid string or null if politician not found or column is null

**2. `getMatchingGrant(grants: UserRoleGrant[], politicianId: string, politicianGeoid: string | null): UserRoleGrant | null`**
- Pure function. Searches grants array for a matching grant:
  - If grant.slug is `campaign_manager`: match requires `grant.resource_id === politicianId`
  - If grant.slug is `compass_stance_editor`: match requires jurisdiction check:
    - If `politicianGeoid` is null: match (fail-open, log console.warn with TODO)
    - If `grant.jurisdiction_geoid` is null: match (unrestricted grant)
    - Otherwise: exact string equality `grant.jurisdiction_geoid === politicianGeoid`
- Returns the first matching grant or null

**3. `getContributorPoliticians(grants: UserRoleGrant[]): Promise<ContributorPolitician[]>`**
- For `campaign_manager` grants: query politicians WHERE `id = $1` using `grant.resource_id`, return array of 0-1 politicians
- For `compass_stance_editor` grants: query politicians WHERE `home_jurisdiction_geoid = $1` using `grant.jurisdiction_geoid`, return matching array
- If grant has null jurisdiction_geoid: return ALL active politicians (unrestricted editor)
- Uses `pool.query` against `essentials.politicians` as the base table (same pattern as `getCompassPoliticians` in compassService.ts). Join with inform.politicians only if needed for additional fields, but essentials.politicians is the canonical source for id, first_name, last_name, full_name, office_title, photo data.
- Returns: `{ id, first_name, last_name, full_name, office_title, photo_url, home_jurisdiction_geoid }`

**4. `writeStanceAuditLog(client: PoolClient, params: StanceAuditParams): Promise<void>`**
- Inserts into `public.role_audit_log` using the provided transaction client
- Params: `{ actorId, targetUserId (same as actorId for stance writes), roleGrantId, featureScope, jurisdictionGeoid, resourceId, topicId, oldValue, newValue, writeInTextChanged }`
- `action` = `'stance_write'`
- `target_type` = `'politician_answer'`
- `target_id` = topicId (string)
- **`fields_changed`** column (`text[]`): Store the NAMES of changed fields as a text array. Examples: `['value', 'write_in_text']` if both changed, `['value']` if only value changed, `['write_in_text']` if only write-in text changed.
- **`snapshot_after`** column (`jsonb`): Store the structured change data: `{ topic_id, old_value, new_value, write_in_text_changed: boolean }`. These are TWO SEPARATE columns — do not conflate them.
- `role_grant_id` = the specific user_roles row UUID (params.roleGrantId) — this is `matchingGrant.id` (the user_roles row UUID), NOT `matchingGrant.role_id` (the roles definition UUID).

Import `pool` from the same location as compassService.ts uses (check import pattern). Import `UserRoleGrant` from `./roleService.js`.

Type exports: `ContributorPolitician`, `StanceAuditParams`.
