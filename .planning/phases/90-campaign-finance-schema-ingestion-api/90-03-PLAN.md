<objective>
Surface the `finance_summary` JSONB column on the two `/api/essentials/politicians` endpoints — list and single — by extending `essentialsService.ts` in four places: two interface declarations and two SELECT/mapper pairs. Closes FINA-03.

Purpose: Plan 01 added the column. Plan 02 populated rows. Without this plan, the data is invisible to API consumers — the CompassV2 and Essentials frontends cannot render the new finance card. This plan is the visibility step: it adds a single new field to both response shapes, backward-compatible (no existing field changes), with `null` for politicians lacking ingested data.
