  <action>
First, query the live Supabase database to get all 21 topics with their current title, short_title, short_name, start_phrase, question_text, and is_active status. Use the Supabase MCP execute_sql tool:

```sql
SELECT id, topic_key, title, short_title, short_name, start_phrase, question_text, is_active
FROM compass.topics
ORDER BY topic_key;
```

Then, for each of the 21 topics, draft three fields:

1. **Title (tension title):** Format `[Topic]: [Pole A] — [Pole B]`
   - Use em dash (—) to separate poles
   - Poles are policy outcome pairs (not abstract "Left vs Right")
   - Randomize pole order per topic — no consistent left/right political ordering
   - Target ~70 characters max
   - Anti-partisan: nobody should detect a pattern framing one side as default

2. **ShortTitle (spoke label):** Concise label for radar chart spokes
   - Review current short titles and improve any that are too vague
   - Keep concise enough for chart display

3. **QuestionText (custom question):** Unique policy question per topic
   - Tone: direct and policy-focused
   - Single question only, no context prefix
   - Avoid ALL leading phrases: no "Where do you stand on...", "Do you think...", "Should we...", "Is it right to..."
   - Example: "How should the U.S. healthcare system be structured?"

Write the drafts to topic-drafts.md organized in review batches grouped by category (e.g., domestic policy, foreign policy, social issues, economic policy, governance). Each entry should show:
- Topic key
- Current title (for reference)
- NEW Title (tension title)
- NEW ShortTitle (spoke label)
- NEW QuestionText (custom question)

Include a header explaining the format and the anti-partisan principle.
