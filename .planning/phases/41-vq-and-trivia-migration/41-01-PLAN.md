Run the following queries:

1. **Table inventory for both schemas:**
```sql
SELECT schemaname, tablename
FROM pg_tables
WHERE schemaname IN ('validation_quests', 'trivia')
ORDER BY schemaname, tablename;
```

2. **Row counts for every table** (use exact COUNT(*) not pg_class estimates -- these schemas are small enough):
For each table found in step 1, run:
```sql
SELECT 'validation_quests.table_name' as tbl, COUNT(*) as cnt FROM validation_quests.table_name
UNION ALL
-- repeat for each table
```

3. **Detect user_id columns** (determines owner-read vs public-read RLS):
```sql
SELECT table_schema, table_name, column_name, data_type
FROM information_schema.columns
WHERE table_schema IN ('validation_quests', 'trivia')
  AND column_name IN ('user_id', 'player_id', 'created_by', 'submitted_by')
ORDER BY table_schema, table_name;
```

4. **Detect politician FK columns in trivia** (for FK reconciliation):
```sql
SELECT table_schema, table_name, column_name, data_type
FROM information_schema.columns
WHERE table_schema = 'trivia'
  AND column_name ILIKE '%politician%'
ORDER BY table_name;
```

5. **Trivia FK gap analysis** (if politician columns found):
```sql
SELECT COUNT(*) as total_rows,
       COUNT(CASE WHEN q.politician_id IS NOT NULL THEN 1 END) as has_politician,
       COUNT(CASE WHEN q.politician_id IS NOT NULL AND ep.id IS NULL THEN 1 END) as unmatched
FROM trivia.<table_with_politician_id> q
LEFT JOIN essentials.politicians ep ON ep.id = q.politician_id
WHERE q.politician_id IS NOT NULL;
```
Adapt the table and column names based on step 4 results.

6. **Check for triggers and functions in both schemas:**
```sql
SELECT trigger_schema, trigger_name, event_object_table, action_timing, event_manipulation
FROM information_schema.triggers
WHERE trigger_schema IN ('validation_quests', 'trivia')
ORDER BY trigger_schema, trigger_name;
```

7. **Check for FK constraints referencing external schemas** (potential restore blockers):
```sql
SELECT tc.table_schema, tc.table_name, tc.constraint_name,
       ccu.table_schema AS foreign_schema, ccu.table_name AS foreign_table
FROM information_schema.table_constraints tc
JOIN information_schema.constraint_column_usage ccu ON ccu.constraint_name = tc.constraint_name
WHERE tc.table_schema IN ('validation_quests', 'trivia')
  AND tc.constraint_type = 'FOREIGN KEY'
  AND ccu.table_schema NOT IN ('validation_quests', 'trivia')
ORDER BY tc.table_schema, tc.table_name;
```

Record all results in the summary document.
