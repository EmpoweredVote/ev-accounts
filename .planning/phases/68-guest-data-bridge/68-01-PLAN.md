Add the following exports to the bottom of essentials/src/lib/compass.js (do NOT modify existing functions):

1. **GUEST_COMPASS_KEY** constant = `"guestCompass"` — the localStorage key for guest compass cache.

2. **parseCompassFragment()** — reads window.location.hash, returns parsed guest data or null:
   - Check if hash starts with `#compass=`
   - Extract the base64 string after `#compass=`
   - Decode: `JSON.parse(atob(base64str))`
   - Validate: result must have `a` (object) and `s` (array)
   - Return `{ answers: result.a, selectedTopics: result.s }` where answers is `{[short_title]: value}` and selectedTopics is `[uuid, ...]`
   - Return null on any error (malformed, invalid, missing)
   - After successful parse, strip fragment: `history.replaceState(null, "", window.location.pathname + window.location.search)`

3. **convertGuestAnswersToApiFormat(guestAnswers, allTopics)** — converts `{[short_title]: value}` to `[{topic_id, value, write_in_text: ""}]`:
   - For each entry in guestAnswers, find topic in allTopics by short_title match
   - If topic found, push `{topic_id: topic.id, value: guestAnswers[short_title], write_in_text: ""}`
   - Return the array (may be empty if no topics match)

4. **saveGuestCompass(answers, selectedTopics)** — saves to localStorage:
   - `localStorage.setItem(GUEST_COMPASS_KEY, JSON.stringify({ a: answers, s: selectedTopics }))`

5. **loadGuestCompass()** — reads from localStorage:
   - Read `localStorage.getItem(GUEST_COMPASS_KEY)`
   - Parse JSON, validate has `a` and `s`
   - Return `{ answers, selectedTopics }` or null on error

6. **clearGuestCompass()** — removes guest cache:
   - `localStorage.removeItem(GUEST_COMPASS_KEY)`

These are pure utility functions with no side effects beyond the explicit localStorage/history calls.

Rewrite the `loadAll()` function inside the useEffect to implement the boot priority:

```javascript
async function loadAll() {
  try {
    // 1. Check for URL fragment (highest priority — fresh bridge data)
    const fragment = parseCompassFragment();

    // 2. Auth check
    const authRes = await fetch(`${API}/auth/me`, { credentials: "include" });

    // 3. Public data (topics + politician stances)
    const [topics, polsWithStances] = await Promise.all([
      fetchTopics(),
      fetchPoliticiansWithStances(),
    ]);

    if (!cancelled) {
      setAllTopics(topics);
      setPoliticianIdsWithStances(
        new Set(polsWithStances.map((p) => String(p.id)))
      );
    }

    // 4. User-specific data — priority: logged-in API > fragment > localStorage cache
    let answers = [];
    let selected = [];

    if (authRes.ok) {
      // Logged-in path: fetch from API, clear any guest cache
      const authData = await authRes.json();
      if (!cancelled) {
        setIsLoggedIn(true);
        setUserName(authData.username ?? null);
      }
      [answers, selected] = await Promise.all([
        fetchUserAnswers(),
        fetchSelectedTopics(),
      ]);
      clearGuestCompass(); // Clean separation: logged-in = API only
    } else if (fragment) {
      // Guest with fresh fragment: convert and cache
      answers = convertGuestAnswersToApiFormat(fragment.answers, topics);
      selected = fragment.selectedTopics;
      saveGuestCompass(fragment.answers, fragment.selectedTopics);
    } else {
      // Guest without fragment: try localStorage cache
      const cached = loadGuestCompass();
      if (cached) {
        answers = convertGuestAnswersToApiFormat(cached.answers, topics);
        selected = cached.selectedTopics;
      }
      // If no cache either, answers and selected stay as [] — CTA mode
    }

    if (!cancelled) {
      setUserAnswers(answers);
      setSelectedTopics(selected);
    }
  } catch (err) {
    console.error("CompassContext load error:", err);
  } finally {
    if (!cancelled) {
      setCompassLoading(false);
    }
  }
}
```

Key behavior:
- Fragment is parsed BEFORE auth check (synchronous, instant)
- If logged in, API data wins and guest cache is cleared
- If guest with fragment, fragment data is used AND cached for future visits
- If guest without fragment, cached data is used
- If nothing, empty arrays = CTA mode (existing behavior preserved)
