Create `backend/src/lib/treasuryService.ts` following the exact pattern of `essentialsService.ts`:

- `import { pool } from './db.js'` — NEVER use supabaseAdmin.schema('treasury'), it will fail at runtime (treasury not in PostgREST exposed schema list)
- Explicit camelCase field mapping for every query result — NEVER spread DB rows
- `Number()` wrapper on all bigint columns: population, fiscal_year, item_count, sort_order, depth

**Functions to implement:**

1. `getCities()` — `SELECT id, name, state, population, created_at, updated_at FROM treasury.cities ORDER BY name` — return array of `{ id, name, state, population: Number(row.population), createdAt, updatedAt }`

2. `getCityById(id: string)` — same columns, WHERE id = $1, return single object or null

3. `getBudgetsByCityId(cityId: string, fiscalYear?: number)` — `SELECT id, city_id, fiscal_year, dataset_type, total_budget, data_source, hierarchy, generated_at, created_at, updated_at FROM treasury.budgets WHERE city_id = $1` + optional `AND fiscal_year = $2` — map to camelCase, `Number()` on fiscal_year, `Number()` on total_budget

4. `getBudgetById(id: string)` — budget row + flat sorted categories: two queries or a JOIN. Return `{ ...budget, categories: [...] }`. Categories query: `SELECT * FROM treasury.budget_categories WHERE budget_id = $1 ORDER BY depth, sort_order` — map: `Number()` on amount, percentage, item_count, sort_order, depth

5. `getLineItemsByBudgetId(budgetId: string)` — `SELECT * FROM treasury.budget_line_items WHERE category_id IN (SELECT id FROM treasury.budget_categories WHERE budget_id = $1)` — map all numeric fields with Number()

6. `createCity(data: { name: string; state: string; population?: number })` — INSERT INTO treasury.cities RETURNING * — map result

7. `createBudget(data: { cityId: string; fiscalYear: number; datasetType: string; totalBudget: number; dataSource?: string; hierarchy?: string[] })` — INSERT INTO treasury.budgets RETURNING *

8. `createBudgetCategory(budgetId: string, data: { parentId?: string; name: string; amount: number; percentage?: number; color?: string; description?: string; whyMatters?: string; historicalChange?: string; itemCount?: number; sortOrder: number; depth: number; linkKey?: string })` — INSERT INTO treasury.budget_categories RETURNING *

9. `createBudgetLineItem(categoryId: string, data: { description?: string; approvedAmount?: number; actualAmount?: number; basePay?: number; benefits?: number; overtime?: number; other?: number; startDate?: string; vendor?: string; date?: string; paymentMethod?: string; invoiceNumber?: string; fund?: string; expenseCategory?: string })` — INSERT INTO treasury.budget_line_items RETURNING *

**TypeScript interfaces** at the top of the file: `TreasuryCity`, `TreasuryBudget`, `TreasuryBudgetCategory`, `TreasuryBudgetLineItem`. All fields camelCase.

**Row mapping helper** (private): `function mapCity(row: any): TreasuryCity` etc. — one mapper per type.

Create `backend/src/routes/treasury.ts` following the pattern of `essentialsPoliticians.ts` (route file) and `admin.ts` (for admin-gated routes):

```
import { Router } from 'express';
import { optionalAuth } from '../middleware/auth.js';

import { requireAdmin } from '../middleware/requireAdmin.js';
import type { Request, Response } from 'express';
import { z } from 'zod';
```

Import all service functions from treasuryService.

**UUID validation:** Define `const UUID_REGEX = /^[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}$/i;` at module level.

**Public read routes (optionalAuth):**

1. `GET /` (maps to /api/treasury/cities) — call getCities(), return 200 with array
2. `GET /cities/:id` — validate UUID, call getCityById, return 200 or 404
3. `GET /cities/:cityId/budgets` — validate UUID, parse optional `?fiscal_year=` as number, call getBudgetsByCityId, return 200
4. `GET /budgets/:id` — validate UUID, call getBudgetById, return 200 or 404
5. `GET /budgets/:id/line-items` — validate UUID, call getLineItemsByBudgetId, return 200

**Admin write routes (requireAuth + requireAdmin):**

6. `POST /cities` — Zod validate body: `{ name: string, state: string, population?: number }`. Call createCity. Return 201.
7. `POST /budgets` — Zod validate body: `{ cityId: string (uuid), fiscalYear: number, datasetType: string, totalBudget: number, dataSource?: string, hierarchy?: string[] }`. Call createBudget. Return 201.
8. `POST /budgets/:id/categories` — validate UUID param, Zod validate body. Call createBudgetCategory. Return 201.
9. `POST /budgets/:id/line-items` — validate UUID param, Zod validate body. Call createBudgetLineItem. Return 201.

**Error handling:** try/catch on every handler. Log with `[GET /treasury/cities]` style prefix. Return `{ code: 'INTERNAL_ERROR', message: 'An unexpected error occurred' }` on 500. Return `{ code: 'INVALID_ID', message: 'Invalid UUID format' }` on bad UUID params. Return `{ code: 'VALIDATION_ERROR', message: string }` on Zod failures.

**IMPORTANT routing structure:** The router mounts at `/api/treasury` in index.ts. So route paths in the router are:
- `router.get('/cities', ...)` for the list
- `router.get('/cities/:id', ...)` for single city
- etc.

**Register in index.ts:**
- Add import: `import treasuryRouter from './routes/treasury.js';`
- Add mount: `app.use('/api/treasury', treasuryRouter);` — place after the essentials routes
