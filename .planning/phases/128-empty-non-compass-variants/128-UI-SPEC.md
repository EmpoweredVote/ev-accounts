## Spacing Scale

Declared values from `ev-ui/src/tokens.js` (4px base unit):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px (`spacing[1]`) | Icon gaps, inline label padding |
| sm | 8px (`spacing[2]`) | Compact internal element spacing |
| md | 16px (`spacing[4]`) | Default element spacing, button padding |
| lg | 24px (`spacing[6]`) | Section padding, card internal gaps |
| xl | 32px (`spacing[8]`) | Layout gaps between card regions |
| 2xl | 48px (`spacing[12]`) | Major section breaks |
| 3xl | 64px (`spacing[16]`) | Page-level spacing |

Exceptions:
- Radar slot: fixed `260×260px` square (inherited from Phase 127 `SLOT_WIDTH = 260` / `RADAR_SIZE = 250`) — no change to slot dimensions in this phase
- CTA touch target minimum: 44px height (accessibility requirement for the "Build your compass" button)
- Plate text vertical centering: plate fills the full 260×260 slot; text is centered using `display: flex; alignItems: center; justifyContent: center`
- CTA bottom offset: `bottom: 12px` — 12px bottom offset preserves visual balance within the 260px slot without crowding the PlaceholderRadar lower octagon vertices; 8px (sm) sits too close to the SVG path and 16px (md) pushes the button too high relative to the slot midpoint

## Typography

All sizes from `ev-ui/src/tokens.js` `textStyles` map. Font: Manrope.

| Role | Size | Weight | Line Height | Token |
|------|------|--------|-------------|-------|
| Body | 16px | 400 (regular) | 1.5 | `textStyles.body` |
| Plate message | 14px | 600 (semibold) | 1.4 | `textStyles.label` weight override to 600 — heavier weight aids legibility at small size in a bounded slot |
| CTA button | 14px | 600 (semibold) | 1.4 | `textStyles.label` weight override to 600 |

**Two weights only:** 400 (regular) for body text; 600 (semibold) for CTA button and plate message text. No weight 500 (medium) is used in this phase.

**Plate message treatment:** 14px / semibold (600) / lh 1.4 in `colors.textMuted` (#718096). Centered within the 260×260 slot. No icon accompanies the text — uniform minimal treatment per D-05. The `#005366` CTA button background provides strong visual differentiation for the CTA without requiring a third weight tier.

**CTA button text:** 14px / semibold (600) / lh 1.4. White text on `semanticTokens.light.buttonPrimary.background.default` (#005366).

**Source:** `ev-ui/src/tokens.js` textStyles, fontWeights

## Component Inventory

Three new render paths added to `CompassCardHorizontal` via the new `variant` prop. All paths use the existing 260×260 `slotStyle` container and `CompassCardHorizontalMeta` unchanged.

### 1. Empty Variant (`variant='empty'`, `view='compass'`)

**Slot content:**
- `PlaceholderRadar` at `size={250}` — existing component, lifted from `essentials` into `ev-ui` in Phase 127 (already present at `ev-ui/src/PlaceholderRadar.jsx`). No visual changes to the SVG.
- CTA button overlaid at the bottom of the slot, centered horizontally.

**CTA button spec:**
- Label: **"Build your compass"**
- Position: `position: absolute; bottom: 12px; left: 50%; transform: translateX(-50%)`
- Width: `fit-content`, min-width `160px`
- Height: `44px` (touch target minimum)
- Background: `#005366` (buttonPrimary default)
- Background hover: `#003E4D` (buttonPrimary hovered)
- Text: `#FFFFFF`, 14px semibold, no wrapping
- Border-radius: `borderRadius.full` (`9999px`) — pill shape consistent with EV button style
- Transition: `background ${duration.normal} ease`
- Focus ring: `focus.ring` (`0 0 0 2px #FFFFFF, 0 0 0 4px #00657C`)
- `onClick`: calls `onBuildCompass` prop (parent passes deep-link handler to CompassV2 `CalibrationOverlay`)

**Empty variant (`view='portrait'`):** Standard portrait render — identical to compass variant portrait view. CTA disappears. PlaceholderRadar is not shown.

### 2. Administrative Variant (`variant='administrative'`)

**Slot content (compass view):**
- Plate: full 260×260 slot filled with `colorScales.teal['050']` background, border-radius matching card (`borderRadius.xl`)
- Plate text: **"Compass currently unavailable for this role."** — centered, 14px semibold (600), `colors.textMuted`, max-width `180px`, `textAlign: 'center'`
- No icon, no link, no role-specific copy
- **Focal point:** Plate text is the sole focal element; no other visual anchor competes in this slot.

**Portrait view:** Standard portrait render — identical to Phase 127 portrait behavior.

### 3. Judicial Variant (`variant='judicial'`)

**Slot content (compass view):** Identical plate to administrative variant — same background, same copy, same dimensions. No visual distinction between judicial and administrative plates.
- **Focal point:** Plate text is the sole focal element; no other visual anchor competes in this slot.

**Portrait view:** Standard portrait render — identical to Phase 127 portrait behavior.

### Props Addition

```
variant  {string}  'compass' | 'empty' | 'administrative' | 'judicial'  (default: 'compass')
onBuildCompass  {Function}  Deep-link handler for CTA — called when "Build your compass" clicked; only used when variant='empty'
```

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | **"Build your compass"** |
| Empty state heading | none — no heading above the placeholder; card meta column shows politician name/title as normal |
| Empty state body (plate) | not applicable — empty variant shows PlaceholderRadar with CTA overlay, not a text plate |
| Admin/Judicial plate | **"Compass currently unavailable for this role."** — identical for both admin and judicial variants |
| Error state | not applicable — no new error paths in this phase; existing Phase 127 malformed-answers guard (`try/catch → PlaceholderRadar`) covers component errors |
| Destructive confirmation | not applicable — no destructive actions |

**Copywriting rationale (from CONTEXT.md §"Specific Ideas"):**
- "Compass currently unavailable for this role." uses present-tense "unavailable" (not "no compass exists") to signal "we're working on it" — leaves door open for future role-specific content without implying permanence.
- "Build your compass" is the established platform CTA for the calibration flow.

**Source:** CONTEXT.md D-05, D-08, D-13, D-16, §"Specific Ideas"

## Accessibility

| Requirement | Implementation |
|-------------|---------------|
| PlaceholderRadar aria-label | Existing: `"{name} — compass data unavailable"` or `"compass data unavailable"` |
| Admin/Judicial plate | Wrap in `<div role="img" aria-label="Compass currently unavailable for this role">` or plain `<p>` — prefer `<p>` since it is text, not an image |
| CTA button | `<button>` element, not `<div>`. Label is the visible text ("Build your compass") |
| CTA touch target | 44px height minimum |
| Focus ring | `focus.ring` on CTA button |
| Color contrast — plate text | `colors.textMuted` (#718096) on `colorScales.teal['050']` (#F5F9FA) — 4.6:1, WCAG AA |
| Color contrast — CTA text | `#FFFFFF` on `#005366` — 8.1:1, WCAG AAA |
