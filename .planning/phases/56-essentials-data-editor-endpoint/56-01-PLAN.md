Add two new exported functions to stanceService.ts (append after the existing writeStanceAuditLog function):

**1. `getEditorMatchingGrant(grants: UserRoleGrant[], politicianGeoid: string | null): UserRoleGrant | null`**

Pure function. Iterates grants looking for `essentials_data_editor` slug:
- `grant.jurisdiction_geoid === null` -> return grant (global access)
- `politicianGeoid === null` -> continue (fail-CLOSED, unlike Phase 55's fail-open for compass_stance_editor)
- `grant.jurisdiction_geoid === politicianGeoid` -> return grant (exact match)
- Otherwise continue to next grant
- Return null if no grant matches

DO NOT modify the existing `getMatchingGrant` function. This is a separate function for a different role with different semantics (fail-closed on NULL politician geoid vs fail-open).

**2. `writeEssentialsAuditLog(client: PoolClient, params: EssentialsAuditParams): Promise<void>`**

New interface `EssentialsAuditParams`:
```typescript
export interface EssentialsAuditParams {
  actorId: string;
  roleGrantId: string;
  featureScope: string;
  jurisdictionGeoid: string | null;
  resourceId: string | null;
  politicianId: string;
  fieldsChanged: string[];           // e.g. ['bio', 'preferred_name']
  changes: Record<string, { old: unknown; new: unknown }>;
}
```

The INSERT query:
```sql
INSERT INTO public.role_audit_log
  (actor_id, target_user_id, feature_scope, jurisdiction_geoid, resource_id,
   action, target_type, target_id, fields_changed, snapshot_after, role_grant_id)
VALUES ($1, $2, $3, $4, $5, 'bio_edit', 'politician', $6, $7, $8, $9)
```
Where: actor_id = target_user_id = actorId (editor is the actor, no separate target user), target_id = politicianId, snapshot_after = JSON.stringify(changes).

This is intentionally a NEW function, not a reuse of writeStanceAuditLog, because the audit shape differs (arbitrary field diffs vs topic value changes).

const patchPoliticianSchema = z.object({
  bio: z.string().max(10000).optional(),
  photo_origin_url: z.string().url().max(2048).optional().or(z.literal('').transform(() => null)),
  preferred_name: z.string().max(200).optional().or(z.literal('').transform(() => null)),

**Route: `router.patch('/:id', requireAuth, requireRole('essentials_data_editor'), handler)`**

Handler flow (9 steps):

1. Validate `:id` is UUID format -> 422 if not
2. Check for restricted fields in `req.body` BEFORE zod parse -> 422 with `{ code: 'RESTRICTED_FIELDS', message: '...', fields: offendingFields }`
3. Parse body with zod -> 422 on validation failure
4. Get grants via `getCachedUserRoles(actorId)`
5. Fetch politician existence + jurisdiction: `SELECT id, home_jurisdiction_geoid FROM essentials.politicians WHERE id = $1 LIMIT 1` -> 404 if not found
6. Call `getEditorMatchingGrant(grants, politicianGeoid)` -> 403 if null
7. Fetch current values for no-op detection: `SELECT bio_text, preferred_name, photo_custom_url FROM essentials.politicians WHERE id = $1`
   Then compute `changed` map: compare each provided field against current DB value. Map API names to DB columns:
   - `body.bio !== undefined && body.bio !== cur.bio_text` -> changed['bio'] = { old: cur.bio_text, new: body.bio }
   - `body.photo_origin_url !== undefined && body.photo_origin_url !== cur.photo_custom_url` -> changed['photo_origin_url'] = { old: cur.photo_custom_url, new: body.photo_origin_url }
   - `body.preferred_name !== undefined && body.preferred_name !== cur.preferred_name` -> changed['preferred_name'] = { old: cur.preferred_name, new: body.preferred_name }
8. If `Object.keys(changed).length === 0` -> return 200 with current record (build response from fetched row), NO audit log
9. Transaction (pool.connect -> BEGIN -> UPDATE -> writeEssentialsAuditLog -> COMMIT -> respond):
   - Build dynamic UPDATE: only SET columns that actually changed. Map API field names to DB columns:
     `bio` -> `bio_text`, `photo_origin_url` -> `photo_custom_url`, `preferred_name` -> `preferred_name`
   - Add `RETURNING id, full_name, first_name, last_name, preferred_name, bio_text, photo_custom_url, COALESCE(photo_custom_url, photo_origin_url, '') AS photo_url` to get updated values
   - Call `writeEssentialsAuditLog(client, { actorId, roleGrantId: matchingGrant.id, featureScope: matchingGrant.feature_scope, jurisdictionGeoid: matchingGrant.jurisdiction_geoid, resourceId: matchingGrant.resource_id, politicianId, fieldsChanged: Object.keys(changed), changes })`
   - ROLLBACK on error, release client in finally

**Response shape** (same for 200 success and 200 no-op):
```typescript
{
  id: string;
  full_name: string | null;
  first_name: string | null;
  last_name: string | null;
  preferred_name: string | null;
  bio: string | null;              // mapped from bio_text
  photo_url: string | null;        // COALESCE(photo_custom_url, photo_origin_url, '')
}
```
Note: Response uses API field name `bio` (not `bio_text`) and `photo_url` (the resolved COALESCE value). This avoids leaking DB column names.
