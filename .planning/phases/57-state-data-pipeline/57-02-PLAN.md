GET /essentials/politician/{id}/committees
  -> SQL: SELECT ... FROM legislative_committee_memberships m JOIN legislative_committees c ... WHERE m.politician_id = ?
  -> No jurisdiction filter — state data included automatically

GET /essentials/politician/{id}/bills
  -> SQL: SELECT ... FROM legislative_bills b WHERE (b.sponsor_id = ? OR b.id IN (SELECT bill_id FROM legislative_bill_cosponsors WHERE politician_id = ?))
  -> No jurisdiction filter — state data included automatically

GET /essentials/politician/{id}/votes
  -> SQL: SELECT ... FROM legislative_votes v LEFT JOIN legislative_bills b ON b.id = v.bill_id WHERE v.politician_id = ?
  -> No jurisdiction filter — state data included automatically

GET /essentials/politician/{id}/legislative-summary
  -> Returns 5 recent bills + 10 recent votes
  -> No jurisdiction filter — state data included automatically

**Step 1: Find test politician IDs for Indiana and California state legislators.**

Query the database to find politician IDs that have legislative data:

```bash
cd /Users/chrisandrews/Documents/GitHub/EV-Backend
source <(grep -v '^#' .env.local | sed 's/^/export /')

# Find an Indiana state legislator with bills
psql "$DATABASE_URL" -c "
SELECT p.id, p.first_name, p.last_name, COUNT(b.id) as bill_count
FROM essentials.politicians p
JOIN essentials.legislative_politician_id_map m ON m.politician_id = p.id AND m.id_type = 'legiscan' AND m.source = 'legiscan-state-people'
JOIN essentials.offices o ON o.politician_id = p.id
JOIN essentials.districts d ON o.district_id = d.id
LEFT JOIN essentials.legislative_bills b ON b.sponsor_id = p.id AND b.jurisdiction = 'indiana'
WHERE d.district_type IN ('STATE_UPPER', 'STATE_LOWER')
GROUP BY p.id, p.first_name, p.last_name
ORDER BY bill_count DESC
LIMIT 5
"

# Find a California state legislator with votes
psql "$DATABASE_URL" -c "
SELECT p.id, p.first_name, p.last_name, COUNT(v.id) as vote_count
FROM essentials.politicians p
JOIN essentials.legislative_politician_id_map m ON m.politician_id = p.id AND m.id_type = 'legiscan' AND m.source = 'legiscan-state-people'
LEFT JOIN essentials.legislative_votes v ON v.politician_id = p.id
JOIN essentials.offices o ON o.politician_id = p.id
JOIN essentials.districts d ON o.district_id = d.id
WHERE d.district_type IN ('STATE_UPPER', 'STATE_LOWER')
GROUP BY p.id, p.first_name, p.last_name
HAVING COUNT(v.id) > 0
ORDER BY vote_count DESC
LIMIT 5
"
```
