**useFilteredPoliticians.js** — Custom hook that manages filter state and computes filtered results.

Create `CompassV2/src/hooks/useFilteredPoliticians.js`:

1. **`tierFromDistrictType(dt)` helper function** (not exported, internal to module):
   Maps district_type string to tier string. This replicates the tier-only logic from essentials classify.js without importing it (different project, no cross-project imports):
   - `NATIONAL_EXEC`, `NATIONAL_UPPER`, `NATIONAL_LOWER` → `"Federal"`
   - `STATE_EXEC`, `STATE_UPPER`, `STATE_LOWER` → `"State"`
   - `LOCAL_EXEC`, `LOCAL`, `COUNTY`, `SCHOOL`, `JUDICIAL` → `"Local"`
   - Anything else (missing/unknown) → `null`

   Note: JUDICIAL is always mapped to Local here because the compass politicians endpoint does not include `chamber_name`, which would be needed to distinguish state appellate courts. This is an acceptable simplification for the compare picker.

2. **`useFilteredPoliticians(politicians)` hook** — accepts the raw politician array (from usePoliticianList), returns:
   - `level` — current level filter string: `"All"` | `"Federal"` | `"State"` | `"Local"` (default `"All"`)
   - `setLevel(lvl)` — setter. When level changes, check if current `stateFilter` is still valid for the new level (i.e., at least one politician matches both new level and current state). If not valid, auto-clear `stateFilter` to `""`.
   - `stateFilter` — current state filter string (2-letter state code or `""` for no filter)
   - `setStateFilter(st)` — setter
   - `clearAll()` — resets level to `"All"` and stateFilter to `""`
   - `hasActiveFilters` — boolean, true when level !== "All" or stateFilter !== ""
   - `levelCounts` — object `{ Federal: N, State: N, Local: N }` with counts. When stateFilter is active, counts reflect only politicians matching that state. When stateFilter is empty, counts reflect all politicians. These counts are used by PoliticianFilters to show `Federal (12)` and to hide zero-count pills.
   - `availableStates` — sorted array of `{ code, name }` objects for states that have at least one politician matching current level filter. Use a static `STATE_NAMES` map (2-letter code → full name) for the ~50 US states + DC. Only include states where at least one politician exists at the current level.
   - `filtered` — the filtered politician array after applying both level and stateFilter + the text query is NOT applied here (that stays in the picker components). The hook only applies level + state.

   Use `useMemo` for `levelCounts`, `availableStates`, and `filtered` to avoid recomputation on every render.
   Use `useState` for `level` and `stateFilter`.

   The auto-clear logic for stateFilter when level changes should be in a `useEffect` watching `level` and `politicians`. If stateFilter is set and no politicians match (level + stateFilter), call setStateFilter("").

3. **STATE_NAMES map** — Include all 50 states + DC + common territories (PR, GU, VI, AS, MP). Format: `{ CA: "California", TX: "Texas", ... }`. Alphabetical by name for display. This is a static constant.

**PoliticianFilters.jsx** — Reusable presentational component.

Create `CompassV2/src/components/PoliticianFilters.jsx`:

Props:
- `level` — current level string
- `onLevelChange(lvl)` — callback
- `levelCounts` — `{ Federal, State, Local }` count object
- `stateFilter` — current state code or ""
- `onStateChange(code)` — callback
- `availableStates` — array of `{ code, name }`
- `hasActiveFilters` — boolean
- `onClearAll()` — callback

Render:

1. **Level pills row** — horizontal flex row with gap-1.5, wrapped in a `div` with `px-3 pt-2 pb-1`:
   - "All" pill always visible. Active when `level === "All"`. Does not show a count.
   - "Federal", "State", "Local" pills — ONLY render if their count > 0. Show count in parentheses, e.g., `Federal (12)`.
   - Active pill style: `bg-[#00657c] text-white` (ev-muted-blue). Inactive pill style: `bg-neutral-100 text-neutral-600 hover:bg-neutral-200`.
   - Pill shape: `rounded-full px-3 py-1 text-xs font-medium cursor-pointer transition-colors`.
   - Each pill is a `<button>` calling `onLevelChange` with its tier string.
   - Single-select: clicking an active pill does nothing (stays selected). There's no deselect — user clicks "All" to clear.

2. **State dropdown + clear controls row** — horizontal flex row with gap-2, `px-3 pb-2`:
   - State dropdown: `<select>` element with `rounded-lg border border-neutral-200 px-2 py-1 text-xs`. Default option: `<option value="">State</option>`. Options from `availableStates` sorted alphabetically by name: `<option value="CA">California</option>`. When stateFilter is set, the select shows the selected state name.
   - Clear individual filters: When stateFilter is set, show a small "x" button next to the state dropdown that calls `onStateChange("")`. When level !== "All", show a small "x" button that calls `onLevelChange("All")`.
   - "Clear all" link: When `hasActiveFilters`, show a `text-xs text-neutral-400 hover:text-neutral-600 cursor-pointer underline` link reading "Clear all" that calls `onClearAll()`. Positioned at the right end of the row with `ml-auto`.

3. **Empty state**: If `!hasActiveFilters`, the state dropdown row can still show (the dropdown always exists with "State" placeholder). The clear controls just won't appear.

4. **Compact layout**: Both rows together should be visually compact — no more than ~60px total height so the politician list remains the primary scrollable area.

Design system: Use Tailwind CSS. Colors from the EV design system: `#00657c` (ev-muted-blue) for active pills, `#59b0c4` (ev-light-blue) for focus rings.
