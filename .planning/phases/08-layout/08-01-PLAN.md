  <action>
Modify the Results page layout so the main content panel scrolls independently while the sidebar stays fixed.

**Layout container changes:**

1. The outer `<div className="flex flex-col md:flex-row">` that wraps FilterSidebar + main needs additional desktop styles. Replace the className with inline styles + a className for mobile. Use a wrapper approach:
   - On desktop (>= 768px): `height: 'calc(100vh - 75px)'`, `overflow: 'hidden'`, `display: 'flex'`, `flexDirection: 'row'`
   - On mobile (< 768px): current behavior (flex-col, normal page scroll)
   - Import `useMediaQuery` from `@chrisandrewsedu/ev-ui` (already available in the ev-ui package exports) to detect desktop vs mobile. Note: the component file already has access to this since FilterSidebar uses it internally, but Results.jsx needs its own check for the layout wrapper.
   - Add: `import { useMediaQuery } from '@chrisandrewsedu/ev-ui';`
   - Create: `const isDesktop = useMediaQuery('(min-width: 769px)');`

2. The `<main className="flex-1">` element needs:
   - On desktop: `overflowY: 'auto'`, `flex: 1`, `minWidth: 0` (prevents flex blowout)
   - On mobile: no overflow changes (normal page scroll)
   - Apply via conditional inline style:
     ```jsx
     <main
       className="flex-1"
       style={isDesktop ? { overflowY: 'auto', minWidth: 0 } : undefined}
     >
     ```

3. **Scroll-spy IntersectionObserver fix:** The existing scroll-spy (lines ~364-381) uses `document.querySelectorAll('[data-tier]')` and observes within the viewport. With the new layout, the scroll container is the `<main>` element, not the page. The IntersectionObserver needs its `root` option set to the scrolling main element.
   - Add a `const mainRef = useRef(null);` at the top of the component
   - Attach `ref={mainRef}` to the `<main>` element
   - In the IntersectionObserver setup, pass `root: isDesktop ? mainRef.current : null` in the options object (null = viewport for mobile, mainRef = scrolling container for desktop)
   - Also add `isDesktop` and `mainRef.current` to the useEffect dependency array (or just `isDesktop`) so it re-creates the observer on layout change
   - Adjust rootMargin to work within the scroll container: keep `'-40% 0px -60% 0px'`

4. **Container wrapper:** Update the flex container div to use conditional styling:
   ```jsx
   <div
     className={isDesktop ? '' : 'flex flex-col'}
     style={isDesktop ? {
       display: 'flex',
       flexDirection: 'row',
       height: 'calc(100vh - 75px)',
       overflow: 'hidden',
     } : undefined}
   >
   ```

5. Add a subtle border-right on the sidebar by ensuring the FilterSidebar's existing `borderRight` style stays (it already has `borderRight: 1px solid #e2ebef` via tokens). No additional work needed here — just verify it renders.
