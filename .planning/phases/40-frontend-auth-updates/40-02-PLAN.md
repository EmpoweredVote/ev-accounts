**Step 1: Create `src/lib/auth.js`**

Create the shared auth module following the exact pattern from the RESEARCH.md "Code Examples" section. Key exports: `apiFetch`, `getToken`, `clearToken`, `setToken`, `extractHashToken`, `redirectToLogin`, `API_BASE`, `AUTH_HUB_URL`, `TOKEN_KEY`.

The `apiFetch()` function must:
- Read token from localStorage
- Attach `Authorization: Bearer {token}` header
- On 401 response: `clearToken()` + `redirectToLogin()` + return null
- Use `API_BASE` derived from `import.meta.env.VITE_API_URL`

**Step 2: Replace Login.jsx with Auth Hub redirect**

Replace the entire Login component with a redirect to Auth Hub:
```jsx
import { useEffect } from "react";
import { AUTH_HUB_URL } from "../lib/auth";

function Login() {
  useEffect(() => {
    const returnTo = new URLSearchParams(window.location.search).get("return")
      || window.location.origin + "/results";
    window.location.replace(
      `${AUTH_HUB_URL}/login?redirect=${encodeURIComponent(returnTo)}`
    );
  }, []);
  return null;
}
export default Login;
```

**Step 3: Replace Register.jsx with Auth Hub redirect**

Same pattern — redirect to Auth Hub signup page:
```jsx
import { useEffect } from "react";
import { AUTH_HUB_URL } from "../lib/auth";

function Register() {
  useEffect(() => {
    const returnTo = new URLSearchParams(window.location.search).get("return")
      || window.location.origin + "/results";
    window.location.replace(
      `${AUTH_HUB_URL}/signup?redirect=${encodeURIComponent(returnTo)}`
    );
  }, []);
  return null;
}
export default Register;
```

NOTE: The `buildGuestState()` function and guest answer migration logic in Register.jsx is being dropped intentionally. Document this in the summary.

**Step 4: Update CompassContext.jsx**
