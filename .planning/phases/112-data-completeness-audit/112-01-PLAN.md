**Main logic:**

1. First, query the election row count to validate assumption A4:
```sql
SELECT id, name FROM essentials.elections WHERE election_date = '2026-05-05' AND state = 'IN'
```
Log to stderr: `Found N election(s) for 2026-05-05 IN`. If 0, print error and exit. If >1, log warning and continue with all matching elections.

2. Query race data (per RESEARCH.md AUDIT-01 pattern):
```sql
SELECT
  r.position_name,
  r.primary_party,
  COUNT(rc.id) AS candidate_count,
  CASE WHEN r.office_id IS NOT NULL THEN 'Y' ELSE 'N' END AS linked_to_geofence,
  r.office_id
FROM essentials.races r
LEFT JOIN essentials.race_candidates rc ON rc.race_id = r.id AND rc.candidate_status = 'active'
JOIN essentials.elections e ON e.id = r.election_id
WHERE e.election_date = '2026-05-05' AND e.state = 'IN'
GROUP BY r.id, r.position_name, r.primary_party, r.office_id
ORDER BY r.position_name, r.primary_party
```

5. `await pool.end()` at the end.

**IMPORTANT anti-pattern:** Do NOT query `essentials.election_records` — that is a legacy BallotReady table. Only use `essentials.elections` + `essentials.races` + `essentials.race_candidates`.

**CSV columns:** `position_name,primary_party,total_candidates,linked_to_politician,stub_candidates`

**Main logic:**

1. Same election validation as races script (query `essentials.elections WHERE election_date = '2026-05-05' AND state = 'IN'`, log count, exit if 0).

2. Query candidate linkage per race (per RESEARCH.md AUDIT-02 pattern):
```sql
SELECT
  r.position_name,
  r.primary_party,
  COUNT(rc.id) AS total_candidates,
  COUNT(rc.politician_id) AS linked_to_politician,
  COUNT(CASE WHEN rc.politician_id IS NULL THEN 1 END) AS stub_candidates
FROM essentials.races r
LEFT JOIN essentials.race_candidates rc ON rc.race_id = r.id
  AND rc.candidate_status = 'active'
JOIN essentials.elections e ON e.id = r.election_id
WHERE e.election_date = '2026-05-05' AND e.state = 'IN'
GROUP BY r.id, r.position_name, r.primary_party
ORDER BY r.position_name, r.primary_party
```

3. If `DRY_RUN`: log total races, total candidates, linked count, stub count to stdout, then exit.

4. Otherwise: write CSV header, then one row per race. Log summary to stderr:
   - `Total races: N`
   - `Total candidates: N (linked: N, stubs: N)`
   - `Races with zero candidates: N`

5. `await pool.end()` at the end.

**IMPORTANT (Pitfall 4):** When `rc.politician_id IS NULL`, this means the candidate is a stub with no linked politician record. The script MUST count these as stubs, not as politicians with missing data. The `stub_candidates` column makes this distinction visible.
