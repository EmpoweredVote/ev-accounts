  <action>
Create a new service file for legislative data queries. These tables are large (19,622 bills, 121,178 votes, 44,021 bill cosponsors) so queries must be efficient.

All functions use `pool.query()` — never PostgREST. All accept a politician_id (UUID string) and return typed arrays.

**1. `getLegislativeByPolitician(politicianId: string): Promise<LegislativeSession[]>`**
- Query essentials.legislative_sessions (or the appropriate table — check 38-01-SUMMARY for exact table name)
- JOIN with essentials.offices to link politician to their legislative body
- Return array of sessions with: id, name, start_date, end_date, legislative_body, etc.
- If politician has no sessions, return []

**2. `getCommitteesByPolitician(politicianId: string): Promise<Committee[]>`**
- Query essentials.committee_memberships (or appropriate table) WHERE politician_id = $1
- JOIN with essentials.committees for committee details
- Return array with: id, name, role (chair/member/etc.), committee_type, etc.
- If no committees, return []

**3. `getBillsByPolitician(politicianId: string, limit?: number): Promise<Bill[]>`**
- Query essentials.bills WHERE sponsor_politician_id = $1 OR exists in essentials.bill_cosponsors
- JOIN for bill details: title, number, status, session, introduced_date
- Default limit: 50 (bills table is 19k rows — don't return all)
- Support `?limit=N` from route (max 100)
- ORDER BY introduced_date DESC (most recent first)
- Return array of bill objects

**4. `getVotesByPolitician(politicianId: string, limit?: number): Promise<Vote[]>`**
- Query essentials.vote_records (or votes) WHERE politician_id = $1
- JOIN with essentials.bills for bill info on each vote
- Default limit: 50 (votes table is 121k rows)
- Support `?limit=N` from route (max 100)
- ORDER BY vote_date DESC (most recent first)
- Return array of vote objects with: bill_title, bill_number, vote_value, vote_date

For all functions:
- Check 38-01-SUMMARY for exact table names, column names, and FK relationships
- Use explicit field whitelists in SELECT — never SELECT *
- Null string fields -> empty string "" (Go convention)
- If the linking table doesn't exist (e.g., no legislative_sessions table), return [] and add a comment noting the table doesn't exist in the schema

Import pool from db.ts.
