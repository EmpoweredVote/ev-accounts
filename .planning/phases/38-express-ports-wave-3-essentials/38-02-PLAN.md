**1. Add `getRepresentativesByAddress(address: string): Promise<AddressSearchResult>`**

This function implements the Census Geocoder -> PostGIS geofence -> politician list flow:

a. Call `geocodeAddress(address)` from geocodingService.ts to get { lat, lng }.
b. Query PostGIS to find matching geofence boundaries:
   - Use the join path discovered in Plan 01 SUMMARY (read 38-01-SUMMARY.md for exact column names)
   - CRITICAL coordinate order: `ST_MakePoint($1, $2)` where $1=longitude (Census x), $2=latitude (Census y)
   - Use `public.ST_Covers(geom, public.ST_SetSRID(public.ST_MakePoint($1::float8, $2::float8), 4326))` — must prefix PostGIS functions with `public.`
   - Join from geofence_boundaries -> districts -> offices -> politicians (exact join columns from 38-01-SUMMARY)
   - Filter: politicians.is_active = true
c. If no boundaries match: return `{ politicians: [], jurisdiction: null }`
d. Build jurisdiction metadata from the matched boundary/district data
e. Map politician rows to Go-parity response shape (see getPoliticiansFlatList below for field mapping)

Import geocodeAddress and GeocodingError from geocodingService.ts. Let GeocodingError propagate to the route handler (don't catch here).

**1. Create `backend/src/routes/essentials.ts` — new unified essentials router:**

This router handles `/api/essentials/*` routes that are NOT politician-specific.

```
GET /address-search?address=... — address to politician lookup
```

Route implementation for address-search:
- Apply `optionalAuth` middleware
- Extract `address` from `req.query.address` as string. If missing, return 422 `{ code: 'VALIDATION_ERROR', message: 'address query parameter is required' }`
- Extract userId from `(req as AuthenticatedRequest).userId` (undefined if unauthenticated)
- Call `getRepresentativesByAddress(address)` from essentialsService
- Determine data_level: userId ? 'connected' : 'inform'
- Return 200 with `{ ...result, data_level }`
- Error handling:
  - GeocodingError with code 'ADDRESS_NOT_FOUND' -> 422 `{ code: 'ADDRESS_NOT_FOUND', message: err.message }`
  - GeocodingError with code 'PO_BOX_REJECTED' -> 422 `{ code: 'PO_BOX_REJECTED', message: err.message }`
  - GeocodingError with code 'GEOCODER_UNAVAILABLE' -> 503 `{ code: 'GEOCODER_UNAVAILABLE', message: 'Address lookup temporarily unavailable.' }`
  - Other errors -> 500 `{ code: 'INTERNAL_ERROR', message: 'An unexpected error occurred' }`

Import: optionalAuth, AuthenticatedRequest from middleware/auth.ts; getRepresentativesByAddress from essentialsService; GeocodingError from geocodingService.
