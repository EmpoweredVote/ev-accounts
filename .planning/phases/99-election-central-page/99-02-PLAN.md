## Objective

Build an Election Central page in `essentials.empowered.vote` that shows upcoming elections, races, and candidates for a given address.

## Tasks

### Task 1 — Add `fetchElectionsByAddress()` to `essentials/src/lib/api.jsx`
type: auto

Add a new exported function `fetchElectionsByAddress(address)` to the essentials API lib.

```js
export async function fetchElectionsByAddress(address) {
  try {
    const res = await publicFetch(
      `/essentials/elections-by-address?address=${encodeURIComponent(address)}`
    );
    if (!res) return { elections: [], error: null };
    if (res.status === 503) return { elections: [], error: 'geocoder_unavailable' };
    if (!res.ok) return { elections: [], error: `${res.status}` };
    const data = await res.json();
    return { elections: Array.isArray(data.elections) ? data.elections : [], error: null };
  } catch (err) {
    console.error('fetchElectionsByAddress error:', err);
    return { elections: [], error: err.message };
  }
}
```

Note: uses `publicFetch` (not `apiFetch`) because elections data is public — no auth required.

**Done criteria:** Function exported from api.jsx, uses publicFetch, handles 503.

### Task 2 — Create `essentials/src/pages/Elections.jsx`
type: auto

Create a new Elections page component:

**Address input**: A simple controlled input + submit button (reuse the address UX pattern from Landing.jsx). On first load show the address form. On submit, call `fetchElectionsByAddress()` and render results.

**Loading**: Show "Finding elections near your address..." text while fetching.

**Empty state**: "No upcoming elections found for this address." if elections array is empty.

**Elections list**: For each election, show:
- Election name + date formatted as "Month Day, Year"
- Election type label ("Primary Election" / "General Election")
- Races grouped by jurisdiction category using `classifyCategory(district_type)` from `../lib/classify`
- Category headers: "Federal", "State", "Local"
- For each race: position_name, seats (if > 1 show "X seats"), then candidates

**Candidate display**: For each candidate:
- Photo thumbnail (img tag) or initials circle if no photo_url
- Full name
- "Incumbent" badge if `is_incumbent === true`
- Wrap in a `<Link to={/candidate/${politician_id}}>` if politician_id is set, else just a div

**Antipartisan**: Never show party. If `election_type === 'primary'`, show "Primary Election" as the badge — no party name.

Use Tailwind CSS classes consistent with existing pages. Import `Layout` from `../components/Layout`.

**Done criteria:** File exists, compiles without errors, renders address form → elections list flow.
