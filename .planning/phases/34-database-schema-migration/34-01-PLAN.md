<task type="auto">
  <name>Task 1: Enumerate schemas, tables, and user-linked columns</name>
  <files>No files created — queries only</files>
  <action>
Run the following SQL queries against production via Supabase MCP (`execute_sql`):

**Query 1 — Schema existence check:**
```sql
SELECT schema_name
FROM information_schema.schemata
WHERE schema_name IN ('essentials','meetings','staging','treasury','transparent_motivations','compass')
ORDER BY schema_name;
```

**Query 2 — Full table inventory with RLS status:**
```sql
SELECT schemaname, tablename, rowsecurity
FROM pg_tables
WHERE schemaname IN ('essentials','meetings','staging','treasury','transparent_motivations','compass')
ORDER BY schemaname, tablename;
```

**Query 3 — User-linked column detection:**
```sql
SELECT table_schema, table_name, column_name, data_type
FROM information_schema.columns
WHERE table_schema IN ('essentials','meetings','staging','treasury','transparent_motivations','compass')
  AND (column_name ILIKE '%user_id%' OR column_name ILIKE '%user_uuid%' OR column_name = 'uid')
ORDER BY table_schema, table_name;
```

**Query 4 — Row counts per table (use dynamic SQL):**
```sql
DO $$
DECLARE
  r RECORD;
  cnt bigint;
BEGIN
  CREATE TEMP TABLE IF NOT EXISTS _row_counts (schema_name text, table_name text, row_count bigint);
  TRUNCATE _row_counts;
  FOR r IN
    SELECT schemaname, tablename
    FROM pg_tables
    WHERE schemaname IN ('essentials','meetings','staging','treasury','transparent_motivations','compass')
    ORDER BY schemaname, tablename
  LOOP
    EXECUTE format('SELECT count(*) FROM %I.%I', r.schemaname, r.tablename) INTO cnt;
    INSERT INTO _row_counts VALUES (r.schemaname, r.tablename, cnt);
  END LOOP;
END $$;
SELECT * FROM _row_counts ORDER BY schema_name, table_name;
```

Record all results. Group tables into three categories:
1. **Public read** (essentials, meetings, treasury, transparent_motivations, compass reference tables) — no user_id column
2. **Owner read** (any table with user_id/user_uuid column in compass or other schemas)
3. **Authenticated read** (all staging tables)

If Query 4 fails due to temp table permissions, run individual `SELECT count(*) FROM schema.table` for each table instead.

Run one more verification query:

**Query 5 — Current GRANT state:**
```sql
SELECT grantee, table_schema, privilege_type, COUNT(*) as table_count
FROM information_schema.table_privileges
WHERE table_schema IN ('essentials','meetings','staging','treasury','transparent_motivations','compass')
  AND grantee IN ('anon', 'authenticated', 'service_role')
GROUP BY grantee, table_schema, privilege_type
ORDER BY table_schema, grantee, privilege_type;
```

This tells us whether any GRANTs already exist (the Go backend may have set some up). If GRANTs already exist, the migration files need to account for that (idempotent GRANT is fine — granting an already-granted privilege is a no-op in PostgreSQL).

Also check for any existing policies (should be none):
```sql
SELECT schemaname, tablename, policyname, roles, cmd
FROM pg_policies
WHERE schemaname IN ('essentials','meetings','staging','treasury','transparent_motivations','compass')
ORDER BY schemaname, tablename;
```

Document all findings in the SUMMARY with:

- User-linked tables and their user_id column names
- Existing GRANTs (if any)
- Existing policies (should be empty)
- Row count totals
- Any surprises or discrepancies from expected counts
