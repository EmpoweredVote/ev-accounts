<objective>
Rename the treasury City model to Municipality, add entity_type and fiscal_year_start_month fields, fix the budget unique index to three columns, and update all handlers and routes.

Purpose: Clears the schema gate for multi-jurisdiction data (SCHM-01, SCHM-02, SCHM-03). Without the three-column index, importing multiple dataset types for the same city/year causes silent duplicates. Without entity_type, counties and townships cannot be distinguished from cities.

Output: Updated Go backend code that compiles, a SQL rename script for pre-deployment, and correct indexes declared in setup.go.
</objective>
