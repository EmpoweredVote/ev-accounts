<!-- JSON file format (from treasury-tracker/public/data/) -->
Operating budget JSON shape:
```json
{
  "metadata": {
    "cityName": "Bloomington",
    "fiscalYear": 2025,
    "population": 79168,
    "totalBudget": 205848964.9,
    "generatedAt": "2026-01-12T01:27:34.646Z",
    "hierarchy": ["primary_function", "priority", "service", "fund", "item_category"],
    "dataSource": "data/operating_budget-all.csv"
  },
  "categories": [{ "name": "...", "amount": ..., "subcategories": [...], "line_items": [...] }]
}
```

Revenue JSON — same shape, metadata has `totalRevenue` field alongside `totalBudget`.

Salary JSON — metadata has `totalCompensation` (NOT `totalBudget`) and `totalEmployees`, `avgCompensation`. The `totalBudget` field IS present and has the same value as `totalCompensation`.

Linked budget files (`budget-YYYY-linked.json`) have the same shape but categories may include `linkedTransactions`. These should NOT be imported — use the non-linked `budget-YYYY.json` files only.

    **ImportBudgets function logic:**

    1. Define the file-to-dataset mapping:
       ```go
       datasets := []struct {
           prefix      string
           datasetType string
       }{
           {"budget", "operating"},
           {"revenue", "revenue"},
           {"salaries", "salaries"},
       }

    2. For each dataset type and year:

       - Skip linked files (only use `budget-YYYY.json`, not `budget-YYYY-linked.json`)
       - Read and unmarshal the JSON file into `budgetJSON`
       - Determine totalBudget: use `metadata.totalBudget` if non-zero, else `metadata.totalCompensation`, else `metadata.totalRevenue` (per Pitfall 5 from RESEARCH.md — salary files have totalCompensation as the primary field, but totalBudget is also present with the same value)
       - If `config.DryRun`, log what would be imported and continue

    3. For each file, in a transaction:

       - Create Budget with:
         - `MunicipalityID: municipality.ID`
         - `FiscalYear: metadata.FiscalYear`
         - `DatasetType: datasetType` (from the mapping, not from JSON — JSON may not have it)
         - `TotalBudget: totalBudget` (resolved above)
         - `FiscalYearStartMonth: 1` (Indiana = January)
         - `DataSource: metadata.DataSource`
         - `Hierarchy: metadata.Hierarchy`
       - Call `importCategories(tx, budget.ID, nil, data.Categories, 0)` — reuse the existing function from handlers.go
       - Commit transaction
       - Increment `result.Inserted`

    4. Return result with totals.

    **Important:** The function uses `db.DB` directly (not HTTP), per D-01. Import `"github.com/EmpoweredVote/EV-Backend/internal/db"`.

        jsonDir := "treasury-tracker/public/data"
        dryRun := false
        for _, arg := range os.Args[2:] {
            switch {
            case arg == "--dry-run":
                dryRun = true
            case strings.HasPrefix(arg, "--data-dir="):

            }
        }
        result, err := treasury.ImportBudgets(treasury.ImportBudgetsConfig{
            DataDir: jsonDir,
            DryRun:  dryRun,
        })
        if err != nil {
            log.Fatal("import-budgets failed: ", err)
        }
        fmt.Printf("Import complete: %d files processed, %d budgets inserted, %d skipped\n",
            result.FilesProcessed, result.Inserted, result.Skipped)
        if len(result.Errors) > 0 {
            fmt.Printf("Errors (%d):\n", len(result.Errors))
            for _, e := range result.Errors {
                fmt.Printf("  - %s\n", e)
            }
        }
        os.Exit(0)
    ```
