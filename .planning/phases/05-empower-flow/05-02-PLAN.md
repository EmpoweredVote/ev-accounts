**Preflight check** (`runPreflight`):
```typescript
export async function runPreflight(userId: string): Promise<PreflightResult>
```
Where `PreflightResult` is:
```typescript
interface PreflightFailure {
  code: string;
  message: string;
  [key: string]: unknown;  // allows threshold, current, etc.
}

interface PreflightSuccess {
  eligible: true;
  summary: {
    legal_name: string;
    compass_completeness: { required: number; answered: number; percent: number; complete: boolean };
    slug_preview: string;
  };
  demotion_context?: {
    previously_demoted: true;
    demoted_at: string;
    demotion_reason: unknown;
    original_slug: string;
  };
}

interface PreflightFailed {
  eligible: false;
  failures: PreflightFailure[];
  demotion_context?: {
    previously_demoted: true;
    demoted_at: string;
    demotion_reason: unknown;
  };
}

type PreflightResult = PreflightSuccess | PreflightFailed;
```

Implementation:
1. Fetch connected_profiles for the user (via pool query): `SELECT id, verification_status, legal_name, candidate_role FROM connect.connected_profiles WHERE user_id = $1`. If no row, throw an error (requireConnected middleware should have caught this, but defense in depth).
2. Fetch existing empowered_profiles row (if any, including demoted): `SELECT id, is_active, demoted_at, demotion_reason, candidate_page_slug FROM empower.empowered_profiles WHERE user_id = $1`.
3. Build demotion context if an inactive empowered_profiles row exists.
4. Collect ALL failures into an array (do NOT short-circuit):
   - If `verification_status !== 'verified'` => `{ code: 'NOT_VERIFIED', message: 'Connected account must be verified' }`
   - If `candidate_role IS NULL` => `{ code: 'ROLE_NOT_SET', message: 'Candidate role must be set before empowerment' }`
   - If `legal_name IS NULL` => `{ code: 'LEGAL_NAME_MISSING', message: 'Legal name is required for empowerment' }`
   - If `candidate_role IS NOT NULL`, call `getCompassCompleteness(userId, candidate_role)`. If `!complete` => `{ code: 'CALIBRATION_INCOMPLETE', message: 'Compass calibration is not complete for your role', threshold: result.required, current: result.answered }`
5. If failures.length > 0, return `{ eligible: false, failures, demotion_context }`.
6. If eligible:
   - For demoted users with an existing slug: reserve the ORIGINAL slug (not a new one). Store via `cache.set(`slug_reservation:${userId}`, existingSlug, 3600)`. Set slug_preview to the original slug.
   - For fresh users: call `reserveSlug(userId, legalName!)` to generate and reserve a new slug.
   - Return `{ eligible: true, summary: { legal_name, compass_completeness, slug_preview }, demotion_context }`.

1. Look up the reserved slug: `getReservedSlug(userId)`. If null, throw with code `PREFLIGHT_EXPIRED`.
2. Fetch connected_profiles row: `SELECT id, legal_name FROM connect.connected_profiles WHERE user_id = $1`.

5. Record consent via `recordConsent(userId, consentedItems)`.
6. Clear the slug reservation: `cache.del(`slug_reservation:${userId}`)`.
7. Return the empowered_profiles data from the RPC result.

**Create `backend/src/routes/empower.ts`:**

Imports:
```typescript
import { Router, Response } from 'express';

```

Three routes, all using `requireAuth` + `requireConnected` middleware chain:

**POST /preflight** (`requireAuth, requireConnected`):
1. Call `runPreflight(authReq.userId)`.
2. If `result.eligible === false`, return 200 with the result (not an error status — the preflight succeeded in telling the user they're ineligible). The response body is `{ eligible: false, failures: [...], demotion_context?: {...} }`.
3. If eligible, return 200 with `{ eligible: true, summary: {...}, demotion_context?: {...} }`.
4. Catch errors: 500 with `{ code: 'INTERNAL_ERROR', message: 'An unexpected error occurred' }`.

**POST /confirm** (`requireAuth, requireConnected`):
Zod schema for request body:
```typescript
const ConfirmSchema = z.object({
  consent: z.object({
    legal_name_public: z.literal(true),
    compass_stances_public: z.literal(true),
    platform_terms: z.literal(true),
  }),
});
```
1. Validate body with `ConfirmSchema.safeParse(req.body)`. On failure, return 422 with `{ code: 'CONSENT_INCOMPLETE', message: 'All three consent items must be explicitly accepted' }`.
2. Call `confirmEmpowerment(userId, ['legal_name_public', 'compass_stances_public', 'platform_terms'])`.
3. On success, return 201 with `{ empowered: true, profile: result.empowered_profile }`.
4. Catch errors:
   - If error message or code contains `PREFLIGHT_EXPIRED`, return 409 with `{ code: 'PREFLIGHT_EXPIRED', message: 'Preflight has expired. Please run preflight again.' }`.
   - Otherwise, 500 with `{ code: 'INTERNAL_ERROR', message: 'Empowerment failed' }`.

**POST /demote** (`requireAuth, requireConnected`):
Zod schema (optional body):
```typescript
const DemoteSchema = z.object({
  reason: z.object({
    lapsed_topic_ids: z.array(z.string()).optional(),
    lapsed_at: z.string().optional(),
    triggered_by: z.enum(['cron', 'admin', 'self']).optional(),
  }).optional(),
});
```
1. Validate body (may be empty/undefined — default to no reason). If present but invalid, return 422.
2. Call `executeDemotion(userId, result.data?.reason)`.
3. Return 200 with `{ demoted: true }`.
4. Catch errors: 500 with `{ code: 'INTERNAL_ERROR', message: 'Demotion failed' }`.
