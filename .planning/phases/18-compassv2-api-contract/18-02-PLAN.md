  <name>Task 1: Update Zod value schema to accept decimal compass values</name>
  <files>backend/src/routes/compass.ts</files>
  <action>
In `backend/src/routes/compass.ts`, update the `postAnswerSchema` Zod object's `value` field.

Current:
```typescript
value: z.number().int().min(1).max(5),
```

Replace with:
```typescript
value: z.number().multipleOf(0.5).min(0.5).max(5.5),
```

This change:
- Removes `.int()` — allows decimal values
- Changes `.min(1)` to `.min(0.5)` — allows extreme write-in placement at 0.5
- Changes `.max(5)` to `.max(5.5)` — allows extreme write-in placement at 5.5
- Adds `.multipleOf(0.5)` — only 0.5-increment values are valid (prevents arbitrary decimals like 1.3)

No other schema changes needed. `topic_id`, `write_in_text`, and `inverted` are unchanged.

Run `cd backend && npx tsc --noEmit` after this change to confirm no type errors introduced.

In `backend/src/routes/compass.ts`, change the following five routes from `requireAuth` to `optionalAuth`, and add short-circuit guards at the start of each handler. All other logic in each handler is preserved exactly.

**Route 1: GET /answers**

Change middleware:
```typescript
router.get('/answers', requireAuth, async ...
```
to:
```typescript
router.get('/answers', optionalAuth, async ...
```

Add as the FIRST line of the handler body (before the try block):
```typescript
if (!authReq.userId) { res.status(200).json([]); return; }
```

**Route 2: POST /answers/batch**

Change `requireAuth` to `optionalAuth`.

Add as the FIRST line of the handler body (before the Zod parse):
```typescript
if (!authReq.userId) { res.status(200).json([]); return; }
```

**Route 3: GET /selected-topics**

Change `requireAuth` to `optionalAuth`.

Add as the FIRST line of the handler body (before the try block):
```typescript
if (!authReq.userId) { res.status(200).json({ topic_ids: [] }); return; }
```

Note: unauthenticated users get `{ topic_ids: [] }`, NOT a 403 NOT_CONNECTED response.

**Route 4: PUT /selected-topics**

Change `requireAuth` to `optionalAuth`.

```typescript
if (!authReq.userId) { res.status(200).json({ topic_ids: [] }); return; }
```

Note: unauthenticated users get `{ topic_ids: [] }`, NOT a 403 or validation error.
