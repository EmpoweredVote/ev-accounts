## Spacing Scale

Declared values (multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps within overlay row, icon internal padding |
| sm | 8px | Coverage card internal padding (horizontal), tooltip padding |
| md | 16px | Coverage card internal padding (vertical), section gap between coverage cards and divider |
| lg | 24px | Gap between coverage card row and "or search by address" divider |
| xl | 32px | Gap between landing page sections (coverage block → address input block) |
| 2xl | 48px | Page top padding (`py-16` = 64px — nearest token is 2xl/3xl) |
| 3xl | 64px | Page-level vertical padding (existing `py-16` class preserved) |

Exceptions:
- Icon overlay bottom/left offset: 4px (xs) — tight photo-corner positioning
- Tooltip offset from anchor: 6px — floating-ui `offset(6)` middleware
- Icon size: 14px — not a spacing value, a dimension (defined in Pattern section)
- Touch target for icon badges: minimum 24px hit area (icons are 14px visual + 5px padding each side)

Source: RESEARCH.md Pattern 2 (overlay CSS), existing Landing.jsx spacing classes, template default scale

## Interaction Contracts

### Coverage Cards (Landing Page)

- **Trigger:** Click or keyboard Enter on either coverage card
- **Action:** `navigate('/results?q={encodeURIComponent(address)}')` using React Router
- **Addresses:**
  - Monroe County, IN: `100 W Kirkwood Ave, Bloomington, IN 47404`
  - Los Angeles County, CA: `500 W Temple St, Los Angeles, CA 90012`
- **Hover state:** Box shadow deepens (`shadow-md` → `shadow-lg`), cursor pointer
- **Focus state:** Teal focus ring (`ring-2 ring-[var(--ev-teal)]`) — keyboard accessible
- **Layout:** Two cards side-by-side on sm+, stacked on mobile. Each card: county name (line 1, 16px semibold), state name (line 2, 14px regular)

Source: CONTEXT.md D-01/D-02/D-04, RESEARCH.md Pattern 4

### "Browse by location →" Link

- **Position:** Below coverage cards row, above the "or search by address" divider
- **Action:** `navigate('/results?mode=browse')` — Results.jsx reads `?mode=browse` on mount and calls `setSearchMode('browse')`
- **Style:** 14px, weight 500, color var(--ev-teal), underline on hover
- **No modal or overlay** — full page navigation to Results

Source: CONTEXT.md D-05, RESEARCH.md Pattern 4

### Icon Tooltips (Politician Cards)

- **Desktop trigger:** Mouse hover on icon badge
- **Mobile trigger:** Tap on icon badge; tap-away dismisses (useDismiss from @floating-ui/react)
- **Keyboard:** Focus on icon span triggers tooltip (useFocus hook)
- **ARIA:** Each icon `<span>` has `aria-label={tooltip text}`. Tooltip div has `role="tooltip"` via useRole hook
- **Tooltip text per icon:**
  - BallotIcon: `"On your ballot — {Mon YYYY}"` (date from ballot.termEndDate formatted as `en-US` short month + year)
  - CompassIcon: `"Compare your views"`
  - BranchIcon: `"{Branch} branch"` where Branch is "Executive", "Legislative", or "Judicial"
- **Icon visibility rules:**
  - BallotIcon: shown if `getSeatBallotStatus()` returns non-null
  - CompassIcon: shown if `politicianIdsWithStances.has(String(pol.id))`
  - BranchIcon: shown if `getBranch(districtType, officeTitle)` returns non-null
- **Rendering order:** BallotIcon → CompassIcon → BranchIcon (left to right in overlay strip)
- **Icon size:** 14px (width + height)

Source: CONTEXT.md D-06/D-07/D-08/D-09/D-10, RESEARCH.md Pattern 2/3

### Election Page Race Grouping

- **Old:** CategorySection per position+party combination (e.g., "Mayor — Democratic Primary", "Mayor — Republican Primary" as separate heavy headers)
- **New:** CategorySection per position only (e.g., "Mayor"). Within each position group, primary elections display a lightweight sub-label (e.g., "Democratic Primary" in 12px gray-500) before that party's candidates. General election candidates all appear together with no party sub-label
- **seededShuffle** preserved for antipartisan ordering within each group
- **Party label** is text only, never colored with party-affiliated colors

Source: CONTEXT.md D-11/D-12/D-14, REQUIREMENTS.md VIS-04, antipartisan principle

## Accessibility Contract

| Requirement | Implementation |
|-------------|---------------|
| WCAG 2.1 AA contrast on icons | Icon colors use teal-700/500/600 on rgba(255,255,255,0.82) — all pass 3:1+ minimum for non-text |
| Tooltip keyboard access | `useFocus` hook on icon span — tooltip appears on keyboard focus |
| Tooltip ARIA | `role="tooltip"` + icon `aria-label={tooltip text}` |
| Coverage card keyboard | `<button>` element (not div) — natively focusable, Enter activates |
| "Browse by location" keyboard | `<a>` or `<button>` element — natively focusable |
| Mobile tooltip dismissal | `useDismiss` hook handles tap-away |
| Seeded shuffle preserved | Antipartisan ordering unchanged on election page |

Source: CONTEXT.md D-08, REQUIREMENTS.md VIS-05
