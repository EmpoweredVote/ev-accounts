**Step 2: Create `essentials/src/utils/branchType.js`**

Export a single function `getBranch(districtType, officeTitle)` that returns `'Executive'`, `'Legislative'`, `'Judicial'`, or `null`.

Mapping (per D-10):
- `NATIONAL_EXEC`, `STATE_EXEC`, `LOCAL_EXEC` → `'Executive'`
- `NATIONAL_UPPER`, `NATIONAL_LOWER`, `STATE_UPPER`, `STATE_LOWER`, `LOCAL`, `SCHOOL` → `'Legislative'`
- `JUDICIAL` → `'Judicial'`
- `COUNTY` → title-based heuristic:
  - If officeTitle matches `/council|commissioner/i` → `'Legislative'`
  - If officeTitle matches `/sheriff|clerk|auditor|assessor|recorder|coroner|treasurer/i` → `'Executive'`
  - Otherwise → `null` (no branch icon shown)
- All other districtType values → `null`

**Step 3: Create `essentials/src/components/IconOverlay.jsx`**

Build a component that renders a semi-transparent strip of icon badges with @floating-ui/react tooltips. The component accepts these props:

```jsx
IconOverlay({ ballot, hasStances, branch })
```

Where:
- `ballot` — object `{ onBallot, termEndDate }` or null (from getSeatBallotStatus)
- `hasStances` — boolean (from politicianIdsWithStances Set)
- `branch` — string `'Executive'`/`'Legislative'`/`'Judicial'` or null (from getBranch)

If all three are falsy, render nothing (return null).

Internal `IconWithTooltip` sub-component pattern:
- Import `useFloating, useHover, useFocus, useDismiss, useRole, useInteractions, FloatingPortal, offset, flip, shift, autoUpdate` from `@floating-ui/react`
- Each icon wrapped in `<span>` with `ref={refs.setReference}`, `aria-label={tooltip}`, `tabIndex={0}`, `style={{ display: 'inline-flex', padding: '5px' }}` (5px padding gives 24px touch target on 14px icon)
- `useFloating` config: `middleware: [offset(8), flip(), shift({ padding: 4 })]`, `whileElementsMounted: autoUpdate`
- `useHover(context)` for desktop hover
- `useFocus(context)` for keyboard focus
- `useDismiss(context)` for mobile tap-away
- `useRole(context, { role: 'tooltip' })` for ARIA
- Tooltip `<div>` inside `<FloatingPortal>`: `style={{ ...floatingStyles, zIndex: 70, background: '#2F3237', color: '#EBEDEF', padding: '4px 8px', borderRadius: '6px', fontSize: '14px', fontFamily: "'Manrope', sans-serif", pointerEvents: 'none', whiteSpace: 'nowrap' }}`
- Tooltip `role="tooltip"` applied via getFloatingProps

Outer container div style:
```javascript
{
  position: 'absolute',
  bottom: 4,
  left: 4,
  display: 'flex',
  gap: 4,
  alignItems: 'center',
  padding: 4,
  background: 'rgba(255,255,255,0.82)',
  borderRadius: 4,
  zIndex: 1,
}
```

Icon rendering order (left to right): BallotIcon, CompassIcon, BranchIcon.
- BallotIcon: shown if `ballot` is truthy. Color: `#003E4D`. Tooltip: `"On your ballot — {Mon YYYY}"` where date = `ballot.termEndDate.toLocaleDateString('en-US', { month: 'short', year: 'numeric' })`.
- CompassIcon: shown if `hasStances` is true. Color: `#00657C`. Tooltip: `"Compare your views"`.
- BranchIcon: shown if `branch` is truthy. Color: `#005366`. Tooltip: `"{branch} branch"` (e.g. "Executive branch").

All icons rendered at `size={14}`.
