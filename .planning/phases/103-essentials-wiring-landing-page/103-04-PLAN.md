Create `ev-accounts/backend/scripts/auditHeadshots.ts` following the established script pattern from `audit-is-appointed.ts`.

**Imports and setup:**
```typescript
import dotenv from 'dotenv';
import path from 'path';
import { fileURLToPath } from 'url';
import pg from 'pg';

const __filename = fileURLToPath(import.meta.url);
const __dirname = path.dirname(__filename);
dotenv.config({ path: path.resolve(__dirname, '..', '.env') });

const pool = new pg.Pool({ connectionString: process.env.DATABASE_URL });
```

**SQL query** — fetch all politicians with optional image join:
```sql
SELECT p.id, p.first_name, p.last_name, pi.url
FROM essentials.politicians p
LEFT JOIN essentials.politician_images pi ON pi.politician_id = p.id AND pi.type = 'default'
ORDER BY p.id
```

**CSV header** (first line of output):
```
politician_id,name,issue,url,details
```

**Four checks (per D-17):**

1. **Missing headshots** — politicians where `pi.url IS NULL`:
   - Output row: `{id},"{first_name} {last_name}",missing_headshot,,no image record`
   - This check runs inline during the query result iteration — no HTTP request needed.

2. **Broken CDN URLs** — for each politician with a URL, `fetch(url, { method: 'HEAD' })` with a 10-second timeout via `AbortController`:
   - If response status is not 200, output: `{id},"{name}",broken_url,{url},HTTP {status}`
   - If fetch throws (timeout or network error), output: `{id},"{name}",broken_url,{url},timeout or error: {message}`
   - Process URLs in batches of 20 concurrent requests to avoid overwhelming CDN.

3. **File size outliers** — from the HEAD response `content-length` header:
   - If content-length > 500000 (500KB), output: `{id},"{name}",large_file,{url},size={contentLength} bytes`
   - If content-length < 2000 (2KB), output: `{id},"{name}",tiny_file,{url},size={contentLength} bytes`
   - If content-length header is missing, skip this check for that URL.

4. **Image dimensions/aspect ratio** — fetch full image bytes (GET request), parse PNG/JPEG headers:
   
   **PNG dimension parsing** (per RESEARCH.md):
   ```typescript
   function parsePngDimensions(buf: Buffer): { width: number; height: number } | null {
     const PNG_SIG = Buffer.from([137, 80, 78, 71, 13, 10, 26, 10]);
     if (buf.length < 24 || !buf.subarray(0, 8).equals(PNG_SIG)) return null;
     return { width: buf.readUInt32BE(16), height: buf.readUInt32BE(20) };
   }
   ```
   
   **JPEG dimension parsing:**
   ```typescript
   function parseJpegDimensions(buf: Buffer): { width: number; height: number } | null {
     for (let i = 0; i < buf.length - 8; i++) {
       if (buf[i] === 0xFF && (buf[i + 1] === 0xC0 || buf[i + 1] === 0xC2)) {
         return { height: buf.readUInt16BE(i + 5), width: buf.readUInt16BE(i + 7) };
       }
     }
     return null;
   }
   ```
   
   **Dimension checks** (only if parsing succeeds):
   - Landscape (width > height): `{id},"{name}",landscape,{url},width={w} height={h}`
   - Too small (height < 100): `{id},"{name}",too_small,{url},width={w} height={h}`
   - Bad aspect ratio (width/height outside 0.5 to 1.2): `{id},"{name}",bad_aspect_ratio,{url},width={w} height={h} ratio={ratio.toFixed(2)}`

   Only fetch full image bytes for URLs that passed the HEAD check (status 200). Process dimension checks in batches of 10 concurrent requests to manage memory.

**Batching strategy:**
- First pass: HEAD requests in batches of 20 (checks 2 and 3)
- Second pass: GET requests for dimension check in batches of 10 (check 4), only for URLs that returned 200 in the HEAD pass

**Output:** All CSV rows go to `process.stdout`. Progress messages go to `process.stderr` (e.g., `console.error('Checking ${rows.length} politicians...')`).

**Cleanup:** Call `await pool.end()` before process exit.

**Support `--dry-run` flag:** If `process.argv.includes('--dry-run')`, only run the SQL query and report counts, skip HTTP requests. Output: `Found {N} politicians, {M} with images, {N-M} missing headshots. Dry run — skipping HTTP checks.`

**CSV value escaping:** Wrap name values in double quotes to handle commas in names. For URL and details fields, no quotes needed (they don't contain commas).
