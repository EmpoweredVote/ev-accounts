   - `0` = absent — field/feature not present at all.

   - `2` = present and usable — field is substantive enough for a voter to act on.
   - `3` = comprehensive — full depth (e.g. bio + sourced quotes + legislative record + photo + contact).

   - Worked example: score "candidate photo" for BallotReady at 200 W Kirkwood — if every candidate card shows a high-res headshot → 3; if only some candidates show placeholder silhouettes → 1; if no images render → 0; if access was blocked → `blocked`.

   1. Race coverage vs baseline (ratio of baseline races surfaced for the primary address)
   2. Candidate photo
   3. Candidate bio / biography prose
   4. Candidate contact info (email, phone, website, mailing)
   5. Stance / issue position data
   6. Candidate quotes / Q&A / direct statements
   7. Legislative record (votes, bills, committee memberships — for sitting officials)
   8. Geofence / address precision (does moving the address change the race list correctly?)
   9. Data freshness (last-updated signals; how old the newest candidate record is)
   10. Antipartisan framing (absence of party labels, endorsements, interest-group ratings — inverted: higher score means MORE antipartisan)

   State: "Up to 5 derived-extra dimensions may be added during execution (plan 07) if a competitor surfaces a feature outside this core 10. Derived extras are noted as such in the matrix."
