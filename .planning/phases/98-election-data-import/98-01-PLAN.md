**Two-pass incumbent matching (per D-05, D-06, D-07):**

Implement as an async function `matchCandidate(pool, candidateFullName, raceOfficeId)` returning `{ politicianId: string | null, isIncumbent: boolean, matchType: 'incumbent' | 'cross-office' | 'ambiguous' | 'none' }`:

Pass 1 — Office-based match:
```sql
SELECT p.id, p.full_name FROM essentials.offices o
JOIN essentials.politicians p ON p.id = o.politician_id
WHERE o.id = $1 AND p.is_active = true
```
If `officeMatch.rows[0]?.full_name.toLowerCase() === candidateFullName.toLowerCase()` → return `{ politicianId: id, isIncumbent: true, matchType: 'incumbent' }`

Pass 2 — Name-based match:
```sql
SELECT id, full_name FROM essentials.politicians
WHERE LOWER(full_name) = LOWER($1) AND is_active = true LIMIT 2
```
If exactly 1 match → return `{ politicianId: id, isIncumbent: false, matchType: 'cross-office' }` (per D-07)
If 2+ matches → log warning `"POSSIBLE MATCH -- needs verification: {name} matches {count} politicians"` (per D-06), return `{ politicianId: null, isIncumbent: false, matchType: 'ambiguous' }`
If 0 matches → return `{ politicianId: null, isIncumbent: false, matchType: 'none' }`

**Office ID lookup for races:**
For each race position_name, attempt to find the matching `essentials.offices` record:
```sql
SELECT o.id FROM essentials.offices o
JOIN essentials.districts d ON d.id = o.district_id
WHERE d.state = $1
  AND (o.title ILIKE '%' || $2 || '%' OR d.label ILIKE '%' || $2 || '%')
LIMIT 1
```
Where `$2` is a simplified district label (e.g., `'District 40'` extracted from position_name). Log unmatched offices in dry-run output but do not fail — `office_id` is nullable on races.

**Election/race upsert logic (per D-03, Pitfall 3):**
Use `INSERT ... ON CONFLICT` with the constraints from migration 044:
```sql
INSERT INTO essentials.elections (name, election_date, election_type, jurisdiction_level, state)
VALUES ($1, $2, $3, $4, $5)
ON CONFLICT (name, election_date, state) DO UPDATE SET updated_at = now()
RETURNING id
```
```sql
INSERT INTO essentials.races (election_id, office_id, position_name, primary_party, seats)
VALUES ($1, $2, $3, $4, $5)
ON CONFLICT (election_id, position_name, primary_party) DO UPDATE SET
  office_id = COALESCE(EXCLUDED.office_id, essentials.races.office_id),
  updated_at = now()
RETURNING id
```
Candidate upsert per D-03 — upsert by `external_id`, preserve manual edits:
```sql
INSERT INTO essentials.race_candidates
  (race_id, full_name, first_name, last_name, is_incumbent, candidate_status, source, external_id, last_verified_at, politician_id)
VALUES ($1,$2,$3,$4,$5,$6,$7,$8,now(),$9)
ON CONFLICT (external_id) WHERE external_id IS NOT NULL
DO UPDATE SET
  full_name = EXCLUDED.full_name,
  is_incumbent = EXCLUDED.is_incumbent,
  candidate_status = EXCLUDED.candidate_status,
  last_verified_at = now()
```
