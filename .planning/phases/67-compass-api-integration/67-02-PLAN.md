Create a new file `essentials/src/contexts/CompassContext.jsx` that provides centralized auth and compass state to the entire Essentials app.

The context should:

1. **Create and export** a `CompassContext` via `createContext()` and a `useCompass()` hook via `useContext()`.

2. **Export a `CompassProvider` component** that wraps children and provides the following values:
   - `isLoggedIn` (boolean) — true if /auth/me returned a valid user
   - `userName` (string|null) — the username from /auth/me
   - `userAnswers` (array) — the user's compass answers `[{topic_id, value}]`, empty array if not logged in
   - `selectedTopics` (array) — the user's selected topic ID strings, empty array if not logged in
   - `allTopics` (array) — full topic list from fetchTopics()
   - `politicianIdsWithStances` (Set) — Set of politician UUID strings that have compass stances
   - `compassLoading` (boolean) — true while initial data is being fetched

3. **On mount (useEffect), fetch all data in parallel:**

```javascript
const API = import.meta.env.VITE_API_URL || "/api";

// Auth check — always runs
const authRes = await fetch(`${API}/auth/me`, { credentials: "include" });
// If 200, user is logged in; if 401 or error, not logged in

// Compass data — always runs (topics + politician stances are public-ish)
const [topics, polsWithStances] = await Promise.all([
  fetchTopics(),
  fetchPoliticiansWithStances(),
]);

// User-specific data — only if logged in
let answers = [];
let selected = [];
if (authRes.ok) {
  [answers, selected] = await Promise.all([
    fetchUserAnswers(),
    fetchSelectedTopics(),
  ]);
}
```

4. **Build politicianIdsWithStances as a Set:**
```javascript
const idSet = new Set(polsWithStances.map(p => String(p.id)));
```

5. **Memoize the context value** with useMemo to prevent unnecessary re-renders.

6. **Error handling:** Wrap the entire mount effect in try/catch. On any error, log it and set compassLoading to false. Individual fetch functions already return [] on error (from Plan 01), so partial failures are handled gracefully.

Import fetchTopics, fetchUserAnswers, fetchSelectedTopics, fetchPoliticiansWithStances from '../lib/compass'.

**Part A: Create AuthIndicator component**

Create `essentials/src/components/AuthIndicator.jsx`:

A small, minimal component that shows user initials when logged in and nothing when not.

```jsx
import { useCompass } from '../contexts/CompassContext';

export default function AuthIndicator() {
  const { isLoggedIn, userName } = useCompass();
  if (!isLoggedIn || !userName) return null;

  const initials = userName
    .split(' ')
    .map(s => s[0])
    .join('')
    .toUpperCase()
    .slice(0, 2) || userName[0]?.toUpperCase() || '?';

  return (
    <div
      style={{
        width: 32,
        height: 32,
        borderRadius: '50%',
        backgroundColor: '#00657c',
        color: '#fff',
        display: 'flex',
        alignItems: 'center',
        justifyContent: 'center',
        fontFamily: "'Manrope', sans-serif",
        fontWeight: 700,
        fontSize: 13,
        flexShrink: 0,
      }}
      title={userName}
    >
      {initials}
    </div>
  );
}
```

Per user decision: "small avatar/initials in nav bar right side when logged in" and "non-logged-in users see nothing in that spot (empty)".
