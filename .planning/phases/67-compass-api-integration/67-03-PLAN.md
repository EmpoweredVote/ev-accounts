  <files>essentials/src/components/CompassPreview.jsx</files>
  <action>
Create `essentials/src/components/CompassPreview.jsx` — a tooltip/popover component that shows a mini radar chart for a politician.

**Props:**
- `politicianId` (string) — politician UUID to fetch answers for
- `politicianName` (string) — for the title label
- `allTopics` (array) — from CompassContext
- `userAnswers` (array) — from CompassContext (user's answers, may be empty)
- `selectedTopics` (array) — from CompassContext (user's selected topic IDs)
- `anchorRef` (ref) — reference to the badge button element for positioning
- `onClose` (function) — dismiss callback

**Behavior:**

1. On mount, call `fetchPoliticianAnswers(politicianId)` to get the politician's answers.

2. Use `buildAnswerMapByShortTitle()` to convert both the politician's answers AND the user's answers into `{[short_title]: value}` maps. Use the user's `selectedTopics` to determine which topic short_titles to include:
   - Get the short_titles from allTopics where topic.id is in selectedTopics
   - If user has no selectedTopics, use all topics the politician answered

3. Render `RadarChartCore` from `@chrisandrewsedu/ev-ui` with:
   - `topics`: the filtered topics from buildAnswerMapByShortTitle
   - `data`: politician's answer map (this is the primary/pink polygon)
   - `compareData`: user's answer map if available (blue polygon overlay). Empty object `{}` if user has no answers.
   - `size={180}` — mini size for popover
   - `labelFontSize={9}` — small labels
   - `padding={40}` — tight padding
   - `labelOffset={12}` — close labels

4. **Positioning:** Position the popover relative to `anchorRef` using a portal or absolute positioning:
   - Desktop: appear above or below the badge button (whichever has more space)
   - Use `position: fixed` with coordinates calculated from `anchorRef.current.getBoundingClientRect()`
   - Add a small arrow/caret pointing to the badge (CSS triangle)
   - Max width: 240px, background white, rounded corners, drop shadow
   - Include a small header: "[PoliticianName]'s Compass" in Manrope font, 12px, ev-teal color

5. **Dismissal:**
   - Desktop: onMouseLeave from the popover dismisses it (with a small 200ms delay to prevent flicker when moving between badge and popover)
   - Mobile: tap outside (use a backdrop overlay with onClick={onClose})
   - Also close on scroll

6. **Loading state:** Show a small spinner (same style as Profile.jsx loading) while fetchPoliticianAnswers is in flight.

7. **Style:** Use inline styles consistent with the ev-ui design tokens (Manrope font, ev-teal colors). The popover should feel like a tooltip, not a modal — no dark backdrop on desktop, lightweight shadow.

Modify `essentials/src/pages/Results.jsx` to show a compass badge on politician cards that have stance data, and render the CompassPreview popover on interaction.

**Changes required:**

1. **Import useCompass and CompassPreview:**
   ```javascript
   import { useCompass } from '../contexts/CompassContext';
   import CompassPreview from '../components/CompassPreview';
   ```

2. **Inside the Results component, consume the context:**
   ```javascript
   const { politicianIdsWithStances, allTopics, userAnswers, selectedTopics, compassLoading } = useCompass();
   ```

3. **Add state for the active preview:**
   ```javascript
   const [previewPol, setPreviewPol] = useState(null); // { id, name, anchorEl }
   ```

4. **Move renderPoliticianCard inside the component** (it is currently defined outside but needs closure access to `politicianIdsWithStances` and `setPreviewPol`). Modify it to conditionally pass `onCompassClick` to PoliticianCard.

   The PoliticianCard's `onCompassClick` handler in ev-ui calls `onCompassClick?.()` with no arguments (it does `e.stopPropagation()` internally). So the callback receives NO arguments. Capture the badge element reference using a data attribute and querySelector:

   ```javascript
   onCompassClick={hasStances ? () => {
     const cardEl = document.querySelector(`[data-pol-id="${pol.id}"] .ev-compass-button`);
     setPreviewPol({
       id: pol.id,
       name: `${pol.first_name} ${pol.last_name}`,
       anchorEl: cardEl,
     });
   } : undefined}
   ```

   Add `data-pol-id={pol.id}` to the wrapping div of each card.

   For vacant offices, do NOT add onCompassClick (they don't have stances).

5. **Render the CompassPreview** at the bottom of the Results component return, just before the closing div:
   ```jsx
   {previewPol && (
     <CompassPreview
       politicianId={previewPol.id}
       politicianName={previewPol.name}
       allTopics={allTopics}
       userAnswers={userAnswers}
       selectedTopics={selectedTopics}
       anchorRef={{ current: previewPol.anchorEl }}
       onClose={() => setPreviewPol(null)}
     />
   )}
   ```

6. **Interaction model:** Use click-to-toggle for both desktop and mobile. The user requested hover behavior, but since PoliticianCard is from ev-ui and we cannot easily attach mouse events to its internal compass button, click-to-toggle with dismiss-on-outside-click is the pragmatic approach. The CompassPreview component handles dismissal internally.

Do NOT modify the sort logic, filter logic, or any other existing functionality. The only changes are: new imports, useCompass(), previewPol state, onCompassClick prop on PoliticianCard, and CompassPreview rendering.
