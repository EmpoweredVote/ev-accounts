  Create `backend/scripts/backfill-pre-phase49-geo-ids.ts` following the pattern from `backfill-indiana-office-titles.ts`:

  **Structure:**
  ```
  import 'dotenv/config';
  import { Pool } from 'pg';
  ```

  1. **Env guard:** Check `DATABASE_URL` is set, exit 1 if not.

  2. **Arg parsing:** `const isDryRun = process.argv.includes('--dry-run');` with mode logging.

  3. **DB Pool:** `new Pool({ connectionString: process.env.DATABASE_URL, ssl: { rejectUnauthorized: false } })`.

  4. **Main function:**

     a. **Find affected users:**
     ```sql
     SELECT user_id
     FROM connect.connected_profiles
     WHERE encrypted_lat IS NOT NULL
       AND location_consent = true
       AND congressional_geo_id IS NULL
     ```
     CRITICAL: Must include `location_consent = true` — the RPC raises EXCEPTION if consent is false.

     b. **Log count:** `Found N users with encrypted coords but no geo_ids`

     c. **Per-user loop:** For each user_id:
        - Call `SELECT connect.resolve_user_jurisdiction($1) AS j` via `pool.query`
        - Parse result: `const j = rows[0]?.j as Record<string, string | null> | null;`
        - If `!j || !j.congressional`: log `[backfill] {user_id}: no boundary match (geofence gap)`, increment `stillNull` counter, continue.
        - If not dry-run: UPDATE connect.connected_profiles with the 10 columns:
          ```sql
          UPDATE connect.connected_profiles
          SET congressional_geo_id        = $2,
              congressional_district_name = $3,
              state_senate_geo_id         = $4,
              state_senate_district_name  = $5,
              state_house_geo_id          = $6,
              state_house_district_name   = $7,
              county_geo_id               = $8,
              county_name                 = $9,
              school_district_geo_id      = $10,
              school_district_name        = $11,
              updated_at                  = now()
          WHERE user_id = $1
          ```
          Parameter order: `[user_id, j.congressional, j.congressional_name, j.state_senate, j.state_senate_name, j.state_house, j.state_house_name, j.county, j.county_name, j.school_district, j.school_district_name]`
        - Log `[backfill] {user_id}: fixed` (or `would fix` in dry-run), increment `fixed` counter.
        - Wrap per-user work in try/catch — log error and continue to next user, don't abort.

     d. **Summary:** Print total affected, fixed, still-null (geofence gap), errors.

  5. **Cleanup:** `await pool.end()` in finally block.

  6. **Main call:** `main().catch(err => { console.error('Fatal error:', err); process.exit(1); });`

  CRITICAL column names (from shipped migration):
  - `congressional_district_name` (NOT congressional_name)
  - `state_senate_district_name` (NOT state_senate_name)
  - `state_house_district_name` (NOT state_house_name)
  - `county_name`
  - `school_district_name`

  The RPC returns keys: `congressional`, `congressional_name`, `state_senate`, `state_senate_name`, `state_house`, `state_house_name`, `county`, `county_name`, `school_district`, `school_district_name`.

  Map RPC keys to DB columns:
  - `j.congressional` -> `congressional_geo_id`
  - `j.congressional_name` -> `congressional_district_name`
  - `j.state_senate` -> `state_senate_geo_id`
  - `j.state_senate_name` -> `state_senate_district_name`
  - `j.state_house` -> `state_house_geo_id`
  - `j.state_house_name` -> `state_house_district_name`
  - `j.county` -> `county_geo_id`
  - `j.county_name` -> `county_name`
  - `j.school_district` -> `school_district_geo_id`
  - `j.school_district_name` -> `school_district_name`
