## Typography

All sizes drawn from existing CSS classes in App.css and component stylesheets, plus the group label pattern introduced by EntitySwitcher. Four sizes are declared for this phase. Two weights only: 400 (all body, caption, option, and label text) and 700 (group labels, heading/hero title only).

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Group label | 11px (0.6875rem) | 700 | 1.2 (uppercase caps, not body content) |
| Caption / description / option text | 14px (0.875rem) | 400 | 1.3 (replaces former 13px caption usage) |
| Body / label / tab label | 16px (1rem) | 400 | 1.6 body / 1.3 label |
| Heading / hero title | 20px (1.25rem) | 700 | 1.2 (matches existing hero h1 pattern) |

Source: index.css body rule, App.css `.dataset-tab-label`, `.dataset-tab-description`. The 11px size is used exclusively for `.entity-group-label` uppercase headers. The 14px size is used for all caption-level and option-item text. No sizes outside this set of four may be introduced in this phase.

## Color

All values from `index.css` `:root` block. No new colors introduced in this phase.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#f5f5f5` (--light-gray) | Page background, dropdown menu background |
| Secondary (30%) | `#ffffff` (--white) | Cards, header bar, dropdown trigger, selected dropdown item |
| Accent (10%) | `#00657c` (--muted-blue) | EntitySwitcher active border/focus ring, dataset total amounts |
| Text muted | `#6b7280` (--text-gray) | Caption text, chevron icon, group labels in dropdown |
| Border | `#e0e0e0` (--medium-gray) | Dropdown border, tab borders, dividers between groups |
| Destructive | not applicable | No destructive actions in this phase |

Accent (`--muted-blue`) reserved for:
- EntitySwitcher button focus ring
- Active/selected entity highlight in dropdown list (left border accent, matching `.dataset-dropdown-item.active` pattern)
- Dataset total amounts (already established pattern)

Disabled state: opacity 0.4 on the element, no color change needed — visual graying via opacity matches the established disabled pattern on NavigationTabs (existing `disabled` button style).

## Component Inventory

### New: EntitySwitcher

Replaces `NavigationTabs.tsx` in the header. Follows the exact dropdown pattern of `YearSelector.tsx`.

**Trigger button (`.entity-switcher-button`):**
- Height: minimum 44px
- Padding: 8px 16px (sm md)
- Display: flex, align-items center, gap 8px (sm)
- Background: `var(--white)`
- Border: 1px solid `var(--medium-gray)`
- Border-radius: 0.5rem (8px)
- Font: Manrope 16px weight 400
- Chevron: `<ChevronDown size={16} />` from lucide-react, rotates 180deg when open (0.2s transition, matching YearSelector)
- Text format: "Name, ST" — e.g., "Bloomington, IN" (source: D-03)

**Dropdown menu (`.entity-switcher-dropdown`):**
- Position: absolute, top 100% + 4px, left 0
- Min-width: 220px
- Background: `var(--white)`
- Border: 1px solid `var(--medium-gray)`
- Border-radius: 0.5rem
- Box-shadow: `0 4px 12px rgba(0, 0, 0, 0.12)`
- z-index: 100
- Dismiss: click outside (same useRef + mousedown pattern as YearSelector lines 14–28)
- Keyboard: Escape closes, matching YearSelector handleKeyDown

**Group headers (`.entity-group-label`):**
- Font: 11px (0.6875rem) weight 700, uppercase, letter-spacing 0.08em
- Color: `var(--text-gray)`
- Padding: 8px 16px 4px
- Not clickable

**Entity options (`.entity-option`):**
- Padding: 8px 16px (sm md)
- Font: 14px (0.875rem) weight 400
- Color: `var(--black)`
- Hover: background `var(--light-gray)`
- Selected: background `var(--light-gray)`, left border 3px solid `var(--muted-blue)`, font weight 400
- Width: 100%

**Groups displayed:**
1. "Cities" group header → city entities (Bloomington IN, Ellettsville IN, Los Angeles CA)
2. "Counties" group header → county entities (Monroe County IN, LA County CA)

### Modified: DatasetTabs

New prop: `availableDatasets?: string[]` — defaults to all three datasets if omitted (backward compat).

**Disabled tab state:**
- Visual: `opacity: 0.4`, `cursor: not-allowed`, `pointer-events: none` (inline styles on the tab button)
- Tooltip: `title="No [dataset] data available"` — native HTML title attribute, no JS tooltip library
- Applies to both desktop `.dataset-tab` and mobile `.dataset-dropdown-item` variants
- A disabled tab is still rendered and visible; it is not hidden

### Modified: Spinner Overlay

Applied to main content area during entity switch (D-07). Header and EntitySwitcher remain interactive and fully mounted.

**Overlay (`.content-loading-overlay`):**
- Position: absolute, inset 0
- Background: `rgba(245, 245, 245, 0.75)` (semi-transparent light-gray)
- Display: flex, align-items center, justify-content center
- z-index: 10 (above content, below header)
- Pointer-events: none (allows header interaction)

**Spinner (`.spinner`):**
- 32px × 32px circle
- Border: 3px solid `var(--medium-gray)`
- Border-top-color: `var(--muted-blue)`
- Border-radius: 50%
- Animation: CSS keyframe `spin` 0.7s linear infinite
- No third-party library — pure CSS

**Trigger:** Existing `loading` boolean in App.tsx, reused when entity switches.

### Modified: YearSelector

Accepts dynamic `years` prop derived from selected entity's `available_datasets`. No visual change — the prop is already typed as `string[]`, so only the caller (App.tsx) changes.

### Modified: Breadcrumb

Entity name replaces hardcoded "City" string. No visual changes to the Breadcrumb component itself — only the `label` value of the breadcrumb item changes at call site in App.tsx.

## Primary Visual Anchor

The `<h1>` hero title — rendered as "{Entity Name} Finances" — is the primary focal point of the modified page. ## URL State Contract

Source: D-10, D-11, D-12. Implemented via native `URLSearchParams` + `window.history.pushState`.

| Param | Type | Example | Default |
|-------|------|---------|---------|
| `entity` | slug string | `bloomington-in` | `bloomington-in` |
| `year` | 4-digit string | `2024` | entity's most recent available year |
| `dataset` | `operating` \| `revenue` \| `salaries` | `operating` | `operating` |

Slug format: `{name-lowercased-hyphenated}-{state-lowercase}` — e.g., `monroe-county-in`, `la-county-ca`. Derived at runtime via `toSlug(m: Municipality)`. Not stored in DB.

Invalid or missing `entity` param: falls back silently to Bloomington, IN with no error shown.

## Copywriting Contract

| Element | Copy |
|---------|------|
| EntitySwitcher aria-label | "Select jurisdiction" |
| EntitySwitcher group: cities | "Cities" |
| EntitySwitcher group: counties | "Counties" |
| Hero title pattern | "{Entity Name} Finances" |
| Disabled dataset tab tooltip | "No [Money In / Money Out / People] data available" (use the dataset label, not the technical id) |
| Spinner accessible label | `aria-label="Loading budget data"` on the overlay div |
| Per-resident info card (hidden) | Omit entirely when population is null — no "N/A" or placeholder text shown |
| Invalid URL entity fallback | No user-visible message — silent fallback to default entity |

No primary CTA in this phase — the EntitySwitcher is a navigation control, not a form submission.
No destructive actions in this phase.

Empty state: not applicable — if an entity has no data at all, it should not appear in the municipalities list. The DatasetTabs disabled state covers the case where a specific dataset type is missing.

Error state (data load failure after entity switch):
- Copy: "Couldn't load [Entity Name] data. Check your connection and try again."
- Treatment: Replaces the spinner overlay; displayed in the content area. Uses the existing error pattern established in Phase 92 (App.tsx catch block sets `budgetData(null)` and shows an error card).

## Accessibility Checklist

- EntitySwitcher dropdown: `aria-expanded`, `aria-haspopup="listbox"`, `role="listbox"` on menu, `role="option"` + `aria-selected` on items — matching YearSelector ARIA pattern
- EntitySwitcher button: `aria-label="Select jurisdiction"`
- Disabled DatasetTabs: retain the button element in DOM (not `display: none`) so screen readers announce "unavailable" state; add `aria-disabled="true"` in addition to `pointer-events: none`
- Spinner overlay: `aria-label="Loading budget data"`, `role="status"`, `aria-live="polite"`
- Hero title: rendered as `<h1>` — no change to existing tag structure
- Keyboard: Escape closes EntitySwitcher dropdown; Tab moves focus through options
