**`backend/src/lib/gemService.ts`** — Create gem service following the empowerService.ts pattern:

```typescript
import { supabaseAdmin } from './supabase.js';
import { pool } from './db.js';

export type GemType = 'red' | 'blue' | 'yellow';
```

Functions to implement:

1. `creditGems(userId: string, gemType: GemType, amount: number, transactionType: string, sourceRef?: string): Promise<void>`
   - Call `supabaseAdmin.schema('connect').rpc('credit_gems', { p_user_id, p_gem_type, p_amount, p_transaction_type, p_source_ref: sourceRef ?? null })`
   - On error, throw `new Error(error.message)`
   - This function is caller-agnostic: cron jobs, inline route handlers, and future event workers all call it.

2. `debitGems(userId: string, gemType: GemType, amount: number, transactionType: string, sourceRef?: string): Promise<void>`
   - Call `supabaseAdmin.schema('connect').rpc('debit_gems', { ... })` same pattern as creditGems
   - On error, check if `error.message.includes('INSUFFICIENT_BALANCE')` — if so, throw `Object.assign(new Error('Insufficient gem balance'), { code: 'INSUFFICIENT_BALANCE' })`
   - Otherwise throw generic error

3. `getBalance(userId: string): Promise<{ red: number; blue: number; yellow: number }>`
   - Use pool (not supabaseAdmin — balance is a server-side computation, same pattern as compassService.ts getCompassCompleteness)
   - Query: `SELECT gem_balance_red, gem_balance_blue, gem_balance_yellow FROM connect.connected_profiles WHERE user_id = $1`
   - Return `{ red: data.gem_balance_red, blue: data.gem_balance_blue, yellow: data.gem_balance_yellow }`
   - Throw if no row found

4. `getTransactionHistory(userId: string, options?: { limit?: number; offset?: number; gemType?: GemType }): Promise<{ transactions: any[]; total: number }>`
   - Use pool for the query
   - Base query: `SELECT id, gem_type, amount, transaction_type, feature_context, reference_id, balance_after, created_at FROM connect.gem_transactions WHERE user_id = $1`
   - If `options.gemType` provided, add `AND gem_type = $2`
   - Order by `created_at DESC`
   - Apply LIMIT (default 50, max 100) and OFFSET (default 0)
   - Also run a COUNT query for total
   - Return `{ transactions, total }`

**`backend/src/lib/roleService.ts`** — Create role service following the empowerService.ts pattern:

```typescript
import { pool } from './db.js';
import { supabaseAdmin } from './supabase.js';
```

Functions to implement:

1. `grantRole(userId: string, roleSlug: string): Promise<void>`
   - Get a client from pool (`const client = await pool.connect()`)
   - Query `public.roles` by slug: `SELECT id, required_tier, is_active FROM public.roles WHERE slug = $1`
   - If not found: throw with code `ROLE_NOT_FOUND`
   - If `!role.is_active`: throw with code `ROLE_INACTIVE`
   - Enforce tier eligibility:
     - If `role.required_tier === 'empowered'`: query `SELECT id FROM empower.empowered_profiles WHERE user_id = $1 AND is_active = true`. If no rows, throw with code `TIER_INELIGIBLE` and message `Role '${roleSlug}' requires Empowered tier`.
     - If `role.required_tier === 'connected'`: query `SELECT id FROM connect.connected_profiles WHERE user_id = $1 AND verification_status = 'verified'`. If no rows, throw with code `TIER_INELIGIBLE`.
   - INSERT new row: `INSERT INTO public.user_roles (user_id, role_id) VALUES ($1, $2)`. NEVER reuse/update revoked rows (CONTEXT.md decision — preserves full history).
   - On unique_violation (user already has active grant for this role): throw with code `ROLE_ALREADY_GRANTED`
   - Release client in `finally` block

2. `revokeRole(userId: string, roleSlug: string): Promise<void>`
   - Use pool.query (no transaction needed — single UPDATE):
   ```sql
   UPDATE public.user_roles ur
   SET revoked_at = now()
   FROM public.roles r
   WHERE ur.role_id = r.id
     AND ur.user_id = $1
     AND r.slug = $2
     AND ur.revoked_at IS NULL
   ```
   - No error if no matching row (idempotent revocation)

3. `getUserRoles(userId: string): Promise<Array<{ role_id: string; slug: string; name: string; granted_at: string }>>`
   - Use pool.query:
   ```sql
   SELECT ur.role_id, r.slug, r.name, ur.granted_at
   FROM public.user_roles ur
   JOIN public.roles r ON r.id = ur.role_id
   WHERE ur.user_id = $1 AND ur.revoked_at IS NULL
   ORDER BY ur.granted_at DESC
   ```

4. `getAllActiveRoles(): Promise<Array<{ id: string; name: string; slug: string; required_tier: string | null; description: string | null }>>`
   - Use pool.query:
   ```sql
   SELECT id, name, slug, required_tier, description
   FROM public.roles
   WHERE is_active = true
   ORDER BY name
   ```
