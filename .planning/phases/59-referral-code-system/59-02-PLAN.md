**Create `backend/src/lib/inviteQuotaService.ts`:**

Import `pool` from `./db.js`. All functions use `pool.query()` — never PostgREST for connect schema.

Functions:

1. `generateInviteCodeIfAllowed(userId: string)` — calls `connect.generate_invite_code_if_allowed($1)`. Returns `{ ok: boolean; code: string | null; error: string | null; active_count: number; cap: number }`.

2. `getMyInvitees(userId: string)` — calls `connect.get_my_invitees($1)`. Returns the invitee list. Then compute derived fields:
   - `active_count`: count of invitees where `graduated = false` AND NOT (slot_locked_until is past AND account_standing = 'active')
   - `cap`: call a separate query `SELECT connect.get_invite_cap_for_level(cp.current_level) as level_cap, cp.invite_cap_override FROM connect.connected_profiles cp WHERE cp.user_id = $1` to compute effective cap (handle -1 unlimited, GREATEST logic)
   - `can_generate`: `active_count < cap`
   - Return shape: `{ active_count, cap, can_generate, invitees: InviteeEntry[] }`

3. `sanctionInvitee(inviteeId: string, trDelta?: number)` — calls `connect.sanction_invitee($1, $2)` with `trDelta ?? -0.25`.

4. `setInviteCapOverride(userId: string, cap: number | null)` — direct `pool.query()` UPDATE on `connect.connected_profiles SET invite_cap_override = $2 WHERE user_id = $1`. Note: `cap` can be null (clear override), -1 (unlimited), or a positive integer.

5. `getInviteOverrides()` — query all users with non-null `invite_cap_override`:
   ```sql
   SELECT cp.user_id, u.display_name, u.email, cp.current_level,
          connect.get_invite_cap_for_level(cp.current_level) as level_cap,
          cp.invite_cap_override,
          CASE WHEN cp.invite_cap_override = -1 THEN 2147483647
               ELSE GREATEST(connect.get_invite_cap_for_level(cp.current_level), COALESCE(cp.invite_cap_override, 0))
          END as effective_cap
   FROM connect.connected_profiles cp
   JOIN public.users u ON u.id = cp.user_id
   WHERE cp.invite_cap_override IS NOT NULL
   ORDER BY u.display_name
   ```

TypeScript interfaces at top of file:
```typescript
interface GenerateResult { ok: boolean; code: string | null; error: string | null; active_count: number; cap: number }
interface InviteeEntry { invitee_id: string; display_name: string; account_standing: string; current_level: number; graduated: boolean; slot_locked_until: string | null; claimed_at: string | null }
interface MyInviteesResponse { active_count: number; cap: number; can_generate: boolean; invitees: InviteeEntry[] }
interface InviteOverride { user_id: string; display_name: string; email: string; current_level: number; level_cap: number; invite_cap_override: number; effective_cap: number }
```

**Update `backend/src/routes/invites.ts`:**

Replace the existing `POST /send` route with `POST /generate`:

```typescript
router.post(
  '/generate',
  requireAuth,
  requireConnected,
  inviteSendLimiter,  // reuse existing rate limiter (10/day is fine)
  async (req, res) => {
    const { userId } = req as AuthenticatedRequest;
    const result = await generateInviteCodeIfAllowed(userId);
    if (!result.ok) {
      const status = result.error === 'NOT_CONNECTED' ? 403 : 409;
      res.status(status).json({ code: result.error, active_count: result.active_count, cap: result.cap });
      return;
    }
    res.status(201).json({ code: result.code, active_count: result.active_count, cap: result.cap });
  }
);
```
