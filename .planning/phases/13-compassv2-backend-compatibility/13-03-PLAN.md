Create a new file backend/src/lib/essentialsService.ts.

Import only supabaseAnon (NOT supabaseAdmin):
  import { supabaseAnon } from './supabase.js';

Define and export getPoliticiansGrouped:

  export interface PoliticianRecord {
    id: string;
    full_name: string | null;
    office_title: string | null;
    photo_origin_url: string | null;
    is_candidate: boolean;
  }

  export interface PoliticianGroup {
    office_title: string;
    incumbent: PoliticianRecord | null;
    candidates: PoliticianRecord[];
  }

  export async function getPoliticiansGrouped(
    includeCandidates: boolean
  ): Promise<PoliticianGroup[]>

Implementation:
1. Query inform.politicians using supabaseAnon:
   - Select: id, full_name, office_title, photo_origin_url, is_candidate
   - Filter: is_active = true
   - If includeCandidates is false: also filter is_candidate = false
   - Order: office_title ascending, full_name ascending
   - If the Supabase error object is returned, throw it (NOT a silent empty array — per locked decision)

2. When includeCandidates is false, the response is a flat list of incumbents. Group them by office_title:
   - For each unique office_title, produce: { office_title, incumbent: politician, candidates: [] }

3. When includeCandidates is true, retrieve ALL active politicians (no is_candidate filter) and group:
   - For each unique office_title: incumbent = first politician where is_candidate = false, candidates = all where is_candidate = true
   - office_title may be null for some politicians — group null titles under the key 'Unknown' or omit them. Decision: include them with office_title: null in the group object (preserves data fidelity).

4. Sort the output groups by office_title (nulls last).

Return the array of PoliticianGroup objects.

NOTE: Do NOT import or reference supabaseAdmin anywhere in this file. The architecture test scans all src/ files for supabaseAdmin references — this file must be clean.
