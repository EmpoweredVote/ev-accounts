**Layer 1: DB Data Audit**

Connect to the production Supabase DB (project `kxsdzaojfaibqjedmesbmp` — use `DATABASE_URL` from ev-accounts `.env` or Supabase SQL editor) and run these queries:

Query 1 — Do Monroe County politicians have quotes?
```sql
SELECT p.full_name, p.id, COUNT(q.id) AS quote_count
FROM essentials.politicians p
JOIN essentials.offices o ON o.politician_id = p.id
JOIN essentials.districts d ON d.id = o.district_id
LEFT JOIN essentials.quotes q ON q.politician_id = p.id
WHERE d.district_type IN ('LOCAL', 'LOCAL_EXEC', 'COUNTY', 'STATE_UPPER', 'STATE_LOWER', 'NATIONAL_LOWER', 'NATIONAL_UPPER')
  AND p.is_active = true
GROUP BY p.full_name, p.id
HAVING COUNT(q.id) > 0
ORDER BY quote_count DESC;
```

Query 2 — Do quotes have matching compass topics (or are they silently dropped)?
```sql
SELECT
  q.topic_key AS quote_topic_key,
  ct.topic_key AS compass_topic_key,
  ct.short_title,
  COUNT(q.id) AS quote_count,
  CASE WHEN ct.id IS NULL THEN 'DROPPED' ELSE 'MATCHED' END AS status
FROM essentials.quotes q
LEFT JOIN inform.compass_topics ct ON ct.topic_key = lower(q.topic_key)
GROUP BY q.topic_key, ct.topic_key, ct.short_title, ct.id
ORDER BY status DESC, q.topic_key;
```

Query 3 — Any quotes with null politician_id?
```sql
SELECT COUNT(*) AS null_politician_id_count FROM essentials.quotes WHERE politician_id IS NULL;
```
