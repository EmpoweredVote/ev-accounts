  <name>Task 1: Add ev-blue and ev-navy tokens to app/src/index.css; add ev-blue to admin/src/index.css</name>
  <files>app/src/index.css, admin/src/index.css</files>
  <action>
    Both files currently have an identical `@theme` block defining `ev-red`, `ev-teal`, `ev-teal-light`, `ev-yellow`, and `ev-black` via `--color-*` custom properties. Tailwind v4 reads these to generate utility classes. Add the v2.0 tokens.

    Update `app/src/index.css` to insert two new declarations inside the existing `@theme { ... }` block, after the existing brand color block. Final block must contain:

    ```css
    @theme {
      /* Empowered Vote brand colors */
      --color-ev-red: #FF5740;        /* Empower features */
      --color-ev-teal: #00657C;       /* Connect (dark / primary) */
      --color-ev-teal-light: #59B0C4; /* Connect (light mode / resonant votes) */
      --color-ev-yellow: #FED12E;     /* Inform features and Gems */
      --color-ev-black: #1c1c1c;
      /* v2.0 Civic Account Experience */
      --color-ev-blue: #3B82F6;       /* v2.0 primary CTA / focus ring */
      --color-ev-navy: #020618;       /* v2.0 page background (NOT gray-950 = #030712) */
    }
    ```

    Update `admin/src/index.css` to add `--color-ev-blue: #3B82F6;` (only the blue token, NOT navy — admin is otherwise untouched in v2.0). Keep the `/* v2.0 Civic Account Experience */` comment so the admin/app token sets stay legible.

    Do NOT remove or reorder the existing tokens. Do NOT touch the `@import "tailwindcss"` line or the `@custom-variant dark (&:where(.dark, .dark *));` line.

    WHY this exact pattern: Tailwind v4 generates utility classes ONLY from `--color-*` named variables inside `@theme`. The `--color-` prefix is mandatory. A `tailwind.config.js` approach silently fails in v4. See research pitfall #1.

    WHY ev-navy is NOT bg-gray-950: gray-950 (#030712) and ev-navy (#020618) are visually similar but differ in red/blue channels. Phase 61+ pages use `bg-ev-navy` explicitly; this token must be declared distinct.
  </action>
  <verify>
    Run `cd app && npm run build` and confirm the build succeeds with no Tailwind errors. Then `grep -E '(ev-blue|ev-navy)' app/src/index.css` shows BOTH tokens. `grep 'ev-blue' admin/src/index.css` shows ev-blue. `grep 'ev-navy' admin/src/index.css` returns nothing (admin must NOT get navy).
  </verify>
  <done>
    `app/src/index.css` contains both `--color-ev-blue: #3B82F6` and `--color-ev-navy: #020618` inside the `@theme` block. `admin/src/index.css` contains `--color-ev-blue: #3B82F6` and does NOT contain `ev-navy`. The app build passes.
  </done>
