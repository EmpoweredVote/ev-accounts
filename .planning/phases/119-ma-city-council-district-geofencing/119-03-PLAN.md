<objective>
Create load-ma-ward-boundaries.ts (parameterized script using MassGIS WARDSPRECINCTS2022_POLY FeatureServer) and run it for all four cities. Then write and apply migrations 661–664, one per city, each inserting per-ward LOCAL district rows, backfilling tiger_geoid, and re-linking ward councillors' offices.

MassGIS serves precinct polygons (multiple per ward) — the script dissolves precincts into ward polygons using ST_Union in a single per-ward INSERT, passing an array of GeoJSON geometries via unnest($3::text[]) (Option B from research). This avoids dynamic SQL and handles variable precinct counts per ward cleanly.

Purpose: Upgrades Springfield, Lowell, Brockton, and Quincy from Tier 2 (citywide blob) to Tier 3 (per-ward geofencing) using a single reusable script.

Output: load-ma-ward-boundaries.ts script run for 4 cities, migrations 661–664 applied to production.

ST_Union INSERT (Option B — preferred per research):
  INSERT INTO essentials.geofence_boundaries (geo_id, ocd_id, name, state, mtfcc, geometry, source, imported_at)
  SELECT $1, $2, $3, '25', 'X0014',
    public.ST_MakeValid(public.ST_Union(
      public.ST_MakeValid(public.ST_ForcePolygonCCW(
        public.ST_SetSRID(public.ST_Force2D(public.ST_GeomFromGeoJSON(geom_json)), 4326)
      ))
    )),
    $4, now()
  FROM unnest($5::text[]) AS geom_json
  ON CONFLICT (geo_id, mtfcc) DO NOTHING
