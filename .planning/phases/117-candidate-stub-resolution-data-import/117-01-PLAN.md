    For EACH stub from Task 1, perform real sourcing in D-05 priority order (this is NOT an availability check — actually retrieve data):

    1. **Monroe County Clerk filings** — Visit monroecounty.in.gov, find CAN-2 filings for the 2026-05-05 primary. Record filing URL, legal name, office sought.
    2. **Candidate website / social** — Find candidate's own site, Facebook, LinkedIn. Record photo URL (source, not CDN), self-authored bio (copy sentence verbatim for D-07 single-source rule).
    3. **Local press** — Herald-Times, WFIU, WFHB, Ballotpedia, LegiScan as fallback ONLY. Record URL + pull-quote sentence.

    For each candidate record the following fields:
    - race_candidate_id (from Task 1)
    - full_name (from clerk filing — canonical spelling)
    - first_name, last_name (split from full_name)
    - office_title (from clerk filing)
    - chamber_id, district_id (lookup via `SELECT id FROM essentials.chambers WHERE ...` — record in CSV so import script doesn't re-query)
    - photo_source_url (may be empty if unsourceable — D-06 fallback)
    - bio_text (single-source extract, ≤180 chars, per D-07 + D-14; may be literal `Candidate for [office title]` if unsourceable per D-06)
    - bio_source_url (single source — the URL the bio sentence came from; empty only if D-06 fallback bio)
    - tier: one of `Confirmed-sourceable`, `Partial`, `Unsourceable`

    Assign tiers:
    - `Confirmed-sourceable` = name + office + photo + bio all from authoritative source (clerk/candidate-site)
    - `Partial` = name + office confirmed, missing photo OR bio
    - `Unsourceable` = only name + office from clerk filing; no photo, no bio

    ```markdown
    - Unsourceable: {Z}/{N}

    ## Confirmed-sourceable
    | Name | Office | Clerk URL | Site URL | Press URL | Photo Y/N | Bio Y/N |
    |---|---|---|---|---|---|---|
    ...

    ## Partial
    (same columns)

    ## Unsourceable
    (same columns)

    ## Scope-down 5-10 (prioritized for April 25 cut)
    1. {name} — {office} — {why it survives}
    2. ...
    ```
