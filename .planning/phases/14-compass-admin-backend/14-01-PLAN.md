**Function 1: admin_create_topic_with_stances**

Signature:
```sql
CREATE OR REPLACE FUNCTION public.admin_create_topic_with_stances(
  p_title text,
  p_question_text text,
  p_short_title text DEFAULT NULL,
  p_is_live boolean DEFAULT false,
  p_stances jsonb DEFAULT '[]'::jsonb
)
RETURNS jsonb
LANGUAGE plpgsql
SECURITY DEFINER
SET search_path = ''
```

Two-pass design:
- Pass 1 (validation only, no writes): loop jsonb_array_elements(p_stances). For each stance: check value::int BETWEEN 1 AND 5 (RAISE EXCEPTION 'INVALID_STANCE_VALUE: ...' if not). Check text IS NOT NULL and trim(text) != '' (RAISE EXCEPTION 'INVALID_STANCE_TEXT: ...' if not). Pass 1 must complete before any INSERT.
- Pass 2 (writes): INSERT INTO inform.compass_topics (title, short_title, question_text, is_live, went_live_at) VALUES (p_title, p_short_title, p_question_text, p_is_live, CASE WHEN p_is_live THEN now() ELSE NULL END) RETURNING * INTO v_topic. Then loop stances again: INSERT INTO inform.compass_stances (topic_id, value, text) VALUES (v_topic.id, ...).
- Return: jsonb_build_object('topic', row_to_json(v_topic), 'stances', COALESCE((SELECT jsonb_agg(row_to_json(s)) FROM inform.compass_stances s WHERE s.topic_id = v_topic.id), '[]'::jsonb)).
- NEVER include is_active in the INSERT — it is GENERATED ALWAYS AS (is_live) STORED. Including it causes a DB error.

**Function 2: admin_assign_topic_categories**

Signature:
```sql
CREATE OR REPLACE FUNCTION public.admin_assign_topic_categories(
  p_topic_id uuid,
  p_category_ids jsonb
)
RETURNS void
LANGUAGE plpgsql
SECURITY DEFINER
SET search_path = ''
```

Logic:
- Check topic exists: IF NOT EXISTS (SELECT 1 FROM inform.compass_topics WHERE id = p_topic_id) THEN RAISE EXCEPTION 'NOT_FOUND'; END IF.
- DELETE FROM inform.compass_topic_categories WHERE topic_id = p_topic_id.
- INSERT INTO inform.compass_topic_categories (topic_id, category_id) SELECT p_topic_id, (cat_id)::uuid FROM jsonb_array_elements_text(p_category_ids) AS cat_id.
- Both DELETE and INSERT are within the same transaction — atomic replace-all.

**Function 3: admin_list_politicians (CREATE OR REPLACE — updates existing)**

Signature:
```sql
CREATE OR REPLACE FUNCTION public.admin_list_politicians()
RETURNS TABLE(...)
LANGUAGE sql
SECURITY DEFINER
SET search_path = ''
```

SELECT from inform.politicians: id, first_name, last_name, preferred_name, full_name, office_title, photo_origin_url, is_active, is_candidate, created_at, plus answer_count as (SELECT COUNT(*) FROM inform.politician_answers pa WHERE pa.politician_id = p.id). The existing RPC from migration 025 omits is_candidate — this CREATE OR REPLACE adds it. ORDER BY p.last_name, p.first_name.
