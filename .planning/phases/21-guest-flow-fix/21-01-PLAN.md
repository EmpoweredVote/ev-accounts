  <action>
BuildCompass.jsx currently fetches `/compass/answers` unconditionally on mount (lines 26-36). For guests this returns 401, `.json()` fails on the error response, and `loaded` never becomes true — causing an infinite "Loading your answers..." spinner.

Fix by following the established pattern from Library.jsx (lines 74-84):

1. Add `isLoggedIn` and `answers` to the destructured values from `useCompass()` on line 18:
   ```js
   const { topics, categories, selectedTopics, setSelectedTopics, answers, isLoggedIn } = useCompass();
   ```

2. Replace the existing `useEffect` (lines 26-36) with a guest-aware version:
   ```js
   useEffect(() => {
     if (!isLoggedIn) {
       // Guest: derive answered IDs from localStorage-backed answers in context
       const ids = topics
         .filter(t => answers[t.short_title] != null && answers[t.short_title] > 0)
         .map(t => t.id);
       setAnsweredTopicIDs(ids);
       setLoaded(true);
       return;
     }

     fetch(`${import.meta.env.VITE_API_URL}/compass/answers`, {
       credentials: "include",
     })
       .then((res) => {
         if (!res.ok) throw new Error("Failed to fetch answers");
         return res.json();
       })
       .then((data) => {
         const ids = data.map((a) => a.topic_id);
         setAnsweredTopicIDs(ids);
         setLoaded(true);
       })
       .catch(() => {
         // Fallback: use localStorage answers if server fetch fails
         const ids = topics
           .filter(t => answers[t.short_title] != null && answers[t.short_title] > 0)
           .map(t => t.id);
         setAnsweredTopicIDs(ids);
         setLoaded(true);
       });
   }, [isLoggedIn, topics, answers]);
   ```

Key changes:
- Early return for guests using the same localStorage-backed `answers` from CompassContext (identical to Library.jsx pattern)
- Added `res.ok` check before calling `.json()` to prevent crash on 401/error responses
- Added `.catch()` fallback for network failures (graceful degradation to localStorage)
- Updated dependency array to include `isLoggedIn`, `topics`, and `answers`

Do NOT change anything else in the component — the topic selection, navigation to `/results`, and rendering logic all work correctly already.
