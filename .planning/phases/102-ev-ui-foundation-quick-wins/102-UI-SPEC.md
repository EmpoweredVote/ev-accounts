## Spacing Scale

All spacing values are from `tokens.js → spacing`. Multiples of 4px.

| Token | Value | Usage in Phase 102 |
|-------|-------|---------------------|
| xs (spacing[1]) | 4px | Icon gap within metadata icon clusters |
| sm (spacing[2]) | 8px | Padding inside metadata icon box; gap between icon and sibling text |
| md (spacing[4]) | 16px | Default internal component padding |
| lg (spacing[6]) | 24px | Section-level padding in CategorySection |
| xl (spacing[8]) | 32px | Layout gaps between sections |
| 2xl (spacing[12]) | 48px | Major section breaks |
| 3xl (spacing[16]) | 64px | Page-level spacing (consumers handle) |

Exceptions:
- Icon default render size is 16px (not a spacing value — this is a render dimension per D-01). `size` prop accepts any number; default is 16.
- `objectPosition: 'center 20%'` is a CSS positional value, not a spacing token. This is the exact value from D-04.

## Color

All values from `tokens.js → colorScales.teal` and `tokens.js → colors`.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#FFFFFF` (`colors.bgWhite`) | Card backgrounds, page surface |
| Secondary (30%) | `#F5F9FA` (`colorScales.teal['050']`) | CategorySection tier backgrounds (state + local tiers); near-white wash |
| Accent (10%) | `#00657C` (`colorScales.teal['500']` / `colors.evMutedBlue`) | State tier accent; text primary; link color |
| Accent dark | `#003E4D` (`colorScales.teal['700']`) | Federal tier accent and text |
| Accent light | `#C0E8F2` (`colorScales.teal['200']`) | Local tier decorative accent (bg stripe, border dot only — never as text) |
| Destructive | `#EF4444` (`colors.error`) | Not used in Phase 102 — no destructive actions |

**Accent reserved for:**
- `CategorySection` title pill: background uses tier `bg` token, border uses tier `accent` token, text uses tier `text` token (per D-09)
- Icon `color` prop default: `'currentColor'` — icon inherits text color from surrounding context

### tierColors Token (new in this phase)

Defined in `tokens.js` per D-07 / D-08. Three tiers, three keys each.

| Tier | bg | accent | text | WCAG on white |
|------|----|--------|------|---------------|
| `federal` | `#E4F3F6` (teal-100) | `#003E4D` (teal-700) | `#003E4D` (teal-700) | 7.5:1 AA |
| `state` | `#F5F9FA` (teal-050) | `#00657C` (teal-500) | `#00657C` (teal-500) | 6.66:1 AA |
| `local` | `#F5F9FA` (teal-050) | `#C0E8F2` (teal-200) | `#005366` (teal-600) | 8.1:1 AA |

**WCAG enforcement:** `teal-200` (#C0E8F2) is 1.8:1 on white — it MUST NOT appear as text. It is used only as a decorative `accent` value (border, dot, stripe). Local tier `text` uses `teal-600` (#005366) which is 8.1:1 on white.

**Sub-tiers (county, school, judicial):** Not in this phase. Three keys only per RESEARCH.md recommendation. Phase 103 may extend if needed.

## Headshot Cropping Contract

Per D-04 / D-05 / D-06. Applied to `PoliticianCard.jsx` and `PoliticianProfile.jsx`.

| Property | Value | Applied to |
|----------|-------|------------|
| `objectFit` | `'cover'` | `<img>` elements only (not placeholder divs) |
| `objectPosition` | `imageFocalPoint ?? 'center 20%'` | `<img>` elements only |
| prop name | `imageFocalPoint` | PoliticianCard + PoliticianProfile |
| prop type | `string` (CSS value) | optional, null-safe |
| default value | `'center 20%'` | resolved via `??` nullish coalescing |

**What `center 20%` means:** Horizontal center; vertical anchor at 20% from top. Keeps face in frame on standard portrait photos where the face occupies the top third of the image.

**Scope:** `objectPosition` is applied ONLY to the `<img>` style object. The initials placeholder `<div>` is never given `objectPosition` — it has no effect on a div.
