Imports:

Local interfaces (mirror DashboardPage):
```ts
interface XP { total: number; level: number; xp_in_level: number; xp_to_next_level: number; }
interface ConnectedProfile {
  xp: XP;
  gems: { yellow: number; blue: number; red: number };
  verification_rating: number;
  vq_hold_active: boolean;
}
interface MeFull {
  id: string;
  email: string;
  tier: 'inform' | 'connected' | 'empowered';
  display_name: string | null;
  is_admin: boolean;
  verification_rating: number;
  connected_profile: ConnectedProfile | null;
}
interface ReferralState {
  unlocked: boolean;
  code: string | null;
  inviteeJoined: boolean;
  inviteeLevel: number | null;
}
interface ActivityEntry {
  source: string;
  amount: number;
  description: string;
  created_at: string;
}
```

State:
- `me: MeFull | null`
- `referral: ReferralState | null`
- `activity: ActivityEntry[]`
- `copied: boolean` (for the invite code copy button)

Data fetching (in three useEffects to keep dependencies clean):
1. On mount: `apiFetch<MeFull>('/account/me').then(setMe).catch(() => {})`.
2. When `me?.connected_profile` becomes non-null:
   - `apiFetch<ReferralState>('/referral').then(setReferral).catch(() => {})`
   - `apiFetch<{ activity: ActivityEntry[] }>('/account/me/activity').then(r => setActivity(r.activity)).catch(() => setActivity([]))`
   Inform-tier users will get 403 from /account/me/activity — silently fall back to `[]` (the section will then show the empty state, which is the documented behavior).

```tsx

  </main>
</div>
```

3. **Recent Activity card** — last 4 entries from `activity`.
   - Heading: `<h2 className="text-white text-lg font-semibold mb-4">Recent Activity</h2>`.
   - When `activity.length === 0`: render an empty state line in `text-gray-400 text-sm`: `"No XP earned yet — explore an Empowered Vote feature to get started."` Do NOT hide the card; the heading + empty state both show.
   - When `activity.length > 0`: take the first 4 with `activity.slice(0, 4)` and render a `<ul className="divide-y divide-gray-800">` with one `<li>` per entry:
     - Left side: title-cased `description` (transform `compass_calibration` → `Compass Calibration`: split on `_`, uppercase first letter of each word, rejoin with space). Below it, the date in `text-xs text-gray-400`, formatted with `new Date(entry.created_at).toLocaleDateString(undefined, { month: 'short', day: 'numeric', year: 'numeric' })`.
     - Right side: `+{entry.amount} XP` in `text-ev-teal-light font-semibold tabular-nums`.
     - Row: `flex items-center justify-between py-3 first:pt-0 last:pb-0`.

4. **Invite card** — locked vs. active state.
   - Render only when `me.connected_profile` exists (Inform-tier users have no referral concept on this page).
   - Heading: `Your Invite Code` in `text-white text-lg font-semibold`.
   - Locked state (when `!referral?.unlocked`): subtitle in `text-gray-400 text-sm` reading exactly `"Reach level 2 to unlock your first referral code"` (verbatim — this string is asserted in success criteria). Do NOT show a code or copy button.
   - Active state (when `referral?.unlocked && referral.code`):
     - Code displayed as monospace badge: `<code className="font-mono text-ev-teal-light text-2xl tracking-widest">{referral.code}</code>` inside a `bg-gray-800 rounded-xl px-4 py-3 flex items-center justify-between`.
     - Copy button on the right: `<button onClick={copyCode} className="text-sm text-ev-teal-light hover:text-white transition-colors">{copied ? 'Copied!' : 'Copy'}</button>`. The `copyCode` callback uses `navigator.clipboard.writeText(referral.code)` and toggles `copied` true for 2 seconds via `setTimeout`. Identical pattern to DashboardPage lines 210–216.

5. **Verification Rating card** — VR display.

   - Caption beneath: `text-sm text-gray-400` reading `"Your VR reflects how reliably you participate in civic verification. Earn more by completing Validation Quests."`
