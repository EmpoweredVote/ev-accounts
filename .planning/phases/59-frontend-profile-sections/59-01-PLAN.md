  <action>
Create two new React components in ev-ui/src/ using inline styles with tokens.js. No Tailwind.

**LegislativeInlineSummary.jsx:**

Props: `{ summary, politicianId }`
- `summary` is the `/legislative-summary` response shape: `{ recent_bills: [], recent_votes: [] }`
- `politicianId` is the opaque ID string (UUID or slug — treat as string, never parse)

Behavior:
1. Guard: if `recent_bills` and `recent_votes` are both empty (or summary is null/undefined), return `null`. This is CRITICAL — local politicians with no legislative data must see the exact same profile as today.
2. Derive stats from data (show only stats that have real values — NO "N/A" or empty stat slots):
   - `attendance %` = (votes where position is NOT "Not Voting" AND NOT "Absent" AND NOT "not_voting") / total votes. Normalize position by replacing underscores with spaces and title-casing before comparison. Only show if totalVotes > 0.
   - `bills advanced` = `recent_bills.length` (backend already filters out "Introduced" status). Only show if > 0.
3. Most recent action: pick the most recent item from bills or votes by date. Format as a one-line plain language summary: for bills, "{number}: {title} — {status_label}"; for votes, "Voted {position} on {bill_title || vote_question} — {result}".
4. Topic tag pills slot: render an empty div with a comment "Topic tags — populated when mapping table ships". This is a deferred feature; the visual slot should exist but show nothing.
5. "View Full Legislative Record" link: renders as an `<a>` tag with `href={'/politician/' + politicianId + '/record'}`. Style as the ev-ui teal link color with a right arrow indicator.

Visual structure (top to bottom, inside a card-style container):
- Stats row (inline-flex, gap between stats, each stat as "value label" format like "94% attendance" or "3 bills advanced")
- Most recent action line (small text, muted color, single line with ellipsis overflow)
- "View Full Legislative Record >" link (teal, right-aligned or left-aligned, your choice)

Styling: Use a white background card with `borderRadius.lg`, subtle `shadows.sm` border, `spacing[4]` padding. Stats use `fontSizes.sm`, `fontWeights.semibold`, `colors.evTeal`. Action line uses `fontSizes.xs`, `colors.textSecondary`. The link uses `fontSizes.sm`, `fontWeights.medium`, `colors.evTeal`.

Import `useMediaQuery` from `'./useMediaQuery'` for mobile-responsive layout (stack stats vertically on mobile).

**LegislativeRecord.jsx:**

Props: `{ committees, leadership, bills, votes, loading, politicianName }`
- All data arrays default to `[]`
- `loading` boolean for loading state
- `politicianName` for page title

This is a HEADLESS content component — no Header, no routing, no data fetching. The essentials page wrapper handles those concerns.

Behavior:
1. If `loading` is true, render a centered spinner (same pattern as Profile.jsx loading state: a rotating circle using CSS animation via inline styles).
2. Render three sections in this fixed order: Committees & Leadership, Sponsored Legislation, Voting Record.
3. All three section headers ALWAYS render, even when data is empty.

**Section 1: Committees & Leadership**
- If `leadership.length > 0`, render leadership roles first as highlighted badges: "{title}" with chamber label. Use `colors.evCoral` background for leadership badges to make them prominent.
- Committee list: flat list of `committee_name` with role badge. Role badge normalization map:
  ```
  chair → "Chair" (evCoral background)
  vice_chair → "Vice Chair" (evTealLight background)
  ranking_member → "Ranking Member" (evTeal background)
  ex_officio → "Ex Officio" (textMuted background)
  member → "Member" (borderMedium background, textSecondary text)
  ```
  Badge: `borderRadius.full`, `fontSizes.xs`, `fontWeights.semibold`, white text (except member which uses textSecondary). Padding `spacing[1] spacing[3]`.
- Default show 25 items. If more, show "Show all {n} committees" link.
- Empty state message: "Committee information is not available for this office."

**Section 2: Sponsored Legislation**
- Year dropdown filter: extract unique years from `introduced_at` using `.slice(0, 4)` (NOT `new Date().getFullYear()` — avoids timezone bug). Sort descending. Prepend "All". Default to "All".
- Each row: bill number (bold, small), title (main text), status badge (colored pill), introduction date (muted), sponsor/cosponsor indicator ("Sponsored" or "Cosponsored" text label).
- Status badge color map:
  ```
  Introduced → borderLight bg, textMuted text
  Passed House → bgLight bg, evTeal text
  Passed Senate → bgLight bg, evTeal text
  Became Law → success+15% bg, success text
  Vetoed → error+15% bg, error text
  Failed → borderLight bg, textMuted text
  Default fallback → borderLight bg, textSecondary text
  ```
- Default show 25 items (filtered by year). "Show all" expands within the selected year filter.
- Empty state message: "Sponsored legislation data is not available for this office."

**Section 3: Voting Record**
- Year dropdown filter: same pattern as bills, but extract years from `vote_date`.
- Each row: bill title or vote question (main text), vote date (muted), position badge (Yea/Nay/etc), outcome text (Passed/Failed), source link (small "Source" text linking to `bill_url` or derived from `source` field).
- Position badge color map:
  ```
  Yea → success+20% bg, success text
  Nay → error+20% bg, error text
  Not Voting → borderLight bg, textMuted text
  Abstain → evYellowLight bg, evYellowDark text
  Absent → borderLight bg, textMuted text
  ```
  Normalize position: replace underscores with spaces, title-case each word.
- Default show 25 items (filtered by year). "Show all" expands within the selected year filter.
- Empty state message: "Voting records are not available for this office."

**Shared patterns across sections:**
- Section header: `fontSizes.xl`, `fontWeights.bold`, `colors.evTeal`, `marginBottom: spacing[4]`.
- Section container: `marginBottom: spacing[8]`.
- Item rows: flex layout, `padding: spacing[3] 0`, `borderBottom: 1px solid borderLight`.
- "Show all" link: `colors.evTeal`, `fontSizes.sm`, `cursor: pointer`, centered, `marginTop: spacing[3]`.
- Year dropdown: native `<select>` element styled with tokens (border, borderRadius.md, fontSizes.sm, padding spacing[1] spacing[2]). Placed in the section header row, right-aligned.

Use the existing `useMediaQuery('(max-width: 768px)')` hook for mobile. On mobile: stack row items vertically instead of horizontal flex.
