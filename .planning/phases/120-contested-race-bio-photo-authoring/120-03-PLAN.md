d) **Validate each entry before processing:**
   - bio_text must be <= 180 characters (Pitfall 5/ASVS V5)
   - politician_id must be a valid UUID format
   - slug must be a non-empty string
   - Skip entries that fail validation with a logged error

e) **Pre-flight: check politician_images unique constraint** at script startup (before processing any candidates):

```typescript
// Check if the unique constraint on (politician_id, type) exists
const constraintCheck = await pool.query(`
  SELECT 1 FROM pg_constraint
  WHERE conrelid = 'essentials.politician_images'::regclass
    AND contype = 'u'
    AND array_length(conkey, 1) = 2
  LIMIT 1
`);
const hasUniqueConstraint = constraintCheck.rows.length > 0;
console.log(hasUniqueConstraint
  ? '[info] politician_images unique constraint found -- using ON CONFLICT upsert'
  : '[info] politician_images unique constraint NOT found -- using DELETE+INSERT pattern');
```

f) **For each candidate, run in a transaction** (120-PATTERNS.md "Transaction-per-candidate core loop"):
   - Pre-flight check: skip if already has both bio and photo
   - UPDATE bio_text if missing: `UPDATE essentials.politicians SET bio_text = $1, updated_at = now() WHERE id = $2`
   - If photo_source_url is not null:
     - Download image bytes using `fetchImageBytes()` helper (120-PATTERNS.md "Image fetch helper")
     - Detect content type from URL extension (jpg/png/gif/webp, default to image/jpeg) -- NEVER omit contentType (Pitfall 7)
     - Upload to Supabase Storage: `supabaseAdmin.storage.from(BUCKET).upload('monroe_2026/{slug}.{ext}', imageBytes, { contentType, upsert: true })`
     - Get public URL: `supabaseAdmin.storage.from(BUCKET).getPublicUrl(filePath)`
     - Write politician_images row using the safe pattern determined by the pre-flight check:
       - **If hasUniqueConstraint:** `INSERT INTO essentials.politician_images (politician_id, url, type, photo_license) VALUES ($1, $2, 'default', 'sourced') ON CONFLICT (politician_id, type) DO UPDATE SET url = EXCLUDED.url`
       - **If NOT hasUniqueConstraint:** DELETE then INSERT (safe when constraint is absent):
         ```sql
         DELETE FROM essentials.politician_images WHERE politician_id = $1 AND type = 'default';
         INSERT INTO essentials.politician_images (politician_id, url, type, photo_license) VALUES ($1, $2, 'default', 'sourced');
         ```
     - UPDATE photo_custom_url: `UPDATE essentials.politicians SET photo_custom_url = $1 WHERE id = $2` (Pitfall 2 -- fallback render path)
   - COMMIT on success, ROLLBACK on error (log error, continue to next candidate)

g) **In dry-run mode:** Log what would be written but skip all DB writes and uploads. Print `[dry-run]` prefix.

h) **Main entry point:** Load JSON, run constraint pre-flight, call import loop, `pool.end()`. Fatal error handler with `pool.end()` + `process.exit(1)`.

i) **Print summary:** `[done] N candidates processed, M bios written, K photos uploaded, J skipped, E errors`

**Step 3: Create `verify-120-imports.sql`** (120-PATTERNS.md verification query):

```sql
-- Phase 120 import verification -- SELECT only, no writes
SELECT
  p.full_name,
  p.slug,
  p.bio_text IS NOT NULL                                AS has_bio,
  length(p.bio_text)                                    AS bio_length,
  pi.url IS NOT NULL                                    AS has_cdn_photo,
  pi.url                                                AS cdn_url,
  pi.url LIKE 'https://kxsdzaojfaibhuzmclfq.supabase.co%' AS cdn_url_valid,
  r.position_name                                       AS race
FROM essentials.race_candidates rc
JOIN essentials.races r ON r.id = rc.race_id
JOIN essentials.elections e ON e.id = r.election_id
JOIN essentials.politicians p ON p.id = rc.politician_id
LEFT JOIN essentials.politician_images pi
  ON pi.politician_id = p.id AND pi.type = 'default'
WHERE e.election_date = '2026-05-05'
  AND e.state = 'IN'
  AND rc.politician_id IS NOT NULL
  AND rc.candidate_status = 'active'
  AND r.id IN (
    SELECT race_id FROM essentials.race_candidates
    WHERE candidate_status = 'active'
    GROUP BY race_id HAVING COUNT(*) > 1
  )
ORDER BY r.position_name, p.last_name;
```
