```go
// SocrataDatasetConfig holds config for one Socrata dataset (one dataset_type).
type SocrataDatasetConfig struct {
    DatasetType      string `json:"dataset_type"`       // "operating", "revenue", "salaries"
    DatasetID        string `json:"dataset_id"`          // Socrata 4x4 ID e.g. "5242-pnmt"
    HierarchyColumns []string `json:"hierarchy_columns"` // e.g. ["Department_Name", "SubDepartment_Name", "Program_Name"]
    AmountColumn     string `json:"amount_column"`       // e.g. "Appropriation"
    FiscalYearColumn string `json:"fiscal_year_column"`  // e.g. "Fiscal_Year"
}

// SocrataEntityConfig holds metadata for a single Socrata entity (e.g. LA City).
type SocrataEntityConfig struct {
    DisplayName          string                 `json:"display_name"`
    State                string                 `json:"state"`
    EntityType           string                 `json:"entity_type"`
    BaseURL              string                 `json:"base_url"`   // e.g. "https://data.lacity.org"
    FiscalYearStartMonth int                    `json:"fiscal_year_start_month"`
    FiscalYears          []int                  `json:"fiscal_years"`
    Datasets             []SocrataDatasetConfig `json:"datasets"`
}

// ArcGISDatasetConfig holds config for one ArcGIS FeatureServer dataset.
type ArcGISDatasetConfig struct {
    DatasetType      string   `json:"dataset_type"`
    FeatureServerURL string   `json:"feature_server_url"`
    FiscalYearField  string   `json:"fiscal_year_field"`  // e.g. "Budget_Fiscal_Year"
    HierarchyColumns []string `json:"hierarchy_columns"`
    AmountColumn     string   `json:"amount_column"`
}

// ArcGISEntityConfig holds metadata for a single ArcGIS Hub entity (e.g. LA County).
type ArcGISEntityConfig struct {
    DisplayName          string                `json:"display_name"`
    State                string                `json:"state"`
    EntityType           string                `json:"entity_type"`
    FiscalYearStartMonth int                   `json:"fiscal_year_start_month"`
    FiscalYears          []int                 `json:"fiscal_years"`
    Datasets             []ArcGISDatasetConfig `json:"datasets"`
}

// ArcGIS response types for JSON parsing.
type ArcGISField struct {
    Name string `json:"name"`
    Type string `json:"type"`
}

type ArcGISFeature struct {
    Attributes map[string]interface{} `json:"attributes"`
}

type ArcGISQueryResponse struct {
    Fields                []ArcGISField   `json:"fields"`
    Features              []ArcGISFeature `json:"features"`
    ExceededTransferLimit bool            `json:"exceededTransferLimit"`
}
```

**2. Socrata fetcher:**

```go
func fetchSocrataCSV(client *http.Client, baseURL, datasetID string) (io.ReadCloser, error)
```
- Build URL: `fmt.Sprintf("%s/api/views/%s/rows.csv?accessType=DOWNLOAD", baseURL, datasetID)`
- GET request with 120-second timeout (large CSVs)
- Check status 200, reject text/html or application/json Content-Type (means dataset ID is wrong)
- Return resp.Body (caller closes)

**3. Socrata tree builder:**

```go
func buildSocrataCategoryTree(records [][]string, headerIdx map[string]int, dataset SocrataDatasetConfig, targetYear int) ([]CategoryImport, float64, error)
```
- Filter rows by `dataset.FiscalYearColumn` matching `strconv.Itoa(targetYear)` — use `strings.TrimSpace` on the field value
- For revenue datasets where FY is a range like "2020-2021", call `parseFiscalYearRange` to extract end year and compare
- Build N-level hierarchy tree from `dataset.HierarchyColumns` (not limited to 3 levels — per D-05, full tree depth from config)
- Use a generic recursive accumulator: for each row, walk the hierarchy columns, creating nested map entries. At the leaf level, accumulate the amount.
- Convert accumulated tree to `[]CategoryImport` with computed percentages
- Reuse `parseAmount` for the amount column (handles commas, parenthesized negatives)
- Reuse `validateHeaders` for column validation
- Return root categories, totalBudget, error

**Implementation approach for N-level tree:** Use a `map[string]*categoryNode` at each level:
```go
type categoryNode struct {
    name     string
    amount   float64
    children map[string]*categoryNode
    order    []string // insertion order
}
```
Walk hierarchy columns per row. At each level, find-or-create node. At the deepest level, also create LineItemImport entries if there are more hierarchy columns. After accumulation, recursively convert `categoryNode` tree to `[]CategoryImport`.

**4. parseFiscalYearRange helper:**

```go
func parseFiscalYearRange(s string) (int, error)
```
- `strings.TrimSpace(s)`
- If contains "-", split on "-" and parse the LAST segment as int (end year)
- Otherwise parse the whole string as int
- Return the year int
