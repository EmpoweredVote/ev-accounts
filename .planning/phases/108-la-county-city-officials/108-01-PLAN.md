<objective>
Gap-fill the 14 LA County cities that already have partial data in essentials.* (per D-01) so every sitting Mayor, every elected city council seat, and every other ELECTED citywide office (per D-03) is represented as an essentials.politicians + essentials.offices row, with photo_origin_url populated (per LAOF-05) and the district's geo_id set to the 7-digit Census FIPS place code (per D-06).

Cities in scope (D-01): Long Beach, Glendale, Burbank, Downey, El Monte, Inglewood, Lancaster, Norwalk, Palmdale, Pasadena, Pomona, Santa Clarita, Torrance, West Covina.

Purpose: These cities are partially seeded today — Long Beach has 8/9 council members but no Mayor record; Glendale has 2/5 at-large members; Pasadena has 3 of ~8 elected positions; the remaining 11 cities have unknown gaps (CONTEXT.md DB audit was incomplete per RESEARCH.md Tier 1 table). This plan closes those gaps so every LA County resident in one of these cities will have their city officials surfaced by GET /api/essentials/representatives/me.

Output: 7 idempotent SQL migration files (293–299) + 1 standing pre-flight script. Each migration begins with a per-city `-- Pre-flight: X of Y seats already in DB (queried YYYY-MM-DD)` comment derived from a real query result (per the explicit guidance at the bottom of 108-RESEARCH.md), and ends with the office_id back-fill UPDATE for the external_id range it touched.

External_id allocation (per D-09 and 108-RESEARCH.md "External ID Range Assignment"):
- -700050..-700099: Long Beach gap-fill
- -700100..-700149: Glendale gap-fill (3 records: -700100, -700101, -700102)
- -700150..-700199: Pasadena + remaining 11 Tier 1 cities (subdivide by city in migration comments)
</objective>
