**Step 2: Create fetch_building_photos.py**

Create `EV-Backend/scripts/fetch_building_photos.py` following the exact pattern from `scrape_headshots.py` (psycopg2 + utils.py imports). The script:

1. Imports: `sys, os, json, re, time, datetime, requests, psycopg2` and from `utils`: `load_env, load_pipeline_config, load_supabase_env, get_supabase_client, upload_photo_to_storage`
2. Constants:
   - `WIKIMEDIA_API = "https://commons.wikimedia.org/w/api.php"`
   - `WIKIMEDIA_HEADERS = {"User-Agent": "EmpoweredVote/1.0 (https://empowered.vote; building-photos) python-requests/2.32"}`
   - `BUILDING_PHOTO_STORAGE_PREFIX = "la_county/building_photos"`
   - `DOWNLOAD_DELAY = 1.0` (seconds between Wikimedia API calls)
3. Functions:
   - `fetch_wikimedia_image_info(wiki_title)` — calls Wikimedia API with `action=query&prop=imageinfo&iiprop=url|extmetadata&titles=File:{wiki_title}`, returns `dict(url, license, attribution, wiki_title)` or None. Strips HTML from Artist field with `re.sub(r'<[^>]+>', '', html)`.
   - `download_image(url)` — downloads image bytes via `requests.get` with WIKIMEDIA_HEADERS, returns `(bytes, content_type)` tuple.
   - `upsert_building_photo(cur, place_geoid, cdn_url, source_url, license_val, attribution, wiki_title)` — `INSERT INTO essentials.building_photos ... ON CONFLICT (place_geoid) DO UPDATE SET ...` for all fields including `fetched_at = NOW()`.
   - `main()` — loads config, iterates `building_photos` array, for each entry: fetch_wikimedia_image_info, download, upload_photo_to_storage with path `la_county/building_photos/{place_geoid}.{ext}`, upsert DB row. Logs progress. Skips entries where Wikimedia API returns None. Uses `time.sleep(DOWNLOAD_DELAY)` between entries. Commits after all inserts.
4. Supports `--dry-run` flag (fetch + print but no upload/DB write) and `--region` flag (defaults to `default_region`).
5. Uses `psycopg2.connect(os.environ["DATABASE_URL"])` same as `scrape_headshots.py`.

**Key patterns to follow:**
- Use explicit content-type from download response header (not guessed from URL extension)
- Storage path: `la_county/building_photos/{place_geoid}.jpg` (use place_geoid not city name)
- Upload with `upload_photo_to_storage(image_bytes, storage_path, content_type)` from utils.py
- CDN URL returned by upload function is what gets written to `building_photos.url`
