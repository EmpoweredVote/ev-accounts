    Implement an `async function main()` that executes the queries below in order. Every query uses `pool.query()` — never `supabaseAdmin.schema('inform')` (the inform schema is not exposed via PostgREST and will silently fail).

    Query A — TOTAL & SOURCED COUNT (SRCA-01 executive summary):
    Aggregate over `inform.politician_answers pa LEFT JOIN inform.politician_context pc ON pc.politician_id = pa.politician_id AND pc.topic_id = pa.topic_id`, restricted to `pa.politician_id IN (SELECT id FROM essentials.politicians WHERE is_active = true)`. Compute:
    - `total_stances` = COUNT(pa.topic_id)
    - `sourced_stances` = SUM(CASE WHEN pc.politician_id IS NOT NULL AND pc.sources IS NOT NULL AND array_length(pc.sources, 1) IS NOT NULL AND EXISTS (SELECT 1 FROM unnest(pc.sources) AS s(url) WHERE url IS NOT NULL AND trim(url) <> '') THEN 1 ELSE 0 END)
    - `unsourced_stances` = total_stances - sourced_stances
    - `pct_sourced` = ROUND(sourced_stances * 100.0 / NULLIF(total_stances, 0), 1)

    CRITICAL: use `array_length(arr, 1) IS NULL` to detect an empty array. Never use `array_length(arr, 1) = 0` — Postgres returns NULL for empty arrays, not 0.

    Query B — TIER BREAKDOWN (SRCA-01 tier table):
    Join through `essentials.offices` and `essentials.districts` with `DISTINCT ON (p.id)` to derive one tier per politician. Tier and tier_rank derived from `essentials.districts.district_type` via this exact CASE:
    - Federal (tier_rank 1): district_type IN ('NATIONAL_UPPER','NATIONAL_LOWER','NATIONAL_EXEC','NATIONAL_JUDICIAL')
    - State (tier_rank 2): district_type IN ('STATE_UPPER','STATE_LOWER','STATE_EXEC','STATE_BOARD','JUDICIAL')
    - Local (tier_rank 3): district_type IN ('LOCAL','LOCAL_EXEC','COUNTY','SCHOOL')
    - Unknown (tier_rank 4): all others / null
    For each tier, emit: total_stances, sourced_stances, unsourced_stances, pct_sourced.
    Add a "City" sub-classification by joining tier-3 rows to `essentials.governments g` and checking `g.name ILIKE 'City of %'`. If the city distinction fails (governments join is fragile), report Local and City rows as separate but document the City counting rule used in the report's Sourced Definition section. NEVER derive tier from `essentials.offices.title` — title="Senator" matches both US and State senators.

    Query C — MILESTONE COHORTS (SRCA-01 cohort table). Run one COUNT/SUM pair per cohort:
    1. v2.3 senators: filter to politicians whose office row has `district_type = 'NATIONAL_UPPER'`
    2. v2.4 candidates: filter `essentials.politicians.external_id BETWEEN -400143 AND -400101`
    3. v2.5 city officials: filter politicians whose office district government_id is in (SELECT id FROM essentials.governments WHERE name IN ('City of San Francisco','City of San Jose','City of San Diego','City of Berkeley','City of Fremont'))
    4. MD officials migrations 269–271: filter `essentials.politicians.full_name IN ('Wes Moore','Aruna Miller','Anthony Brown','Brooke Lierman','Dereck Davis')` — these have zero stances and must show 0/0 with a clarifying note

    Query D — PER-POLITICIAN TARGET LIST (SRCA-02 CSV):
    Use the Pattern 3 query from 100-RESEARCH.md. Group by politician, compute total_stances/unsourced_count/unsourced_pct/majority_unsourced. Tier subquery uses `DISTINCT ON (p2.id)` to prevent multi-office duplication. Filter `WHERE p.is_active = true`. Use `HAVING SUM(...) > 0` so only politicians with at least one unsourced stance appear (per SRCA-02 wording "all politicians with any unsourced stances"). Order by `tier_rank ASC NULLS LAST, majority_unsourced DESC, unsourced_count DESC, full_name ASC`.

    Query E — WEAK-SOURCE COUNT (sourced rows whose only URL is a domain root):
    Count rows where the only non-blank element of sources matches `^https?://[^/]+/?$` (no path) — surfaces homepage-only URLs like `https://sd07.senate.ca.gov`. These remain counted as SOURCED in the totals but are reported separately in the "Weak Sources Note" section per RESEARCH.md Open Question #1.

    Query F — MD OFFICIALS DEDICATED SECTION:
