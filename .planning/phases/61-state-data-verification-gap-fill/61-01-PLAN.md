  <action>
Create a validation script following the exact same pattern as validate_committee_coverage.py. The script audits bills, votes, and bridge records for Indiana and California.

Structure (follow validate_committee_coverage.py conventions):
1. Load .env.local from parent of scripts/ via dotenv
2. Accept --dry-run, --verbose, --state (IN|CA|both) flags via argparse
3. Accept optional --legiscan-check flag that calls LegiScan getDatasetList to compare session totals (costs 1 API call per state). Without this flag, report DB counts only (no API calls)
4. Use BILL_VOTE_THRESHOLD = 0.90 constant (90% match acceptable per user decision)

STATE_CONFIGS dict for each state (IN, CA):
- state_abbr, jurisdiction
- current_session_year_start: IN=2026, CA=2025 (matching import_state_legislative.py STATE_SESSIONS)
- session_label for display
- spot_check_leaders: list of (spec, description) where spec is partial UUID or "LOOKUP:Name"
  - IN: Speaker Todd Huston, Senate President Pro Tem Rodric Bray (97c61094), plus 1 rank-and-file per chamber
  - CA: Assembly Speaker Robert Rivas, Senate President Pro Tem Mike McGuire, plus 1 rank-and-file per chamber

Checks to implement (per state):

A. **DB bill/vote counts** (always runs):
   - Count total bills in essentials.bills for sessions matching jurisdiction and current year
   - Count total vote records in essentials.votes for those sessions
   - Count distinct politicians with at least one bill sponsorship or cosponsorship
   - Count distinct politicians with at least one vote
   - Print counts formatted like validate_committee_coverage.py

B. **LegiScan session total comparison** (only with --legiscan-check):
   - Call getDatasetList for the state
   - Find dataset matching current session year_start
   - The dataset response includes bill_count — compare against our DB count
   - Calculate match percentage: min(db_count, legiscan_count) / max(db_count, legiscan_count)
   - PASS if >= 90%, FAIL otherwise
   - Note: LegiScan getDatasetList returns metadata without downloading the dataset — 1 API call total per state
   - Use the existing legiscan_query function pattern from import_state_legislative.py (copy the function, don't import — scripts are standalone)
   - Track API usage via COUNTER_PATH (same pattern as import script)

C. **Bridge record completeness**:
   - Enumerate all state legislators in our DB (politicians with STATE_UPPER/STATE_LOWER offices for the state)
   - For each, check if a row exists in essentials.legislative_politician_id_map with id_type='legiscan'
   - Report: X/Y legislators have bridge records (percentage)
   - List any legislators WITHOUT bridge records (these are likely the source of data gaps)

D. **Zero-activity legislator analysis**:
   - For each state legislator in DB, check if they have any bills (sponsor or cosponsor) OR any votes
   - For those with zero activity, check offices.start_date (or similar) to determine if term started within last 6 months of the session — if so, flag as "new — may have limited activity"
   - Otherwise flag as "established — suspected gap"
   - Report aggregate: X new with zero activity (expected), Y established with zero activity (investigate)

E. **Orphaned record detection**:
   - Count bills where sponsor_id IS NULL (no primary sponsor linked)
   - Count votes where politician_id is not in essentials.politicians (broken FK — unlikely but check)
   - Count bill_cosponsors where politician_id is not in essentials.politicians
   - Report counts + sample 3 orphaned bills (bill_number, title) if any exist

F. **Spot-check verification**:
   - For each spot-check leader, resolve their politician_id
   - Verify they have a bridge record in legislative_politician_id_map
   - Count their bills (as sponsor + cosponsor) and votes
   - Print: "[Name] — X bills (Y as sponsor), Z votes [OK|LOW]"
   - Flag LOW if a leadership figure has fewer than 5 total bills+votes (likely a gap)

G. **Overall pass/fail**:
   - Without --legiscan-check: PASS if bridge coverage >= 80% AND no "established" legislators with zero activity exceeds 10% of roster
   - With --legiscan-check: above criteria PLUS bill count match >= 90%
   - Exit 0 if both states PASS, exit 1 if either FAIL

Print API verification hints (curl commands) like validate_committee_coverage.py does.

Important: Do NOT import from import_state_legislative.py — copy any needed utility functions (legiscan_query, budget tracking). Scripts in this project are standalone.
