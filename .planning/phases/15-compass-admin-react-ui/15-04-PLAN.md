    CategoryCard sub-component (local function in same file):

    Props: `{ category: Category & { topics: Topic[] }; allTopics: Topic[]; onAssigned: () => void; }`

    This component handles the topic assignment for ONE category. Because the assignment API is `PUT /api/admin/compass/topics/:id/categories` (PUT on a TOPIC, not on the category), the UI must approach assignment from the topic side:
    - Show the current topics assigned to this category
    - Show all other topics with a checkbox to add them
    - Or simpler: a multi-select of all topics, pre-checking currently assigned ones; saving sends each changed topic's full category list

    Simplest correct approach: show current assignments + an "Assign topic" dropdown. Because the PUT endpoint is topic-centric (sets all categories for a topic), the admin assigns a TOPIC to a CATEGORY by:
    1. Selecting a topic from `allTopics` that is NOT yet in this category
    2. The save sends `PUT /api/admin/compass/topics/:topicId/categories` with `{ category_ids: [all existing category IDs for that topic] + [this category.id] }`

    But we don't have the topic's existing category list without a separate fetch. Keep it simple: since PUT replaces all assignments and we only have the category's topic list (not each topic's full category list), the safest UI is:

    Show assigned topics as chips with a remove button, plus a dropdown to add topics. For ADD: send `PUT /topics/:topicId/categories` with `[category.id]` PLUS any other category IDs that topic already belongs to. We can derive this from the `categories` state — look up all categories and see which ones already contain that topic.

    ```tsx
    function CategoryCard({ category, allTopics, onAssigned }: {
      category: Category & { topics: Topic[] };
      allTopics: Topic[];
      onAssigned: () => void;
    }) {
      // topics NOT yet in this category
      const unassignedTopics = allTopics.filter(t => !category.topics.some(ct => ct.id === t.id));
      const [selectedTopicId, setSelectedTopicId] = useState<string>('');
      const [assigning, setAssigning] = useState(false);

      // NOTE: We need access to all categories to compute a topic's current category IDs.
      // Since CategoryCard is a child and doesn't have allCategories prop, use a simpler approach:
      // The PUT call for "add this topic to this category" sends { category_ids: [category.id] }
      // plus any categories the topic is currently in. We DON'T have that data easily.
      // Resolution: Accept that adding a topic to a category via this UI will REPLACE its full
      // category assignment to just [category.id]. For Alpha seeding, this is acceptable — topics
      // will typically belong to one category. Document this constraint in a code comment.
      // If multi-category support is needed later, the UI needs a richer fetch.

      async function handleAssign() {
        if (!selectedTopicId) return;
        setAssigning(true);
        try {
          await apiFetch(`/admin/compass/topics/${selectedTopicId}/categories`, {
            method: 'PUT',
            body: JSON.stringify({ category_ids: [category.id] }),
          });
          setSelectedTopicId('');
          onAssigned();
        } catch (err) {
          console.error('Failed to assign topic:', err);
        } finally { setAssigning(false); }
      }

      return (
        <div className="bg-white border border-gray-200 rounded-lg p-4">
          <div className="flex items-center justify-between mb-3">
            <h3 className="text-sm font-semibold text-gray-900">{category.title}</h3>
            <span className="text-xs text-gray-400">{category.topics.length} topic{category.topics.length !== 1 ? 's' : ''}</span>
          </div>
          {/* Assigned topics */}
          {category.topics.length > 0 && (
            <div className="flex flex-wrap gap-1.5 mb-3">
              {category.topics.map(t => (
                <span key={t.id} className="px-2 py-0.5 text-xs bg-yellow-50 text-ev-black border border-ev-yellow rounded-full">
                  {t.title}
                </span>
              ))}
            </div>
          )}
          {/* Add topic */}
          {unassignedTopics.length > 0 && (
            <div className="flex gap-2 mt-2">
              <select value={selectedTopicId} onChange={e => setSelectedTopicId(e.target.value)}
                className="flex-1 px-2 py-1.5 text-xs border border-gray-300 rounded-md bg-white">
                <option value="">Assign a topic...</option>
                {unassignedTopics.map(t => (
                  <option key={t.id} value={String(t.id)}>{t.title}</option>
                ))}
              </select>
              <button onClick={handleAssign} disabled={!selectedTopicId || assigning}
                className="px-3 py-1.5 text-xs bg-ev-yellow text-ev-black rounded-md font-medium hover:bg-yellow-400 disabled:opacity-50">
                {assigning ? 'Assigning...' : 'Assign'}
              </button>
            </div>
          )}
        </div>
      );
    }
    ```
