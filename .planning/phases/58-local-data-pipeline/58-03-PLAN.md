**Script structure:**
```
#!/usr/bin/env python3
"""
LA County Board of Supervisors Data Importer (Legistar REST API)

Fetches committee assignments and legislation metadata from the Legistar OData API
for the 5 current LA County supervisors. No token required.

Usage:
    python import_local_lacounty.py --dry-run --verbose
    python import_local_lacounty.py --verbose
    python import_local_lacounty.py --committees-only --verbose
    python import_local_lacounty.py --legislation-only --verbose

Environment variables (loaded from EV-Backend/.env.local):
    DATABASE_URL   PostgreSQL connection string
"""
```

**Constants:**
```python
LEGISTAR_BASE = "https://webapi.legistar.com/v1/LACounty"

SUPERVISOR_PERSON_IDS = {
    799: "Hilda L. Solis",
    938: "Janice Hahn",
    937: "Kathryn Barger",
    1141: "Holly J. Mitchell",
    1300: "Lindsey P. Horvath",
```

**Functions to implement:**

1. **`legistar_get(endpoint, params=None)`** — Wrapper for Legistar API calls. Base URL + endpoint, 30s timeout, raise_for_status, return JSON. Handle 404 gracefully (return None).

2. **`build_supervisor_bridge(conn)`** — For each supervisor PersonId:
   - Query `SELECT id, full_name FROM essentials.politicians WHERE is_active = true` (load once)
   - Use RapidFuzz `fuzz.token_sort_ratio` with threshold 80 to match Legistar names to DB names
   - Single-match-only: skip if 0 or 2+ matches above threshold
   - INSERT bridge row with id_type='legistar', id_value=str(person_id), source='legistar-lacounty'
   - ON CONFLICT DO NOTHING
   - Return dict mapping legistar_person_id -> politician_uuid

3. **`ensure_session(conn)`** — Upsert a LegislativeSession for LA County:
   - jurisdiction="la-county-ca", external_id="lacounty-current", source="legistar", is_current=true
   - Name: "LA County Board of Supervisors (Current Term)"
   - Return session UUID

4. **`fetch_active_office_records(person_id, cutoff_date="2025-01-01")`** — GET `/OfficeRecords` with `$filter=OfficeRecordPersonId eq {person_id} and OfficeRecordEndDate gt datetime'{cutoff_date}'` and `$top=100`. Return list of OfficeRecord dicts.

5. **`fetch_active_bodies()`** — GET `/Bodies?$filter=BodyActiveFlag eq 1 and (BodyTypeId eq 1 or BodyTypeId eq 2)&$top=200`. Return list of Body dicts. These are the committees/boards the supervisors sit on.

6. **`import_committees(bridge_map, session_id, conn)`** — For each supervisor PersonId in bridge_map:
   - Fetch active OfficeRecords
   - For each OfficeRecord:
     - Upsert LegislativeCommittee with external_id="legistar-{OfficeRecordBodyId}", jurisdiction="la-county-ca", name=OfficeRecordBodyName, chamber="local", source="legistar"
     - Determine type: "board" if BodyTypeId=1, "committee" if BodyTypeId=2 (from active_bodies lookup, or default "committee")
     - Upsert LegislativeCommitteeMembership with congress_number=0, is_current=true
     - Parse role from OfficeRecordTitle: "Chair" -> "chair", "Vice Chair" -> "vice_chair", "Alternate" -> "alternate", "Member" -> "member", else "member"
   - Log: "Imported X committee memberships across Y committees for Z supervisors"

7. **`fetch_bos_matters(top=1000, skip=0)`** — GET `/Matters?$filter=MatterBodyId eq 76&$top={top}&$skip={skip}&$orderby=MatterLastModifiedUtc desc`. Return list of Matter dicts.

8. **`fetch_matter_histories(matter_id)`** — GET `/Matters/{matter_id}/Histories`. Return list of MatterHistory dicts. Handle empty arrays gracefully.

9. **`extract_matter_attribution(matter, histories)`** — Try multiple attribution sources in priority order:
   - First: `matter["MatterRequester"]` if non-NULL and non-empty
   - Second: Check each history for `MatterHistoryMoverName` if non-NULL
   - Third: Check each history for `MatterHistorySeconderName` if non-NULL
   - Match extracted names against bridge_map using RapidFuzz `fuzz.token_sort_ratio` with threshold 75
   - Return list of matched politician UUIDs (may be empty)
   - **Per locked decision:** Return empty list if no politician match found — do NOT import without attribution

10. **`import_legislation(bridge_map, session_id, conn, max_matters=None)`** — For all BOS matters:
    - Fetch matters with pagination ($top=1000, $skip for more)
    - For each matter, fetch histories
    - Call extract_matter_attribution — if no matches, log and skip
    - Upsert LegislativeBill with external_id="legistar-{MatterId}", jurisdiction="la-county-ca"
    - Set sponsor_id to first matched politician UUID
    - Set number=MatterFile (or str(MatterId) if NULL)
    - Set title=MatterTitle, raw_status=MatterStatusName
    - Normalize status: map MatterStatusName to standard labels (Approved/Adopted -> "Passed", Filed -> "Filed", etc.)
    - Set introduced_at from MatterIntroDate
    - Set URL to `https://lacounty.legistar.com/LegislationDetail.aspx?ID={MatterId}`
    - Log: "Imported X matters, skipped Y (no politician attribution)"
    - Also log the percentage of matters with attribution vs without

11. **`main()`** — Argparse with flags:
    - `--dry-run`: Read API data but don't write to database
    - `--verbose`: Print detailed API responses and match results
    - `--committees-only`: Only import committees and memberships
    - `--legislation-only`: Only import legislation (assumes bridge already built)
    - `--max-matters N`: Limit matters processed (for testing)

**Important implementation details:**
- Use `from rapidfuzz import fuzz` for name matching
- Do NOT use the OData `in` operator — it is not supported by Legistar v3
- Loop through supervisor PersonIds individually for OfficeRecords
- $top=1000 should cover the BOS matters dataset; add $skip pagination if response length equals $top
- Handle date parsing: Legistar returns dates as `/Date(milliseconds)/` format or ISO strings — parse both
- All INSERT statements use parameterized queries (%s placeholders)
- Add 0.5s delay between Legistar API calls to be respectful
- gen_random_uuid() for new rows, SELECT after upsert to get IDs
- Log attribution statistics at the end: "Attribution rate: X% of Y matters"
