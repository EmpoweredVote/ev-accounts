**Imports and setup:**
```python
import sys, json, re, time, argparse
from pathlib import Path
import requests
import psycopg2
import psycopg2.extras
sys.path.insert(0, str(Path(__file__).parent))
from utils import load_env, load_supabase_env, load_pipeline_config, upload_photo_to_storage
```

**Constants:**
- `SUPERVISOR_STORAGE_PREFIX = "la_county/supervisors"`
- `COUNCIL_STORAGE_PREFIX = "la_county/la_city_council"`
- Browser User-Agent string (Chrome on macOS — same as research pattern)
- Default request headers including `Referer: https://bos.lacounty.gov/` for kc-usercontent.com CDN

**Core functions:**

1. `download_image(url, timeout=15)` — GET with browser User-Agent and Referer header. Returns (image_bytes, content_type) tuple. `content_type` from response `Content-Type` header, default to `"image/jpeg"` if missing/invalid. Raise on HTTP error.

2. `find_politician_id(cur, full_name)` — Simple lookup by `full_name ILIKE %s AND is_active = true` on `essentials.politicians`, returning UUID string or None. ORDER BY last_synced DESC LIMIT 1. Use the exact name from config (which matches FALLBACK names from scrape_la_officials.py).

3. `upsert_politician_image(cur, politician_id, cdn_url, photo_license)` — Check for existing `(politician_id, type='default')` row. If exists: UPDATE url and photo_license. If not: INSERT with gen_random_uuid(), type='default'. Return "updated" or "inserted". This satisfies Success Criterion 5 (idempotent re-run).

4. `process_headshot(cur, entry, storage_prefix, dry_run=False)` — Main per-politician logic:
   - Skip if `entry["photo_url"]` is None/empty (print skip message)
   - Call `find_politician_id()` — skip if not found (print warning)
   - Call `download_image()` — catch requests exceptions, print error, continue
   - Determine storage path: `{storage_prefix}/{entry["storage_filename"]}`
   - If not dry_run: call `upload_photo_to_storage(image_bytes, storage_path, content_type)`
   - If not dry_run: call `upsert_politician_image(cur, politician_id, cdn_url, entry["photo_license"])`
   - Print progress: name, CDN URL, DB action
   - Return result dict with name, status, cdn_url

5. `main()` — Parse args (--region, --dry-run, --group [supervisors|la_city_council|all]). Load env, supabase env, pipeline config. Connect to DB with psycopg2 (cursor_factory=RealDictCursor). Process supervisors then council in order. 1-second delay between downloads (rate limiting). Commit after each group. Print summary: total processed, uploaded, skipped, errors.

**Error handling:**
- Wrap each politician in try/except — log error, continue to next
- Print final summary with counts
- Exit code 0 if any uploads succeeded, 1 if all failed

**Important implementation details:**
- Do NOT call `next_ext_id()` — this script does not create new politicians
- Do NOT import or use SQLAlchemy — use psycopg2 directly (consistent with research pattern)
- Content-type detection: prefer `response.headers.get("Content-Type")` over URL extension guessing. Strip parameters (e.g., `"image/jpeg; charset=utf-8"` -> `"image/jpeg"`). Default to `"image/jpeg"` if response header is missing or not an image/* type.
- The storage_filename in config determines the Supabase path — if a photo is .webp, the storage_filename should end in .webp and content_type should be `"image/webp"`
- Use `argparse` for CLI: `--region` (default from config), `--dry-run` (download but don't upload/upsert), `--group` (supervisors, la_city_council, or all)
