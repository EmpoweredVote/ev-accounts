**Check 1 — Headshot CDN Health (HEAD requests, 80% threshold):**
- Query all DISTINCT headshot URLs from `essentials.politician_images` for active LA County LOCAL/LOCAL_EXEC/COUNTY politicians where `pi.type = 'default'` AND `pi.url LIKE '%supabase%'`. Use `LIMIT 600` as safety cap.
- Also query TOTAL active LA County LOCAL/LOCAL_EXEC/COUNTY politicians (regardless of headshot) to compute population coverage.
- Loop through CDN URLs issuing `requests.head(url, timeout=5, allow_redirects=True)` with `time.sleep(0.1)` between requests.
- Print progress every 50 URLs.
- Print failed URLs (non-200 status) individually.
- Report TWO metrics:
  - CDN health: "X/Y CDN URLs return HTTP 200 (Z%)" — threshold is 80%.
  - Population coverage: "A/B LA County politicians have headshots (C%)" — informational context, not the pass/fail metric.
- PASS if CDN health >= 80%. FAIL otherwise.

**Check 2 — Contact Website Presence (SQL, 89/89 cities):**
- Load `city_sources.json` using `Path(__file__).parent / "city_sources.json"`.
- For each of the 89 cities in `data["cities"]`, collect roster member names.
- For each city, query: do ANY of its roster members (matched by `p.full_name = ANY(names)`) have a `politician_contacts` row where `contact_type = 'city_website'` and `website_url != ''`?
- Track cities_with_contact count and list of cities_without_contact.
- PASS if cities_with_contact == 89. FAIL otherwise (list missing cities).

**Check 3 — Zero Hotlinks (SQL only):**
- Query `essentials.politician_images` joined through offices/districts for active CA politicians with `district_type IN ('LOCAL', 'LOCAL_EXEC', 'COUNTY')` where `pi.type = 'default'` AND `pi.url IS NOT NULL` AND `pi.url != ''` AND `pi.url NOT LIKE '%supabase%'`.
- If any rows returned, list each (politician name + URL) and FAIL.
- If zero rows, PASS.

**Summary table (after all checks):**

  ```
  3. Zero Government Hotlinks                    PASS   0 hotlinks found
  ======================================================================
  OVERALL: PASS
  ```
- Exit 0 if all pass, exit 1 if any fail.
