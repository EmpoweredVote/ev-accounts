Create a new file at `app/src/pages/WelcomeScreen.tsx`. The page is a default-exported React component (matches the existing `LoginPage` / `SignupPage` pattern in `app/src/pages/`).

Structure:

```tsx
import { Link, useSearchParams } from 'react-router-dom';
import { AppNav } from '../components/AppNav';
import { AuthCard } from '../components/AuthCard';
import { PrimaryButton } from '../components/PrimaryButton';
import { SecondaryButton } from '../components/SecondaryButton';

export default function WelcomeScreen() {
  const [searchParams] = useSearchParams();
  const redirect = searchParams.get('redirect');
  const redirectSuffix = redirect ? `?redirect=${encodeURIComponent(redirect)}` : '';

  return (
    <div className="min-h-screen bg-ev-navy flex flex-col">
      <AppNav />
      <div className="flex-1 flex items-center justify-center px-4 py-12">
        <div className="w-full max-w-sm">
          <AuthCard>
            <div className="space-y-1 text-center">
              <h1 className="text-2xl font-bold text-white">Join to participate</h1>
              <p className="text-sm text-gray-400 leading-relaxed">
                Empowered Vote is a civic platform built on trust. You are welcome to
                explore freely — and if a topic moves you, you can join the conversation.
              </p>
            </div>

            <div className="space-y-3">
              <Link to={`/signup${redirectSuffix}`} className="block">
                <PrimaryButton>Create account</PrimaryButton>
              </Link>
              <Link to={`/login${redirectSuffix}`} className="block">
                <SecondaryButton>Log in</SecondaryButton>
              </Link>
            </div>

            <div className="text-center pt-1">
              <Link
                to="/"
                className="text-sm text-ev-teal-light font-medium hover:underline"
              >
                Continue exploring
              </Link>
            </div>
          </AuthCard>
        </div>
      </div>
    </div>
  );
}
```

Implementation rules and pitfalls (from 61-RESEARCH.md):

1. Page background MUST be `bg-ev-navy` — NOT `bg-ev-black`. The two tokens look similar but are distinct (#020618 vs #1c1c1c). Always use `bg-ev-navy` on Phase 61 surfaces.
2. Use `useSearchParams` from `react-router-dom` (not `window.location.search`) — this is the idiomatic React Router v6 hook and matches the rest of the codebase's style.
3. Forward `?redirect=` to BOTH `/signup` and `/login` using a `redirectSuffix` variable. Use `encodeURIComponent(redirect)` when building the suffix to keep URL-encoded params safe.
4. "Continue exploring" links to `/`. This is intentional — Phase 64 will replace the AuthGuard redirect at `/` with InformLanding for unauthenticated users. For now, unauthenticated visitors clicking "Continue exploring" will be bounced to `login.empowered.vote/login` by AuthGuard. This is documented behavior, not a bug.
5. Copy must be invitational. DO NOT use phrases like "Get started", "Sign up today", "Join now", "Don't miss out", or any urgency/conversion language. The phrasing above ("welcome to explore freely... if a topic moves you, you can join the conversation") is the trust-first model.
6. The `<Link>` wrapping a `<PrimaryButton>` works because PrimaryButton is a real `<button type="button">` and Link's anchor wraps it. Do NOT change PrimaryButton to be a link itself — its responsibility is button rendering only (per Phase 60 60-03 SUMMARY's separation of concerns).
7. AuthCard does NOT set max-width — the parent (`max-w-sm` on the inner wrapper) does. Do not add `max-w-sm` inside AuthCard.
8. No `display_name` / `legal_name` fields anywhere on this page — it's an entry surface only, not a form.
