**Insert SSO check in the auth useEffect (lines 96-115):**

The current auth useEffect is:
```javascript
useEffect(() => {
  extractHashToken();
  if (!getToken()) return;
  publicFetch('/account/me')
    .then(...)
    .catch(() => {});
}, []);
```

Replace with an async IIFE that:

1. Calls `extractHashToken()` first (synchronous — preserves existing behavior)
2. If `getToken()` returns null (no existing token), attempt SSO:
   - Create an `AbortController` with a 2-second timeout
   - Call `fetch('/api/auth/session', { credentials: 'include', signal: controller.signal })` — relative URL via Netlify proxy
   - If response is ok, parse JSON, call `setToken(result.access_token)`
   - On ANY failure: do nothing silently. No console.error.
   - Clear the timeout in finally.
3. After SSO attempt (or skip), check `getToken()` again:
   - If token exists: call `publicFetch('/account/me')` (existing pattern)
   - If 401: call `clearToken()`, fall through to guest
   - If ok: `setIsLoggedIn(true)`, `setUsername(data.display_name || null)`, set `help_seen` if `completed_onboarding`
   - If no token: do nothing (guest mode)
4. In the `finally` block: call `setAuthChecking(false)`

The pattern is:
```javascript
useEffect(() => {
  (async () => {
    try {
      extractHashToken();

      // SSO check — only when no local token exists
      if (!getToken()) {
        try {
          const controller = new AbortController();
          const timeout = setTimeout(() => controller.abort(), 2000);
          const res = await fetch('/api/auth/session', {
            credentials: 'include',
            signal: controller.signal,
          });
          clearTimeout(timeout);
          if (res.ok) {
            const data = await res.json();
            if (data.access_token) setToken(data.access_token);
          }
        } catch {
          // Silent fallback — no cookie or network error
        }
      }

      // Auth check (existing logic, now runs after potential SSO)
      if (getToken()) {
        const r = await publicFetch('/account/me');
        if (r.status === 401) {
          clearToken();
        } else if (r.ok) {
          const data = await r.json();
          setIsLoggedIn(true);
          setUsername(data.display_name || null);
          if (data.completed_onboarding) {
            localStorage.setItem("help_seen", "true");
          }
        }
      }
    } catch {
      // Silent — degrade to guest
    } finally {
      setAuthChecking(false);
    }
  })();
}, []);
```

IMPORTANT: Do NOT modify the other two useEffects in CompassContext (the data-loading ones for topics/categories and selectedTopics sync). The SSO check only affects the auth state useEffect.

**Layout.jsx — replace logout function:**

The current logout function (lines 14-40) uses `apiFetch('/auth/logout')` which does NOT send `credentials: 'include'`, and calls `navigate("/")` on both success and error paths.

Replace with:

```javascript
const logout = async () => {
  try {
    const token = getToken();
    await fetch('/api/auth/logout', {
      method: 'POST',
      credentials: 'include',
      headers: {
        ...(token ? { Authorization: `Bearer ${token}` } : {}),
      },
    });
  } catch {
    // Network error — clear local state anyway
  }
  clearToken();
  localStorage.removeItem("compareUser");
  localStorage.removeItem("invertedSpokes");
  localStorage.removeItem("selectedTopics");
  localStorage.removeItem("answers");
  localStorage.removeItem("writeIns");
  setSelectedTopics([]);
  setAnswers({});
  setWriteIns({});
  setIsLoggedIn(false);
};
```

Key changes:
- Native `fetch` with `credentials: 'include'` (NOT apiFetch)
- Bearer token in Authorization header
- ALL `navigate("/")` calls removed — user stays on current page
- All localStorage clearing and state resets preserved
- Always clears local state regardless of API call success
