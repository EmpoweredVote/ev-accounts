  **Part A: Create shared helper in stanceService.ts**

  Add a new exported async function `getDistrictGeoidForPolitician(politicianId: string): Promise<string | null>` that replaces the current `getPoliticianJurisdiction`. It queries the office->district join instead of reading `home_jurisdiction_geoid`:

  ```sql
  SELECT d.geo_id
  FROM essentials.politicians p
  JOIN essentials.offices o ON o.politician_id = p.id
  JOIN essentials.districts d ON d.id = o.district_id
  WHERE p.id = $1
  LIMIT 1
  ```

  Returns `d.geo_id` or null if no row found.

  Keep the old `getPoliticianJurisdiction` function but change its body to call `getDistrictGeoidForPolitician` internally (so existing callers in compassContributor.ts do not break). Add a comment marking it as a thin wrapper.

  **Part B: Fix getContributorPoliticians scoped queries**

  In the `compass_stance_editor` scoped branch (currently line ~236-269), replace the WHERE clause `p.home_jurisdiction_geoid = $1` with a district-join approach:

  ```sql
  SELECT DISTINCT ON (p.id)
    p.id, p.first_name, p.last_name, p.full_name,
    COALESCE(o.title, '') AS office_title,
    COALESCE(p.photo_custom_url, CASE WHEN p.photo_origin_url LIKE 'http%' THEN p.photo_origin_url END, pi.url, '') AS photo_url,
    p.home_jurisdiction_geoid
  FROM essentials.politicians p
  JOIN essentials.offices o ON o.politician_id = p.id
  JOIN essentials.districts d ON d.id = o.district_id
  LEFT JOIN LATERAL (
    SELECT url FROM essentials.politician_images
    WHERE politician_id = p.id AND type = 'default' LIMIT 1
  ) pi ON true
  WHERE p.is_active = true AND d.geo_id = $1
  ORDER BY p.id
  ```

  KEY CHANGES: `LEFT JOIN essentials.offices` becomes `JOIN` (INNER), added `JOIN essentials.districts d ON d.id = o.district_id`, filter is `d.geo_id = $1` instead of `p.home_jurisdiction_geoid = $1`.
