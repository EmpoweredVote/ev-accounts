**Active grants state (grants.length > 0):**
Use `ui-ux-pro-max` skill for the card layout design. One card per grant. Each card shows:
1. **Role display name** — use ROLE_DISPLAY_NAMES constant:
   ```typescript
   const ROLE_DISPLAY_NAMES: Record<string, string> = {
     compass_stance_editor: 'Compass Editor',
     campaign_manager: 'Candidate Coordinator',
     essentials_data_editor: 'Essentials Editor',
   };
   ```
2. **Scope badge** — jurisdiction_geoid displayed as-is (e.g., "06037") for Alpha. If null and feature_scope is "platform", show "Unrestricted". If resource_id is present (campaign_manager), show "Single Politician" or similar.
3. **Grant date** — formatted from `granted_at` (ISO string). Use `new Date(grant.granted_at).toLocaleDateString()`.
4. **Granter** — static text "Granted by Empowered Vote" (real granter attribution is future work).
5. **CTA button** — navigates to the appropriate editor route based on role_slug:
   - `compass_stance_editor` → `/contributor/compass-editor`
   - `campaign_manager` → `/contributor/campaign-manager`
   - `essentials_data_editor` → `/contributor/essentials-editor`

API call pattern (from DashboardPage):
```tsx
const [grants, setGrants] = useState<ContributorGrant[]>([]);
const [loading, setLoading] = useState(true);

useEffect(() => {
  apiFetch<ContributorGrant[]>('/contributor/me')
    .then(setGrants)
    .catch(() => {})
    .finally(() => setLoading(false));
}, []);
```

```typescript
interface ContributorGrant {

  jurisdiction_geoid: string | null;
  resource_id: string | null;
  granted_at: string;
}
```
