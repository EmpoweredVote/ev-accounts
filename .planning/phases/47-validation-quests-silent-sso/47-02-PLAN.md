Replace the existing `signOut()` function in AuthContext.tsx with:

```ts
async function signOut(): Promise<void> {
  // Clear shared ev_session cookie first — propagates logout to all EV apps
  try {
    const accountsApiUrl = import.meta.env.VITE_ACCOUNTS_API_URL as string;
    if (accountsApiUrl) {
      await fetch(`${accountsApiUrl}/api/auth/logout`, {
        method: 'POST',
        credentials: 'include',
      });
    }
  } catch {
    // Network failure — continue to local signOut regardless
    console.error('[SSO] logout cookie clear failed');
  }

  await supabase.auth.signOut();
  // onAuthStateChange fires SIGNED_OUT — state clears automatically via the handler above
}
```

Key requirements:
- POST (not GET) to /api/auth/logout
- credentials: 'include' is MANDATORY for cross-origin cookie transport
- Use VITE_ACCOUNTS_API_URL (accounts API), NOT VITE_API_URL (VQ backend)
- The POST runs FIRST, then supabase.auth.signOut() runs regardless of POST outcome
- Do NOT add a Bearer Authorization header — the endpoint uses the cookie, not a bearer token
- The try/catch ensures signOut() never throws due to the logout POST
- Do NOT change who calls signOut() — Header.tsx already calls `void signOut()` via useAuth()
