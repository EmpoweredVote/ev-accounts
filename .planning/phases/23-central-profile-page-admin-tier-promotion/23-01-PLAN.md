**Migration (20260314000035_phase23_tier_promotion.sql):**

Create in a BEGIN/COMMIT block:

1. `CREATE TABLE IF NOT EXISTS connect.tier_promotion_log` with columns:
   - `id UUID PRIMARY KEY DEFAULT gen_random_uuid()`
   - `admin_id UUID NOT NULL REFERENCES public.users(id)`
   - `admin_email TEXT NOT NULL` (denormalized — avoids auth.users join at read time)
   - `target_user_id UUID NOT NULL REFERENCES public.users(id)`
   - `previous_tier TEXT NOT NULL`
   - `new_tier TEXT NOT NULL`
   - `note TEXT` (nullable)
   - `created_at TIMESTAMPTZ NOT NULL DEFAULT now()`
   Indexes on `target_user_id` and `admin_id`.

2. `CREATE OR REPLACE FUNCTION connect.promote_to_connected(...)` — SECURITY DEFINER, SET search_path = '':
   Parameters: `p_admin_id UUID, p_admin_email TEXT, p_target_user_id UUID, p_note TEXT DEFAULT NULL`
   Returns JSONB.
   Logic:
   - Look up `display_name` from `public.users` WHERE `id = p_target_user_id`. RAISE EXCEPTION 'USER_NOT_FOUND' if not found.
   - Check for existing `connect.connected_profiles` row WHERE `user_id = p_target_user_id`. RAISE EXCEPTION 'ALREADY_CONNECTED_OR_HIGHER' if found.
   - INSERT into `connect.connected_profiles`: user_id, display_name, account_standing='active', verification_status='pending', verification_method='admin_promotion', total_xp=0, gem_balance_yellow=0, gem_balance_blue=0, gem_balance_red=0, completed_onboarding=false. Also set `gem_balance=0` (legacy column may still have NOT NULL constraint — check migration 004).
   - INSERT into `connect.tier_promotion_log`: admin_id=p_admin_id, admin_email=p_admin_email, target_user_id=p_target_user_id, previous_tier='inform', new_tier='connected', note=p_note.
   - Return `jsonb_build_object('ok', true, 'display_name', v_display_name)`.

3. GRANT EXECUTE on the function to service_role.

**profileService.ts (NEW FILE):**

Service using `supabaseAdmin` for all reads (unauthenticated callers have no JWT).

`getPublicProfile(userId: string)`:
- Fetch `public.users` row: `id, display_name, created_at` via supabaseAdmin. Return null if not found.
- Fetch `connect.connected_profiles` row: `user_id, display_name, total_xp, selected_topic_ids` via supabaseAdmin.schema('connect'). Use `.maybeSingle()`.
- Fetch `empower.empowered_profiles` row: `user_id, legal_name, candidate_page_slug, is_active, empowered_at, demoted_at` via supabaseAdmin.schema('empower'). Filter `.is('deleted_at', null)`. Use `.maybeSingle()`.
- Derive tier: `(empowered && empowered.is_active) ? 'empowered' : connected ? 'connected' : 'inform'`
- For Connected/Empowered: call `adminRpc('calculate_level', { p_total_xp: connected.total_xp })` to get level. Use `total_xp` (NEVER `xp`).
- Build base response: `{ username, tier, level, total_xp }` where `username` = empowered?.candidate_page_slug ?? connected?.display_name ?? user.display_name.
- If Connected or Empowered: add `selected_topic_ids` (from connected_profiles, default to []).
- If Empowered:
  - Fetch ALL compass answers via supabaseAdmin.schema('inform').from('compass_responses').select('topic_id, value, write_in_text, inverted, updated_at').eq('user_id', userId).is('deleted_at', null). Add as `compass_answers`.
  - Build `empowered_profile` from empowered_profiles row: `{ legal_name, candidate_page_slug, is_active, empowered_at, demoted_at }`. NOTE: empowered_profiles and inform.politicians are SEPARATE entities — there is NO FK between them. The empowered_profile block comes from empowered_profiles only, NOT from inform.politicians.
- EXCLUDE from response: gems, tolerance_rating, legal_name (at root), email, location_consent.

`getOwnerProfile(userId: string, email: string)`:
- Call `getPublicProfile(userId)` for the base shape.
- Add owner-only fields: `gem_balances: { yellow, blue, red }` (from connected_profiles `gem_balance_yellow/blue/red` — default 0 for Inform users), `location_consent` (from connected_profiles via `getLocationConsent` helper from connectService.ts or direct read), `email`.
- Return the combined shape.
