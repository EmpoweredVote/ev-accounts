5. **Replace get_calibration_lapsed_users** RPC — Phase 4 version lacks went_live_at awareness. CREATE OR REPLACE:
   ```sql
   CREATE OR REPLACE FUNCTION public.get_calibration_lapsed_users(
     p_days_threshold INTEGER DEFAULT 30
   )
   RETURNS TABLE (
     user_id UUID,
     overdue_topic_ids UUID[],
     days_overdue INTEGER
   )
   LANGUAGE sql
   SECURITY DEFINER
   SET search_path = ''
   AS $$
     SELECT
       ep.user_id,
       array_agg(ct.id) AS overdue_topic_ids,
       (CURRENT_DATE - MIN(ct.went_live_at)::date)::integer AS days_overdue
     FROM empower.empowered_profiles ep
     JOIN inform.compass_topics ct ON ct.is_live = true
       AND ct.went_live_at IS NOT NULL
       AND ct.went_live_at <= now() - (p_days_threshold || ' days')::interval
     WHERE ep.is_active = true
     AND NOT EXISTS (
       SELECT 1 FROM inform.compass_responses cr
       WHERE cr.user_id = ep.user_id AND cr.topic_id = ct.id
     )
     GROUP BY ep.user_id;
   $$;
   ```

- `getInviteTree(rootUserId?: string): Promise<{ nodes: object[], edges: object[] }>` — use recursive CTE on connect.invite_chains:
  ```sql
  WITH RECURSIVE tree AS (
    SELECT ic.inviter_id, ic.invitee_id, u.display_name, u.email,
           CASE WHEN ep.is_active = true THEN 'empowered'
                WHEN cp.id IS NOT NULL THEN 'connected'
                ELSE 'inform' END AS tier,
           cp.account_standing
    FROM connect.invite_chains ic
    JOIN public.users u ON u.id = ic.invitee_id
    LEFT JOIN connect.connected_profiles cp ON cp.user_id = ic.invitee_id
    LEFT JOIN empower.empowered_profiles ep ON ep.user_id = ic.invitee_id
    WHERE ($1::uuid IS NULL OR ic.inviter_id = $1)
    UNION
    SELECT ic2.inviter_id, ic2.invitee_id, u2.display_name, u2.email,
           CASE WHEN ep2.is_active = true THEN 'empowered'
                WHEN cp2.id IS NOT NULL THEN 'connected'
                ELSE 'inform' END AS tier,
           cp2.account_standing
    FROM connect.invite_chains ic2
    JOIN tree t ON ic2.inviter_id = t.invitee_id
    JOIN public.users u2 ON u2.id = ic2.invitee_id
    LEFT JOIN connect.connected_profiles cp2 ON cp2.user_id = ic2.invitee_id
    LEFT JOIN empower.empowered_profiles ep2 ON ep2.user_id = ic2.invitee_id
  )
  SELECT * FROM tree;
  ```
  Transform rows into React Flow-compatible nodes and edges arrays. Each row = one edge (inviter_id -> invitee_id) + one node (invitee_id with tier + standing + display_name). Also add root nodes (inviters who are not invitees in the result set).
