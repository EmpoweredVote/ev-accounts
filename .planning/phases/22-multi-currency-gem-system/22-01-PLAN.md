Mirror the `award_xp` RPC pattern from migration 030 exactly. Create a NEW function `connect.award_gems` (do NOT modify `credit_gems` — it remains for internal/cron use).

Function signature:
```sql
CREATE OR REPLACE FUNCTION connect.award_gems(
  p_user_id          UUID,
  p_gem_type         TEXT,
  p_amount           INTEGER,
  p_idempotency_key  TEXT,
  p_source_ref       UUID DEFAULT NULL
)
RETURNS TABLE (
  id               UUID,
  user_id          UUID,
  gem_type         TEXT,
  amount           INTEGER,
  idempotency_key  TEXT,
  balance_after    INTEGER,
  created_at       TIMESTAMPTZ,
  is_duplicate     BOOLEAN
)
```

Implementation steps (same pattern as award_xp):
1. Validate p_gem_type IN ('red', 'blue', 'yellow') — RAISE EXCEPTION if invalid
2. Validate p_amount > 0
3. `PERFORM pg_advisory_xact_lock(hashtext(p_user_id::text));` — serialize per-user
4. Idempotency check: `SELECT * FROM connect.gem_transactions WHERE idempotency_key = p_idempotency_key`. If FOUND, read current balance via EXECUTE format for the gem_type column, RETURN QUERY with is_duplicate = TRUE
5. Lock profile: `EXECUTE format('SELECT gem_balance_%s FROM connect.connected_profiles WHERE user_id = $1 FOR UPDATE', p_gem_type) INTO v_current_balance USING p_user_id;` — RAISE if NULL (no profile)
6. v_new_balance := v_current_balance + p_amount
7. UPDATE the denormalized balance column via EXECUTE format (same pattern as credit_gems)
8. INSERT into gem_transactions with idempotency_key included
9. RETURN QUERY with is_duplicate = FALSE

SECURITY DEFINER, SET search_path = '', LANGUAGE plpgsql.
GRANT EXECUTE to authenticated.

IMPORTANT: Use `gem_balance_yellow`, `gem_balance_blue`, `gem_balance_red` column names (NOT yellow_gem_balance).

**2. backend/src/middleware/gemServiceKeyAuth.ts** — NEW file. Do NOT reuse serviceKeyAuth.ts (different header and permission model).

```typescript
import { Request, Response, NextFunction } from 'express';
import { env } from '../lib/env.js';

export interface GemServiceKeyRequest extends Request {
  permittedGemTypes: string[];
}

// Parse GEMS_SERVICE_KEYS at module load time.
// Shape: { "ctc-key-abc": ["yellow"], "vq-key-xyz": ["yellow", "red"] }
// If env var absent → empty map → all award requests get 401.
// If env var present but malformed JSON → process.exit(1).
let GEM_SERVICE_KEY_MAP: Record<string, string[]> = {};

if (env.GEMS_SERVICE_KEYS) {
  try {
    const parsed = JSON.parse(env.GEMS_SERVICE_KEYS);
    // Validate structure: each key must map to a non-empty string array
    for (const [key, types] of Object.entries(parsed)) {
      if (!Array.isArray(types) || types.length === 0 || !types.every(t => typeof t === 'string')) {
        console.error(`[startup] GEMS_SERVICE_KEYS: key "${key}" has invalid types — must be non-empty string array`);
        process.exit(1);
      }
      const validTypes = ['yellow', 'blue', 'red'];
      for (const t of types as string[]) {
        if (!validTypes.includes(t)) {
          console.error(`[startup] GEMS_SERVICE_KEYS: key "${key}" has invalid gem type "${t}"`);
          process.exit(1);
        }
      }
    }
    GEM_SERVICE_KEY_MAP = parsed;
  } catch (e) {
    console.error('[startup] GEMS_SERVICE_KEYS is malformed JSON:', e);
    process.exit(1);
  }
}
```

Export `requireGemServiceKey` middleware:
