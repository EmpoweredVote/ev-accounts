  <action>
    Create backend/scripts/run-senator-source-triage.ts as a standalone tsx-runnable script following the structure of backend/scripts/run-source-coverage-audit.ts.

    Required module setup: import dotenv, path, fileURLToPath, pg, and node:fs (writeFileSync, mkdirSync) — exact pattern from run-source-coverage-audit.ts. Load backend/.env via dotenv.config with __dirname-relative path. Hard-fail on missing DATABASE_URL.

    Constants to copy verbatim from run-source-coverage-audit.ts: the SOURCED_CASE and UNSOURCED_CASE multi-line SQL CASE expressions. These define the locked sourced definition. Do not reword them. Their match must remain identical between Phase 100 and Phase 101.

    Define an additional constant HOMEPAGE_ONLY_REGEX = `'^https?://[^/]+/?$'` as a TypeScript string holding the Postgres regex pattern. Use the Postgres `~` operator against this pattern (not regexp_match) so it matches the existing audit script's Query E semantics.

    Define a CTE or subquery senate_politicians using DISTINCT ON (p.id) joining essentials.politicians → essentials.offices (on politician_id, is_vacant = false) → essentials.districts (on district_id, district_type = 'NATIONAL_UPPER'). Filter to p.is_active = true. Select p.id, p.full_name, p.party, p.state. ORDER BY p.id (required by DISTINCT ON). This must produce exactly 100 senator rows.

    Query A — Senate triage summary. Aggregate over senate_politicians × inform.politician_answers × LEFT JOIN inform.politician_context. Produce columns: total_senators, total_stances, unsourced_stance_count (SUM UNSOURCED_CASE), weak_stance_count (count where sources is non-null, array_length non-null, every non-blank URL matches HOMEPAGE_ONLY_REGEX, and at least one non-blank URL exists — adapt Query E from run-source-coverage-audit.ts).

    Query B — Per-senator target list with classification. For each senator that has at least one unsourced OR weak-sourced stance, aggregate:
      - full_name, politician_id, state, party (from senate_politicians CTE)
      - total_stances = COUNT(pa.topic_id)
      - unsourced_count = SUM(UNSOURCED_CASE)
      - weak_count = count of pa rows whose pc row exists with at least one non-blank URL but every non-blank URL matches HOMEPAGE_ONLY_REGEX
      - affected_topic_keys = array_agg(DISTINCT t.topic_key) FILTER (WHERE row is unsourced or weak)
      - classification:
          - 'unsourced_only' when unsourced_count > 0 AND weak_count = 0
          - 'weak_only' when unsourced_count = 0 AND weak_count > 0
          - 'both' when both > 0
    JOIN inform.compass_topics t ON t.id = pa.topic_id. HAVING (unsourced_count > 0 OR weak_count > 0). ORDER BY state ASC, full_name ASC.

    Query C — Affected-topic detail rollup. Per (senator, topic_key) include current_value (pa.value), current_sources (pc.sources), state (unsourced vs weak). This is reported in the markdown report but NOT exported in the CSV (CSV stores affected_topic_keys as a single comma-separated string).

    Report builder (buildReport) writes Markdown sections in this order: Executive Summary table; Methodology block (links to locked sourced definition + homepage-only regex); Unsourced Senator Stances (one section per senator with their topic list + current value); Weak-Sourced Senator Stances (same shape, one section per senator); Combined Target List (full table mirroring the CSV); Plan 02 Scoping Note (states the count and recommends batching: ≤10 senators = 1 plan, 11–25 = 2 plans, 26+ = 3 plans per D-03).

    CSV builder (buildCsv) writes the header line then one row per target with affected_topic_keys joined by '|' (pipe delimiter) inside double-quoted CSV field to allow comma-safe parsing downstream.

    Main entry point writes outputs to .planning/phases/101-candidate-profiles/ resolved via __dirname (../../.planning/phases/101-candidate-profiles relative to backend/scripts/). Support a --dry-run flag that prints counts to stderr without writing files (mirror run-source-coverage-audit.ts argv check).

    Exit handling: await pool.end() before process.exit(0). On caught error, log to stderr and exit(1).
  </action>
