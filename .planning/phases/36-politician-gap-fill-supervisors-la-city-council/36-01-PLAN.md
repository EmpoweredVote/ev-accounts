The script does two things:

**Part 1: Schema migration (idempotent)**
```sql
ALTER TABLE essentials.politicians
    ADD COLUMN IF NOT EXISTS is_active boolean NOT NULL DEFAULT true,
    ADD COLUMN IF NOT EXISTS data_source text;
```
Then backfill:
```sql
UPDATE essentials.politicians SET is_active = true WHERE data_source IS NULL;
```

**Part 2: Fix geo_ids for all CA LOCAL districts**

Step A — Fix all CA LOCAL districts (supervisors + all Phase 35 city councils):
```sql
UPDATE essentials.districts
SET geo_id = ocd_id
WHERE state = 'CA'
  AND district_type = 'LOCAL'
  AND (geo_id IS NULL OR geo_id = '')
  AND ocd_id LIKE 'ocd-division/country:us/state:ca/%'
RETURNING id, ocd_id, district_type, label
```
Print count and first 10 rows for verification.

Step B — Fix LA City mayor (LOCAL_EXEC — uses Census GEOID not OCD-ID):
```sql
UPDATE essentials.districts
SET geo_id = '0644000'
WHERE state = 'CA'
  AND district_type = 'LOCAL_EXEC'
  AND ocd_id = 'ocd-division/country:us/state:ca/place:los_angeles'
  AND (geo_id IS NULL OR geo_id = '')
RETURNING id, ocd_id, geo_id
```

Step C — Verification queries:
- Count supervisor districts with geo_id set (expect 5): `WHERE ocd_id LIKE '%county:los_angeles/council_district:%' AND geo_id != ''`
- Count LA City council districts with geo_id set (expect 15): `WHERE ocd_id LIKE '%place:los_angeles/council_district:%' AND geo_id != ''`
- Count LA City mayor district with geo_id='0644000' (expect 1): `WHERE ocd_id = 'ocd-division/country:us/state:ca/place:los_angeles' AND district_type = 'LOCAL_EXEC' AND geo_id = '0644000'`

CRITICAL: The geo_id update for LOCAL districts sets geo_id = ocd_id for ALL CA LOCAL districts (not just supervisors/LA City). This is intentional per RESEARCH.md Pitfall 3 — it activates all Phase 35 geofences (Long Beach, Pasadena, Torrance, Inglewood, West Covina) in one pass. The WHERE clause `(geo_id IS NULL OR geo_id = '')` makes it idempotent.

CRITICAL: The LA City mayor must use geo_id = '0644000' (Census GEOID for LA City G4110 boundary), NOT the OCD-ID. Phase 34 imported the G4110 boundary with geo_id='0644000'. Using OCD-ID format would not match.
