**Create admin/src/components/RolesTab.tsx:**

Props: `userId: string`, `displayName: string`, `roles: Role[]` (where Role includes `slug, name, granted_at, feature_scope, jurisdiction_geoid, resource_id`), `onRefresh: () => void` (callback to re-fetch account data after grant/revoke).

Update the Role interface at the top of AccountDetailPage.tsx to include `feature_scope: string`, `jurisdiction_geoid: string | null`, `resource_id: string | null` — or define the extended interface in RolesTab.tsx and export it.

**Roles table (slim layout):**
- Columns: Role | Scope | Granted | Actions
- Role column: display `role.name` (human-readable) with `role.slug` in smaller mono text below
- Scope column: if `jurisdiction_geoid` is not null, show label "Jurisdiction:" + value. If `resource_id` is not null, show label "Politician:" + value. If both null, show "Platform-wide" in gray.
- Granted column: formatted date from `granted_at`
- Actions column: Revoke button (right-aligned, red text, small)
- Empty state: "No roles assigned" text + Grant Role button

**Grant Role button:** Primary blue button above the table. Opens GrantRoleModal.

**Revoke confirmation:** Use headlessui `Dialog` (same pattern as PoliticiansPage.tsx). On clicking Revoke, open a Dialog with text: "Revoke {role.name} for {displayName}? This cannot be undone." with Cancel (gray) and Confirm Revoke (red) buttons. On confirm: `apiFetch('/admin/roles/revoke', { method: 'POST', body: JSON.stringify({ user_id: userId, role_slug: role.slug, feature_scope: role.feature_scope, jurisdiction_geoid: role.jurisdiction_geoid, resource_id: role.resource_id }) })`. On success: close dialog, show brief green success message (inline div, auto-dismiss after 2s), call `onRefresh()`. On failure: close dialog, show red error message inline.

**Skeleton loading:** Not needed here — roles come from the parent's existing account fetch. If `roles` is empty array, show empty state.

**Create admin/src/components/GrantRoleModal.tsx:**

Props: `open: boolean`, `onClose: () => void`, `userId: string`, `onGranted: () => void` (refresh callback).

Uses headlessui Dialog (import `Dialog, DialogPanel, DialogTitle` from `@headlessui/react`).

**Form fields:**
1. Role selector: `<select>` dropdown. Fetch available roles from `GET /admin/roles` (existing endpoint — returns `{ roles: [{ id, slug, name, is_active }] }`). Filter to active only. Display `name` as option text, use `slug` as value.

2. Conditional field based on selected role slug:
   - If slug === `campaign_manager`: Hide jurisdiction field. Show politician picker — fetch politicians from `GET /admin/politicians` (existing endpoint) on role selection. Render as `<select>` with politician name as text, politician id as value. This sets `resource_id`.
   - For ALL other roles: Show jurisdiction text input (`<input type="text">` with placeholder "e.g., 06037 (optional)"). This sets `jurisdiction_geoid`. Hide politician picker.

3. Feature scope: Do NOT show this as a user-facing field. Derive it automatically:
   - `campaign_manager` with resource_id -> feature_scope = 'resource'
   - Any role with jurisdiction_geoid filled -> feature_scope = 'jurisdiction'
   - Otherwise -> feature_scope = 'platform'

**Submit:** POST to `/admin/roles/grant` with `{ user_id: userId, role_slug, feature_scope, jurisdiction_geoid, resource_id }`. On success: show "Role granted" message inside the modal for 1.5s, then auto-close and call `onGranted()`. On failure: show inline error "Failed to grant role: {error message}" below the form, modal stays open.

**Loading state:** Disable submit button while request is in flight, show "Granting..." text on button.
