**adminService.ts — getRoleAuditLog function:**

Add a new exported function:
```
export async function getRoleAuditLog(filters: {
  feature_scope?: string;
  jurisdiction_geoid?: string;
  from_date?: string;
  to_date?: string;
  page: number;
  page_size: number;
}): Promise<{ entries: unknown[]; total: number; page: number; page_size: number }>
```

Implementation using pool.query:
1. Build a parameterized WHERE clause from non-empty filters:
   - `feature_scope = $N` if provided
   - `jurisdiction_geoid = $N` if provided
   - `created_at >= $N` if from_date provided
   - `created_at < $N + interval '1 day'` if to_date provided (use `< to_date::date + 1` to include the full to_date day)
2. Run a COUNT query for total
3. Run the SELECT query with `ORDER BY created_at DESC`, `LIMIT page_size OFFSET (page - 1) * page_size`
4. SELECT columns: `ral.id, ral.actor_id, ral.target_user_id, ral.action, ral.feature_scope, ral.jurisdiction_geoid, ral.resource_id, ral.created_at`
5. JOIN `public.users actor_u ON actor_u.id = ral.actor_id` and `public.users target_u ON target_u.id = ral.target_user_id` to include `actor_u.display_name AS actor_display_name` and `target_u.display_name AS target_display_name` — the frontend needs display names for linking.
6. Return `{ entries, total, page, page_size }`

**admin.ts — GET /role-audit-log route:**

```
router.get('/role-audit-log', async (req, res) => {
  try {
    const feature_scope = req.query.feature_scope as string | undefined;
    const jurisdiction_geoid = req.query.jurisdiction_geoid as string | undefined;
    const from_date = req.query.from_date as string | undefined;
    const to_date = req.query.to_date as string | undefined;
    const page = Math.max(1, parseInt(req.query.page as string) || 1);
    const page_size = [25, 50].includes(parseInt(req.query.page_size as string) || 25)
      ? parseInt(req.query.page_size as string)
      : 25;

    const result = await getRoleAuditLog({ feature_scope, jurisdiction_geoid, from_date, to_date, page, page_size });
    res.json(result);
  } catch (err) {
    res.status(500).json({ error: 'Internal server error' });
  }
});
```
