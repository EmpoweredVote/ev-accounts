1. **CacheStatusResponse struct** (place near top of file with other types, after the type aliases around line 34):
```go
type CacheStatusResponse struct {
    FederalFresh bool `json:"federalFresh"`
    StateFresh   bool `json:"stateFresh"`
    LocalFresh   bool `json:"localFresh"`
    AllFresh     bool `json:"allFresh"`
    Warming      bool `json:"warming"`
}
```

2. **isWarmingInProgress helper** (place in the helpers section near tryAcquireLock/releaseLock):
- Accepts context and key string
- Calls `pg_try_advisory_lock(hashtext(?))` via db.DB.WithContext(ctx).Raw(...)
- If lock acquired (returns true), IMMEDIATELY release it with `pg_advisory_unlock(hashtext(?))` and return false (not warming)
- If lock NOT acquired (returns false), return true (warming in progress)
- On any error, return false (assume not warming)
- This follows the pattern described in research Pitfall 2 -- acquire-then-release to probe without blocking warmers

3. **getCacheStatus function** (internal, not exported):
- Accepts context and zip string
- Defines `const maxAge = 90 * 24 * time.Hour` (matching handleZipLookup's existing constant)
- Checks federal cache: `db.DB.WithContext(ctx).First(&federalCache)` -- single row with ID=1
- Checks state cache: First derive state from ZipCache record if available, otherwise fallback to `zipPrefixToState(zip)` -- this is the existing pattern from handleZipLookup lines 197-204
- Checks local/ZIP cache: `db.DB.WithContext(ctx).Where("zip = ?", zip).First(&zipCache)` -- reuses the zipCache already fetched for state derivation
- Computes `allFresh = federalFresh && (state == "" || stateFresh) && localFresh`
- Checks warming: OR together `isWarmingInProgress(ctx, "federal")`, `isWarmingInProgress(ctx, "state-"+state)`, `isWarmingInProgress(ctx, "zip-"+zip)` -- these key patterns match the keys used by tryAcquireLock in handleZipLookup
- Returns CacheStatusResponse and error
- This function performs NO JOINs, NO politician data queries, NO warmer triggers -- purely read-only cache table lookups

4. **GetCacheStatus handler** (exported, for route registration):
- Extract zip from URL with `chi.URLParam(r, "zip")`
- Validate with `isZip5(zip)` -- return 400 "Invalid zip parameter" if invalid
- Record start time `t0 := time.Now()`
- Call `getCacheStatus(r.Context(), zip)`
- On error: log with `[GetCacheStatus]` prefix, return 500
- Add Server-Timing header: `addServerTiming(w, [2]string{"total", fmt.Sprintf("%d", time.Since(t0).Milliseconds())})`
- If warming is true: set `Retry-After: 3` header
- Always set `Cache-Control: no-store, no-cache, must-revalidate` (prevents CDN/browser caching of status responses)
- Call `writeJSON(w, status)` to send response

DO NOT modify any existing functions. DO NOT touch handleZipLookup, GetPoliticiansByZip, or any other existing handler. All new code is additive.
