## Goal
A new `essentials.quotes` database table exists and an `./server import-quotes` CLI subcommand loads `data/quote_collection.csv` into it, with validation and upsert semantics. The table schema stores everything needed to serve quotes via API in Plan 03.

## Context
- The quote CSV has 61 data rows with columns: `full_name,topic_key,quote_text,source_url,source_name`
- Quotes live in the essentials schema alongside politician data (per user decision)
- Read & Rank `Quote` interface needs: `id`, `text`, `candidateId`, `issue`, `sourceUrl`, `sourceName`
- Read & Rank also needs `Candidate` and `IssueData` arrays -- these will come from the API in Plan 03
- The quotes table needs politician_id (FK to essentials.politicians) and topic_key (for issue grouping)
- Politician resolution uses the same strategy as stance import: full_name match primary, external_id fallback
- Topic key validation: must exist in compass.topics
- CONTEXT.md says no URL validation -- source URLs imported as-is

<task id="50-02-01" title="Create essentials.quotes model and migration">
Add the Quote model to the essentials package:

1. In `EV-Backend/internal/essentials/models.go`, add a new `Quote` struct at the end of the file (after the existing models):
   ```go
   type Quote struct {
       ID           uuid.UUID `json:"id" gorm:"type:uuid;default:uuid_generate_v4();primaryKey"`
       PoliticianID uuid.UUID `json:"politician_id" gorm:"type:uuid;not null;index:idx_quotes_politician"`
       TopicKey     string    `json:"topic_key" gorm:"not null;index:idx_quotes_topic_key"`
       QuoteText    string    `json:"quote_text" gorm:"type:text;not null"`
       SourceURL    string    `json:"source_url"`
       SourceName   string    `json:"source_name"`
       CreatedAt    time.Time `json:"created_at"`
       UpdatedAt    time.Time `json:"updated_at"`
   }

   func (Quote) TableName() string {
       return "essentials.quotes"
   }
   ```
   - Composite unique index on (politician_id, topic_key, quote_text) is NOT needed because the same politician can have multiple quotes per topic (e.g., Newsom has 2 abortion quotes, 2 deportation quotes)
   - Instead, add a unique constraint comment noting that deduplication is handled at import time by matching on (politician_id, topic_key, source_url)

2. In `EV-Backend/internal/essentials/setup.go`, add `&Quote{}` to the `AutoMigrate` call, placing it after `&PoliticianContact{}`
</task>

<task id="50-02-02" title="Create quote import package">
Create `EV-Backend/internal/quoteimport/csv.go`:

1. Define `QuoteRow` struct: `FullName string`, `TopicKey string`, `QuoteText string`, `SourceURL string`, `SourceName string`
2. Create `ParseCSV(path string) ([]QuoteRow, error)`:
   - Open file, csv.Reader with `LazyQuotes: true` (quote_text contains commas and quotes)
   - Required columns: `full_name`, `topic_key`, `quote_text`, `source_url`, `source_name`
   - Return parsed rows

Create `EV-Backend/internal/quoteimport/import.go`:

1. Define `Config` struct: `CSVPath string`, `DryRun bool`
2. Define `ImportResult` struct: `Processed int`, `Inserted int`, `Updated int`, `Skipped int`, `Errors []string`
3. Create `Run(cfg Config) (*ImportResult, error)`:
   - Use `db.DB` (global GORM connection)
   - Load all `compass.Topic` records, build `map[string]bool` keyed by `topic_key` (for validation only)
   - Load all `essentials.Politician` records (`id`, `full_name`, `external_id`), build `map[string]uuid.UUID` keyed by `full_name`
   - **Detect ambiguous names:** After building the full_name map, make a second pass over the politicians to find names that appear more than once. Build a `map[string]bool` (`ambiguousNames`) containing any `full_name` that maps to more than one politician ID. Implementation: iterate politicians, track counts in a `map[string]int`; any name with count > 1 goes into `ambiguousNames`.
   - Parse CSV via `ParseCSV(cfg.CSVPath)`
   - For each row:
     a. **Validate** topic_key exists in topics map; if not, add error, skip
     b. **Validate** quote_text is non-empty; if empty, add error, skip
     c. **Check ambiguous name**: if `full_name` is in `ambiguousNames`, add error `"row N: ambiguous politician name 'X' — multiple matches in database"`, skip
     d. **Resolve politician**: full_name match; if not found, add error, skip
     e. If `cfg.DryRun`, increment Processed, continue
     f. **Upsert quote**: check for existing `essentials.Quote` WHERE `politician_id = ? AND topic_key = ? AND source_url = ?`
        - If found: update `quote_text`, `source_name`; increment Updated
        - If not found: create new Quote with `uuid.New()` as ID; increment Inserted
     g. Increment Processed
   - Print summary and errors
</task>

<task id="50-02-03" title="Wire import-quotes CLI subcommand into main.go">
In `EV-Backend/main.go`, extend the subcommand switch (added in Plan 50-01) with an `import-quotes` case:

1. Add import for `"github.com/EmpoweredVote/EV-Backend/internal/quoteimport"`
2. Add case to the switch:
   ```go
   case "import-quotes":
       csvPath := "data/quote_collection.csv"
       dryRun := false
       if len(os.Args) > 2 {
           csvPath = os.Args[2]
       }
       for _, arg := range os.Args[2:] {
           if arg == "--dry-run" {
               dryRun = true
           }
       }
       result, err := quoteimport.Run(quoteimport.Config{
           CSVPath: csvPath,
           DryRun:  dryRun,
       })
       if err != nil {
           log.Fatal("import-quotes failed: ", err)
       }
       fmt.Printf("Import complete: %d processed, %d inserted, %d updated, %d skipped\n",
           result.Processed, result.Inserted, result.Updated, result.Skipped)
       os.Exit(0)
   ```

**NOTE:** Plan 50-01 (wave 1) has already executed and created the subcommand switch block in `main.go` with the `import-stances` case. Add the `import-quotes` case to the existing switch block — do NOT recreate the switch.
</task>
