<decisions_made>

- Used bidirectional ST_Contains + ST_PointOnSurface instead of ST_Intersects — ST_Intersects catches all boundaries that touch (including neighbors sharing an edge), while point-on-surface only matches districts whose center is within the area OR that contain the area's center
- Added stateAbbrevToFIPS mapping — geofence_boundaries stores Census FIPS codes (06), Google Geocoding returns abbreviations (CA)
- Stripped " County" / " Parish" suffixes from Google geocoding county names — DB stores just "Los Angeles" not "Los Angeles County"
- Handle Census TIGER city name suffixes (" city", " town", " village") — DB stores "Los Angeles city" but Google returns "Los Angeles"
- NULL external_id handled with COALESCE(p.external_id, 0) — only 2 politicians have NULL but it crashed the entire scan
- No ZIP boundaries exist in DB (272 5-digit geo_ids are county/district FIPS, not ZIPs) — ZIP searches fall through to city/county boundary resolution via geocoding result
</decisions_made>
