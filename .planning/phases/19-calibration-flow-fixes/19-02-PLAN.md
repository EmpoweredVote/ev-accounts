**Compass.jsx data pipe changes:**
Currently, `answers` only contains entries for answered topics. The RadarChart `data` prop receives `answers` directly, meaning unanswered topics have NO entry and therefore NO spoke.

Change the data preparation in Compass.jsx to include ALL selectedTopics in the chart data:
```js
// Build chart data including unanswered topics with value 0
const chartData = useMemo(() => {
  const data = {};
  for (const id of selectedTopics) {
    const topic = topics.find(t => t.id === id);
    if (!topic) continue;
    const val = answers[topic.short_title];
    data[topic.short_title] = (val != null && val > 0) ? val : 0;
  }
  return data;
}, [selectedTopics, topics, answers]);
```

Add this as a `useMemo` in the Compass component, replacing the direct use of `answers` as chart data.

Build the `unansweredSpokes` set:
```js
const unansweredSpokes = useMemo(() => {
  const set = {};
  for (const id of selectedTopics) {
    const topic = topics.find(t => t.id === id);
    if (!topic) continue;
    const val = answers[topic.short_title];
    if (!(val != null && val > 0)) {
      set[topic.short_title] = true;
    }
  }
  return set;
}, [selectedTopics, topics, answers]);
```

Pass both to RadarChart:
```jsx
<RadarChart
  data={chartData}
  unansweredSpokes={unansweredSpokes}
  compareData={compareAnswers}
  invertedSpokes={invertedSpokes}
  onToggleInversion={...}
  onReplaceTopic={...}
/>
```

Update the `onReplaceTopic` handler: when a user clicks a gray (unanswered) spoke, instead of opening the LibraryDrawer, trigger calibration for that specific topic. Add a new handler:
```js
const handleSpokeClick = (shortTitle) => {
  const topic = topics.find(t => t.short_title === shortTitle);
  if (!topic) return;
  const val = answers[shortTitle];
  const isUnanswered = !(val != null && val > 0);
  if (isUnanswered) {
    // Open calibration starting at this topic
    handleStartCalibration();
  } else {
    // Existing behavior: open LibraryDrawer
    setDrawerTopic(topic);
  }
};
```

Use `handleSpokeClick` as the `onReplaceTopic` callback for the RadarChart.
