# Requirements: Empowered Vote Platform

**Defined:** 2026-03-06
**Core Value:** Users can explore political issues and discover their elected officials without friction — the experience must feel polished and trustworthy enough to demo confidently.

## v2026.3.2 Requirements

Requirements for Compass on Profiles milestone. Each maps to roadmap phases.

### Compass Card

- [x] **CARD-01**: User can see a compass comparison card on a politician's Essentials profile page
- [x] **CARD-02**: Compass card only appears for politicians who have compass stances in the database
- [x] **CARD-03**: Compass card left side shows a radar chart with user's compass and politician's stances overlaid
- [x] **CARD-04**: Compass card right side shows a condensed topic-by-topic stance breakdown
- [x] **CARD-05**: Each topic row shows the politician's stance position with brief summary text
- [x] **CARD-06**: Each topic row shows source links for the politician's stance data

### Cross-App Data

- [x] **DATA-01**: Logged-in users' compass answers are accessible from the Essentials app
- [x] **DATA-02**: Guest users' compass answers are accessible from the Essentials app
- [x] **DATA-03**: Politician compass stances are fetchable from the Essentials profile page

## Future Requirements

### Compass Evolution

- **COMP-01**: Politician self-calibrated compass with own topic priorities
- **COMP-02**: Toggle between user-calibrated and politician-calibrated compass on profiles
- **COMP-03**: "My reps" surfacing on CompassV2 compare page (Essentials address data)
- **COMP-04**: Multi-politician comparison (2-3 overlays at once) on profiles

### Cross-App Integration

- **INTG-01**: Read & Rank quotes on Essentials profiles

## Out of Scope

| Feature | Reason |
|---------|--------|
| Politician self-calibrated compass | No politicians have calibrated yet |
| Toggle between user vs politician compass views | Depends on politician calibration |
| Multi-politician comparison on profiles | Adds complexity without current need |
| Read & Rank quotes on Essentials profiles | Separate integration scope |
| Compass calibration flow in Essentials | Users calibrate on CompassV2 app |
