### Known Integration Gap

**districts.geo_id not yet populated** — The full address→geofence→politician lookup chain is:

```
Address → ST_Covers(geofence_boundaries.geometry) → geo_id
       → FindPoliticiansByGeoMatches: WHERE d.geo_id = geo_id
       → essentials.districts → essentials.offices → essentials.politicians
```

The `districts.geo_id` column is empty for LA County records. BallotReady populates `districts.ocd_id` but not `districts.geo_id`. Phase 36 must execute `UPDATE essentials.districts SET geo_id = ocd_id` to bridge the gap. Until then, point-in-polygon queries find correct geofence hits but the politician JOIN returns zero results.
