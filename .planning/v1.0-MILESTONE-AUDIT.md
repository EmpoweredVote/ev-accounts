### Integration Gaps (3)

**GAP-01: Library.jsx compass-preview batch fetch — console noise for guests**
- File: `CompassV2/src/pages/Library.jsx` lines 146-185
- The second useEffect calls `POST /compass/answers/batch` without checking `isLoggedIn`. For guests, this returns 401, and the missing `.catch()` produces an unhandled promise rejection.
- Impact: Console noise only — no functional break.
- Fix: `if (!isLoggedIn) return;` or `.catch(() => {})`

**GAP-02: Register.jsx "Sign In" link goes to Library, not /login**
- File: `CompassV2/src/pages/Register.jsx` line 92
- `onModeSwitch={() => navigate("/")}` sends users to Library instead of `/login`.
- Impact: UX confusion — users can still reach login via header menu.
- Fix: Change to `navigate("/login")`

**GAP-03: Register.jsx buildGuestState race condition**
- File: `CompassV2/src/pages/Register.jsx` lines 18-37
- `buildGuestState()` maps localStorage keys via `topics.find()`. If topics haven't loaded from API yet, the mapping produces empty answers.
- Impact: Low probability — topics typically load in ~200ms, users take longer to fill the form. But on slow connections, answers could silently drop.
- Fix: Add `topics.length === 0` guard
