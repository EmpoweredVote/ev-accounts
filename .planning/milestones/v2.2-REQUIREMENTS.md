## v2.2 Requirements (Phases 69–71)

### TIGER Schema

- [x] **GEO-01**: PostGIS confirmed enabled; `essentials.geo_districts` table with layer discriminator (`layer TEXT NOT NULL`, `UNIQUE(layer, geoid)`) + GIST index — Phase 69
- [x] **GEO-02**: `connect.user_districts` table — cached district resolution per user (user_id, layer, geoid, tiger_geoid, district_type), upsertable by layer — Phase 69
- [x] **GEO-03**: `tiger_geoid` column added to `essentials.districts` — Phase 69

### RPCs

- [x] **GEO-04**: `essentials.resolve_user_districts(lat, lng, layers[])` RPC — point-in-polygon via `ST_Contains`, returns matching rows with `tiger_geoid` — Phase 69
- [x] **GEO-05**: `essentials.cache_user_districts(user_id, lat, lng)` RPC — resolves and upserts into `user_districts`; coordinates never leave Postgres — Phase 69

### TIGER Data Import

- [x] **GEO-06**: CA Assembly (80 districts) imported from TIGER 2024 SLDL shapefile (`tl_2024_06_sldl.zip`) — Phase 69
- [x] **GEO-07**: CA Senate (40 districts) imported from TIGER 2024 SLDU shapefile (`tl_2024_06_sldu.zip`) — Phase 69
- [x] **GEO-08**: US House CA (52 districts) imported from TIGER 2024 CD119 shapefile (`tl_2024_06_cd119.zip`) — Phase 69
- [x] **GEO-09**: `tiger_geoid` backfilled on existing `essentials.districts` records for all 3 CA layers — Phase 69

### Backend Integration

- [x] **GEO-10**: `cache_user_districts` called (fail-open) from both location-write flows — `POST /connect/set-location` (Connected) + `PATCH /account/location-hint` (Inform) — Phase 70
- [x] **GEO-11**: `GET /api/account/districts` endpoint — auth-only, both tiers; returns `{ ca_assembly, ca_senate, us_house }` grouped by layer; 204 when no cache — Phase 70
- [x] **GEO-12**: Path 0 in `GET /essentials/representatives/me` — joins `connect.user_districts → essentials.districts` on `(tiger_geoid, district_type)`; no live PostGIS lookup for cached users; Path 1/1.5/204 fallbacks unchanged — Phase 70

### School Districts

- [x] **GEO-13**: CA school districts (unified, elementary, secondary) imported from TIGER 2024; 975 polygons (346 + 517 + 112); migration 093 extends default `p_layers` to 6 layers — Phase 71
- [x] **GEO-14**: School districts surface on `login.empowered.vote/profile` Location tab; `GET /api/account/school-district` endpoint; Path 0 `layerTypeMap` extended (forward-compat) — Phase 71
