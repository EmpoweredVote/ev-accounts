**Part B: AddTopicModal 8-topic cap enforcement**

In AddTopicModal.jsx:

1. The modal currently allows adding topics without checking the combined count of `selectedTopics.length + selected.length`.
2. Add cap enforcement to the `toggleSelect` function:
```js
const toggleSelect = (id) => {
  setSelected((prev) => {
    if (prev.includes(id)) return prev.filter((x) => x !== id);
    // Cap check: selectedTopics already on compass + newly selected must not exceed 8
    if (selectedTopics.length + prev.length >= 8) return prev;
    return [...prev, id];
  });
  setHasChanges(true);
};
```

3. In the "Available to Add" list, disable the Add button for individual topics when the cap is reached:
```jsx
const isAtCap = selectedTopics.length + selected.length >= 8;

  disabled={isAtCap && !selected.includes(topic.id)}
  className={`px-3 py-1 rounded cursor-pointer ${
    selected.includes(topic.id)
      ? "bg-black text-white"
      : isAtCap
      ? "bg-gray-100 text-gray-400 cursor-not-allowed"
      : "bg-gray-200"
  }`}
>
  {selected.includes(topic.id) ? "Remove" : "Add"}
</button>
```
