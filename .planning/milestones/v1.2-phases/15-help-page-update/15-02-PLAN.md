<task type="auto">
  <name>Task 2: Add first-visit auto-routing to /help</name>
  <files>CompassV2/src/App.jsx, CompassV2/src/pages/Login.jsx</files>
  <action>
Add auto-routing so first-time users are redirected to /help before using the app.

**Detection strategy (localStorage-based for guests, API-based for logged-in):**

For guest users (not logged in):
- Check `localStorage.getItem("help_seen")` on app load
- If not set, redirect to /help
- When the user completes or closes the /help page, Onboarding.jsx already calls `navigate("/results")` — at that point, set `localStorage.setItem("help_seen", "true")`

For logged-in users:
- The existing `completed_onboarding` flag from `/auth/me` already drives this in Login.jsx
- Login.jsx already redirects to `/help` if `!data.completed_onboarding`
- No change needed for logged-in detection — it works correctly

**Implementation in App.jsx:**
- Create a small `<HelpGuard>` wrapper component (or inline logic) that checks if the user should be redirected to /help
- Wrap the main routes (Library `/`, `/library`, `/results`, `/build`, `/quiz`) with this guard
- The guard checks: if `localStorage.getItem("help_seen")` is falsy AND the current route is not `/help`, `/login`, or `/register`, redirect to `/help`
- Do NOT wrap `/help`, `/login`, `/register`, `/admin`, `/401` routes with the guard (these should be accessible regardless)
- Simple implementation: a `<Navigate to="/help" />` from react-router when the condition is met

**Implementation in Onboarding.jsx:**
- In the `handleNext` function (when on last slide), add `localStorage.setItem("help_seen", "true")` before navigating
- In the close (X) button handler, also add `localStorage.setItem("help_seen", "true")` before navigating
- This ensures both completion and early-close mark the help as seen

**Login.jsx update:**
- Change the post-login redirect from `/help` to `/help` (no change to destination) — BUT also set `localStorage.setItem("help_seen", "true")` AFTER the user is redirected to /help and completes it (this is already handled by Onboarding.jsx setting the flag on close/complete)
- Change the `!data.completed_onboarding` redirect destination: currently goes to `/help`, which is correct. Keep as-is.
- Update the post-login redirect for completed_onboarding users: change from `/library` to `/results` to match the new primary destination

**handleResetCompass consideration:**
- The reset compass handler in Compass.jsx clears calibration state. It should NOT clear `help_seen` — the help walkthrough is educational, not tied to compass data. User only needs to see it once.

**Important:** Do NOT clear `help_seen` from localStorage in Compass.jsx's `handleResetCompass`. The help page is an introduction, not a per-compass-session thing.
