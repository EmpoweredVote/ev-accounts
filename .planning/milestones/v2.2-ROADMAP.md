## Milestone Summary

**Decimal Phases:** None

**Key Decisions:**

- PostGIS calls inside SECURITY DEFINER must use `public.ST_Contains`, `public.ST_SetSRID`, etc. when `SET search_path = ''` — no implicit schema resolution
- `tiger_geoid` is non-unique across SLDL/SLDU (assembly D20 + senate D20 share `'06020'`); always filter on `(tiger_geoid, district_type)` together
- `CREATE OR REPLACE FUNCTION` does not replace a different-arity signature — always `DROP FUNCTION IF EXISTS` first to avoid silent "function is not unique" failures (Migration 094 fixed 093)
- Path 0 precedes all existing paths; any failure falls through to Path 1 via single `console.warn` — never short-circuits to error/204
- Fire-and-forget backfill pattern: `void pool.query(...).catch(e => console.warn(...))` after `res.json()` with `districtRows.length === 0` guard
- Operator bulk re-cache: per-user RPC + bulk RPC + Node orchestrator; coordinates decrypt inside Postgres only; idempotent

**Issues Resolved:**

- Migration 094 fixed silent district-cache failures caused by ambiguous 3-arg `cache_user_districts` overload left by Migration 093
- GEO-14 gap (Location tab hidden from Inform users) — fixed post-audit by updating `ProfilePage.tsx:719` gate to check `last_essentials_location` presence

**Issues Deferred:**

- TD-2 (non-blocking): 204 handling for `/account/districts` and `/account/school-district` relies on SyntaxError from empty body parse being swallowed by `.catch(() => {})` — fragile pattern, acceptable for Alpha
- TD-3 (non-blocking): `tiger_geoid` non-uniqueness correctness requires migrations 089+091 to run in sequence — no production risk with ordered migration runs
- School board members: `layerTypeMap` extended with school layers in Path 0 (forward-compat); zero-row joins until a future ingestion phase populates `essentials.politicians` school board records

**Technical Debt Incurred:**

- None material. School board ingestion is a separate future phase, not tech debt.
