Follow the 033 migration pattern: header comment block, BEGIN/COMMIT wrapping, IF NOT EXISTS for idempotency.

Header comment must include:
- These three tables model upcoming/current election events — DIFFERENT from essentials.election_records which is a legacy BallotReady table for historical career data
- Antipartisan rationale: "NO party affiliation fields in any table. Empowered Vote derives political alignment from compass answers, legislative votes, and sourced quotes. Party labels are partisan signals that undermine voter independence. Even if upstream data sources (SoS filings, county clerk data) include party fields, they are explicitly excluded at ingestion."

Three tables inside BEGIN/COMMIT:

**essentials.elections** — the election event:
- id: uuid PK with uuid_generate_v4() default
- name: text NOT NULL (e.g. "2026 Indiana Primary")
- election_date: date NOT NULL (PostgreSQL date type, NOT text)
- election_type: text NOT NULL with CHECK (election_type IN ('primary','general','retention','special'))
- jurisdiction_level: text NOT NULL with CHECK (jurisdiction_level IN ('federal','state','county','city','district'))
- state: character(2) nullable
- description: text nullable
- created_at: timestamptz NOT NULL DEFAULT now()
- updated_at: timestamptz NOT NULL DEFAULT now()

**essentials.races** — a position within an election:
- id: uuid PK with uuid_generate_v4() default
- election_id: uuid NOT NULL REFERENCES essentials.elections(id) ON DELETE CASCADE
- office_id: uuid nullable REFERENCES essentials.offices(id) — comment: nullable because some races may not yet have a corresponding offices record
- position_name: text NOT NULL (display name like "City Council District 3")
- seats: int NOT NULL DEFAULT 1
- description: text nullable
- created_at/updated_at: timestamptz NOT NULL DEFAULT now()

**essentials.race_candidates** — a person in a race:
- id: uuid PK with uuid_generate_v4() default
- race_id: uuid NOT NULL REFERENCES essentials.races(id) ON DELETE CASCADE
- politician_id: uuid nullable REFERENCES essentials.politicians(id) — comment: NULL for challengers per D-05, incumbents link to existing records
- full_name: text NOT NULL (denormalized for challengers)
- first_name: text nullable
- last_name: text nullable
- photo_url: text nullable (for challengers without politician record)
- is_incumbent: boolean NOT NULL DEFAULT false
- candidate_status: text NOT NULL DEFAULT 'active' with CHECK (candidate_status IN ('active','withdrawn','filed')) — comment: active=on ballot, filed=early-stage unconfirmed, withdrawn=removed per D-06
- last_verified_at: timestamptz nullable (data freshness tracking)
- source: text nullable (data origin: sos_excel, county_clerk, manual)
- external_id: text nullable (SoS filing ID if available)
- created_at/updated_at: timestamptz NOT NULL DEFAULT now()
- Add comment: "NO party_name, party_affiliation, or partisan fields. See antipartisan rationale above."

**Indexes** (all with IF NOT EXISTS):
1. idx_elections_election_date ON essentials.elections(election_date)
2. idx_elections_state ON essentials.elections(state)
3. idx_races_election_id ON essentials.races(election_id)
4. idx_races_office_id ON essentials.races(office_id)
5. idx_race_candidates_race_id ON essentials.race_candidates(race_id)
6. idx_race_candidates_politician_id ON essentials.race_candidates(politician_id) WHERE politician_id IS NOT NULL (partial index)
7. idx_race_candidates_status ON essentials.race_candidates(candidate_status)
8. idx_race_candidates_external_id as UNIQUE ON essentials.race_candidates(external_id) WHERE external_id IS NOT NULL (partial unique)

Add COMMENT ON COLUMN explaining the purpose, which Indiana courts qualify, and the distinction from districts.retention.

**Step 2 — Flag Indiana retention offices:**
```sql
UPDATE essentials.offices o
SET faces_retention_vote = true
FROM essentials.chambers ch
JOIN essentials.governments g ON g.id = ch.government_id
WHERE o.chamber_id = ch.id
  AND g.state = 'IN'
  AND o.is_appointed_position = true
  AND (
    ch.name ILIKE '%supreme court%'
    OR ch.name ILIKE '%court of appeals%'
    OR ch.name ILIKE '%tax court%'
  );
```
