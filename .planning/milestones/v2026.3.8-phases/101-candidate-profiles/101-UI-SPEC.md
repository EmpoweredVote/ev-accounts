## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#f0f8fa` (`--ev-bg-light`) | Page background, `min-h-screen` wrapper, loading state background |
| Secondary (30%) | `#ffffff` + `#fffef5` | Card surfaces, banner backgrounds, PoliticianProfile card interior |
| Accent (10%) | `#00657c` (`--ev-teal`) | Spinner border, `pac-matched` text, interactive teal elements |
| Election / warning accent | `#fed12e` (`--ev-yellow`) | Candidate banner left border for active election context |
| Ballot accent | `#f6ad55` | "Seat is on the ballot" banner left border (amber — existing pattern) |
| Destructive | `#ff5740` (`--ev-coral`) | Destructive actions only — not used in this phase |

Accent reserved for: loading spinner (`border-[var(--ev-teal)]`), matched text in autocomplete, and any teal interactive link or button. Never apply `--ev-teal` to decorative or informational elements.

`--ev-yellow` is reserved specifically for the "Candidate for [position]" election context banner border. Do not use it for generic highlight or informational UI.

`#f6ad55` (amber) is reserved specifically for the "This seat is on the ballot" reelection banner border. Maintain this distinction from `--ev-yellow` — the two banner types must be visually distinguishable.

Source: `essentials/src/index.css` CSS custom properties + existing banner inline styles in `CandidateProfile.jsx` lines 97–141.

## Interaction Contracts

### Loading State

Single top-level spinner for the entire profile. Do not use per-section skeletons.

```
Centered spinner, py-24, teal ring:
  animate-spin rounded-full h-10 w-10 border-4 border-[var(--ev-teal)] border-t-transparent
```

Source: Exact class string from existing `CandidateProfile.jsx` line 64–66 and `Profile.jsx` line 73–75. Maintain identical markup.

### Banner Variants

Two distinct banner types, both rendered as left-bordered info blocks inside `PoliticianProfile`'s `banner` prop:

**Variant A — Active candidate banner** (all candidates reaching this page):
- Left border: 4px solid `#fed12e`
- Background: `#fffef5`
- Title: "Candidate for [position_name]" at 15px / weight 700 / `#2d3748`
- Subtitle: "Election: [formatted date]" at 13px / weight 400 / `#718096`

**Variant B — Seat on ballot banner** (incumbent whose term is expiring):
- Left border: 4px solid `#f6ad55`
- Background: `#fffaf0`
- Title: "This seat is on the ballot" at 15px / weight 700 / `#2d3748`
- Subtitle: "Incumbent is seeking reelection · Election: [date]" or "Open seat" at 13px / `#718096`

Variant A takes priority for the candidate profile context. Variant B is rendered via `getSeatBallotStatus` and should remain as-is.

### Back Navigation

Inherits the `ev:fromView` sessionStorage pattern exactly as implemented. Back label reads "Elections" when `fromView === 'elections'`, otherwise "Representatives".

### Not-Found State

When `fetchRaceCandidate` returns null (withdrawn or invalid ID):

```
Centered within <main>, py-16:
  Heading: "Candidate not found" — 16px / weight 700 / #2d3748
  Body: "This candidate may have withdrawn or the link may be incorrect." — 14px / weight 400 / #718096
  Back button: standard back navigation using ev:fromView pattern
```
