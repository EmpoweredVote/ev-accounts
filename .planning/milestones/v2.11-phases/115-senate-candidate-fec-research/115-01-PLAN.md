Name helpers (inline — do NOT import from fecResearch):
  normalize(s): lowercase, strip accents using ACCENT_MAP (same map as fecResearch.ts), remove non-a-z/space chars

candidateSearch(lastName, stateAbbr, apiKey):

  await sleep(SLEEP_MS) before the fetch call
  Return typed results: Array<{ candidate_id: string; name: string; state: string; office: string }>

main():
  1. Read apiKey from process.env.FEC_API_KEY — throw if missing
  2. Log DRY_RUN mode
  3. Query NATIONAL_UPPER NULL-finance politicians (SQL above in interfaces block)
  4. Log count found
  5. Initialize stats: { confirmed: 0, written: 0, no_committee: 0, no_match: 0, not_applicable: 0, error: 0 }
  6. For each politician:
     a. If pol.full_name.toLowerCase() is in NOT_APPLICABLE set AND NOT DRY_RUN:
        - Log: NOT_APPLICABLE  {pol.full_name}
        - DELETE + INSERT politician_sources with research_status='not_applicable', external_id='', notes=NOT_APPLICABLE_NOTE
        - stats.not_applicable++
        - continue
     b. If NOT_APPLICABLE but DRY_RUN: log NOT_APPLICABLE line, stats.not_applicable++, continue
     c. Derive stateAbbr: FIPS_TO_ABBR[pol.fips_code] — if undefined, log SKIP (unknown FIPS), continue
     d. Extract lastName: parseDbName(pol.full_name).last
     e. Call candidateSearch(lastName, stateAbbr, apiKey)
     f. Score all results with scoreMatch; pick highest
     g. If best score < 0.8 OR no results:
        - Log: NO_MATCH  {pol.full_name} ({stateAbbr}) — best score {score}
        - If NOT DRY_RUN: DELETE + INSERT politician_sources with research_status='needs_research',
          external_id='', notes= JSON of top 3 candidates (candidate_id, name, score) or 'No candidates found'
        - stats.no_match++; continue
     h. Selected fecId = best result's candidate_id
     i. Log: MATCH  {pol.full_name} → {fecId} (score {score})
     j. stats.confirmed++
     k. If DRY_RUN: continue
     l. DELETE + INSERT politician_sources with research_status='confirmed', external_id=fecId, notes=''
     m. Call fetchFecData(fecId, apiKey)
     n. If null: stats.no_committee++; continue
     o. UPDATE essentials.politicians SET finance_summary = $1::jsonb WHERE id = $2
     p. Log:   [OK] ${totalRaised.toLocaleString()} written
     q. stats.written++
  7. Log === DONE === and JSON.stringify(stats, null, 2)
  8. await pool.end()
