**PoliticianProfile.jsx — Add term date subtitle below title (PROF-02):**

Add a term date formatting helper at the top of the file (before the component):

```javascript
function formatTermDate(dateStr) {
  if (!dateStr) return null;
  const d = new Date(dateStr);
  if (isNaN(d.getTime())) return null;
  return d.toLocaleDateString('en-US', { month: 'short', year: 'numeric' });
}

function getTermLine(pol) {
  const start = formatTermDate(pol.term_start);
  if (!start) return null;
  const end = formatTermDate(pol.term_end);
  return end ? `${start} \u2013 ${end}` : `Since ${start}`;
}
```

Edge case rules from user decisions:
- Missing dates (both null): `getTermLine` returns null, hide the line entirely
- Start only, no end: display as "Since Jan 2023"
- Both dates present: display as "Jan 2023 – Jan 2027" (use en-dash \u2013)
- Expired terms: show normally with no special indicator

Note: Use en-dash (\u2013) for the date range, not em-dash (\u2014) — the em-dash was used in the old card rendering but en-dash is typographically correct for date ranges.

In the component JSX, add the term date line directly below the `<h2 style={styles.title}>` (line 232), inside the `nameTitle` div:

```jsx
<h2 style={styles.title}>{pol.office_title}</h2>
{getTermLine(pol) && (
  <p style={styles.termDate}>{getTermLine(pol)}</p>
)}
```

Add `termDate` to the styles object (Claude's discretion for exact styling — use these values):

```javascript
termDate: {
  fontFamily: fonts.primary,
  fontWeight: fontWeights.regular,
  fontSize: fontSizes.sm,
```

This uses `fontSizes.sm` (14px), `colors.textMuted` (#718096), and no label prefix — just the date range by itself. The `marginBottom: spacing[3]` (12px) provides spacing before the next content below.
