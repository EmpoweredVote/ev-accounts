Add two helper functions ABOVE the CompassProvider component (module-level, not inside the component):

1. **getOrCreateGuestId()** — reads `guestId` from localStorage; if missing, generates one via `crypto.randomUUID()` and stores it. Returns the string ID.

```js
function getOrCreateGuestId() {
  let id = localStorage.getItem("guestId");
  if (!id) {
    id = crypto.randomUUID();
    localStorage.setItem("guestId", id);
  }
  return id;
}
```

2. **shouldFlip(guestId, topicId)** — deterministic hash of the concatenated strings, returns boolean. Use a djb2-style hash with unsigned 32-bit wrapping:

```js
function shouldFlip(guestId, topicId) {
  let hash = 0;
  const str = guestId + String(topicId);
  for (let i = 0; i < str.length; i++) {
    hash = ((hash * 31) + str.charCodeAt(i)) >>> 0;
  }
  return (hash & 1) === 1;
}
```

3. **Rewrite `initRandomInversions`** — change the signature from `(shortTitles)` (array of strings) to `(topicsArray)` (array of topic objects with `{ id, short_title }`). The new implementation:

```js
const initRandomInversions = useCallback((topicsArray) => {
  setInvertedSpokesRaw((prev) => {
    const hasExisting = topicsArray.some((t) => t.short_title in prev);
    if (hasExisting) return prev;
    const guestId = getOrCreateGuestId();
    const next = { ...prev };
    for (const topic of topicsArray) {
      if (shouldFlip(guestId, topic.id)) {
        next[topic.short_title] = true;
      }
    }
    localStorage.setItem("invertedSpokes", JSON.stringify(next));
    return next;
  });
}, []);
```

Key changes from current code:
- Iterates topic objects instead of short title strings
- Uses `shouldFlip(guestId, topic.id)` instead of `Math.random() < 0.5`
- The `hasExisting` guard remains to prevent re-randomizing already-set topics

Do NOT add `guestId` to the localStorage keys that get cleared on logout (in Layout.jsx). The research confirms `guestId` should persist across logout so a returning user on the same browser keeps their stance order.
