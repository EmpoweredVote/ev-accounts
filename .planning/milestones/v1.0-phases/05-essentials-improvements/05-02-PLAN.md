  <action>
Add a `badge` prop (string) to PoliticianCard. When truthy, render a small absolute-positioned pill in the top-right corner of the card.

1. Add `badge` to the destructured props alongside existing props.

2. Add a badge style object:
```javascript
badge: {
  position: 'absolute',
  top: spacing[1],
  right: spacing[1],
  backgroundColor: colors.evCoral,
  color: colors.textWhite,
  fontFamily: fonts.primary,
  fontWeight: fontWeights.semibold,
  fontSize: '10px',
  lineHeight: 1,
  padding: `${spacing[1]} ${spacing[2]}`,
  borderRadius: borderRadius.full,
  zIndex: 1,
  letterSpacing: '0.02em',
  textTransform: 'uppercase',
}
```

3. Inside the JSX, immediately after the opening `<div style={styles.card}>`, render the badge conditionally:
```jsx
{badge && <span style={styles.badge}>{badge}</span>}
```

The card already has `position: 'relative'` in its styles, so absolute positioning will work correctly. The badge renders inside the card's relative context, so `overflow: 'hidden'` on the card will not clip it (it is inside the card bounds).

4. Update the JSDoc comment to document the new prop:
```
 * @param {string} props.badge - Optional badge label (e.g., "Candidate") shown as coral pill
```

**IMPORTANT:** Do NOT change `overflow: 'hidden'` on the card. The badge sits inside the card and does not need to overflow. The badge should appear over the image area in horizontal variant and over the top-right in vertical variant.
