2. **Download:** TIGER 2024 CA PLACE shapefile from `https://www2.census.gov/geo/tiger/TIGER2024/PLACE/tl_2024_06_place.zip` into `./shapefile_data/`

3. **Filter MTFCC to G4110 only** — this is CRITICAL. The PLACE shapefile contains G4110 (incorporated places), G4150 (CDPs), and G4210 (other). Only G4110 should be imported. Without this filter, unincorporated community CDPs would create false city council matches. Filter with: `gdf = gdf[gdf['MTFCC'] == 'G4110']`

4. **Also filter STATEFP to '06'** (CA only) — same as canonical script

5. **Reproject from NAD83 to WGS84:** `if gdf.crs != "EPSG:4326": gdf = gdf.to_crs("EPSG:4326")` — TIGER ships in EPSG:4269 (NAD83)

6. **Validate geometry before import:** Check `gdf.geometry.is_valid`, apply `gdf.geometry.make_valid()` if any invalid

7. **Build clean GeoDataFrame** with columns: `geo_id` (from GEOID, 7 chars: STATEFP+PLACEFP), `name` (from NAMELSAD), `mtfcc` (G4110), `state` ('06'), `geometry`, `source` ('census_tiger_2024'), `imported_at` (datetime.now().isoformat()). Note: `ocd_id` is intentionally NULL — consistent with existing Indiana G4110 records, and geofence_lookup.go uses geo_id not ocd_id for matching.

8. **Import with duplicate handling:** Use `to_postgis(if_exists='append')` with the same `import_individually()` fallback on unique constraint violations (catches duplicates row-by-row, skipping existing).

9. **Reuse helper functions** from the canonical script: `download_file()`, `extract_shapefile()`, `import_individually()` — copy these verbatim.

10. **Include verify_import() function** that runs these checks:
    - Count of CA G4110 records (expected: ~482, acceptable range 450-520)
    - ST_IsValid check: `SELECT COUNT(*) FROM essentials.geofence_boundaries WHERE state = '06' AND mtfcc = 'G4110' AND NOT ST_IsValid(geometry)` (expected: 0)
