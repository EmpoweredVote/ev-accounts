**Part B: Create `EV-Backend/scripts/scrape_la_officials.py`**

Reusable config-driven scraper using psycopg2 direct (not SQLAlchemy ORM), following promote_scraped_officials.py pattern.

**Script architecture:**

```
1. Load config from politician_sources.json
2. Run gap_fill_geo_ids.py first (schema migration + geo_id fix) — call as subprocess or inline
3. For each source in config:
   a. Scrape official names from source URL
   b. For each official:
      i.   Find district row by ocd_id
      ii.  Find existing politician via seat-first dedup (ocd_id + title -> fuzzy name match)
      iii. If exact/fuzzy match: UPDATE data fields (overwrite with fresher scraped data per CONTEXT.md)
      iv.  If new_person_in_seat: mark old politician is_active=false, INSERT new politician
      v.   If no seat exists: CREATE district + chamber + office + politician (unlikely for supervisors/council but handle it)
4. Run dedup verification query
5. Run point-in-polygon verification queries
```

**Key functions to implement:**

1. `parse_la_county_bos(html)` — Parser for bos.lacounty.gov supervisor page. Return list of dicts: `[{district: 1, name: "Hilda L. Solis", ...}, ...]`. Use BeautifulSoup. The page lists all 5 supervisors with names and district numbers. IMPORTANT: If the page structure makes scraping unreliable, fall back to the hardcoded list from RESEARCH.md (verified Feb 2026 from authoritative sources):
   ```
   D1: Hilda L. Solis, D2: Holly J. Mitchell, D3: Lindsey P. Horvath,
   D4: Janice Hahn, D5: Kathryn Barger
   ```

2. `parse_la_city_clerk(html)` — Parser for clerk.lacity.gov/articles/current-elected-officials. Return list of dicts for all 15 council members. Use BeautifulSoup. IMPORTANT: Same hardcoded fallback strategy — if HTML parsing fails, use the verified Feb 2026 roster from RESEARCH.md (D1 Eunisses Hernandez through D15 Tim McOsker).

3. `parse_la_city_clerk_mayor(html)` — Extract mayor name from same clerk.lacity.gov page. Expected: Karen Ruth Bass. Hardcoded fallback if parsing fails.

4. `find_existing_politician_for_seat(cur, ocd_id, title, scraped_name)` — Seat-first dedup:
   - Step 1: Query `districts d JOIN offices o ON o.district_id = d.id JOIN politicians p ON p.id = o.politician_id WHERE d.ocd_id = %s AND LOWER(o.title) LIKE LOWER(%s)`
   - Step 2: Exact full_name match (case-insensitive)
   - Step 3: Fuzzy last-name match with Levenshtein distance <= 1 (Claude's discretion: threshold = 1, not 2, per RESEARCH.md Pitfall 5 — short names like "Hahn" need tight threshold)
   - Return `(politician_id, match_type)` where match_type is 'exact', 'fuzzy', 'new_person_in_seat', or None (no seat exists)
   - NOTE: Match on title uses LIKE with '%Supervisor%' or '%Council Member%' — not exact match, since existing titles may vary slightly

5. `upsert_politician(cur, source_config, official_data)` — Main upsert logic:
   - If exact/fuzzy match: UPDATE full_name, party, data_source, last_synced on existing record. If scraped data is fresher (per CONTEXT.md: "overwrite with scraped data"), also update first_name, last_name, photo_origin_url, bio_text.
   - If new_person_in_seat: `UPDATE politicians SET is_active = false WHERE id = old_id`, then INSERT new politician + office record. Use `next_ext_id()` from utils.py for synthetic external_id. Generate UUID with `uuid.uuid4()` for id.
   - If no seat: Create district (with ocd_id, geo_id=ocd_id for LOCAL or '0644000' for LOCAL_EXEC, state='CA'), find-or-create chamber, create office, create politician. Use `next_ext_id()` for all external_ids.
   - Always set `data_source = source_config['url']` and `source = 'scraped'` and `last_synced = NOW()` and `is_active = true`.

6. `verify_no_duplicates(cur)` — Run the dedup verification query from RESEARCH.md:
   ```sql
   SELECT d.ocd_id, p.full_name, COUNT(*) as active_count
   FROM essentials.politicians p
   JOIN essentials.offices o ON o.politician_id = p.id
   JOIN essentials.districts d ON o.district_id = d.id
   WHERE p.is_active = true
     AND d.state = 'CA'
     AND d.district_type IN ('LOCAL', 'LOCAL_EXEC')
     AND d.ocd_id LIKE 'ocd-division/country:us/state:ca/%'
   GROUP BY d.ocd_id, p.full_name
   HAVING COUNT(*) > 1
   ```
   Print results. POL-05 requires this returns 0 rows.

7. `verify_point_in_polygon(cur)` — Run the supervisor and council PIP tests from RESEARCH.md:
   - East LA unincorporated (34.0239, -118.1726): expect 1 supervisor
   - LA City Hall (34.0537, -118.2427): expect 1 council member + 1 mayor
