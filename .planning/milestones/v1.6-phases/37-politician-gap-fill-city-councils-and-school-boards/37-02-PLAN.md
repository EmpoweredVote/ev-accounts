**Step 1: Verify Phase 34 G5420 geo_id format**

Before building the config, query the database to determine what geo_id format Phase 34 used for G5420 school district boundaries:
```sql
SELECT geo_id, name, mtfcc
FROM essentials.geofence_boundaries
WHERE mtfcc = 'G5420' AND state = 'CA'
ORDER BY name
LIMIT 20;
```

Compare the returned geo_id values to CDE FedID (7 chars, e.g., `0601620` for ABC Unified) and CDCode (7 chars, e.g., `1964212`). Determine which field matches. Per RESEARCH.md Pitfall 4: this verification is critical — if geo_ids don't match, the JOIN fails silently.

Also check for non-UNSD school district boundaries that may have been imported:
```sql
SELECT geo_id, name, mtfcc
FROM essentials.geofence_boundaries
WHERE mtfcc IN ('G5400', 'G5410') AND state = 'CA'
ORDER BY name
LIMIT 10;
```

**Step 2: Download CDE district list**

Download the CDE school directory data file to get the definitive list of LA County districts:
```python
import csv, io, requests
url = "https://www.cde.ca.gov/SchoolDirectory/report?rid=dl2&tp=txt"
resp = requests.get(url, headers={"User-Agent": "Mozilla/5.0"}, timeout=30)
text = resp.content.decode("utf-8", errors="replace")
reader = csv.DictReader(io.StringIO(text), delimiter="\t")
la_districts = [
    row for row in reader
    if row.get("County", "").strip() == "Los Angeles"
]
```

Filter to school districts only (exclude individual schools). Identify district types: Unified, Elementary, High School. Per CONTEXT.md: exclude community college districts (deferred per Deferred Ideas).

**Step 3: Cross-reference CDE list with existing geofence_boundaries**

For each CDE district, check if a G5420 boundary exists with a matching geo_id:
```sql
SELECT geo_id, name FROM essentials.geofence_boundaries
WHERE mtfcc = 'G5420' AND geo_id = %s;
```

Use the geo_id format identified in Step 1 (likely TIGER GEOID or CDE FedID). Districts without a matching boundary are logged but still included in the config — their board members will be scraped but the PIP join won't work until boundaries are imported.

Create `EV-Backend/scripts/scrape_school_boards.py` — a batch scraper for all LA County school district board members.

**Architecture:**
- Reads `school_sources.json` for district list
- Per-district website scraping with requests + BeautifulSoup (primary), Playwright fallback for JS-heavy sites
- Per-district COMMIT (same pattern as Plan 01's per-city commit)
- Reuses core functions from `scrape_la_officials.py`: `get_connection()`, `find_existing_politician_for_seat()`, `upsert_politician()`, `normalize_party()`, `split_name()`, `verify_no_duplicates()`

**Key functions to implement:**

1. `fetch_board_page(district_config)` — Fetch the district's board of education page. Try the configured URL first. If URL is null or returns error, try common URL patterns. Fall back to Playwright for JS-heavy sites (same `fetch_html_with_fallback` pattern from Plan 01 or RESEARCH.md Pattern 3).

2. `parse_board_members(html, district_config)` — Parse board member names from HTML. Common patterns on school board sites:
   - "Board of Education" or "Board of Trustees" headings followed by member cards/list
   - Table with member names, titles (President, VP, Clerk, Member)
   - Card layouts with photos and names
   - For trustee-area districts: look for "Area N" or "Trustee Area N" labels

   Extract: name (required), role/title (President/VP/Clerk/Member), trustee area number (if applicable).

3. `find_or_create_school_chamber(cur, district_config)` — Create chamber for this school district's board. Pattern: `"{District Name} Board of Education"` or `"{District Name} Board of Trustees"`.

4. `find_or_create_school_district_row(cur, district_config, member_data)` — For at-large boards: one district row with `district_type = SCHOOL`, `geo_id` from config. For trustee-area boards: per-area district rows (if sub-boundaries available) or shared district row (if whole-district boundary only).

   **geo_id assignment for school districts:**
   - All school district board members: `district_type = SCHOOL`
   - At-large boards: all members share `geo_id` matching the G5420 boundary
   - Trustee-area boards WITHOUT sub-boundaries: all members share `geo_id` (whole-district), logged as gap
   - Trustee-area boards WITH sub-boundaries: each member gets their trustee area's geo_id

5. `process_district(conn, district_config)` — Per-district processing:
   a. Fetch and parse board page
   b. For each board member:
      - Set `party = "Nonpartisan"` explicitly (per CONTEXT.md decision)
      - `data_source` = district website URL
      - `source` = "scraped"
      - `is_active` = true
   c. Dedup using `find_existing_politician_for_seat()` — match on ocd_id + title "Board Member" or "Trustee"
   d. COMMIT per district; update status in config
   e. On failure: rollback, log failure reason, continue

**Data quality rules (per CONTEXT.md):**
- Minimum viable record: name + seat only
- Party = "Nonpartisan" for all school board members (explicit, not null)
- Grab everything available: name, title/role (President, VP, etc.), term dates if shown
- `data_source` = district website URL
- `source` = "scraped"

**OCD-ID convention for school districts:**
Pattern: `ocd-division/country:us/state:ca/school_district:{district_name_normalized}`
For trustee areas: append `/trustee_area:{n}`

**Per-district commit pattern:**
```python
for district in districts:
    if district.get("status") == "scraped":
        continue  # Skip already-processed districts on re-run
    conn.autocommit = False
    try:
        process_district(conn, district)
        conn.commit()
        district["status"] = "scraped"
    except Exception as e:
        conn.rollback()
        district["status"] = "failed"
        district["failure_reason"] = str(e)
```
