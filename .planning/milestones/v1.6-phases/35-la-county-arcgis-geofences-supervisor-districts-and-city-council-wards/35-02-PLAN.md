**Step 1: Query the database to get all LA County cities with district-based council records.**

Run this SQL to identify which cities have LOCAL district records (meaning they have district-based council seats in BallotReady):
```sql
SELECT DISTINCT
    SPLIT_PART(ocd_id, '/place:', 2) as place_slug,
    COUNT(*) as district_count
FROM essentials.districts
WHERE state = 'CA'
    AND district_type = 'LOCAL'
    AND ocd_id LIKE '%/place:%/council_district:%'
GROUP BY SPLIT_PART(ocd_id, '/place:', 2)
ORDER BY place_slug;
```

This gives the list of cities that need council ward boundaries. Cross-reference with the existing `arcgis_sources.json` entries.

**Step 2: For each city with TBD URLs, attempt to discover ArcGIS FeatureServer endpoints.**

Strategy for URL discovery (try in order):
1. Try common ArcGIS Hub patterns: `https://opendata-{city}.hub.arcgis.com/` or `https://data-{city}.opendata.arcgis.com/`
2. Search for `"{city name}" site:arcgis.com council district` via WebSearch
3. Try direct FeatureServer URL patterns: `https://services[N].arcgis.com/{org_id}/arcgis/rest/services/{name}/FeatureServer/0/query?f=json`
4. For each candidate URL, verify by fetching `?f=json` (not geojson) to check it returns valid metadata with the expected number of features

For each resolved URL, verify:
- HTTP 200 response
- Has `features` key in GeoJSON response
- Feature count matches expected district count
- Has a district number field (inspect field names)
- Geometry is polygon/multipolygon

**Step 3: Update arcgis_sources.json.**

For each city:
- **Resolved**: Fill in `source_url`, `district_field`, `source_label`, `notes` with verification date
- **Unresolved**: Move to the `gaps` array with reason `"No ArcGIS boundary published"` or `"FeatureServer URL not found"`
- **At-large**: Keep with `election_type: "at-large"` and `source_url: null`

For cities NOT in the existing DB (no BallotReady district records), do NOT add them — we only import boundaries for cities where politician records already exist in `essentials.districts`.

**Step 4: Run the import script for newly resolved cities.**

After updating the config, run `import_arcgis_geofences.py` which will:
- Skip entries with `source_url: "TBD"` or `null`
- Skip entries with `election_type: "at-large"`
- Import all entries with valid URLs
- Report failures at the end

- Torrance has a portal at `https://open-data-torranceca.hub.arcgis.com/` — inspect for council district layer
- ArcGIS Hub pages are JavaScript-heavy; WebFetch may not extract URLs — prefer trying known patterns and direct FeatureServer URL inspection
- Per CONTEXT decision: spend reasonable investigation time per city, then log as gap if URL is not discoverable. Do NOT spend excessive time on any single city.
- Per CONTEXT decision: import and flag low-quality data (broken geometries) rather than skipping — set `quality_flag` accordingly.

**URL discovery time budget:** ~2-3 minutes per city. If no FeatureServer URL is found within that time, mark as gap and move on.
