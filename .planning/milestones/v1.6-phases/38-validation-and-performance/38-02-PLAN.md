Create `.planning/IMPORT-PIPELINE.md` — a step-by-step runbook documenting the complete LA County data import pipeline.

**Document structure (per CONTEXT.md locked decision and RESEARCH.md runbook outline):**

**Header:**
- Title: "LA County Data Import Pipeline Runbook"
- Brief overview: what the pipeline does (import geofences + politicians for full representative hierarchy), what the result looks like (any address returns federal through school board officials)
- When this was last run (v1.6, Feb 2026)

**Prerequisites section:**
- Python 3.10+ with virtual environment (`EV-Backend/scripts/.venv`)
- Supabase direct connection (port 5432, NOT pooler 6543) — explain why (VACUUM and multi-statement ops break on pooler)
- Go backend with AutoMigrate for schema setup
- Required Python packages: `pip install -r EV-Backend/scripts/requirements.txt`
- `.env.local` with `DATABASE_URL` pointing to direct connection

**Phase 1: Schema Setup**
- Run Go backend (`go run .` in EV-Backend) to trigger AutoMigrate
- Verify `geofence_boundaries` has composite unique constraint on `(geo_id, mtfcc)`
- Verify `geofence_lookup.go` uses `ST_Covers` (not `ST_Contains`)
- Note: G4110, G4120, G5400, G5410 must be in MTFCC-to-district-type map
- What varies by region: Nothing — schema is universal

**Phase 2: TIGER Shapefile Import (Federal, State, School, City Boundaries)**
- Data sources: Census TIGER FTP (list exact URLs for CA: tl_2024_us_cd118, tl_2024_06_sldu, tl_2024_06_sldl, tl_2024_06_unsd, tl_2024_06_place)
- Script: `import_ca_legislative_geofences.py` for G5200 (Congressional), G5210 (State Senate), G5220 (State Assembly)
- Script: `import_ca_place_boundaries.py` for G4110 (incorporated cities)
- G5420 (school districts) imported in same legislative geofences script
- Verification: count rows per MTFCC in `geofence_boundaries`, verify ST_IsValid on all geometries
- What varies by region: State FIPS code (06 for CA), TIGER vintage year (2024 for v1.6), number of expected boundaries

**Phase 3: Local Geofence Import (County Supervisor + City Council Wards)**
- LA County supervisor districts: ArcGIS source URL, imported as X0001 MTFCC with ocd_id as geo_id
- LA City council wards: LA City GeoHub source, X0001 MTFCC
- Other city council wards: `arcgis_sources.json` config-driven import script
- Document the 5 gap cities (Santa Clarita, Downey, El Monte, Palmdale, Pomona) where no ArcGIS source was found
- What varies by region: ArcGIS source URLs are county-specific; gap cities differ; some counties may have no district-based elections

**Phase 4: Politician Data Gap-Fill**
- Step 1: Run `gap_fill_geo_ids.py` to populate geo_id on district records (links politicians to geofences)
- Step 2: Run `scrape_la_officials.py` for county supervisors + LA City council + mayor
- Step 3: Run `scrape_city_councils.py` for remaining incorporated cities (config in `city_sources.json`)
- Step 4: Run `scrape_school_boards.py` for school districts (config in `school_sources.json`)
- Execution order matters: geo_ids first, then politicians
- Synthetic external_id ranges: v1.5 uses -100001+, v1.6 uses -200001+ — next region should use -300001+
- What varies by region: politician data sources, scraping strategies, CA SOS PDF availability

**Phase 5: Validation and Performance**
- Run `validate_la_county.py` (created in Plan 01)
- Script performs: VACUUM ANALYZE, GiST index check, PIP verification for 13-16 test addresses
- Interpret the pass/fail report: which tiers are expected per address type
- Expected acceptable gaps: unincorporated areas lack city tier; gap cities lack council ward boundaries
- What varies by region: test addresses, expected tier counts, gap city list

**What Varies by Region (summary table):**
| Element | LA County Value | What Changes |
|---------|----------------|--------------|
| State FIPS | 06 | Different state code |
| TIGER vintage | 2024 | Update annually |
| ArcGIS sources | `arcgis_sources.json` | County-specific URLs |
| SOS PDF | CA cities-towns.pdf | State-specific roster source |
| External ID range | -200001 | Next available negative range |
| Gap cities | 5 specific cities | Varies by available GIS data |

**Known limitations:**
- LAUSD returns all 7 board members for any LAUSD address (no trustee area sub-boundaries available)
- 5 gap cities have no council ward boundaries (at-large geofences only)
- Federal officials from US Senate/President are supplemented by statewide fetch, not geofences

Keep the tone practical and procedural — this is a runbook, not a design document. Use numbered steps. Reference specific script filenames and SQL queries where helpful.
