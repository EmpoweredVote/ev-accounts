**5. Tier detection function `check_tiers(cur, lat, lng)`:**
Run the PIP query (mirroring `geofence_lookup.go FindGeoIDsByPoint + FindPoliticiansByGeoMatches`):
```sql
SELECT DISTINCT
    p.full_name, p.party, o.title as office_title,
    d.district_type, d.geo_id, gb.mtfcc, d.ocd_id
FROM essentials.politicians p
JOIN essentials.offices o ON o.politician_id = p.id
JOIN essentials.districts d ON o.district_id = d.id
JOIN essentials.geofence_boundaries gb ON gb.geo_id = d.geo_id
WHERE ST_Covers(gb.geometry, ST_SetSRID(ST_MakePoint(%s, %s), 4326))
  AND p.is_active = true
ORDER BY d.district_type, p.full_name
```
Parameters: `(lng, lat)` — note PostGIS uses (x=lng, y=lat).

Map results to tier names using a classify function:
- `NATIONAL_LOWER`, `NATIONAL_UPPER`, `NATIONAL_EXEC` -> "federal"
- `STATE_LOWER` -> "state_assembly"
- `STATE_UPPER` -> "state_senate"
- `STATE_EXEC` -> "state" (counted toward state tiers if present)
- `SCHOOL` -> "school"
- `LOCAL_EXEC` -> "city"
- `LOCAL` -> classify further:
  - If `ocd_id` contains `county:los_angeles/council_district` OR `office_title` contains "Supervisor" -> "county" (Pitfall 2 from RESEARCH.md: LA County supervisors have district_type=LOCAL, not COUNTY)
  - Otherwise -> "city"
- `COUNTY` -> "county"
- `JUDICIAL` -> "judicial" (informational, not checked as required tier)

Return a dict: `{tier_name: [(full_name, office_title, party), ...]}`.
