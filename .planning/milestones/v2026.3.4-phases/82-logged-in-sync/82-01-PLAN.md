- API_BASE constant: `(import.meta.env as Record<string, string>).VITE_API_URL || 'https://api.empowered.vote'`
- Export interface `AuthState { isLoggedIn: boolean; loading: boolean; }`
- Export function `useAuthState(): AuthState` — calls `fetch(`${API_BASE}/auth/me`, { credentials: 'include' })` once on mount in a `useEffect(fn, [])`. On `.then(res => setState({ isLoggedIn: res.ok, loading: false }))`. On `.catch(() => setState({ isLoggedIn: false, loading: false }))`. Initial state: `{ isLoggedIn: false, loading: true }`.
- Auth state must NOT be persisted to Zustand/localStorage — local React state only (session is server-authoritative).

**EV-readrank/src/utils/verdictSync.ts:**
- Import `IssueProgress` type from `'../store/useReadRankStore'`
- API_BASE constant: same pattern as above
- Export interface `VerdictPayload { quote_id: string; verdict: 'agreed' | 'disagreed'; }`
- Export function `buildVerdictPayload(issueProgress: Record<string, IssueProgress>): VerdictPayload[]` — uses a `Map<string, 'agreed' | 'disagreed'>` to deduplicate. Iterates `Object.values(issueProgress)`. For each progress: maps `agreedQuotes` and `rankedQuotes` both to `'agreed'` (idempotent via `map.set()`), maps `disagreedQuotes` to `'disagreed'`. Returns `Array.from(map.entries()).map(([quote_id, verdict]) => ({ quote_id, verdict }))`.
- Export async function `postVerdicts(issueProgress: Record<string, IssueProgress>): Promise<void>` — calls `buildVerdictPayload`, returns early if payload is empty. Fires `fetch(`${API_BASE}/compass/verdicts`, { method: 'POST', credentials: 'include', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify(payload) })`. Wraps in try/catch — on failure logs `console.warn('Failed to sync verdicts to backend:', err)` and returns. This is fire-and-forget — no return value, no re-throw, no UI feedback.
