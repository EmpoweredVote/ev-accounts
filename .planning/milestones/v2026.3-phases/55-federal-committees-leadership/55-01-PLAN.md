```go
type committeeYAML struct {
    ThomasID          string             `yaml:"thomas_id"`
    Name              string             `yaml:"name"`
    Type              string             `yaml:"type"`  // "house", "senate", "joint"
    HouseCommitteeID  string             `yaml:"house_committee_id"`
    SenateCommitteeID string             `yaml:"senate_committee_id"`

}

type subcommitteeYAML struct {
    ThomasID string `yaml:"thomas_id"` // numeric string: "15", "22"
    Name     string `yaml:"name"`
}

// CRITICAL: committee-membership-current.yaml is a MAP, not an array
// Top-level keys are thomas_id (parent committee) or composed keys (parent_thomas_id + sub_thomas_id)
type committeeMemberYAML struct {
    Name     string `yaml:"name"`
    Bioguide string `yaml:"bioguide"`
    Party    string `yaml:"party"`
    Rank     int    `yaml:"rank"`
    Title    string `yaml:"title"`   // "Chairman", "Ranking Member", "Ex Officio" — NOT normalized
    Chamber  string `yaml:"chamber"` // only for joint committees
}
```

**3. normalizeCommitteeRole function:**
```go
func normalizeCommitteeRole(title string) string {
    t := strings.ToLower(strings.TrimSpace(title))
    switch {
    case strings.Contains(t, "chair") && !strings.Contains(t, "vice") && !strings.Contains(t, "ranking"):
        return "chair"
    case strings.Contains(t, "ranking"):
        return "ranking_member"
    case strings.Contains(t, "vice") && strings.Contains(t, "chair"):
        return "vice_chair"
    case strings.Contains(t, "ex officio"):
        return "ex_officio"
    default:
        return "member"
    }
}
```

**4. Helper: lookupPoliticianByBioguide** — Queries `legislative_politician_id_map` for `id_type = "bioguide"` and `id_value = bioguide`. Returns `(uuid.UUID, error)`. Cache results in a local `map[string]uuid.UUID` within ImportCommittees to avoid repeated DB calls.

**5. Helper: getOrCreateSession** — Queries `legislative_sessions` for `jurisdiction = "federal"` AND `external_id = strconv.Itoa(congressNumber)`. If found, return existing ID. If not found, create a new LegislativeSession with:
- Jurisdiction: "federal"
- Name: fmt.Sprintf("%dth Congress", congressNumber) — note: for 119 this gives "119th Congress", close enough (ordinal suffix doesn't need to be perfect)
- ExternalID: strconv.Itoa(congressNumber)
- IsCurrent: true (only for the current congress)
- Source: "congress-legislators"

Return the session UUID.

**6. ImportCommittees main function flow:**

Step 1: Call getOrCreateSession(cfg.CongressNumber).

Step 2: Download + parse `committees-current.yaml` as `[]committeeYAML` — follow the exact HTTP GET + io.ReadAll + yaml.Unmarshal pattern from backfill_ids.go.

Step 3: Download + parse `committee-membership-current.yaml` as `map[string][]committeeMemberYAML` — **CRITICAL: this is a map, not an array.**

Step 4: Build bioguide-to-politician UUID cache by loading ALL bridge rows for `id_type = "bioguide"` in a single query into a `map[string]uuid.UUID`.

Step 5: Upsert top-level committees. For each committee in the parsed array:
- Map `type` field: "house" → chamber "house", "senate" → chamber "senate", "joint" → chamber "joint"
- ExternalID: thomas_id (e.g., "HSAG")
- Jurisdiction: "federal"
- Type: "committee"
- SessionID: session UUID from step 1
- Use `clause.OnConflict{Columns: []clause.Column{{Name: "external_id"}, {Name: "jurisdiction"}}, DoUpdates: clause.AssignmentColumns([]string{"name", "type", "chamber", "parent_id", "is_current", "session_id"})}` with `clause.Returning{Columns: []clause.Column{{Name: "id"}}}` to get the DB-assigned UUID back
- Store in `committeeMap[thomas_id] = committee.ID`

Step 6: Upsert subcommittees. For each parent committee, iterate `parent.Subcommittees`:
- Compose ExternalID as `parent.ThomasID + sub.ThomasID` (e.g., "HSAG" + "15" = "HSAG15")
- ParentID: &parentDBID (from committeeMap)
- Type: "subcommittee"
- Chamber: same as parent
- Store in `committeeMap[composedKey] = subcommittee.ID`

Step 7: Upsert memberships. For each `(thomasID, members)` in the membership map:
- Look up committee UUID from committeeMap[thomasID]
- If not found, log and skip (this handles historical or unrecognized committees)
- For each member, look up politician UUID from bioguide cache
- If bioguide not in cache, increment skipped counter and log
- If DryRun, just count
- Otherwise, upsert LegislativeCommitteeMembership with:
  - CommitteeID, PoliticianID, CongressNumber from config
  - Role: normalizeCommitteeRole(member.Title)
  - IsCurrent: true
  - SessionID: session UUID
  - OnConflict on (committee_id, politician_id, congress_number), DoUpdates: role, is_current, session_id

Step 8: Log summary and return result.

**IMPORTANT anti-patterns to avoid:**
- Do NOT use `gopkg.in/yaml.v3` — use `github.com/goccy/go-yaml`
- Do NOT match politicians by name — always use bridge table
- Do NOT add GORM foreign key tags — use bare UUID fields only
- Do NOT hardcode congress number — accept from config with default 119

```go
case "import-committees":
    dryRun := false
    congressNumber := 119
    for _, arg := range os.Args[2:] {
        if arg == "--dry-run" {
            dryRun = true
        }
        if strings.HasPrefix(arg, "--congress=") {
            n, err := strconv.Atoi(strings.TrimPrefix(arg, "--congress="))
            if err != nil {
                log.Fatal("invalid --congress value: ", arg)
            }
            congressNumber = n
        }
    }
    result, err := essentials.ImportCommittees(essentials.ImportCommitteesConfig{
        DryRun:         dryRun,
        CongressNumber: congressNumber,
    })
    if err != nil {
        log.Fatal("import-committees failed: ", err)
    }
    fmt.Printf("Import complete: %d committees, %d subcommittees, %d memberships upserted, %d skipped\n",
        result.CommitteesUpserted, result.SubcommitteesUpserted, result.MembershipsUpserted, result.Skipped)
    if result.SessionCreated {
        fmt.Printf("Created new legislative session for %dth Congress\n", congressNumber)
    }
    if len(result.Errors) > 0 {
        fmt.Printf("Errors (%d):\n", len(result.Errors))
        for _, e := range result.Errors {
            fmt.Printf("  - %s\n", e)
        }
    }
    os.Exit(0)
```

Add `"strconv"` and `"strings"` to the imports in main.go if not already present.

Note: The `strconv` import is needed for --congress flag parsing. The `strings` import is needed for HasPrefix/TrimPrefix. Check if they are already imported before adding.
