**Script structure:**
```
#!/usr/bin/env python3
"""
Bloomington Common Council Data Importer (OnBoard HTML Scraping)

Scrapes committee memberships and legislation metadata from bloomington.in.gov/onboard.
Matches council members to existing essentials.politicians records via name matching.

Usage:
    python import_local_bloomington.py --dry-run --verbose
    python import_local_bloomington.py --verbose
    python import_local_bloomington.py --committees-only --verbose
    python import_local_bloomington.py --legislation-only --verbose

Environment variables (loaded from EV-Backend/.env.local):
    DATABASE_URL   PostgreSQL connection string
"""
```

**Functions to implement:**

1. **`scrape_council_members(committee_id=1)`** — GET `/onboard/committees/{id}/members`, parse HTML with BeautifulSoup. Extract:
   - Member names (from link text or heading tags containing `/onboard/members/{id}`)
   - OnBoard member IDs (from URL path)
   - Seat text (parse for role: "Council President", "Chair", etc.)
   - Return list of dicts: `[{name, onboard_id, seat_text, role}]`

2. **`scrape_sub_committee_members(committee_id)`** — Same as above but for sub-committee pages (IDs: 77, 81, 49). May have different HTML structure — handle gracefully.

3. **`build_politician_bridge(members, conn)`** — For each scraped member:
   - Query `SELECT id, full_name FROM essentials.politicians WHERE is_active = true` (load once)
   - Use RapidFuzz `fuzz.token_sort_ratio` with threshold 80 for matching
   - Single-match-only: skip if 0 or 2+ matches above threshold
   - INSERT bridge row with id_type='onboard', id_value=onboard_member_id, source='onboard-scrape'
   - ON CONFLICT DO NOTHING
   - Return dict mapping onboard_id -> politician_uuid

4. **`ensure_session(conn)`** — Upsert a LegislativeSession for Bloomington:
   - jurisdiction="bloomington-in", external_id="bloomington-current", source="onboard-scrape", is_current=true
   - Name: "Bloomington Common Council (Current Term)"
   - Return session UUID

5. **`import_committees(bridge_map, session_id, conn)`** — For each committee (1, 77, 81, 49):
   - Upsert LegislativeCommittee with external_id="onboard-{committee_id}", jurisdiction="bloomington-in", chamber="local", source="onboard-scrape"
   - For committee 1 (City Council): parent_id=NULL, type="committee"
   - For sub-committees: parent_id=City Council UUID, type="subcommittee"
   - Scrape members for each committee
   - Upsert LegislativeCommitteeMembership with congress_number=0, is_current=true
   - Parse role from seat text: "Council President" -> "president", "Chair" -> "chair", else "member"
   - Log: "Imported X memberships for Y committees"

6. **`scrape_legislation_list(committee_id=1, max_pages=50)`** — GET `/onboard/committees/1/legislation?page={N}`, paginate until no more items. Parse legislation links matching `/onboard/committees/1/legislation/{id}`. Extract title text. Return list of dicts: `[{id, title, url}]`

7. **`scrape_legislation_detail(committee_id, legislation_id)`** — GET `/onboard/committees/{committee_id}/legislation/{legislation_id}`. Parse:
   - Full description text
   - Attempt sponsor extraction with flexible regex patterns:
     - `r"[Ss]ponsored by Councilmembers?\s+(.+?)(?:\s+(?:allows|consolidates|renames|updates|amends|directs|is|repeals|establishes|appropriates|authorizes)\b|\.|\s*$)"`
     - Also try: `r"[Ss]ponsored by (.+?)(?:\.|$)"` as fallback
   - If sponsor found, try to split multiple sponsors on " and " or ", "
   - Return dict: `{description, sponsors: [str], raw_sponsor_text}`

8. **`import_legislation(bridge_map, session_id, conn, max_items=None)`** — For each legislation item:
   - Scrape detail page for sponsor extraction
   - Match sponsor names against bridge_map (by RapidFuzz against known politician names)
   - **Per locked decision:** Only import items where at least one sponsor is matched to a politician
   - Skip items with no sponsor attribution — log them as skipped
   - Upsert LegislativeBill with external_id="onboard-{legislation_id}", jurisdiction="bloomington-in"
   - Set sponsor_id to first matched politician UUID
   - For additional matched sponsors, insert LegislativeBillCosponsor rows
   - Log: "Imported X legislation items, skipped Y (no sponsor attribution)"

9. **`main()`** — Argparse with flags:
   - `--dry-run`: Read and log but don't write to database
   - `--verbose`: Print detailed HTTP responses and match results
   - `--committees-only`: Only import committees and memberships
   - `--legislation-only`: Only import legislation (assumes bridge already built)
   - `--max-legislation N`: Limit legislation items processed (for testing)

**Important implementation details:**
- Use `from rapidfuzz import fuzz` for name matching
- Timeouts: 30s per request, 2s delay between OnBoard requests (be respectful to city server)
- Handle HTTP errors gracefully — log and continue
- Use `ON CONFLICT DO NOTHING` or `ON CONFLICT DO UPDATE` matching the unique index columns
- Session UUID: use `gen_random_uuid()` in INSERT, SELECT after upsert to get the ID
- Committee membership unique index is (committee_id, politician_id, congress_number) — congress_number=0 for local
- All INSERT statements use parameterized queries (%s placeholders) — never string interpolation for SQL values
- Load all active politicians once at script start for matching efficiency
