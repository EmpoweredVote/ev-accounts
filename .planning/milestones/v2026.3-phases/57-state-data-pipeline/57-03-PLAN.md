**Part B: Create import_state_committees.py script**

Create a NEW Python script at `EV-Backend/scripts/import_state_committees.py` that imports committee memberships from Open States API v3.

**Script structure:**

1. **CLI arguments:**
   - `--state` (required): IN or CA
   - `--dry-run`: Log operations without DB writes
   - `--verbose`: Debug logging

2. **Configuration:**
   ```python
   STATE_CONFIG = {
       "IN": {"jurisdiction": "indiana", "openstates_jurisdiction": "Indiana"},
       "CA": {"jurisdiction": "california", "openstates_jurisdiction": "California"},
   }
   ```

3. **Open States API client functions:**
   - `fetch_committees(api_key, jurisdiction, page=1, per_page=50)` — calls `GET https://v3.openstates.org/committees` with `?jurisdiction={jurisdiction}&include=memberships&per_page=50&page={page}&apikey={api_key}`
   - Handle pagination: loop until `page >= max_page`
   - Rate limiting: `time.sleep(6)` between requests (10/minute limit = 1 every 6 seconds)
   - Return list of all committee objects with their memberships

4. **Committee matching strategy:**
   Two-pass approach to match Open States committees to existing DB committees:

   **Pass 1 — Name match to existing:** For each Open States committee, try to find an existing committee in `essentials.legislative_committees` by matching name (case-insensitive, trimmed) + jurisdiction. If found, use that DB row's UUID.

   **Pass 2 — Create new:** If no name match found, INSERT a new committee row with:
   - `external_id` = Open States OCD organization ID (e.g., "ocd-organization/...")
   - `jurisdiction` = "indiana" or "california"
   - `name` = Open States committee name
   - `type` = Open States classification ("committee" or "subcommittee")
   - `chamber` = derived from parent committee's org_classification or committee name: if name contains "Senate" or parent is "upper" → "senate"; if "House"/"Assembly" or "lower" → "house"; else "joint"
   - `source` = "openstates"
   - `is_current` = true

5. **Membership linking strategy:**
   For each committee membership from Open States:

   a. Extract `person_name` from the membership object.
   b. Split into first_name and last_name. Handle cases like "John D. Smith" (first="John", last="Smith") and "De León" (multi-word last names).
   c. Look up the politician in `essentials.politicians` using:
      ```sql
      SELECT p.id FROM essentials.politicians p
      JOIN essentials.offices o ON o.politician_id = p.id
      JOIN essentials.districts d ON o.district_id = d.id
      WHERE LOWER(p.last_name) = LOWER(%s)
        AND LOWER(p.first_name) ILIKE LOWER(%s) || '%'
        AND d.state = %s
        AND d.district_type IN ('STATE_UPPER', 'STATE_LOWER')
      ```
      Use `ILIKE first_name || '%'` to handle middle names/initials (e.g., "Vernon G." matches "Vernon").
      Use single-match-only guard: if 0 or 2+ matches, log and skip.

   d. Also check if there's a bridge row in `legislative_politician_id_map` with `id_type='openstates'` and the OCD person ID — if so, use that politician_id directly.

   e. INSERT membership:
      ```sql
      INSERT INTO essentials.legislative_committee_memberships
          (id, committee_id, politician_id, congress_number, role, is_current, session_id)
      VALUES (gen_random_uuid(), %s, %s, 0, %s, true, %s)
      ON CONFLICT (committee_id, politician_id, congress_number) DO UPDATE SET
          role = EXCLUDED.role,
          is_current = EXCLUDED.is_current,
          session_id = EXCLUDED.session_id
      ```
      - `congress_number` = 0 (non-federal)
      - `role` = normalize Open States role: "chair" → "chair", "vice-chair" → "vice_chair", "vice chair" → "vice_chair", "ranking member" → "ranking_member", anything else → "member"
      - `session_id` = current session from `legislative_sessions` for this jurisdiction (is_current=true)

6. **Bridge row creation:**
   When a match is found, also upsert a bridge row with `id_type='openstates'` and `id_value` = OCD person ID to speed up future imports:
   ```sql
   INSERT INTO essentials.legislative_politician_id_map
       (id, politician_id, id_type, id_value, verified_at, source)
   VALUES (gen_random_uuid(), %s, 'openstates', %s, NOW(), 'openstates-committees')
   ON CONFLICT DO NOTHING
   ```

7. **Environment variables:**
   - `OPENSTATES_API_KEY` — required (from .env.local or shell)
   - `DATABASE_URL` — required (from .env.local)

8. **Logging:**
   - Report total committees fetched, matched to existing, newly created
   - Report total memberships: linked, skipped (no match), skipped (ambiguous)
   - Report final counts from DB queries
