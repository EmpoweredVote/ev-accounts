**BackfillLegislativeIDs function** — the main entry point:

1. **Download** `legislators-current.yaml` via HTTP GET. Log the URL being fetched. If download fails, return error.

2. **Parse YAML** into `[]legislatorYAML` using `github.com/goccy/go-yaml`. If parse fails, return error.

3. **Query database** for all active NATIONAL_UPPER + NATIONAL_LOWER politicians. Use this query pattern:
```go
type federalPol struct {
    ID               uuid.UUID
    FirstName        string
    LastName         string
    FullName         string
    BioguideID       string
    RepresentingState string
}
var federalPols []federalPol
db.DB.Raw(`
    SELECT p.id, p.first_name, p.last_name, p.full_name, p.bioguide_id,
           o.representing_state
    FROM essentials.politicians p
    JOIN essentials.offices o ON o.politician_id = p.id
    JOIN essentials.districts d ON o.district_id = d.id
    WHERE d.district_type IN ('NATIONAL_UPPER', 'NATIONAL_LOWER')
      AND p.is_active = true
`).Scan(&federalPols)
```

4. **Build a lookup map** from the YAML: `bioguideMap[bioguideID]legislatorYAML` for fast exact matching. Also build `nameStateMap[lowercase(last_name)+"|"+state][]legislatorYAML` for fallback matching.

5. **Match each database politician** using tiered matching:
   - **Tier 1 (HIGH confidence):** Politician already has `bioguide_id` set. Look up in `bioguideMap`. If found, insert bridge row directly.
   - **Tier 2 (HIGH confidence):** Politician has no `bioguide_id`. Search `nameStateMap` by `lowercase(last_name) + "|" + representing_state`. If exactly ONE match, update `politicians.bioguide_id` AND insert bridge row. Log the match.
   - **Tier 3 (MEDIUM confidence):** If multiple name+state matches exist, log as "ambiguous — manual review needed" and skip. Do NOT insert.
   - **No match:** Log as "unmatched — not in congress-legislators" and skip.

6. **For each match** (Tier 1 or Tier 2):
   - If NOT dry run: Insert into `legislative_politician_id_map`:
     ```go
     bridge := LegislativePoliticianIDMap{
         PoliticianID: pol.ID,
         IDType:       "bioguide",
         IDValue:      bioguideID,
         VerifiedAt:   time.Now(),
         Source:       "congress-legislators-yaml",
     }
     result := db.DB.Create(&bridge)
     ```
   - If Tier 2 match: Also update the politician's `bioguide_id` field:
     ```go
     db.DB.Model(&Politician{}).Where("id = ?", pol.ID).Update("bioguide_id", bioguideID)
     ```
   - Use `ON CONFLICT DO NOTHING` behavior: Check if bridge row already exists before inserting (query by politician_id + id_type + id_value), skip if exists.

7. **Return BackfillResult** with counts.

8. **Log summary** at the end: "Backfill complete: X matched, Y inserted, Z skipped, N errors"

**Important constraints:**
- Do NOT attempt to match NATIONAL_EXEC politicians (cabinet, VP, President) — they have no bioguide_id.
- Do NOT use `gopkg.in/yaml.v3` — use `github.com/goccy/go-yaml`.
- Do NOT insert bridge rows for MEDIUM confidence (ambiguous) matches.
- Support `--dry-run` flag that logs what would happen without writing to database.

case "backfill-legislative-ids":
    dryRun := false
    for _, arg := range os.Args[2:] {
        if arg == "--dry-run" {
            dryRun = true
        }
    }
    result, err := essentials.BackfillLegislativeIDs(essentials.BackfillConfig{
        DryRun: dryRun,
    })
    if err != nil {
        log.Fatal("backfill-legislative-ids failed: ", err)

    fmt.Printf("Backfill complete: %d matched, %d inserted, %d skipped\n",
        result.Matched, result.Inserted, result.Skipped)
    if len(result.Errors) > 0 {
        fmt.Printf("Errors (%d):\n", len(result.Errors))
        for _, e := range result.Errors {
            fmt.Printf("  - %s\n", e)
        }
    }
