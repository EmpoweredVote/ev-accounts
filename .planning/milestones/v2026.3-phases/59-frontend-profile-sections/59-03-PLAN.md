
Replace with a simple section divider style:
```jsx
const card = {
  borderTop: `1px solid ${colors.borderLight}`,
  padding: `${spacing[4]} ${spacing[4]} 0`,

  fontFamily: fonts.primary,
};
```

This removes the standalone card appearance (no box-shadow, no border-radius, no separate background) and instead adds a subtle top border to separate the legislative summary from the main profile content above it. The padding has no bottom padding since the topCard container already handles outer padding. The `marginTop` adds visual spacing from the content above.
