## Key Decisions

| Decision | Rationale |
|----------|-----------|
| Stance corrections require real fetched URLs, no party-inference | SACC-02 contract: every correction must cite at least one real source. Null-source stances better deleted than left with inference-based context. |
| Dooley sources fixed via real campaign/news sources | Football coach Wikipedia page was categorically wrong; found real sources for the GA Senate candidate. |
| Brian W. Jones ukraine-support deleted | Only "evidence" was party-affiliation inference. Deletion is safer than leaving a no-evidence stance in the DB. |
| finance_summary on essentials.politicians (not inform.politicians) | REQUIREMENTS.md predates Phase 35 dedup. Confirmed correct table in RESEARCH.md Critical Finding. |
| FEC ingestion acceptance bar: >= 100 populated (not "all federal") | Full coverage blocked by 44 politicians with no FEC ID in either crosswalk path. Relaxed bar met (209/258). |
| Two-query elections approach (geofence + statewide) | Avoids complex single-query geofence logic for statewide races. Dedup on merge prevents duplicates. |
| primary_party on race record only (antipartisan) | Candidate records never store party affiliation in the elections data model — follows platform antipartisan display principle. |
| Elections page auto-fetch from address context | Reduces friction for users who already have location on file. |
| FEC re-run after initial 201/258: recovered 8 | Re-ran idempotent script; resolved 8 transient timeouts. Final count: 209/258. |
