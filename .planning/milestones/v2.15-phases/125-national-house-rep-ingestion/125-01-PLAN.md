Shared US House chamber UUID (reuse, NEVER create): c2facc31-7b13-428c-b7b9-32d0d3b95f76

politician + office insert block (per rep, from migration 311):
```sql
WITH ins_p AS (
  INSERT INTO essentials.politicians
    (id, full_name, first_name, last_name, party, is_active, is_appointed,
     is_vacant, is_incumbent, external_id)
  VALUES (gen_random_uuid(), '<official_full>', '<first>', '<last>', '<party_normalized>',
          true, false, false, true, <external_id>)
  ON CONFLICT (external_id) DO NOTHING
  RETURNING id
)
INSERT INTO essentials.offices
  (id, district_id, chamber_id, politician_id, title, representing_state,
   is_appointed_position, is_vacant, role_canonical)
SELECT gen_random_uuid(), d.id, 'c2facc31-7b13-428c-b7b9-32d0d3b95f76', p.id,
       'U.S. Representative', '<STATE_USPS>', false, false, NULL
FROM essentials.districts d
CROSS JOIN ins_p p
WHERE d.tiger_geoid = '<TIGER_GEOID>' AND d.district_type = 'NATIONAL_LOWER'
  AND p.id IS NOT NULL
  AND NOT EXISTS (
    SELECT 1 FROM essentials.offices o
    WHERE o.district_id = d.id
      AND o.chamber_id = 'c2facc31-7b13-428c-b7b9-32d0d3b95f76'
  );
```

office_id backfill (end of migration, scoped to this batch's external_id range):
```sql
UPDATE essentials.politicians p
SET office_id = o.id
FROM essentials.offices o
WHERE o.politician_id = p.id
  AND p.external_id BETWEEN -56999 AND -1000
  AND p.office_id IS NULL;
```

unseeded-district query:
```sql
SELECT d.id, d.tiger_geoid
FROM essentials.districts d
LEFT JOIN essentials.offices o ON o.district_id = d.id
WHERE d.district_type = 'NATIONAL_LOWER' AND o.politician_id IS NULL;
```

YAML source: https://raw.githubusercontent.com/unitedstates/congress-legislators/main/legislators-current.yaml
- current term = last entry in terms[]; filter type === 'rep'
- name.official_full (fallback name.first + ' ' + name.last); name.first; name.last
- terms[last].state (2-letter USPS), terms[last].district (0 = at-large), terms[last].party

Mapping rules (from .planning/research/SUMMARY.md):
- tiger_geoid = STATE_FIPS(2) + zero-padded CD(2); at-large district 0 -> '00'
- party: 'Democrat' -> 'Democratic'; else pass through
- external_id = -(state_fips_int * 1000 + cd_int)
- Requires a USPS<->FIPS lookup (52 entries incl. DC=11) embedded in the script

<action>
Create backend/scripts/seed-national-house-reps.ts. It must:
1. Download legislators-current.yaml from the raw GitHub URL (reuse downloadWithRedirects from load-national-house-districts.ts; cache to a tmp path). Parse YAML (add `yaml` or `js-yaml` dep if not present; prefer whichever is already in backend/package.json).
2. Build the current-rep roster: for each legislator, take the LAST terms[] entry; keep only type === 'rep'; capture state (USPS), district (int), party, name.official_full, name.first, name.last, id.bioguide.
3. Embed a USPS<->FIPS map (50 states + DC=11). Compute tiger_geoid = FIPS(2) + zeroPad(district,2) with at-large district 0 -> '00'. Compute external_id = -(FIPS_int*1000 + district_int). Normalize party: 'Democrat' -> 'Democratic'.
4. Connect via pg Pool (DATABASE_URL, ssl rejectUnauthorized:false). Query unseeded NATIONAL_LOWER districts (LEFT JOIN offices WHERE politician_id IS NULL), returning d.id and d.tiger_geoid.
5. Match: for each unseeded district, parse its tiger_geoid -> (state_fips, cd) and look up the roster rep keyed by the SAME tiger_geoid. Produce three buckets: matched (district+rep), vacancy (unseeded district with no current YAML rep), already-seeded (YAML rep whose district is not in the unseeded set).
6. Expose two modes: `--dry-run` (default: no writes, no file output, print the coverage report) and `--generate` (write the migration file — implemented in task 2). The script must make NO INSERT/UPDATE calls to the DB in either mode (generation only).
</action>
