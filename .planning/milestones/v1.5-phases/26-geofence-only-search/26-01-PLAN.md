**Area 2: Geocode failure handling**

When `GeoClient.Geocode` returns an error, instead of falling through to BallotReady, return an appropriate error:
- If the error message contains "could not determine US state" → return 422 with "Address must be within the United States"
- Otherwise → return 400 with "Could not resolve address"

**Area 3: Delete the BallotReady fallback block and replace with no-geofence path**

Find the block that falls through to BallotReady when geofence returns zero results or zero officials (research says lines 2916-3037 approximately). Delete the entire BallotReady fallback block.

Replace it with the no-geofence fallback path. The two cases that previously fell through (no geoMatches, or geoMatches but no officials) should both execute:

```go
// No local geofence data — return federal + state officials from cache.
geoState := strings.ToUpper(geoResult.State)
if geoState == "" {
    http.Error(w, "Address must be within the United States", http.StatusUnprocessableEntity)
    return
}

officials, err := fetchFederalAndStateFromDB(geoState)
if err != nil {
    log.Printf("[SearchPoliticians] no-geofence DB fetch error for state=%s: %v", geoState, err)
    http.Error(w, "Internal server error", http.StatusInternalServerError)
    return
}

log.Printf("[SearchPoliticians] no-geofence fallback: returned %d federal+state officials for state=%s", len(officials), geoState)
w.Header().Set("X-Data-Status", "no-geofence-data")
w.Header().Set("X-Formatted-Address", geoResult.Formatted)
writeJSON(w, officials)
return
```
