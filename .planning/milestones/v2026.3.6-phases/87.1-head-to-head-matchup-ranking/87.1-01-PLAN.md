Create `EV-readrank/src/utils/matchupAlgorithm.ts` with three pure exported functions:

1. **`makePairKey(idA: string, idB: string): string`** — Returns canonical pair key by sorting the two IDs and joining with `-`. Example: `makePairKey("b", "a")` returns `"a-b"`.

2. **`getPendingMatchups(agreed: RankedQuote[], completedPairKeys: string[]): [string, string][]`** — Iterate all i,j pairs (i < j), compute key via `makePairKey`, check against a `Set` built from `completedPairKeys`, return array of `[id, id]` tuples for uncompleted pairs. Import `RankedQuote` type from the store.

3. **`computeRankings(rankedQuotes: RankedQuote[], wins: Record<string, number>): RankedQuote[]`** — Sort a copy of rankedQuotes by wins descending (ties broken by timestamp ascending — earlier agree wins). Map with sequential `rank: i + 1`. Return the reranked array.

All functions are pure with no side effects. Use TypeScript. Do NOT use `Set` as a parameter type — accept `string[]` and convert internally.

Reference algorithm: concept-i-maximum.jsx lines 11-23.
