## Decisions Made
- Store version bumped to 4 with wipe-on-migrate — same pattern as v3 migration, guarantees returning users land on hub cleanly
- `completedMatchupPairs` stored as `string[]` not `Set` — Zustand persist middleware cannot serialize Set objects to JSON
- `activeMatchupPair` set eagerly inside `agreeWithQuote` — so the UI can transition to matchup mode immediately after the second agree without waiting for an explicit trigger
- `computeRankings` tie-breaks by `timestamp` ascending — quote agreed earlier wins ties, preserving temporal priority among equal-win quotes
