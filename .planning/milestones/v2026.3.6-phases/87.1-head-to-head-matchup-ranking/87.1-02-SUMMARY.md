## Decisions Made

- MatchCard uses raw CSS transform for 3D tilt (not Framer Motion) — better performance for continuous mouse move tracking
- Drag-rank gate (blur overlay + pending bottom sheet) removed entirely — matchup flow replaces the pending-ranking UX pattern established in Phase 87
- Mode transition uses opacity/scale fade (0.4s cubic-bezier) on the content wrapper — provides clear visual context switch without layout shift
- Results button gated on `activeMatchupPair === null` to ensure all matchups complete before results are shown
- MegaParticles capped at 16 particles (not 24 from reference concept) — lighter visual for EV brand
- Loser state is simple fade+shrink (no shatter fragments) — v1 simplification, can enhance later
