**MatchCard.tsx** — Individual matchup card component (adapted from reference MatchCard, EV-themed):

Props: `{ quote: RankedQuote; side: 'left' | 'right'; onPick: (side: 'left' | 'right') => void; selected: 'left' | 'right' | null; disabled: boolean }`

Features:
- **3D tilt on hover:** Track mouse position via `onMouseMove`, compute `rotateX/Y` from mouse offset (+-12deg). Use inline `transform` style (not Framer Motion for this — raw CSS transform is smoother for continuous tracking per reference pattern).
- **Holographic shine:** Radial gradient overlay following cursor position using `shineX%/shineY%` derived from mouse coordinates. Color: `rgba(0, 101, 124, 0.08)` (ev-muted-blue tint, not amber).
- **Winner state (isWinner = selected === side):** `scale(1.06) translateY(-8px)`, box-shadow with ev-coral glow (`rgba(255, 87, 64, 0.4)`), conic gradient border with ev-coral/ev-yellow. Show CHOSEN badge above card with `slamDown` animation. Show particle burst (`MegaParticles` sub-component with ev-coral color).
- **Loser state (isLoser = selected && selected !== side):** `scale(0.7) rotateY(20deg)`, `opacity: 0`, transition 0.6s. Simple fade+shrink (skip shatter fragments for v1 — can enhance later).
- **Card content:** Quote text in Manrope 400, 15px, line-height 1.75. Clamp to 4 lines via `-webkit-line-clamp: 4`. Show "POSITION A" / "POSITION B" label at top in Manrope 600, 10px, uppercase, letter-spacing 0.12em, color `#94a3b8` (hover: `#00657c`). Show keyboard hint at bottom: `[ 1 ] or <-` / `[ 2 ] or ->` in Manrope 500, 10px, `#d4cdc3`.
- **Card background:** `#fffefb` (warm-white, NOT dark theme). Border: `1px solid #e8e2d9`. Border-radius: 18px. Outer wrapper has conic-gradient border on winner, subtle border glow on hover.
- **Disabled state:** `pointer-events: none` when `disabled` prop is true.
- **MegaParticles sub-component:** 16 particles (not 24 — lighter than reference) bursting outward from center on winner pick. Color: ev-coral. Use CSS custom properties `--dx`/`--dy` with `megaBurst` keyframe. Particles stored in a `useRef` to avoid re-randomization on render.

**MatchupPhase.tsx** — Container for the head-to-head matchup:

Props: `{ onMatchupComplete?: () => void }` (optional callback when all matchups done and swipe should resume)

Implementation:
- Read from store: `getCurrentIssueProgress()` to get `activeMatchupPair`, `rankedQuotes`, `matchupWins`, `completedMatchupPairs`, `quotesToEvaluate`, `currentQuoteIndex`.
- Read `recordMatchupWin` from store.
- Resolve left/right quotes from `activeMatchupPair` IDs by finding them in `rankedQuotes`.
- Local state: `selected: 'left' | 'right' | null` (which card was picked), managed via `useState`.
- **Banner:** "CHOOSE YOUR CHAMPION" text in Manrope 700, 15px, letter-spacing 0.15em, gradient text using ev-coral to ev-yellow via `-webkit-background-clip: text`. Decorative top/bottom border lines using `linear-gradient` with ev-coral at 30% opacity. `bannerSlam` animation on mount.
- **Card layout:** Flex row with 16px gap. Each side is a `<MatchCard>`. Between them: VS divider — 42px circle, border `1.5px solid rgba(255, 87, 64, 0.3)`, radial gradient background with ev-coral at 15% opacity, "VS" text in Manrope 800, 13px, color ev-coral. `vsPulse` animation.
- **Pick flow:**
  1. User clicks a card -> `setSelected(side)`, trigger screen shake via `shakeRef` class toggle.
  2. Trigger screen flash (ScreenFlash sub-component: fixed overlay with ev-coral at 10% opacity, `screenFlash` keyframe 0.4s).
  3. After 800ms timeout: call `recordMatchupWin(winnerId, loserId)` from store, then `setSelected(null)` to reset for next pair.
  4. The store's `recordMatchupWin` automatically advances `activeMatchupPair` to next pair or sets it to `null`. When `activeMatchupPair` becomes `null`, EvaluationPhase (Task 3) handles returning to swipe mode.
- **Screen shake:** Apply to a wrapper div via ref + CSS class toggle. Use `shakeRef.current?.classList.add('screen-shake')` / `setTimeout remove 400ms`. Class defined in index.css.
- **Keyboard shortcuts:** `useEffect` with keydown listener: `1` or `ArrowLeft` picks left, `2` or `ArrowRight` picks right. Guard against `selected !== null` (prevent double-pick). Clean up listener on unmount.
- **Progress indicator:** Below cards, show `"{remainingQuotes} more to evaluate after"` in Manrope 500, 11px, color `#94a3b8` — only when `currentQuoteIndex < quotesToEvaluate.length`.
- **ScreenFlash sub-component** (inline in MatchupPhase.tsx): Fixed overlay, `inset: 0`, background: `rgba(255, 87, 64, 0.1)`, `screenFlash` keyframe, `pointer-events: none`, `z-index: 1000`. Rendered conditionally via `flashColor` state.
