**Create `EV-readrank/src/components/PracticeRound.tsx`**

This component renders the practice evaluation experience. It does NOT reuse `EvaluationPhase` directly (that component reads from `getCurrentIssueProgress()` which requires `currentIssueId`). Instead, PracticeRound reproduces the evaluation layout reading from `practiceProgress` directly.

Key design decisions:
- Renders QuoteCard with `onAgree={agreePracticeQuote}` and `onDisagree={disagreePracticeQuote}` props
- Renders matchup UI inline using MatchCard (NOT MatchupPhase — that reads from getCurrentIssueProgress)
- Renders a simplified sidebar for desktop that shows ranked quotes with wins (reads from practiceProgress directly, NOT RankedListSidebar which has store coupling)
- Shows a persistent "Practice Round" banner at top with pizza accent
- Shows a persistent "Skip practice" text link
- When all 5 quotes are evaluated and all matchups resolved, transitions to PracticeResultsScreen

Structure:
```typescript
import React, { useState, useCallback, useEffect, useRef } from 'react';
import { useMotionValue, MotionValue, animate } from 'framer-motion';

import { useReadRankStore, type Quote, type RankedQuote } from '../store/useReadRankStore';

```
