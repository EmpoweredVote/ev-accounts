**Step C: Create validation script**

Create `validate_committee_coverage.py` that:
1. Connects to DATABASE_URL from .env.local
2. For each state (IN, CA):
   a. Count total state legislators: politicians with office in district_type IN ('STATE_UPPER', 'STATE_LOWER') AND district.state = state_abbr
   b. Count legislators with at least one committee membership in legislative_committee_memberships (JOIN through legislative_committees WHERE jurisdiction = state_jurisdiction)
   c. Calculate coverage percentage
   d. Print coverage: "{state}: {covered}/{total} legislators have committee assignments ({pct}%)"
   e. Flag PASS/FAIL against 80% threshold
3. Spot-check specific legislators:
   - IN: Pick 3 legislators (1 senate leader, 1 house leader, 1 rank-and-file) — query for name + committee count
   - CA: Pick 3 legislators (1 senate leader, 1 assembly leader, 1 rank-and-file) — query for name + committee count
   - Print their names, committee count, and sample committee name
4. Check API accessibility: For one known politician UUID per state, make a curl-style check that GET /essentials/politician/{id}/committees returns data (or print the curl command for manual verification)
5. Exit code: 0 if both states pass 80% threshold, 1 otherwise

Include --dry-run (just print what would be checked) and --verbose flags.
