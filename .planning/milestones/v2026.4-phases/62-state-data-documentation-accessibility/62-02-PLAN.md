  ### Overview
    - What these scripts do: import committee memberships (IGA + Open States) and legislative data (LegiScan) for IN and CA
    - Session config: state_legislative_config.json is the single source for session years

  ### Additional Environment Variables
    - LEGISCAN_API_KEY — required for import_state_legislative.py
    - OPENSTATES_API_KEY — required for import_state_committees.py --state CA
    - Where to get each key (LegiScan dashboard, Open States dashboard)

  ### Scripts Reference
    For each script, document: purpose, usage command, flags, expected output

    1. import_state_legislative.py
       - Purpose: Download LegiScan dataset ZIPs, import bills/votes/cosponsors
       - Usage: python3 import_state_legislative.py --state IN --sessions current,previous [--dry-run] [--verbose]
       - Expected output: "X bills imported, Y votes imported"
       - Budget impact: ~5 API queries per state (dataset approach)

    2. import_state_committees.py
       - Purpose: Import committee memberships from IGA (IN) or Open States (CA)
       - Usage: python3 import_state_committees.py --state IN [--dry-run] [--verbose]
       - Expected output: "X committees, Y memberships"
       - IN runtime: ~1 minute; CA runtime: ~40 minutes (rate limiting)

    3. validate_state_legislative.py
       - Purpose: 7-check audit of bills, votes, bridge records
       - Usage: python3 validate_state_legislative.py [--verbose] [--legiscan-check]
       - Expected output: "PASS" with exit code 0

    4. validate_committee_coverage.py
       - Purpose: Verify 80%+ committee coverage per state
       - Usage: python3 validate_committee_coverage.py [--verbose]
       - Expected output: "IN: X%, CA: Y% — PASS"

    5. verify_state_api.py
       - Purpose: Confirm all legislative data accessible via Go API endpoints
       - Usage: python3 verify_state_api.py [--api-url http://localhost:5050] [--verbose]
       - Expected output: "8/8 checks passed"
       - Requires: Go server running (cd EV-Backend && go run .)

  ### New Session Playbook
    Numbered checklist for when a new legislative session starts:

    1. Edit state_legislative_config.json — update current_year_start (and previous_year_start if needed)
    2. Run committee import for IN: python3 import_state_committees.py --state IN --dry-run (verify), then without --dry-run
    3. Run committee import for CA: python3 import_state_committees.py --state CA --dry-run (verify), then without --dry-run
    4. Run legislative import for IN: python3 import_state_legislative.py --state IN --sessions current --dry-run, then without --dry-run
    5. Run legislative import for CA: python3 import_state_legislative.py --state CA --sessions current --dry-run, then without --dry-run
    6. Run validation: python3 validate_committee_coverage.py --verbose
    7. Run validation: python3 validate_state_legislative.py --verbose
    8. Start Go server and run: python3 verify_state_api.py --verbose

    Note: Always run --dry-run first. This catches config errors before writing to the database.

  ### Tracking Files
    - ~/.ev-backend/legiscan_counter.json — LegiScan API budget tracker
    - ~/.ev-backend/legiscan_import_tracker.json — Last import metadata per state
    - ~/.ev-backend/committee_import_tracker.json — Last committee import metadata per state
    - ~/.ev-backend/dataset_hashes.json — Cached dataset hashes (skip re-download if unchanged)

  ### Troubleshooting
    Document each known gotcha with symptom, cause, and fix:

    1. "server closed the connection unexpectedly" during CA committee import
       - Cause: Supabase closes idle connections after ~15 min; CA Open States pagination takes ~15 min
       - Fix: Already handled in import_state_committees.py (reconnect after API fetch). If it recurs, check that the reconnect block in import_committees() is active.

    2. LegiScan API budget exhaustion (HTTP 429 or empty responses)
       - Cause: Free tier = 30,000 queries/month; dataset approach uses ~5/state but individual re-runs add up
       - Fix: Check ~/.ev-backend/legiscan_counter.json for current usage. Wait for monthly reset or use --dry-run to verify config without API calls.

    3. Open States rate limiting (HTTP 429)
       - Cause: Free tier = 10 requests/minute
       - Fix: Script enforces 6-second delay. If 429 still occurs, the retry logic (3 retries, 60s each) handles it automatically. No action needed.

    4. High "no match" count during CA committee import
       - Cause: Open States CA jurisdiction returns multi-state committees (interstate legislative councils). Only CA legislators in our DB are matched.
       - Fix: Not a bug. The 20,000+ no-match entries are expected. Check actual match count and coverage percentage instead.

    5. "No module named 'psycopg2'" or "No module named 'dotenv'"
       - Fix: pip install -r requirements-state.txt (use Python 3.10+ or the project's .venv)

    6. validate_state_legislative.py reports zero-activity legislators
       - Cause: Missing legiscan bridge records (e.g., Robert Johnson IN, Pachecco/Valladares CA)
       - Fix: These need manual bridge record insertion or a reimport. Documented in 61-STATE-LEGISLATIVE-AUDIT.md.
