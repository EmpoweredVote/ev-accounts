Verification logic per endpoint:
- HTTP status == 200
- Response parses as JSON
- For array endpoints: len > 0 (non-empty — per user decision, no strict count thresholds)
- For array endpoints: spot-check first item has expected key (name/title/result)
- For summary: response is dict with expected structure
