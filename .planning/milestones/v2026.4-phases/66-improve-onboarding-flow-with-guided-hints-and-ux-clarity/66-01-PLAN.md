  <files>CompassV2/src/components/CoachMark.jsx</files>
  <action>
Create a new CoachMark component at `CompassV2/src/components/CoachMark.jsx` that provides a Figma/Notion-style immersive spotlight overlay system. The component must support both sequential tours (multi-step with Next/Skip All) and one-shot contextual hints (single step, dismiss permanently).

Implementation requirements:

1. **Portal-based rendering:** Use `createPortal` to render into `document.body` so the overlay sits above all content regardless of DOM position. Use z-index 60+ (CalibrationOverlay uses z-50).

2. **Spotlight cutout:** Render a full-page semi-transparent dark overlay (`bg-black/60`) with a transparent cutout around the target element. Use the target element's `getBoundingClientRect()` to position the cutout. Add 8px padding around the cutout and round the cutout corners (8px border-radius). Implement the cutout using CSS `clip-path` with an inset polygon, or an SVG mask with a transparent rect — whichever produces the cleanest result. The overlay must block pointer events on everything except the spotlight area.

3. **Tooltip:** Position a white tooltip card near the spotlight cutout. The tooltip should auto-position based on available space (prefer below, fall back to above/left/right). Include:
   - Text content (passed as `children` or `message` prop)
   - For tours: "Next" button (advances to next step) and "Skip All" text button (dismisses entire tour)
   - For single hints: just a "Got it" dismiss button
   - Subtle arrow/caret pointing toward the spotlight area

4. **Props API:**
```jsx
<CoachMark
  targetRef={ref}           // React ref to the highlighted element
  message="Click any spoke to flip its direction"
  onDismiss={() => {}}      // Called when dismissed (sets localStorage flag)
  onNext={() => {}}         // Called when "Next" clicked (tour mode only)
  onSkipAll={() => {}}      // Called when "Skip All" clicked (tour mode only)
  stepLabel="1 of 4"        // Optional — shown in tour mode
  show={true}               // Controls visibility
/>
```

5. **Responsive:** Recalculate position on window resize and scroll. Use a ResizeObserver or window event listener.

6. **Animation:** Use Framer Motion for tooltip entrance (fade + slight slide-up, 200ms). The overlay backdrop should fade in (150ms).

7. **Styling:** Use Tailwind classes consistent with the project. Tooltip background white, text gray-800, "Next" button uses `bg-black text-white rounded-full` styling. "Skip All" uses gray text link style. "Got it" uses same style as "Next" for single hints.

8. **Export:** Default export `CoachMark` component. Also export a `useCoachMark` helper hook:
```jsx
export function useCoachMark(storageKey) {
  const [dismissed, setDismissed] = useState(
    () => !!localStorage.getItem(storageKey)
  );
  const dismiss = () => {
    localStorage.setItem(storageKey, "1");
    setDismissed(true);
  };
  return { show: !dismissed, dismiss };
}
```

This hook follows the existing localStorage pattern used for `onboarding_spokeFlip`.
