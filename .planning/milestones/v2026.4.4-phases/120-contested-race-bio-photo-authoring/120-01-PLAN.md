Connect to the production database using the ev-accounts `.env` DATABASE_URL. Execute this SQL query (from RESEARCH.md Pattern 1):

```sql
SELECT
  p.id AS politician_id,
  p.full_name,
  p.slug,
  p.bio_text IS NULL AS missing_bio,
  pi.url IS NULL AS missing_photo,
  r.position_name AS race,
  r.primary_party
FROM essentials.race_candidates rc
JOIN essentials.races r ON r.id = rc.race_id
JOIN essentials.elections e ON e.id = r.election_id
JOIN essentials.politicians p ON p.id = rc.politician_id
LEFT JOIN essentials.politician_images pi
  ON pi.politician_id = p.id AND pi.type = 'default'
WHERE e.election_date = '2026-05-05'
  AND e.state = 'IN'
  AND rc.politician_id IS NOT NULL
  AND rc.candidate_status = 'active'
  AND r.id IN (
    SELECT race_id FROM essentials.race_candidates
    WHERE candidate_status = 'active'
    GROUP BY race_id HAVING COUNT(*) > 1
  )
ORDER BY r.position_name, p.last_name;
```

Create the bio authoring methodology document per D-07. This doc is explicitly required by Phase 124's success criteria (BIO-02) for repeatability across the 45-candidate batch.

Write `120-BIO-METHODOLOGY.md` with these sections:

**## Bio Sourcing Rules**
- Single named source per bio (D-14). Extract facts from ONE URL, lightly compress into one sentence. Never synthesize across multiple sources.
- Source URL must be recorded in the REVIEW-DATA.md alongside the bio text.
- Source priority: Official government pages > Campaign websites > News articles > Social media profiles.

**## Tone and Voice**
- Neutral factual tone (D-11). Dry, objective facts: role, background, reason for running.
- No editorial voice, no superlatives, no endorsement language.
- Example: "Monroe County educator and longtime community volunteer seeking County Council District 3 seat."

**## Length**
- Target: 120-180 characters, one sentence (D-12).
- Hard maximum: 180 characters (validated by import script).

**## Antipartisan Constraint**
- Party affiliation is omitted from bios (D-13).
- Exception: Party may appear ONLY if it is the candidate's literal professional/service role (e.g., "served as Monroe County GOP chair" or "president of Monroe County Democrats").
- Never frame as "Republican candidate" or "Democrat running for..."

**## Fallback**
- When insufficient public information exists about a candidate: use the office-title-only fallback (D-15).
- Format: "Candidate for [office title]."
- Example: "Candidate for Monroe County Council District 3."

**## Photo Source Priority**
- Order (D-08): Official government photos > Campaign website > Social media profiles > News article photos.
- Always download and re-upload to Supabase Storage CDN (D-09). Never hotlink.
- If no photo is findable, proceed without -- use existing ev-ui missing-photo fallback (D-10).

**## Photo Upload Checklist**
1. Download image from source URL
2. Upload to Supabase Storage bucket `politician_photos` with path `monroe_2026/{slug}.{ext}`
3. Always set `contentType: 'image/jpeg'` or `'image/png'` (never omit)
4. INSERT into `essentials.politician_images` with `type='default'`
5. UPDATE `essentials.politicians.photo_custom_url` (fallback render path)
6. Both writes are required -- `politician_images` is the primary render path in PoliticianProfile.jsx

**## Review Process**
- All bios and photo URLs are compiled into a REVIEW-DATA.md table (D-06).
- User reviews and approves/edits before the import script runs (D-05).
- Source citations stored in REVIEW-DATA.md (no `bio_source_url` DB column needed for this batch size).
