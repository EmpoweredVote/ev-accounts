## Goal

Replace the static politician header in ComparePanel with the InlinePoliticianPicker, wire up the switching behavior so selecting a new politician updates the radar chart with a smooth morph animation (keeping the old polygon visible until new data arrives), and ensure the full CompareModal remains accessible for initial selection and via a browse button.

## Context

**Current state after Plan A:**
- `InlinePoliticianPicker` component exists with collapsed trigger, dropdown, search, keyboard nav, clear, and browse-all callbacks
- `usePoliticianList` shared hook provides cached politician list
- `CompareModal` uses the shared hook

**Current compare flow in Compass.jsx:**
- `comparePol` state (line 381): currently selected politician object, persisted to localStorage
- `compareAnswers` state (via CompassContext): fetched in `useEffect` (lines 530-557) whenever `comparePol` changes
- `ComparePanel` receives `politician` prop (the `comparePol` object)
- `CompareModal` opens via `isCompareModal` state, calls `onCompare(p)` which sets `comparePol`
- `Legend` component shows "You" and politician name, clicking the blue swatch clears comparison
- `ActionButtons` shows "Compare" button that opens CompareModal
- Desktop layout (line 640): ComparePanel only renders when `showChart && comparePol`
- Mobile layout (line 652): Compare tab shows ComparePanel when `comparePol` is set, otherwise shows "Select a politician" prompt

**User decisions (locked):**
- Radar chart animates smooth morph from old polygon to new (react-spring already supports this)
- During API fetch for new stances: keep old polygon visible, then morph when new data arrives (no empty/loading state on chart)
- Both radar chart AND ComparePanel update to reflect the new politician
- If a topic was selected in ComparePanel, preserve that topic selection when switching
- Full CompareModal opens for initial selection — no change to existing flow
- Once a politician is selected, inline picker handles all subsequent switching
- Small expand/browse button to re-open full modal from compare page
- Clearing comparison returns to "Select a politician to compare" prompt state

**Files to read before starting:**
- `CompassV2/src/components/ComparePanel.jsx` — the politician header (lines 98-121) being replaced
- `CompassV2/src/components/InlinePoliticianPicker.jsx` — the component from Plan A
- `CompassV2/src/pages/Compass.jsx` — full compare state management (comparePol, compareAnswers, isCompareModal, Legend, ActionButtons)
