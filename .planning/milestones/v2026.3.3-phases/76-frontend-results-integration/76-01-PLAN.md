   - Iterate polList, grouping politicians by `pol.government_body_name`
   - Politicians with a truthy `government_body_name` go into named sub-groups keyed by that name
   - Politicians without `government_body_name` (undefined or empty string — both falsy) go into an unnamed bucket
   - Build result array: named sub-groups first (sorted alphabetically by body name for stable ordering), then unnamed bucket using `getDisplayName(category)` as title

         websiteUrl={websiteUrl}

         {defaultSort(category, pols).map((pol) => renderPoliticianCard(pol))}
       </CategorySection>
     ))
