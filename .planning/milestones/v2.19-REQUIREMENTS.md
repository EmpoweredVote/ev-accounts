# Requirements: v2.19 Local Civic Coverage

**Milestone goal:** Every resident of three new local jurisdictions — **Falls Church VA**, **Greene County MO**, and **Springfield MO** — sees their full slate of locally-elected officials (city council, constitutional officers, county officers, and school board) in the representatives feed, with sourced compass alignment, headshots, and the location/coverage plumbing that makes each jurisdiction discoverable.

**Approach:** Pure data + coverage milestone — no new stack, no backend routing changes (the local feed query in `essentialsService.ts` already surfaces officials by `geofence_boundaries ⋈ districts` + `ST_Covers`). Each jurisdiction follows an established blueprint: Falls Church on the **Alexandria VA independent-city** template, Greene County on the **LA County** template, Springfield as a **city + school-board** build (extending both). Evidence-only stances throughout (the project standard): every answer paired to a real fetched source URL; honest blanks where the record is source-walled; never inferred from party.

**Context:** This was executed informally (inline, at user request — not GSD-phased) in the days after v2.18 closed, then formalized retroactively into this milestone. Phases 145–147 have no plan directories; the per-jurisdiction deep-dive memory files are the build record. Three sibling CA-city builds (Burbank/Norwalk/Bellflower, inline phases 154–156) and the Nevada work (phases 158–159, owned by the essentials team) were executed in the same window but are **out of scope** for this milestone per operator decision.

## v2.19 Requirements

### Local Civic Coverage (LCC)

- [x] **LCC-01 — Records**: Full elected rosters seeded for all three jurisdictions — Falls Church VA (17: 7 council + 3 constitutional officers + 7 school board), Greene County MO (13: 3 commission + sheriff + prosecutor + 8 county officers), Springfield MO (16: 9 council + 7 SPS R-XII board) = **46 records**. Each on the correct government → chamber → district structure, `external_id = -(government_geo_id || 3-digit seq)`, collision-checked against live negative IDs before insert. Appointed/shared offices correctly excluded (FC City Manager, FC Commonwealth's Atty + Clerk shared w/ Arlington; Springfield City Manager; Greene County offices belong to the county, not the city).
- [x] **LCC-02 — Geofence boundaries**: Location boundaries imported so each jurisdiction surfaces for a resident point — Falls Church coterminous school `G5420` geofence (copied from the place `G4110` polygon, per the Alexandria pattern); Greene County `G4020` polygon (Census TIGERweb `State_County` layer 1); Springfield place `G4110` + school-district `G5420` (TIGERweb `Places_CouSub_…` layer 4 + `School` layer 0 — school NOT coterminous, fetched separately). All inserted via `ST_Multi(ST_SetSRID(ST_GeomFromGeoJSON,4326))`; verified `ST_Covers` at an in-jurisdiction point + a far negative control = 0.
- [x] **LCC-03 — Stances**: Evidence-only sourced compass stances for every official with a documentable record — **118 answers** (Falls Church 55 across 10 / Greene County 26 across 5 / Springfield 37 across 9), 100% paired to an `inform.politician_context` row carrying a real fetched source URL, **0 unsourced**. Honest blanks where the record is source-walled (ministerial officers, brand-new freshmen, rate-limited candidate questionnaires) — never inferred from party. Topics concentrate on local governance (zoning/housing/growth/taxes/public-safety/transit/school issues); national topics correctly skipped, no padding.
- [x] **LCC-04 — Headshots**: An official headshot on every seeded record — **46 portraits** (FC 17 / Greene 13 / Springfield 16) at 600×750 4:5, Storage-mirrored to the `politician_photos` bucket + `essentials.politician_images` row. Springfield required a **clean-sourcing pass** (default CivicEngage thumbnails carried a baked-in decorative ring → rejected; SPS board portraits sourced from `sps.org/meet-the-board`, council from Springfield Daily Citizen press).
- [x] **LCC-05 — Coverage surfacing**: `essentials` coverage entries added so each jurisdiction is discoverable in the locality typeahead and (for cities) on the landing grid — Falls Church + Springfield as `COVERAGE_STATES` (landing chip + typeahead; `hasContext: true` → purple chip since stances exist); Greene County as `COVERAGE_COUNTIES` (search-only; browse uses `skip_overlap=1` to show only the county's own officials). *(essentials repo `C:\Transparent Motivations\essentials`, branch main → Netlify deploy on push — separate deploy from this repo.)*
