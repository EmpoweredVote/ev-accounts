### Gap 2 — SACC-02 Partial: Two Open Human Items (HUMAN ACTION REQUIRED)

Phase 88 VERIFICATION.md status is `human_needed` (7/9 truths). Two items require human decision:

**Item A: Derek Dooley wrong Wikipedia source**

All 7 of Dooley's `inform.politician_context` rows in the live DB cite `https://en.wikipedia.org/wiki/Derek_Dooley_(American_football)` — the Tennessee Volunteers football coach, not the 2026 Georgia Senate candidate. Migration 122 applied value corrections (all 2→4) which may be directionally correct, but the sourcing documentation is factually wrong.

*Resolution options:*
1. Find the correct Wikipedia page or reliable source for the Senate candidate and run a follow-up migration updating all 7 `sources` arrays.
2. If no Wikipedia article exists, replace sources with `['https://dooleyforgeorgia.com/']` plus any directly-cited campaign sources that support each specific stance.

**Item B: Brian W. Jones Ukraine-Support Party-Inference**

The `inform.politician_context` row for Brian W. Jones (CA state senator) on `ukraine-support` contains "he likely supports continued aid" — prohibited SACC-02 party-inference language. No correction was applied because no direct evidence was found.

*Resolution options:*
1. Remove the `inform.politician_answers` and `inform.politician_context` rows for Jones × ukraine-support entirely (safest — no unverified stance in DB).
2. Accept the gap formally and add a note to the 88-03-TIER2-DETERMINATIONS.md with rationale.

### Gap 3 — FINA-02 Partial: 57 Federal Politicians with NULL finance_summary
