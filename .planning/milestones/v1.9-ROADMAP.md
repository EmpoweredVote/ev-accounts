# Milestone v1.9: Compare UX & Search Fixes

**Status:** SHIPPED 2026-02-28

## Overview

Improved the compass compare experience with a quick-switch inline dropdown and politician list filters, and fixed Essentials search accuracy for larger areas plus the search-from-results bug.

**Plans**: 2 plans

### Phase 53: Search Accuracy & Bug Fix
**Goal**: Search returns all relevant representatives for area-level queries and works on first attempt from results page
**Plans**: 2 plans
- [x] 53-01: Backend area-intersection search — ST_Intersects, IsAreaQuery classifier, ResolveAreaBoundary
- [x] 53-02: Frontend simplification — unified POST search path, searchKey re-fetch fix, area label

---

## Milestone Summary

**Key Decisions:**
- Module-level cache for usePoliticianList — self-contained, no Provider needed
- handleSwitchPolitician keeps old compareAnswers for smooth react-spring morph
- IsAreaQuery deny-list approach — point types return false, all else treated as area
- Single search path — all queries use POST search endpoint uniformly
- searchKey counter forces hook re-fetch even for same query text

**Issues Resolved:**
- Compare page required reopening full-screen modal to switch politicians
- Politician list had no filtering by state or governance level
- City/ZIP searches returned only single-point results
- Re-search from results page required double entry
