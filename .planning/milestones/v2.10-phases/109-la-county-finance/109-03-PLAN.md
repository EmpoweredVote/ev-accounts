<objective>
Close LAFI-02 — the Netfile path for the 26 LA County cities other than LA City. Build a new probe-and-seed script that asks Netfile QuickNameSearch (REST, NOT the broken WebForms approach) under `aid=LACO` and any discovered city-specific agency codes whether each city's officials have machine-readable filings. For every probe that returns committees, insert confirmed `la_county_netfile` politician_sources rows. Trigger `runAdapterForAll('la_county_netfile')` so contributions ingest into transparent_motivations.contributions. Then build the new `write-la-county-city-finance-summary.ts` aggregation script (mirrors the LA City summary script with source_system = 'la_county_netfile' / source = 'LA_COUNTY_NETFILE') and run it to populate finance_summary.

Purpose: LAFI-02 requires that Netfile is assessed for every city seeded in Phase 108 and finance data is ingested for every city where machine-readable data is accessible — with documented gaps where it is not. RESEARCH.md Pitfall 3 warns LACO may not cover most city filings, so the probe step is mandatory before any blind seeding.

Output:
- New `backend/scripts/seed-la-county-city-netfile.ts` that (a) probes each of the 26 cities, (b) seeds confirmed la_county_netfile sources where the probe succeeds, (c) triggers the la_county_netfile adapter ingest
- New `backend/scripts/write-la-county-city-finance-summary.ts` that aggregates Netfile contributions into finance_summary with source = 'LA_COUNTY_NETFILE'
- Coverage report (in the seed script run log) listing, per city, the agency code probed and the outcome — used by the plan SUMMARY to document gaps
</objective>
