**Step 1: Reset curated cities for re-processing**

For every city in city_sources.json that has roster members with NEW headshot_url entries (added during Task 1), reset the city's `headshot_status` to `null` so the scraper will re-process it.

Use a Python one-liner to identify and reset these cities:

```python
python3 -c "
import json
with open('city_sources.json') as f:
    config = json.load(f)

reset_count = 0
for city in config['cities']:
    # Check if any roster member has a headshot_url that hasn't been processed
    has_new_overrides = False
    for member in city.get('roster', []):
        if member.get('headshot_url') and city.get('headshot_status') in ('scraped', 'blocked', 'failed'):
            has_new_overrides = True
            break
    if has_new_overrides:
        old_status = city.get('headshot_status')
        city['headshot_status'] = None
        reset_count += 1
        print(f'Reset {city[\"name\"]} (was: {old_status})')

with open('city_sources.json', 'w') as f:
    json.dump(config, f, indent=2)
print(f'\\nReset {reset_count} cities for re-processing')
"
```
