<objective>
Build scrape_city_headshots.py — the batch headshot scraper for 89 LA County city councils.

Purpose: This script auto-discovers headshot portrait URLs from each city's council web page, downloads images, uploads to Supabase Storage CDN, and upserts CDN URLs with photo_license into essentials.politician_images. It handles Cloudflare-blocked cities gracefully (marking them "blocked"), enforces inter-city rate limiting (1.5s minimum per PIPE-02), and supports idempotent re-runs via per-city status tracking in city_sources.json. A --check-coverage flag validates coverage via HEAD requests. This satisfies PHOTO-03 (80%+ headshot coverage) and PIPE-02 (rate limit enforcement).

Output: `scrape_city_headshots.py` ready to run against the live database.
</objective>

**Constants:**
- `INTER_CITY_DELAY = 1.5` — minimum seconds between city page fetches (PIPE-02)
- `DOWNLOAD_DELAY = 0.5` — seconds between individual image downloads within a city
- `TIMEOUT = 15` — HTTP request timeout
- `LEVENSHTEIN_THRESHOLD = 1` — max edit distance for fuzzy name matching
- `PORTRAIT_EXTENSIONS = {".jpg", ".jpeg", ".png", ".webp"}`
- `EXCLUDE_PATTERNS` — compiled regex matching logo, icon, banner, header, footer, background, seal, flag, map, arrow, chevron, search, menu
- `BROWSER_HEADERS` — Chrome on macOS User-Agent string (same as scrape_headshots.py)
- `WIKIPEDIA_HEADERS` — Wikipedia-compliant User-Agent (same as scrape_headshots.py)

**Core functions (implement ALL of these):**

1. `is_cloudflare_blocked(response)` — Returns True if response has status 403/429/503 AND has cf-ray header or "cloudflare" in server header. Returns False otherwise. CRITICAL: check BOTH status code AND cf-ray/server header — a 403 without cf-ray is a regular HTTP error, not Cloudflare.

2. `fetch_council_page(url)` — Fetches HTML of a council page. Returns tuple `(html, used_playwright, blocked_reason)`.
   - First try `requests.get()` with BROWSER_HEADERS and TIMEOUT
   - If Cloudflare detected: return `(None, False, "cloudflare")`
   - If requests succeeds but text content < 500 chars: fall back to Playwright
   - Playwright fallback: `sync_playwright()` context manager, headless Chromium, goto with 30s timeout, wait_for_load_state("networkidle"), get page.content()
   - If Playwright HTML contains "Checking your browser" or similar Cloudflare challenge: return `(None, True, "cloudflare")`
   - If both fail: return `(None, False, "fetch_failed")`
   - Import `playwright.sync_api` lazily inside the function (only when needed)

3. `extract_headshot_url(html, member_name, city_url)` — Extracts the best-candidate headshot URL for a council member from the page HTML. Returns absolute URL string or None.
   - Parse HTML with BeautifulSoup
   - Extract member's last name (lowercase) for matching
   - **Strategy 1 — Name proximity:** Find all text elements containing the last name. For each match, walk up to 4 parent levels looking for img tags. Filter images by: (a) src has a portrait-like extension (.jpg/.jpeg/.png/.webp), (b) src does NOT match EXCLUDE_PATTERNS, (c) alt text does NOT match EXCLUDE_PATTERNS. Return first qualifying match as absolute URL via `urljoin(city_url, src)`.
   - **Strategy 2 — Alt text match:** If Strategy 1 returns nothing, scan all img tags on the page. If any img's alt text contains the last name AND has a valid extension AND doesn't match exclusion patterns, return it.
   - **Strategy 3 — Wikipedia fallback:** If both strategies return None, attempt a Wikipedia lookup: fetch `https://en.wikipedia.org/wiki/{First_Last}` with WIKIPEDIA_HEADERS. If the page exists (200), parse it and look for the infobox image (`.infobox img`). If found, resolve to absolute URL and return it. This catches higher-profile members who have Wikipedia articles.
   - If nothing found, return None.

4. `make_storage_path(city_id, member_name, extension="jpg")` — Returns deterministic Supabase Storage path. Strip trailing `_city_council` from city_id to get city_slug. Slugify member_name: lowercase, replace non-alphanumeric with hyphens, strip leading/trailing hyphens. Return `f"la_county/cities/{city_slug}/{name_slug}.{extension}"`.

5. `get_connection()` — Create psycopg2 connection from DATABASE_URL using urlparse pattern (same as scrape_headshots.py). Use direct connection port 5432, NOT pooler port 6543.

6. `find_politician_id(cur, full_name)` — Two-tier lookup:
   - First: exact ILIKE match on `essentials.politicians WHERE full_name ILIKE %s AND is_active = true ORDER BY last_synced DESC LIMIT 1`
   - If no result: split full_name into words, extract last_name (last word). Query all active politicians, compare last names using `Levenshtein.distance(db_last_name, target_last_name) <= LEVENSHTEIN_THRESHOLD`. If exactly one match, return it. If multiple fuzzy matches, return None (ambiguous).
   - Return UUID string or None.

7. `upsert_politician_image(cur, politician_id, cdn_url, photo_license)` — Same pattern as scrape_headshots.py: check for existing (politician_id, type='default') row. UPDATE if exists, INSERT with gen_random_uuid() if not. Return "updated" or "inserted".

8. `download_image(url, timeout=15)` — Same as scrape_headshots.py: GET with appropriate headers (Wikipedia headers for wikimedia.org URLs, browser headers for others). Return (image_bytes, content_type). Derive content_type from response Content-Type header, strip parameters, default to "image/jpeg". Raise on HTTP error.

9. `process_city(conn, city_config, dry_run=False)` — Main per-city logic. Returns `(success: bool, upload_count: int, failure_reason: str|None)`.
   - Extract `city_config["url"]` and `city_config["roster"]`
   - Call `fetch_council_page(url)` — if blocked, return (False, 0, "cloudflare")
   - If fetch failed, return (False, 0, failure_reason)
   - For each roster member: call `extract_headshot_url(html, member["name"], url)`
   - After extracting all URLs for the city, check for duplicate detection: if all non-None URLs are identical (same URL returned for every member), log a warning and set all to None (likely extracted a logo, not portraits). Mark the city as needing manual review.
   - For each member with a non-None headshot URL:
     - Call `find_politician_id(cur, member["name"])` — skip if not found
     - Call `download_image(headshot_url)` — skip on error, enforce DOWNLOAD_DELAY between downloads
     - Determine file extension from content_type (image/jpeg->jpg, image/png->png, image/webp->webp)
     - Call `make_storage_path(city_id, member["name"], extension)`
     - If not dry_run: call `upload_photo_to_storage(image_bytes, storage_path, content_type)`
     - If not dry_run: call `upsert_politician_image(cur, politician_id, cdn_url, photo_license)`
     - photo_license: `"cc_by_sa_4.0"` if URL contains wikimedia.org, else `"scraped_no_license"`
   - After all members: `conn.commit()` (per-city commit)
   - Return (True, upload_count, None) on success

10. `check_coverage(conn)` — Coverage validation via HEAD requests (required by PHOTO-03 success criterion 1).
    - Query all `politician_images.url` for LOCAL/LOCAL_EXEC politicians in CA with Supabase CDN URLs
    - Issue HEAD request to each URL with 5s timeout and 100ms inter-request delay
    - Print and return (ok_count, total_count, coverage_pct)

11. `main()` — CLI entry point with argparse:
    - `--dry-run` — download and extract but skip upload/DB writes
    - `--city CITY_ID` — process a single city only (for debugging)
    - `--resume` — skip cities until the first non-scraped/non-blocked city (useful for resuming after interruption)
    - `--limit N` — process at most N cities (for batched runs)
    - `--check-coverage` — run coverage check only (no scraping)
    - Load env, supabase env (unless dry-run), city_sources.json
    - Connect to DB
    - Main loop: iterate cities from city_sources.json, skip if headshot_status in ("scraped", "blocked"), enforce INTER_CITY_DELAY between cities, call process_city()
    - After each city: update headshot_status in city_config ("scraped"/"blocked"/"failed") with headshot_scraped_at, headshot_count, headshot_blocked_reason, headshot_failure_reason as appropriate
    - At end of main loop: write updated city_sources.json back to disk
    - Print summary: processed, skipped, blocked, failed, total_uploaded

**Critical implementation details:**
- Do NOT call `next_ext_id()` — this script does NOT create new politicians, only adds photos to existing records
- Do NOT import or use SQLAlchemy — use psycopg2 directly
- Use `conn.autocommit = False` and explicit `conn.commit()` after each city
- Wrap each city in try/except — log error, mark as failed, continue to next city
- Import playwright lazily inside fetch_council_page (only when the requests fallback is needed)
- Wikipedia fallback in extract_headshot_url must use WIKIPEDIA_HEADERS and add a 2s delay before the request
