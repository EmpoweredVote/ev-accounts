    PoliticianID uuid.UUID `json:"politician_id" gorm:"type:uuid;index"`

    Email        string    `json:"email"`

Create `EV-Backend/scripts/import_city_contacts.py` with two sections: (A) city website URLs for all 89 cities, (B) supervisor phone numbers.

**Section A: City Website URLs**

1. Load `city_sources.json` (89 LA County cities excluding LA City — but include LA City manually with `lacity.gov`).
2. For each city, extract the base website URL from the council page URL: `urlparse(url).scheme + '://' + urlparse(url).netloc`.
3. Find all active politicians linked to that city's OCD-ID prefix in the DB.
4. For each politician, upsert a contact row:
   - `contact_type = 'city_website'`
   - `source = 'scraped'`
   - `website_url = base_domain_url`
   - Use SELECT + INSERT/UPDATE pattern (no unique constraint exists on politician_contacts)

The query to find politicians for a city:
```sql
SELECT p.id, p.full_name
FROM essentials.politicians p
JOIN essentials.offices o ON p.office_id = o.id
JOIN essentials.districts d ON o.district_id = d.id
WHERE d.ocd_id LIKE %s
  AND p.is_active = true
```

Where the LIKE pattern is the city's `ocd_id` base from city_sources.json with a `%` wildcard appended (to match both at-large and district positions).

The idempotent pattern for each politician:
```sql
-- Check if a 'city_website' contact from 'scraped' source already exists
SELECT id FROM essentials.politician_contacts
WHERE politician_id = %s AND source = 'scraped' AND contact_type = 'city_website'
LIMIT 1
```
If exists: UPDATE the website_url.
If not: INSERT a new row with politician_id, source='scraped', contact_type='city_website', website_url.

**For LA City (not in city_sources.json):** Hardcode LA City website as `https://lacity.gov`. Find LA City politicians via OCD-ID prefix `ocd-division/country:us/state:ca/place:los_angeles`.
