## Bug Found and Fixed During Audit

### calculate_level column name mismatch

**Severity:** Critical (silent wrong values — always returned `level: 0`)

**Root cause:** `connect.calculate_level` returns `RETURNS TABLE (level INT, xp_in_level INT, xp_to_next_level INT)`. TypeScript callers were reading `levelRow.current_level` — a column name that belongs to `award_xp`'s return table, not `calculate_level`'s. Because of `?? 0` fallbacks, this was a silent bug: no crash, just `level: 0` for every user.

**Affected locations (all fixed):**
- `backend/src/lib/xpService.ts` line 178: `levelRow.current_level` → `levelRow.level`
- `backend/src/routes/account.ts` line 93: `levelRow?.current_level ?? 0` → `levelRow?.level ?? 0`
- `backend/src/routes/account.ts` line 300: `levelRow?.current_level ?? 0` → `levelRow?.level ?? 0`

**Not affected:** `awardXp()` calls `award_xp` RPC (correctly returning `current_level`). Fix did not touch that path.

**Post-fix verification:** `npx tsc --noEmit` clean; 87/87 CI tests pass, 100 skipped (network-dependent).
