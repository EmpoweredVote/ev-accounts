# Quick Task 260401-q95: Monroe County 2026 Primary Seed Script Summary

Idempotent SQL seed script for all Monroe County 2026 primary election races and candidates, sourced from the county clerk certified candidate list.

## What Was Done

### Task 1: Create idempotent SQL seed script

Created `ev-accounts/backend/scripts/seed-monroe-county-2026-primary.sql` with:

- **1 election** upsert: "2026 Indiana Primary" (May 5, 2026, county-level, IN)
- **39 races** across 5 categories:
  - 11 county-wide (commissioner, council, assessor, clerk D+R, recorder, sheriff, prosecutor)
  - 2 judicial (circuit court judges)
  - 2 town council (Ellettsville wards)
  - 14 township trustee (13 townships, 2 split D/R)
  - 10 township board (9 townships, 2 split D/R; 3 seats each)
- **69 candidates** with correct name parsing from "Last, First" PDF format
- **2 withdrawn** candidates: Joe Davis (Council D2), Eric S. Petry (Perry Trustee)

**Idempotency approach:**
- Election: `ON CONFLICT (name, election_date, state) DO UPDATE`
- Races: `ON CONFLICT (election_id, position_name, primary_party) DO UPDATE`
- Candidates: `INSERT ... WHERE NOT EXISTS (race_id, full_name)` — no unique constraint exists on race_candidates for (race_id, full_name), so NOT EXISTS is used instead of ON CONFLICT
- Withdrawn: `UPDATE ... SET candidate_status = 'withdrawn'` after insert (idempotent — runs safely on re-run)

**Special name handling:**
- `Marte', Ruben` -> `Ruben Marte'` (apostrophe in last name, escaped as `Marte''` in SQL)
- `Smith III, William (Will) E.` -> `William E. Smith III` (suffix moved, nickname dropped)
- `Hingle, Susan (Gus)` -> `Susan Hingle` (nickname dropped, legal name used)
- `Hawk, Matha (Marty)` -> `Matha Hawk` (nickname dropped, legal name used)
