<objective>
Cap `essentials.quotes` at 2 rows per (politician_id, topic_key) via interactive user-in-the-loop curation, then rewrite identity-leaking quotes using Claude with human approval per rewrite. Preserve originals; add `deidentified_text` column and serve it as the primary `text` field to Read-Rank.

Purpose: Read-Rank's blind evaluation phase cannot work if quotes reveal the speaker or if one politician dominates a topic with many quotes. This produces a clean, balanced, speaker-obscured quote pool.

Output: Schema migration, backup snapshot, curation script, deidentification script, extended backend route. No frontend changes — read-rank consumes the existing response shape.
</objective>

**CRITICAL: This plan is NOT autonomous.** Two tasks require the orchestrator (Claude driving execute-plan) to pause and collect user input. The executor MUST use the host assistant's question-asking tool (AskUserQuestion when available, otherwise emit a numbered prompt and wait for user reply on the conversation) — NOT stdin in the tsx script.

**Recommended protocol (emits-JSON-then-apply):**

1. Script runs in **plan mode** (`--plan` flag): emits a JSON decision file to `.planning/quick/260420-rh4-readrank-quote-limit-deid/curation-plan.json` (or `deid-plan.json`) listing every group / every flagged quote with all context needed for a human decision. Script exits.
2. Orchestrator reads the JSON, iterates groups/quotes, asks the user via AskUserQuestion (multiSelect where group has ≤4 quotes; plain-text numbered prompt for larger groups or free-form rewrite-approval).
3. Orchestrator writes user answers back to `.planning/quick/260420-rh4-readrank-quote-limit-deid/curation-decisions.json` (or `deid-decisions.json`).
4. Script runs in **apply mode** (`--apply`): reads decisions JSON and performs deletes / UPDATE deidentified_text, inside a single transaction per batch with a dry-run preview.

This keeps the tsx script non-interactive (safe, resumable, scriptable) while the human-in-the-loop happens at the orchestrator layer where AskUserQuestion lives.

Run the FOUR detection patterns — flag if ANY match:

    1. **Office titles (regex, case-insensitive):**
       `\b(as|i'm|i am|my time as|serving as|when i was|elected as)\s+(a\s+)?(senator|representative|congress(wo)?man|governor|mayor|council(member|or)?|president|secretary|chair(man|woman)?|commissioner|judge|justice)\b`
       also: `\b(in\s+congress|on\s+the\s+(city\s+)?council|in\s+the\s+(house|senate|statehouse|assembly)|on\s+the\s+bench)\b`

    2. **Jurisdiction/location (regex + per-politician):**
       `\b(in\s+my\s+(district|ward|precinct|state|city|county|town))\b`
       `\b(here\s+in|we\s+in)\s+[A-Z][a-z]+\b`
       per-politician: fuzzy match politician's district name and any state-demonym ("Hoosiers" for Indiana, etc.) — maintain a small demonym table keyed off the district's state.

    3. **Self-naming / first-person office (regex):**
       `\b(my\s+(administration|campaign|office|staff|colleagues|constituents|caucus|district)|our\s+(caucus|party|administration|campaign))\b`
       `\bI,\s*[A-Z][a-z]+\s+[A-Z][a-z]+` (self-introduction pattern)

    4. **Proper nouns from politician record:** case-insensitive substring match of politician's `full_name`, last-token(full_name), each office's `title`, district name, any party name.

    System prompt (cached) — approximate content, refine in execution:
    ```
    You rewrite political quotes to remove speaker-identifying cues while preserving:
    - policy stance and specific claims
    - tone and voice
    - approximate length (±20%)

    Remove:
    - Office titles referring to self ("As Senator", "my time as Governor")
    - Jurisdiction self-references ("in my district", "here in California", state demonyms like "Hoosiers")
    - Self-naming ("I, John Smith", "my administration", "our caucus")
    - The speaker's name, last name, district name, party name, office title

    Rules:
    - Preserve first-person voice when possible. Prefer neutralizing ("in my district" → "in our community" or "in the district I represent" → "in this community") over third-person rewrite.
    - DO NOT invent facts, numbers, or claims not present in the original.
    - DO NOT soften or sharpen the stance.
    - If the quote cannot be deidentified without gutting it, return the exact string "UNFIXABLE" and nothing else.

    Output ONLY the rewritten quote, no preamble, no quotation marks.
    ```
