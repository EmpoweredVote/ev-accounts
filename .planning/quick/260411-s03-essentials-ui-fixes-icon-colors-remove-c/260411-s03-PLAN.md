<task type="auto">
  <name>Task 3: Stop truncating politician names on cards</name>
  <files>essentials/src/index.css</files>
  <action>
The ev-ui `PoliticianCard` (horizontal variant) applies inline styles to the name `<h3>`: `whiteSpace: 'nowrap'`, `overflow: 'hidden'`, `textOverflow: 'ellipsis'`. We cannot edit ev-ui (scope constraint), so override via CSS in `essentials/src/index.css`. Inline styles lose to external CSS with `!important`.

Append this block to the end of `essentials/src/index.css`:

```css
/* Politician card: never truncate names — allow wrap to 2 lines */
.ev-politician-card h3 {
  white-space: normal !important;
  overflow: visible !important;
  text-overflow: clip !important;
  display: -webkit-box !important;
  -webkit-line-clamp: 2 !important;
  -webkit-box-orient: vertical !important;
  line-height: 1.25 !important;
}
```

Rationale: The responsive grid uses `minmax(min(250px, 100%), 1fr)` which at typical viewports gives ~250-320px card widths — too narrow for long names like "Elizabeth Sensenstein" on a single line. Allowing 2-line wrap preserves the grid layout at all breakpoints (mobile included) while guaranteeing no truncation. A 2-line clamp is a safety net; in practice any realistic name fits in 2 lines.

Do NOT modify PoliticianCard in ev-ui. Do NOT modify the grid column count in Results.jsx or SubGroupSection.
  </action>

In `essentials/src/utils/branchType.js`, fix the `COUNTY` case in `getBranch()`. Currently the regex `/council|commissioner/i` lumps commissioners into Legislative, which is wrong — County Commissioners are the executive body for a county in Indiana (and most US states), while the County Council handles appropriations/legislation.

Replace the COUNTY case with:

```js
case 'COUNTY': {
  const title = officeTitle || '';
  // County Council = legislative (appropriations, ordinances)
  if (/council/i.test(title)) return 'Legislative';
  // County Commissioners = executive (run day-to-day county government)
  if (/commissioner/i.test(title)) return 'Executive';
  // Other constitutional county officers = executive
  if (/sheriff|clerk|auditor|assessor|recorder|coroner|treasurer|prosecutor|surveyor/i.test(title))
    return 'Executive';
  return null;
}
```

Changes from current:
1. Split `/council|commissioner/` into two separate checks with different returns.
2. Commissioners now return `'Executive'` (was `'Legislative'`).
3. Added `prosecutor` and `surveyor` to the constitutional-officer list (common elected county exec roles, minor sanity pass per task brief).

Do NOT touch the other district_type cases (NATIONAL_*, STATE_*, LOCAL_EXEC, SCHOOL, JUDICIAL). The task brief says only fix the county issue unless something is glaringly broken — the split is the only necessary fix; the prosecutor/surveyor additions are tiny and safe. If you disagree, keep just the council/commissioner split and drop the additions.
