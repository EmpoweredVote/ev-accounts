# Politician Stance Researcher — Colorado Springs cohort memory

- [Colorado Springs local-scale chairs (Henjum worked example)](project_colorado_springs_local_scale_chairs.md) — how a full CPR questionnaire + coloradosprings.gov/news + koaa.com search mapped onto the 22-topic ladder; 4/22 cleanly seat (3 from CPR, 1 more — local-immigration — from a KOAA vote+quote on a sanctuary-city resolution).
- [Colorado Springs web sourcing beyond tier-1](project_colorado_springs_web_sourcing.md) — which URL patterns actually return content (council bio pages, coloradosprings.gov/search, koaa.com/search) vs. dead ends (outlet `?s=` search, Ballotpedia stub, placeholder campaign sites, krdo.com search).
- [Appointee sourcing + Legistar API attachments (Casey worked example)](project_colorado_springs_appointee_and_legistar_api.md) — a council-vacancy application packet is a first-person policy record equivalent to a campaign questionnaire; Legistar's WebForms UI can't be WebFetched but its attachment PDFs (`legistar2.granicus.com/.../attachments/<uuid>.pdf`) can be, once the API resolves the event ID. Also: 2 of 10 answers seated, 2 failed the "defers to a plan" test (ConnectCOS, Strategic Doing list) — read the whole paragraph, cite only the self-stated (non-deferred) sentence.
- [State-leg worked example: Ken DeGraaf HD22](project_colorado_springs_state_leg_degraaf.md) — `completecolorado.com/author/<slug>/` surfaces a legislator's own op-eds directly (richer than any bill list); pikespeakbulletin/socoinsider/coloradosun/coloradonewsline all confirmed dead for this rep; a compound-clause topic chair (data-centers) had to be SKIPPED despite an on-topic prime-sponsored bill because the bill only satisfied one clause of each candidate chair. 1/28 seated is a normal, honest yield for a thin-record rep — don't over-reach to fill rows.
- [State-leg worked example: Amy Paschal HD18](project_colorado_springs_state_leg_sponsorship_trap_paschal.md) — 17 prime-sponsored bills, but reading each bill's TEXT (not title) killed 15 of them as sponsorship-trap or off-ladder mismatches (injection wells ≠ fossil-fuels chair, rail-district governance ≠ transportation-priorities, county redistricting's elected-board veto ≠ either independent-commission chair, tenant utility billing ≠ rent-regulation, etc.). Only 2/28 seated (climate-change, judicial-criminal-justice), both because the bill's own text did BOTH halves of a compound chair. `completecolorado.com/author/`, `?s=` search on 4 outlets, cohousedems.com bio, and Wikipedia were all confirmed dead ends for this legislator.
- [State-leg worked example: Jarvis Caldwell HD20](project_colorado_springs_state_leg_caldwell.md) — current-session bill list was nearly all bipartisan/technical (useless); the caucus site's `/news/<slug>` articles (fetch `/news` to recover hrefs missing from the profile page) and a completecolorado.com committee-testimony writeup carried the research instead — floor speeches and opposition testimony beat sponsorship. Magnitude ambiguity kills rhetoric-level quotes too, not just bills: a strong unrestricted "school choice" quote still left 2 voucher chairs (4 vs 5) plausible because it named no funding mechanism — skipped. A categorical bill (HB25-1072, bond floor for repeat violent offenders) still failed to seat jail-capacity chair 5 because it only evidenced one clause ("prioritizing detention") of that chair's compound text, not the other ("expanding capacity... as primary response to crime"). 2/28 seated (climate-change=4, judicial-criminal-justice=5).
- [State-leg worked example: Larry Liston SD-10](project_colorado_springs_state_leg_liston.md) — `coloradopolitics.com/?s=%22name%22+<keyword>` (topic-qualified, not bare-name) beat completecolorado/socoinsider/pikespeakbulletin, which were all near-empty for this 13-year incumbent; a 2019 Q&A-format interview was the single richest source found. LWV Pikes Peak forum confirmed real (`lwvcs.org`→ClubExpress) but ClubExpress 403s WebFetch — never located. Wikipedia's uncited death-penalty claim could NOT be corroborated (wrong bill number in its own prose sent me to HB20-1091 first; real bill is SB20-100) — skipped rather than seat on an uncorroborated secondary claim. 3/28 seated (misinformation=4, taxes=4, climate-change=3).
