Source B is a **detector, not an oracle**. Each disagreement is a reading queue against the
member's own page, never a verdict.

### 🟢 C publishes an identifier, so a disagreement is not a guessing game

PA-2 could compare its third authority only by surname. South Carolina's RFA layer carries each
district's `URL`, which holds that member's `scstatehouse.gov` code — so a disagreement is a
comparison of identifiers, and a nickname or a punctuation change cannot masquerade as a
turnover. The name comparison is kept as well, because a code can be right while a label is stale.
