## Primary Sources — Indiana Legislature
- https://iga.in.gov — Indiana General Assembly (bill text, votes, actions)
- https://legiscan.com/IN — LegiScan Indiana session tracking

## Local News — Bloomington/Monroe County
- https://www.idsnews.com — Indiana Daily Student (IU's student paper; strong local Bloomington political coverage)
- https://bloomingtonian.com — The Bloomingtonian (local Bloomington news)
- https://wfhb.org — WFHB community radio (podcast interviews with local candidates)
- https://bsquarebulletin.com — B Square Bulletin (Bloomington local news)

## Statewide Indiana News
- https://indianacapitalchronicle.com — Indiana Capital Chronicle (nonprofit statehouse reporting)
- https://www.ipm.org — Indiana Public Media / WFIU (NPR affiliate, Indianapolis + Bloomington)
- https://www.wfyi.org — WFYI Indianapolis (PBS/NPR affiliate)
- https://mirrorindy.org — Mirror Indy (nonprofit Indianapolis news)

## Progressive Indiana Sources (partisan lean — use for direct quotes only)
- https://www.progressiveindiana.net — Progressive Indiana (interviews with progressive candidates)
