# CA Assembly Batch 1 — Research Notes (2026-05-18)

## Key source: leginfo.legislature.ca.gov bill votes pages work reliably via WebFetch
- Use `billVotesClient.xhtml?bill_id=<ID>` — these return full vote tallies
- Use `billTextClient.xhtml?bill_id=<ID>` for bill content
- Bill search forms (billSearchClient.xhtml) return 0 results via WebFetch — not usable
- Ballotpedia pages return empty content for these members
- ontheissues.org returns 404 for CA Assembly members
- Official asmdc.org pages return SSL cert errors
- Wikipedia works for background but thin on votes
