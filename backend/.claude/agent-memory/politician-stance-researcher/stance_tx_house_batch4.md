## Key sourcing notes
- Texas Tribune 403s and 404s throughout — URLs don't follow predictable slug patterns
- capitol.texas.gov/BillLookup/History.aspx?LegSess=89R&Bill=[BILLNO] — works for individual bill lookups
- capitol.texas.gov BillSummary search returns HTTP 500 consistently — unusable
- Ballotpedia pages returned blank for all 5 members
- Wikipedia worked well for Cain and Harrison; thin for Landgraf/Noble/Money
- brookslandgraf.com (no https cert issues) has campaign issues page — useful
